La idea básica: HTML describe el contenido y su significado; CSS controla su aspecto y JavaScript puede añadir comportamiento. Un elemento suele tener etiqueta de apertura, contenido y etiqueta de cierre: <p>Hola</p>. Los atributos añaden información: <a href="...">. Escribe las etiquetas en minúsculas, anídalas correctamente y usa la etiqueta adecuada para cada contenido.
01

El documento y sus partes

Estructura básica

Documento HTML mínimo

<!doctype html> declara HTML moderno; html contiene todo; head guarda información del documento y body el contenido visible. La indentación ayuda a leer, aunque no cambia el resultado. 

<!doctype html>
<html lang="es">
<head><meta charset="utf-8"><title>Mi página</title></head>
<body><h1>Hola</h1></body>
</html>

Partes: doctype, html, head, body

Declaración doctype

Debe estar al principio del archivo. Le indica al navegador que interprete el documento con los estándares modernos; no es una etiqueta HTML normal ni se cierra.

<!doctype html>

Declaración requerida para páginas HTML actuales.

Elemento raíz e idioma

lang declara el idioma principal de la página. Ayuda a lectores de pantalla, correctores y buscadores. Usa códigos como es, en o gl; si una parte cambia de idioma, puede llevar su propio lang.

<html lang="es">
  ...
</html>

Elemento: <html>; atributo recomendado: lang

Cabecera técnica: head

<head> contiene datos sobre la página: título, codificación, descripción, enlaces a CSS e iconos. Normalmente no contiene el texto principal que se muestra dentro del documento.

<head>
  <meta charset="utf-8">
  <title>Mi página</title>
</head>

Elemento: <head>

Contenido de la página: body

Dentro de <body> va el contenido que forma la página: encabezados, texto, imágenes, formularios y demás elementos visibles o interactivos.

<body>
  <h1>Bienvenida</h1>
  <p>Este es el contenido.</p>
</body>

Elemento: <body>

Codificación de caracteres

Indica cómo interpretar letras y símbolos. utf-8 permite representar la mayoría de escrituras y evita problemas con tildes, eñes y símbolos. Es mejor ponerlo al comienzo de head. 

<meta charset="utf-8">

Elemento vacío: <meta>; atributo: charset

Título de la pestaña

<title> define el título de la pestaña, el nombre usado en marcadores y parte del resultado de búsqueda. Debe ser breve y describir esta página, no solo el sitio.

<title>Recetas de temporada | Mi cocina</title>

Elemento: <title>, dentro de <head>

Adaptación de la ventana móvil

Esta etiqueta hace que el ancho de diseño coincida con el ancho del dispositivo móvil. Sin ella, el navegador puede presentar una versión reducida de una página pensada para escritorio.

<meta name="viewport" content="width=device-width, initial-scale=1">

Elemento: <meta>

Descripción de la página

Una descripción breve resume el contenido y puede mostrarse en resultados de búsqueda. No sustituye al título ni garantiza que el buscador use exactamente ese texto.

<meta name="description" content="Guía de rutas por Galicia">

Elemento: <meta>, atributo name="description"

Anidar y cerrar etiquetas

Los elementos deben cerrarse en orden inverso al que se abrieron. Los elementos vacíos, como img y br, no envuelven contenido ni llevan etiqueta de cierre. 

<p>Texto <strong>importante</strong>.</p>
<img src="foto.jpg" alt="Paisaje">

No cruces etiquetas: abre, cierra y anida cada elemento correctamente.

Cómo leer una etiqueta

Una etiqueta de apertura va entre signos menor y mayor. El nombre, como p, dice qué elemento es. La etiqueta de cierre lleva una barra, y entre ambas va el contenido.

<p>Este es el contenido.</p>

Apertura: <p>; cierre: </p>

Atributos: nombre y valor

Los atributos se escriben dentro de la etiqueta de apertura. El nombre indica qué información se da y el valor suele ir entre comillas. Escribe las etiquetas en minúsculas para facilitar la lectura.

<a href="contacto.html" class="enlace">
  Contacto
</a>

Atributos: href y class

Atributos booleanos

Un atributo booleano se activa por estar presente: no hace falta escribir true o false. Para desactivarlo, quítalo. Si un botón contiene disabled, queda deshabilitado. 

<input type="checkbox" checked>
<button disabled>No disponible</button>

Ejemplos: checked, required, selected, open

Instrucciones para buscadores: robots

Este metadato puede sugerir si un buscador debe incluir la página en resultados y seguir sus enlaces. No es un control de seguridad ni garantiza que todos los buscadores lo respeten.

<meta name="robots" content="index, follow">

Elemento: meta; contenido frecuente: noindex, nofollow

Color de la interfaz del navegador

theme-color sugiere un color para elementos de la interfaz del navegador en algunos dispositivos, como la barra superior móvil.

<meta name="theme-color" content="#245b49">

Metadato opcional dentro de head.

Enlace canónico

rel="canonical" indica a los buscadores cuál es la dirección principal de una página cuando el mismo contenido puede abrirse desde varias URLs.

<link rel="canonical" href="https://ejemplo.test/guia/html">

Elemento: link; relación: canonical

Manifiesto de aplicación web

Un archivo de manifiesto (JSON) describe el nombre, los iconos y los colores de una web que puede instalarse como aplicación. Se enlaza desde head.

<link rel="manifest" href="manifest.webmanifest">

Elemento: link; relación: manifest

Esquema de color admitido

El metadato color-scheme avisa al navegador de que la página admite modo claro y oscuro, de modo que los controles y el fondo por defecto se adapten.

<meta name="color-scheme" content="light dark">

Elemento: meta; nombre: color-scheme

Orden recomendado en head

Pon primero charset (dentro de los primeros 1024 bytes), después viewport, el título y las hojas de estilo. Los scripts, mejor con defer o al final, para no bloquear la carga.

<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Mi página</title>
  <meta name="description" content="Resumen breve">
  <link rel="stylesheet" href="estilos.css">
  <script src="app.js" defer></script>
</head>

Un orden coherente facilita el mantenimiento y evita errores de codificación.

02

Títulos, párrafos y significado

Texto y contenido

Encabezados: h1 a h6

Representan títulos y niveles de sección: h1 es el nivel principal; h2 abre una sección y h3 puede organizar una subsección. Elige por jerarquía, no por el tamaño visual: CSS cambia su aspecto.

<h1>Viajes</h1>
<h2>Rutas de montaña</h2>
<h3>Ruta del río</h3>

Elementos: <h1> … <h6>

Párrafo

<p> representa un párrafo. El navegador separa los párrafos visualmente; no uses muchos espacios ni saltos br para fingir una estructura de párrafos.

<p>Un párrafo completo de texto.</p>

Elemento: <p>

Importancia: strong

<strong> marca contenido de gran importancia, seriedad o urgencia. Los navegadores suelen mostrarlo en negrita, pero su sentido no es simplemente «poner letras gruesas».

<p><strong>Aviso importante:</strong> cierra la puerta.</p>

Elemento semántico: <strong>

Énfasis: em

<em> marca énfasis que puede cambiar el sentido de una frase; se puede anidar para aumentar el énfasis. Normalmente se presenta en cursiva.

<p>Yo <em>nunca</em> dije eso.</p>

Elemento semántico: <em>

Negrita y cursiva sin énfasis semántico

<b> llama la atención sin añadir importancia; <i> marca una voz, término o expresión distinta. Para importancia usa strong; para énfasis usa em. Si solo quieres cambiar aspecto, usa CSS. 

<p>La palabra <i>in situ</i> es latina.</p>

Elementos: <b>, <i>

Salto de línea: br

<br> introduce un salto de línea que forma parte del contenido, como en una dirección o un poema. No lo uses para crear espacio entre bloques; para eso se usan párrafos o CSS.

<p>Calle Mayor, 12<br>Santiago</p>

Elemento vacío: <br>

Cambio temático: hr

<hr> representa un cambio de tema o separación entre secciones del contenido; normalmente el navegador lo pinta como una línea horizontal.

<p>Fin del capítulo uno.</p>
<hr>
<p>Comienza otro tema.</p>

Elemento vacío: <hr>

Cita larga: blockquote

<blockquote> contiene una cita extensa que forma un bloque. cite puede indicar la URL de la fuente, aunque no suele mostrarse como texto; incluye una atribución legible si hace falta.

<blockquote cite="https://ejemplo.test/fuente">
  <p>Una cita extensa.</p>
</blockquote>

Elemento: <blockquote>; atributo: cite

Cita breve: q

<q> marca una cita corta dentro de una frase; el navegador suele añadir comillas según el idioma. Para textos citados largos, usa blockquote.

<p>Ella dijo: <q>Volveré pronto</q>.</p>

Elemento: <q>

Abreviaturas: abbr

<abbr> representa una abreviatura. El atributo title puede explicar su forma completa; no dependas solo del tooltip para información imprescindible.

<abbr title="HyperText Markup Language">HTML</abbr>

Elemento: <abbr>

Fechas y horas: time

<time> marca una fecha u hora legible por personas; datetime aporta una versión normalizada para máquinas. Puede contener una fecha, una hora o una duración. 

<time datetime="2026-10-20">20 de octubre</time>

Elemento: <time>

Texto relevante: mark

<mark> resalta texto relevante en su contexto, por ejemplo una coincidencia de búsqueda. No equivale a marcar importancia duradera con strong.

<p>Busca la palabra <mark>HTML</mark>.</p>

Elemento: <mark>

Texto secundario: small

<small> representa comentarios secundarios, letra pequeña o notas legales. El tamaño visual puede modificarse con CSS.

<p>Precio: 10 € <small>Impuestos incluidos</small></p>

Elemento: <small>

Cambios en un documento

<del> marca texto eliminado y <ins> texto añadido. Pueden incluir datetime para el momento del cambio y cite para su explicación.

<p>Precio: <del>20 €</del> <ins>15 €</ins></p>

Elementos: <del>, <ins>

Subíndices y superíndices

<sub> desplaza texto como subíndice y <sup> como superíndice; útiles en fórmulas, referencias o exponentes.

H<sub>2</sub>O y x<sup>2</sup>

Elementos: <sub>, <sup>

Código y texto de ordenador

<code> marca código breve; <pre> conserva espacios y saltos; <kbd> indica entrada del teclado; <samp>, salida de un programa; <var>, una variable.

<pre><code>console.log("Hola");</code></pre>
Presiona <kbd>Ctrl</kbd> + <kbd>S</kbd>.

Elementos: code, pre, kbd, samp, var

Punto posible de salto: wbr

<wbr> indica dónde el navegador puede partir una palabra larga si no cabe. No fuerza un salto como br.

<p>una-palabra-muy-larga<wbr>-que-puede-partirse</p>

Elemento vacío: <wbr>

Texto preformateado: pre

pre conserva los espacios y los saltos de línea tal como están escritos y suele mostrarse con letra monoespaciada. Para código, anida un code dentro.

<pre><code>function saludar() {
  return "Hola";
}</code></pre>

Elemento: pre; combina bien con code

Definir un término: dfn

dfn marca el término que se define en ese momento, normalmente la primera vez que aparece en el texto.

<p>Un <dfn>hipervínculo</dfn> es un enlace
que conecta dos recursos.</p>

Elemento: dfn; puede acompañarse de abbr

Título de una obra: cite

cite marca el título de una obra (libro, película, artículo). No se usa para el nombre de una persona.

<p>Mi lectura favorita es <cite>Don Quijote de la Mancha</cite>.</p>

Elemento: cite; en blockquote el atributo cite guarda una URL.

Anotaciones de pronunciación: ruby

ruby muestra una pequeña anotación sobre un texto, habitual para indicar la pronunciación en japonés o chino. rt contiene la anotación y rp el respaldo para navegadores sin soporte.

<ruby>漢<rp>(</rp><rt>kan</rt><rp>)</rp></ruby>

Elementos: ruby, rt, rp

Dirección del texto aislada: bdi y bdo

bdi aísla un fragmento cuyo sentido de escritura se desconoce (por ejemplo, un nombre escrito por el usuario). bdo fuerza una dirección concreta.

<p>Usuario: <bdi>إيان</bdi> ha comentado.</p>
<p><bdo dir="rtl">Texto al revés</bdo></p>

Elementos: bdi, bdo; atributo: dir

Valor legible por máquinas: data

data asocia a un texto un valor que un programa puede leer, sin cambiar lo que ve la persona. Para fechas y horas usa mejor time.

<p><data value="8412">Café de la casa</data></p>

Elemento: data; atributo: value

Tachado y subrayado con significado: s y u

s marca contenido que ya no es correcto o relevante (como un precio anterior). u marca texto con una anotación no textual, como una falta ortográfica señalada. Para un simple efecto visual, usa CSS.

<p>Precio: <s>30 €</s> 24 €</p>
<p>Esto tiene una <u>falta</u> marcada.</p>

Elementos: s, u

03

Agrupar elementos y pasos

Listas y agrupaciones

Lista sin orden: ul

<ul> agrupa elementos en los que el orden no importa. Cada entrada debe ir dentro de un <li>.

<ul>
  <li>Pan</li>
  <li>Leche</li>
</ul>

Elementos: <ul> y <li>

Lista ordenada: ol

<ol> agrupa pasos o elementos cuyo orden importa. start cambia el número inicial, reversed invierte el conteo y type el estilo de numeración.

<ol start="3">
  <li>Preparar</li>
  <li>Servir</li>
</ol>

Elementos y atributos: ol, li, start, reversed, type

Elegir el tipo de numeración

En ol, type puede usar 1 para números, A/a para letras y I/i para números romanos. El aspecto también se puede cambiar con CSS. 

<ol type="I">
  <li>Primera parte</li>
  <li>Segunda parte</li>
</ol>

Atributo: type de ol

Elemento de lista: li

<li> representa una entrada dentro de ul, ol o un menú. En una lista ordenada se puede usar value para cambiar el número de una entrada y las siguientes.

<ol>
  <li>Primero</li>
  <li value="5">Quinto</li>
</ol>

Elemento: <li>; atributo opcional: value

Lista de términos y descripciones

<dl> contiene términos <dt> y sus descripciones <dd>. Sirve para glosarios, metadatos o pares de nombre y valor. 

<dl>
  <dt>HTML</dt>
  <dd>Lenguaje para estructurar páginas.</dd>
</dl>

Elementos: dl, dt, dd

Contenedor genérico de bloque: div

<div> agrupa contenido sin añadir significado especial. Úsalo cuando no haya un elemento semántico más adecuado y necesites agrupar para CSS o JavaScript.

<div class="tarjeta">
  <h2>Título</h2>
  <p>Descripción</p>
</div>

Elemento genérico de bloque: <div>

Contenedor genérico en línea: span

<span> agrupa una parte del texto sin crear un bloque ni añadir significado. Puede recibir una clase para aplicar CSS o localizarlo con JavaScript.

<p>El estado es <span class="activo">activo</span>.</p>

Elemento genérico en línea: <span>

Listas dentro de listas

Para crear niveles, coloca la lista secundaria dentro del li al que pertenece. Así queda claro qué subelementos dependen de cada elemento principal.

<ul>
  <li>Fruta
    <ul><li>Manzana</li></ul>
  </li>
</ul>

No pongas una lista secundaria suelta directamente entre elementos de la lista principal.

Menú de comandos: menu

menu es una lista sin orden pensada para conjuntos de acciones o barras de herramientas. Funciona como ul y se lee como una lista.

<menu>
  <li><button type="button">Copiar</button></li>
  <li><button type="button">Pegar</button></li>
</menu>

Elemento: menu

Listas de navegación

Un menú de enlaces suele ser una lista dentro de nav: así los lectores de pantalla anuncian cuántos enlaces hay y es fácil de estilizar con CSS.

<nav aria-label="Principal">
  <ul>
    <li><a href="/">Inicio</a></li>
    <li><a href="/guias">Guías</a></li>
    <li><a href="/contacto">Contacto</a></li>
  </ul>
</nav>

Estructura: nav > ul > li > a

04

Navegar, descargar y mostrar imágenes

Enlaces e imágenes

Enlace: a y href

<a> crea un enlace cuando tiene href. El texto debe explicar el destino o la acción; evita «pincha aquí» sin contexto.

<a href="contacto.html">Contactar</a>

Elemento: <a>; destino: href

Enlaces externos y nueva pestaña

target="_blank" abre normalmente otra pestaña. Explica ese comportamiento a la persona; los navegadores modernos aíslan la página nueva, y rel="noopener" puede dejarse explícito. Usa noreferrer si tampoco quieres enviar la referencia de origen.

<a href="https://ejemplo.test"
   target="_blank" rel="noopener">Visitar sitio</a>

Atributos: target, rel

Elegir dónde se abre: target

Sin target, el enlace normalmente se abre en la pestaña actual. _blank pide abrir otra pestaña; _self indica explícitamente la actual. Evita abrir pestañas nuevas sin necesidad y avisa cuando lo hagas.

<a href="https://ejemplo.test" target="_blank"
  rel="noopener">Sitio externo</a>

Atributos: target y rel

Enlace a una sección de la página

Un enlace cuyo href empieza con # lleva a un elemento cuyo id coincide. El identificador debe ser único en el documento. 

<a href="#horario">Ver horario</a>
<h2 id="horario">Horario</h2>

Atributos: href, id

Enlaces de correo y teléfono

mailto: abre una aplicación de correo; tel: permite llamar desde dispositivos compatibles. Indica claramente la dirección o el número.

<a href="mailto:hola@ejemplo.test">Enviar correo</a>
<a href="tel:+34123456789">Llamar</a>

Esquemas de URL: mailto:, tel:

Enlace para descargar

El atributo download sugiere descargar el recurso en lugar de abrirlo. Su efecto depende del navegador y del origen del archivo.

<a href="guia.pdf" download>Descargar guía</a>

Elemento: a; atributo: download

Rutas relativas, absolutas y fragmentos

Una ruta relativa, como contacto.html o ../index.html, se calcula desde la carpeta actual. Una URL absoluta incluye protocolo y dominio. Un fragmento con #id apunta a una parte concreta del documento. 

<a href="../contacto.html#formulario">Contactar</a>

Atributo de destino: href

Imagen: img, src y alt

src indica el archivo; alt ofrece una alternativa textual para quien no ve la imagen o si no carga. Describe la información relevante, no empieces con «imagen de». Si es puramente decorativa, usa alt="".

<img src="montana.jpg"
     alt="Pico nevado al amanecer">

Elemento vacío: <img>; atributos esenciales: src, alt

Dimensiones y carga de imágenes

Indicar width y height ayuda al navegador a reservar espacio y evitar saltos visuales. loading="lazy" puede aplazar imágenes fuera de pantalla; no lo uses normalmente en la imagen principal visible al abrir.

<img src="bosque.jpg" alt="Bosque"
     width="800" height="600" loading="lazy">

Atributos: width, height, loading

Imágenes adaptables: picture

<picture> permite ofrecer diferentes formatos o versiones según una condición. Cada <source> propone una opción y el <img> final es obligatorio como alternativa y aporta el texto alt.

<picture>
  <source srcset="foto.webp" type="image/webp">
  <img src="foto.jpg" alt="Costa rocosa">
</picture>

Elementos: picture, source, img

Variantes de imagen: srcset y sizes

srcset ofrece archivos con distintas resoluciones; sizes describe cuánto espacio ocupará la imagen en pantalla para que el navegador elija. El atributo src sigue siendo una alternativa útil. 

<img src="foto-800.jpg"
  srcset="foto-400.jpg 400w, foto-800.jpg 800w"
  sizes="(max-width: 600px) 100vw, 800px"
  alt="Costa rocosa">

Atributos: srcset, sizes

Imagen con pie: figure y figcaption

<figure> agrupa una ilustración, imagen, gráfico o ejemplo que puede entenderse como unidad; <figcaption> aporta su pie o explicación.

<figure>
  <img src="mapa.jpg" alt="Mapa de la ruta">
  <figcaption>Ruta junto al río.</figcaption>
</figure>

Elementos: <figure>, <figcaption>

Cuándo y cómo cargar una imagen

loading="lazy" aplaza imágenes fuera de pantalla; loading="eager" las carga enseguida. decoding="async" permite decodificar sin bloquear la presentación. No aplaces con lazy la imagen principal que se ve al entrar.

<img src="paisaje.jpg" alt="Costa rocosa"
  loading="lazy" decoding="async">

Atributos: loading, decoding

Usar un SVG como imagen

Un archivo SVG puede incluirse con img como cualquier imagen. Si comunica información, describe su contenido en alt; si solo decora, usa alt="".

<img src="icono.svg" alt="Buscar">

Elemento: img; archivo vectorial: SVG

Enlaces con texto descriptivo

El texto del enlace debe tener sentido por sí solo, porque muchas personas navegan por una lista de enlaces. Evita «haz clic aquí» o «leer más» sin contexto.

<!-- Mejor -->
<a href="guia.pdf">Descargar la guía de rutas (PDF, 2 MB)</a>

<!-- Evitar -->
<a href="guia.pdf">Haz clic aquí</a>

Un buen enlace dice adónde lleva.

Enlace o botón

Usa a cuando la acción lleva a otra dirección o sección; usa button cuando ejecuta una acción en la página (abrir un menú, enviar, borrar). No uses un a sin href como botón.

<a href="/precios">Ver precios</a>
<button type="button">Abrir menú</button>

Navegar: a; actuar: button

Valoración de enlaces: nofollow, ugc, sponsored

El atributo rel puede indicar a los buscadores la naturaleza del enlace: sponsored para publicidad, ugc para contenido generado por usuarios y nofollow si no quieres dar tu respaldo.

<a href="https://tienda.test" rel="sponsored noopener">Tienda</a>
<a href="https://foro.test/usuario" rel="ugc nofollow">Perfil</a>

Atributo: rel; se pueden combinar valores separados por espacios.

Idioma del destino: hreflang

hreflang indica el idioma del recurso enlazado. Es informativo y ayuda a identificar traducciones.

<a href="/en/guide" hreflang="en" lang="en">English version</a>

Atributos: hreflang, lang

Prioridad de carga: fetchpriority

fetchpriority="high" sugiere al navegador que descargue antes una imagen clave (la principal de la página). No uses loading="lazy" en esa imagen.

<img src="portada.jpg" alt="Costa de Galicia"
  width="1200" height="600" fetchpriority="high">

Atributo: fetchpriority; valores: high, low, auto

05

Datos relacionados en filas y columnas

Tablas

La tabla completa: table

<table> es el contenedor de datos relacionados en filas y columnas, como un horario o una lista de precios. No se usa para colocar las partes de una página: para eso se utiliza CSS con Flex o Grid. Dentro de la tabla se ponen un título, grupos de filas y las filas de datos.

<table>
  <caption>Horario de rutas</caption>
  <thead>...</thead>
  <tbody>...</tbody>
</table>

Elemento principal: <table>

Fila: tr

<tr> significa «fila de tabla». Dentro se colocan las celdas de esa fila, en el orden en que deben leerse: encabezados th o datos td.

<tr>
  <th scope="row">Monte Pindo</th>
  <td>Sábado</td>
</tr>

Elemento: <tr>

Celda de encabezado: th

<th> nombra una columna o una fila. El navegador suele mostrarlo en negrita y centrado, pero lo importante es su significado: tecnologías de apoyo pueden anunciar el encabezado asociado al dato.

<th scope="col">Día</th>
<th scope="row">Monte Pindo</th>

Elemento: <th>

Celda de datos: td

<td> contiene un dato normal de la tabla: una hora, un precio o una descripción. Va dentro de una fila tr. Si el contenido describe la fila o la columna, usa th en vez de td. 

<td>Sábado</td>
<td>08:30</td>

Elemento: <td>

Grupo de encabezados: thead

<thead> agrupa una o más filas con los encabezados de la tabla. Normalmente contiene filas tr con celdas th. Ayuda a entender la estructura y permite aplicar estilos o repetición de encabezados al imprimir.

<thead>
  <tr><th scope="col">Día</th></tr>
</thead>

Elemento: <thead>

Grupo de filas de datos: tbody

<tbody> agrupa las filas principales de datos. Una tabla puede tener uno o varios grupos de cuerpo; cada grupo contiene filas tr.

<tbody>
  <tr><td>Sábado</td></tr>
</tbody>

Elemento: <tbody>

Grupo de pie: tfoot

<tfoot> agrupa filas de resumen o totales. Puede colocarse después del cuerpo en el HTML; el navegador conserva su función de pie. No es obligatorio si no hay resumen.

<tfoot>
  <tr><th scope="row">Total</th><td>2 rutas</td></tr>
</tfoot>

Elemento: <tfoot>

Título de la tabla: caption

<caption> da un título o descripción breve que ayuda a entender qué datos se están viendo. Se escribe justo después de abrir table y debe ser único por tabla. 

<table>
  <caption>Salidas de octubre</caption>
  ...
</table>

Elemento: <caption>

Relacionar encabezados: scope

scope se pone en un th para decir qué datos encabeza: col para una columna, row para una fila, colgroup para un grupo de columnas y rowgroup para un grupo de filas. Así los lectores de pantalla pueden relacionar mejor cada dato con su encabezado.

<th scope="col">Hora</th>
<th scope="row">Monte Pindo</th>

Atributo de th: scope

Ocupar varias columnas: colspan

colspan hace que una celda ocupe el número indicado de columnas. Por ejemplo, colspan="2" la extiende sobre dos columnas. Las celdas siguientes de esa fila deben ajustarse para que la tabla siga teniendo una cuadrícula coherente. 

<th colspan="2">Datos de salida</th>

Atributo numérico de td o th: colspan

Ocupar varias filas: rowspan

rowspan hace que una celda se extienda hacia abajo por varias filas. Por ejemplo, rowspan="2" ocupa dos filas; las filas siguientes no deben repetir esa celda. El valor rowspan="0" puede abarcar el resto de filas del grupo actual. 

<th scope="rowgroup" rowspan="2">Sábado</th>

Atributo numérico de td o th: rowspan

Asociación explícita: headers e id

En tablas complejas, un th puede llevar un id y una celda td puede indicar en headers los identificadores de todos sus encabezados relacionados, separados por espacios. Para tablas simples suele bastar con scope. 

<th id="ruta" scope="col">Ruta</th>
<td headers="ruta dia">Monte Pindo</td>

Atributos: headers en celdas y id único en los encabezados

Agrupar columnas: colgroup y col

<colgroup> agrupa columnas y <col> representa una o varias columnas; span indica cuántas abarca. Se colocan al principio de la tabla, después de caption y antes de las filas. Sirven para identificar columnas y aplicarles algunos estilos, pero no reemplazan sus encabezados. 

<colgroup>
  <col>
  <col span="2">
</colgroup>

Elementos: <colgroup>, <col>; atributo: span

Ejemplo completo: horario de rutas

En la primera fila, «Salida» encabeza dos columnas con colspan; «Ruta» ocupa ambas filas de encabezado con rowspan. Cada fila identifica su ruta con un encabezado de fila. El pie combina dos celdas para mostrar el total.

<table>
  <caption>Horario de rutas</caption>
  <thead>
    <tr>
      <th scope="col" rowspan="2">Ruta</th>
      <th scope="colgroup" colspan="2">Salida</th>
    </tr>
    <tr>
      <th scope="col">Día</th>
      <th scope="col">Hora</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <th scope="row">Monte Pindo</th>
      <td>Sábado</td><td>08:30</td>
    </tr>
    <tr>
      <th scope="row">Fraga de Catasós</th>
      <td>Domingo</td><td>09:00</td>
    </tr>
  </tbody>
  <tfoot>
    <tr>
      <th scope="row" colspan="2">Total de rutas</th>
      <td>2</td>
    </tr>
  </tfoot>
</table>

Fíjate en el orden: caption, encabezados, filas de datos y resumen final.

06

Recoger datos y ofrecer controles

Formularios

Formulario: form

<form> agrupa controles que se pueden enviar. action indica el destino y method suele ser get (datos en la URL) o post (datos en la petición). Un formulario necesita un servicio o servidor para procesar lo enviado. 

<form action="/contacto" method="post">
  ...
</form>

Elemento: <form>; atributos: action, method

Etiqueta accesible: label

<label> da nombre visible a un control. Asocia su for con el id del campo; también puede envolver directamente el control. Pulsar la etiqueta activa el campo correspondiente. 

<label for="correo">Correo electrónico</label>
<input id="correo" name="correo" type="email">

Elemento: <label>; asociación: for = id

Campo de entrada: input

<input> crea un control de una línea. type define su función, name la clave enviada y value su valor. placeholder es solo una pista, no reemplaza a label. 

<input type="text" id="nombre"
  name="nombre" autocomplete="name">

Elemento vacío: <input>

Placeholder no sustituye a label

placeholder es una pista dentro del campo que desaparece al escribir. No dice de forma permanente qué debe rellenarse. Mantén una etiqueta label visible para que el campo conserve un nombre claro.

<label for="correo">Correo</label>
<input id="correo" name="correo" type="email"
  placeholder="nombre@ejemplo.es">

Pista: placeholder; nombre visible: label

Name y value: qué se envía

name es la clave que identifica un dato al enviarlo; value es el valor. Sin name, normalmente el control no se incluye en el envío del formulario.

<input name="ciudad" value="Lugo">
<!-- Se envía ciudad=Lugo -->

Atributos: name y value

Tipos frecuentes de input

text, email, password, number, tel, url, search, date, time, datetime-local, checkbox, radio, range, color y file adaptan el control y su teclado. Elige el tipo que corresponda al dato. 

<input type="email" name="correo">

Atributo: type de input

Texto de varias líneas: textarea

<textarea> permite escribir texto largo. Su contenido inicial va entre las etiquetas; rows y cols sugieren dimensiones. Para límites de longitud usa minlength y maxlength.

<label for="mensaje">Mensaje</label>
<textarea id="mensaje" name="mensaje"
  rows="5" maxlength="1000"></textarea>

Elemento: <textarea>

Lista desplegable: select y option

<select> agrupa opciones <option>. El atributo value de cada opción es lo que se envía. selected marca la opción inicial. 

<select name="talla">
  <option value="m">Mediana</option>
  <option value="l" selected>Grande</option>
</select>

Elementos: select, option

Elegir varias opciones: multiple

El atributo booleano multiple permite seleccionar más de una opción. La combinación de teclas para elegir varias puede variar por dispositivo; para pocas opciones pueden ser más claras varias casillas.

<select name="pais" multiple>
  <option value="es">España</option>
  <option value="pt">Portugal</option>
</select>

Atributo booleano: multiple

Agrupar opciones: optgroup

<optgroup> pone un título a un grupo de opciones dentro de una lista desplegable. El atributo label es obligatorio para nombrar el grupo.

<optgroup label="Bebidas">
  <option value="te">Té</option>
</optgroup>

Elemento: <optgroup>

Botones y tipos

type="submit" envía el formulario; type="reset" restablece valores y suele sorprender a las personas; type="button" no envía por sí solo. Dentro de un formulario, declara siempre el tipo para evitar envíos accidentales.

<button type="submit">Enviar</button>
<button type="button">Mostrar ayuda</button>

Elemento: <button>; valores de type

Casilla: checkbox

Permite activar una opción independiente; pueden marcarse varias. checked la marca inicialmente y required puede exigir aceptarla.

<input type="checkbox" id="aviso"
  name="aviso" value="si">
<label for="aviso">Acepto el aviso</label>

Control: input type="checkbox"

Opción única: radio

Un grupo de radios permite elegir una sola opción. Los controles relacionados comparten el mismo name; cada uno tiene un value distinto y una etiqueta propia. 

<input type="radio" id="envio1"
  name="envio" value="normal">
<label for="envio1">Normal</label>

Control: input type="radio"

Agrupar controles: fieldset y legend

<fieldset> agrupa controles relacionados; <legend> proporciona el título del grupo, especialmente útil para radios y casillas.

<fieldset>
  <legend>Método de envío</legend>
  ...
</fieldset>

Elementos: fieldset, legend

Validación básica del navegador

required hace obligatorio el campo; minlength/maxlength limitan texto; min/max/step validan números y fechas; pattern comprueba un patrón. Esto ayuda a la experiencia, pero el servidor debe validar también. 

<input type="number" name="edad"
  min="0" max="120" required>

Atributos de validación: required, min, max, step, pattern

Campo obligatorio: required

Este atributo booleano pide al navegador que no envíe el formulario si falta un dato requerido. Explica con una etiqueta visible qué se necesita. La comprobación del navegador ayuda, pero el servidor también debe validar lo recibido.

<label for="nombre">Nombre</label>
<input id="nombre" name="nombre" required>

Atributo booleano: required

Foco inicial: autofocus

autofocus pide que el campo reciba el foco al cargar la página o abrir un diálogo. Úsalo con moderación: puede mover el foco sin que la persona lo espere, sobre todo en móvil.

<input name="busqueda" autofocus>

Atributo booleano: autofocus

Opción marcada inicialmente: checked

checked marca una casilla o botón de opción al abrir la página. En un mismo grupo de radios normalmente solo una opción debería aparecer marcada.

<input type="radio" name="envio"
  value="normal" checked>

Atributo booleano de input: checked

Autocompletar formularios

autocomplete indica el tipo de dato para que el navegador pueda completar campos: name, email, street-address, postal-code, entre otros. Usa tokens adecuados para facilitar formularios accesibles. 

<input name="email" type="email"
  autocomplete="email">

Atributo: autocomplete

Sugerencias: datalist

<datalist> ofrece sugerencias a un campo, pero normalmente permite escribir otros valores. El list del input debe coincidir con el id del datalist.

<input list="ciudades" name="ciudad">
<datalist id="ciudades">
  <option value="Lugo">
</datalist>

Elementos: input, datalist, option

Resultado calculado: output

<output> representa el resultado de un cálculo o de una acción del usuario. Puede asociarse a controles con for; JavaScript suele actualizar su contenido.

<output name="total" for="cantidad precio">0</output>

Elemento: <output>

Deshabilitado o solo lectura

disabled impide interactuar y normalmente excluye el valor del envío. readonly impide editar un campo compatible pero conserva su valor en el envío. No uses estos atributos para ocultar información que debe validarse en el servidor. 

<input value="ABC" readonly>
<button disabled>No disponible</button>

Atributos booleanos: disabled, readonly

Enviar archivos: enctype

Si el formulario envía archivos, usa method="post" y enctype="multipart/form-data". El campo de archivo usa type="file"; accept puede sugerir formatos, pero el servidor debe comprobarlos también. 

<form method="post" enctype="multipart/form-data">
  <input type="file" name="foto" accept="image/*">
</form>

Atributos: enctype, type="file", accept

Controlar la validación del formulario

El navegador comprueba restricciones como required antes de enviar. El atributo novalidate desactiva esa comprobación al enviar el formulario; no elimina la necesidad de validar los datos en el servidor. 

<form action="/buscar" method="get">
  <input name="q" required>
</form>

Atributo booleano: novalidate

Números: number, min, max y step

type="number" muestra un campo numérico. min, max y step limitan el rango y el incremento permitido; el navegador los valida al enviar.

<label for="cantidad">Cantidad</label>
<input type="number" id="cantidad" name="cantidad"
  min="1" max="10" step="1" value="1">

Atributos: min, max, step

Fechas y horas: date, time y datetime-local

Estos tipos abren un selector de fecha u hora adaptado al dispositivo. El valor enviado siempre tiene un formato estándar (2026-12-25), sea cual sea cómo se muestre.

<label for="dia">Día</label>
<input type="date" id="dia" name="dia" min="2026-11-05">

<label for="hora">Hora</label>
<input type="time" id="hora" name="hora">

<input type="datetime-local" name="cita">

Tipos: date, time, datetime-local, month, week

Deslizador y color: range y color

type="range" crea un deslizador con valores entre min y max. type="color" abre un selector de color. Combínalos con output para mostrar el valor.

<label for="volumen">Volumen</label>
<input type="range" id="volumen" min="0" max="100" value="50">

<label for="tema">Color</label>
<input type="color" id="tema" value="#245b78">

Tipos: range, color

Campo oculto: hidden

Un campo hidden envía un dato con el formulario sin mostrarlo. No es seguro para información sensible: cualquiera puede verlo y modificarlo en el navegador.

<input type="hidden" name="idPedido" value="8412">

Tipo: hidden; valida siempre en el servidor.

Contraseñas y códigos: password y autocomplete

type="password" oculta lo que se escribe. Con autocomplete ayudas a los gestores de contraseñas y a los móviles a rellenar el campo correctamente.

<input type="password" name="clave"
  autocomplete="current-password">
<input type="password" name="nueva"
  autocomplete="new-password" minlength="12">
<input name="codigo" inputmode="numeric"
  autocomplete="one-time-code">

Valores habituales: current-password, new-password, one-time-code

Enviar a otro destino: formaction y formmethod

Un botón de envío puede sobrescribir el destino, el método o la validación del formulario con formaction, formmethod, formtarget y formnovalidate.

<form action="/guardar" method="post">
  <input name="titulo">
  <button>Guardar</button>
  <button formaction="/borrador" formnovalidate>
    Guardar borrador
  </button>
</form>

Atributos de botón: formaction, formmethod, formnovalidate

Un control fuera del formulario: atributo form

El atributo form asocia un control con un formulario aunque no esté dentro de él, usando el id del formulario.

<form id="buscador" action="/buscar"></form>

<input type="search" name="q" form="buscador">
<button form="buscador">Buscar</button>

Atributo: form, con el id del formulario

Buscar con search

type="search" indica un campo de búsqueda. Algunos navegadores añaden un botón para borrar el texto. Envuélvelo en un elemento search o en un formulario con role="search".

<search>
  <form action="/buscar">
    <label for="q">Buscar</label>
    <input type="search" id="q" name="q">
    <button>Buscar</button>
  </form>
</search>

Tipo: search; elemento: search

07

Dar significado a las regiones del documento

Estructura semántica

Cabecera: header

<header> contiene contenido introductorio o de navegación para la página o una sección, como un logotipo o título. Puede haber varios; no es lo mismo que head. 

<header>
  <h1>Mi sitio</h1>
  <nav>...</nav>
</header>

Elemento semántico: <header>

Navegación: nav

<nav> contiene un bloque importante de enlaces de navegación, como el menú principal o un índice. No es necesario envolver en nav cada enlace aislado.

<nav aria-label="Principal">
  <a href="/">Inicio</a>
  <a href="/contacto">Contacto</a>
</nav>

Elemento semántico: <nav>

Contenido principal: main

<main> identifica el contenido principal y único de la página. Normalmente debe haber uno visible por documento; no lo uses para barras laterales, menús o contenido repetido.

<main>
  <h1>Artículo principal</h1>
  ...
</main>

Elemento semántico: <main>

Sección temática: section

<section> agrupa contenido relacionado que forma una sección temática; normalmente tiene un encabezado. No es solo un contenedor para estilos: si no tiene significado propio, quizá corresponde un div.

<section>
  <h2>Próximas rutas</h2>
  ...
</section>

Elemento semántico: <section>

Contenido independiente: article

<article> es una pieza que puede entenderse por separado, como una noticia, publicación, comentario o ficha independiente.

<article>
  <h2>Una noticia</h2>
  <p>Texto de la noticia.</p>
</article>

Elemento semántico: <article>

Contenido complementario: aside

<aside> agrupa contenido relacionado indirectamente con el contenido principal, como una nota, glosario o barra lateral.

<aside>
  <h2>Consejo</h2>
  <p>Lleva agua suficiente.</p>
</aside>

Elemento semántico: <aside>

Pie: footer

<footer> contiene información de cierre de una página o sección: autoría, enlaces relacionados o información legal.

<footer>
  <p>© 2026 Mi sitio</p>
</footer>

Elemento semántico: <footer>

Información de contacto: address

<address> contiene información de contacto de la persona u organización responsable del contenido más cercano. No es una etiqueta genérica para cualquier dirección postal.

<address>
  <a href="mailto:hola@ejemplo.test">Escríbenos</a>
</address>

Elemento: <address>

Contenido desplegable: details y summary

<details> crea un control expandible nativo; <summary> es su encabezado visible. El atributo booleano open lo muestra inicialmente expandido. 

<details>
  <summary>¿Cuándo abre?</summary>
  <p>De lunes a viernes.</p>
</details>

Elementos: <details>, <summary>

Título con subtítulo: hgroup

<hgroup> agrupa un encabezado con contenido relacionado, como un subtítulo o texto alternativo asociado. No sustituye los niveles h1–h6.

<hgroup>
  <h1>El bosque</h1>
  <p>Una guía de naturaleza</p>
</hgroup>

Elemento: <hgroup>

Región de búsqueda: search

<search> identifica una zona de búsqueda o filtrado. Puede contener un formulario con su etiqueta y campo; no reemplaza las etiquetas accesibles de los controles.

<search>
  <form role="search">
    <label for="q">Buscar</label>
    <input id="q" name="q" type="search">
  </form>
</search>

Elemento semántico: <search>

Landmarks: regiones que orientan

header, nav, main, aside y footer ayudan a recorrer la página con tecnologías de apoyo. Usa main para el contenido principal, normalmente una vez, y nombra con aria-label las navegaciones distintas. 

<nav aria-label="Navegación principal">...</nav>
<main>...</main>

Elige elementos semánticos antes de añadir roles ARIA.

Elegir entre section, article y div

Usa article para contenido que tiene sentido por sí solo (una noticia, un comentario), section para agrupar un tema con su propio título, y div cuando solo necesitas un contenedor para estilos o scripts.

<article>
  <h2>Nueva guía</h2>
  <section>
    <h3>Novedades</h3>
    <p>...</p>
  </section>
  <div class="botones">...</div>
</article>

Pregunta clave: ¿tiene significado propio? Si no, div.

Esquema típico de una página

Una página bien estructurada tiene una cabecera, un menú, un único main, y un pie. Los lectores de pantalla usan estas regiones para saltar entre zonas.

<body>
  <header>...</header>
  <nav>...</nav>
  <main>
    <article>...</article>
    <aside>...</aside>
  </main>
  <footer>...</footer>
</body>

Un único main visible por página.

08

Audio, vídeo y contenido externo

Multimedia

Audio: audio

<audio> incorpora sonido. controls ofrece controles del navegador; es preferible que la reproducción empiece por decisión de la persona. Añade texto alternativo o transcripción para la información hablada importante.

<audio controls>
  <source src="audio.ogg" type="audio/ogg">
  <source src="audio.mp3" type="audio/mpeg">
  Tu navegador no puede reproducir el audio.
</audio>

Elementos: audio, source

Vídeo: video

<video> reproduce vídeo. controls muestra controles; poster define una imagen inicial; width/height reservan espacio. Para accesibilidad, ofrece subtítulos y, cuando haga falta, descripción/transcripción. 

<video controls poster="portada.jpg"
  width="640" height="360">
  <source src="video.mp4" type="video/mp4">
</video>

Elementos: video, source, track

Subtítulos y pistas: track

<track> añade pistas de texto a audio o vídeo, como subtítulos (kind="subtitles"), leyendas (captions) o descripciones. src suele apuntar a un archivo WebVTT y srclang indica el idioma. 

<track kind="captions" src="es.vtt"
  srclang="es" label="Español" default>

Elemento vacío: <track>

Fuentes alternativas: source

<source> ofrece archivos multimedia alternativos dentro de picture, audio o video. El navegador selecciona una opción compatible; indica su formato con type. 

<source src="audio.ogg" type="audio/ogg">

Elemento vacío: <source>

Incrustar otra página: iframe

<iframe> inserta otra página o servicio. Dale un title descriptivo. Usa sandbox con los permisos mínimos si el contenido no es de confianza; puede limitar funciones que el marco necesita.

<iframe src="https://ejemplo.test/mapa"
  title="Mapa del centro"></iframe>

Elemento: <iframe>; atributos: title, sandbox, loading

Mapa de imagen: map y area

<map> asocia zonas interactivas a una imagen; cada <area> define una forma y enlace. Cada zona requiere una alternativa textual con alt; puede ser difícil de adaptar y usar en pantallas táctiles.

<map name="plano">
  <area shape="rect" coords="0,0,80,80"
    href="sala.html" alt="Sala principal">
</map>

Elementos: map, area

Gráficos vectoriales SVG

<svg> es un formato de gráficos vectoriales que puede incluirse en HTML. Los elementos geométricos tienen atributos propios; proporciona una alternativa accesible si el gráfico comunica información.

<svg viewBox="0 0 100 100" role="img"
  aria-labelledby="titulo-svg">
  <title id="titulo-svg">Círculo verde</title>
  <circle cx="50" cy="50" r="40" fill="green">
  </circle>
</svg>

Elemento: <svg>; alternativa: título o descripción accesible

Lienzo de dibujo: canvas

<canvas> reserva una superficie para gráficos dibujados con JavaScript. El contenido entre las etiquetas sirve de alternativa si el navegador no lo representa; para gráficos informativos, ofrece también una explicación accesible.

<canvas id="grafico" width="320" height="180">
  Gráfico de ventas por mes
</canvas>

Elemento: <canvas>; se dibuja con JavaScript

Limitar permisos de un iframe

sandbox restringe lo que puede hacer el contenido incrustado; añade solo los permisos necesarios, como allow-scripts. allow controla funciones específicas del dispositivo o pantalla. No concedas permisos amplios a contenido que no controles.

<iframe src="widget.html" title="Mapa"
  sandbox="allow-scripts" loading="lazy"></iframe>

Atributos: sandbox, allow, loading

Reproducción automática: autoplay, muted y loop

Los navegadores suelen bloquear el sonido automático. Un vídeo decorativo puede reproducirse solo si está silenciado. loop lo repite y playsinline evita que iOS lo abra a pantalla completa.

<video src="fondo.mp4" autoplay muted loop playsinline
  aria-hidden="true"></video>

Atributos: autoplay, muted, loop, playsinline

Cuánto cargar: preload

En audio y video, preload indica cuánto descargar antes de que alguien pulse reproducir: none (nada), metadata (duración y dimensiones) o auto (lo que el navegador decida).

<video controls preload="metadata" poster="portada.jpg">
  <source src="clase.mp4" type="video/mp4">
</video>

Atributo: preload; valores: none, metadata, auto

Contenido externo: embed y object

embed y object incrustan recursos externos, como un PDF o un SVG interactivo. object permite contenido alternativo si no se puede mostrar. Muchas veces es más claro ofrecer un enlace de descarga.

<object data="folleto.pdf" type="application/pdf"
  width="600" height="800">
  <a href="folleto.pdf">Descargar el folleto (PDF)</a>
</object>

Elementos: object, embed

Fórmulas matemáticas: MathML

MathML describe fórmulas con etiquetas que el navegador puede dibujar y que las tecnologías de apoyo pueden leer.

<math>
  <mfrac>
    <mi>a</mi>
    <mn>2</mn>
  </mfrac>
  <mo>+</mo>
  <msup><mi>x</mi><mn>2</mn></msup>
</math>

Elemento raíz: math; comunes: mi, mn, mo, mfrac, msup

Retrasar un iframe: loading lazy

loading="lazy" en un iframe retrasa su descarga hasta que está cerca de la zona visible. Añade siempre un title que explique su contenido.

<iframe src="https://ejemplo.test/mapa" title="Mapa de la ruta"
  loading="lazy" width="600" height="400"></iframe>

Atributos: loading, title

09

Controles, diálogos y acciones

Elementos interactivos

Diálogo: dialog

<dialog> crea un diálogo nativo. Para abrirlo como modal se usa su método showModal() desde JavaScript; botones con formmethod="dialog" pueden cerrarlo. Informa de su título y conserva una forma clara de cerrar. 

<dialog id="aviso">
  <h2>Aviso</h2>
  <form method="dialog">
    <button>Cerrar</button>
  </form>
</dialog>

Elemento: <dialog>; abrir/cerrar con JavaScript o formulario

Botón para una acción

Usa <button> para realizar una acción en la página; usa <a href> para navegar a otro destino. Los botones tienen foco y se pueden activar con teclado. 

<button type="button">Mostrar detalles</button>

Elemento interactivo: <button>

Progreso de una tarea: progress

<progress> representa cuánto se ha completado de una tarea. Con max se define el total; con value, la cantidad actual. Para progreso indeterminado se omite value. Añade una etiqueta asociada. 

<label for="subida">Subida</label>
<progress id="subida" value="3" max="10">30%</progress>

Elemento: <progress>

Medida dentro de un intervalo: meter

<meter> representa una medida dentro de un rango conocido, como nivel de batería. No representa el progreso de una tarea (para eso está progress).

<label for="espacio">Espacio usado</label>
<meter id="espacio" min="0" max="100"
  value="65">65%</meter>

Elemento: <meter>

Plantilla: template

<template> guarda contenido HTML que no se muestra al cargar la página. JavaScript puede clonar su contenido para crear elementos. Una plantilla sola no añade comportamiento ni contenido visible.

<template id="ficha">
  <article><h2>Título</h2></article>
</template>

Elemento: <template>

Hueco de un componente: slot

<slot> define dónde se inserta contenido en el Shadow DOM de un componente web. Fuera de ese contexto no tiene el mismo propósito que un contenedor corriente.

<slot name="titulo">Título alternativo</slot>

Elemento de componentes web: <slot>

Contenido emergente nativo: popover

El atributo popover convierte un elemento en un panel que se puede mostrar y ocultar. popover="auto" permite cerrar al pulsar fuera o con Escape; manual deja el control al código o a botones con popovertarget. 

<button popovertarget="ayuda">Ayuda</button>
<div id="ayuda" popover>Texto de ayuda</div>

Atributos: popover, popovertarget

Acordeón exclusivo: details con name

Varios details que comparten el mismo valor de name forman un grupo: al abrir uno, el navegador cierra los demás.

<details name="faq" open>
  <summary>¿Qué es HTML?</summary>
  <p>Un lenguaje de marcado.</p>
</details>
<details name="faq">
  <summary>¿Qué es CSS?</summary>
  <p>Un lenguaje de estilos.</p>
</details>

Atributos: name (grupo) y open

Desactivar una zona: inert

El atributo inert hace que un elemento y todo su contenido no puedan recibir foco ni clics, y que las tecnologías de apoyo los ignoren. Es útil para bloquear el fondo mientras se muestra un panel.

<main inert>
  <!-- Contenido bloqueado -->
</main>
<div role="dialog" aria-modal="true">...</div>

Atributo global: inert

Contenido comprensible y utilizable por todas las personas

Accesibilidad

Texto alternativo de imágenes

El atributo alt comunica la información de una imagen a quienes no pueden verla. Imágenes decorativas llevan alt=""; gráficos informativos necesitan una alternativa que explique el dato o un resumen cercano.

<img src="grafico.png"
  alt="Las ventas aumentaron cada mes">

Atributo: alt de img y area

Orden de teclado y tabindex

Los controles nativos ya se pueden usar con teclado. En general evita valores positivos de tabindex, que crean un orden inesperado. tabindex="0" incorpora un elemento a la secuencia; -1 permite enfocarlo por código sin añadirlo a Tab. 

<div tabindex="0">Contenido enfocable</div>

Atributo global: tabindex. No lo uses para convertir cualquier cosa en botón.

Nombre accesible: aria-label y aria-labelledby

Prefiere etiquetas HTML visibles y semánticas. Si un control no tiene un nombre visible adecuado, aria-label puede aportar uno; aria-labelledby referencia texto existente mediante su id. ARIA cambia la información accesible, no crea funcionalidad. 

<nav aria-label="Principal">...</nav>

Atributos ARIA: aria-label, aria-labelledby

Ocultar elementos de tecnologías de apoyo

aria-hidden="true" quita un elemento y sus descendientes del árbol accesible, pero no los oculta visualmente ni impide interacción. No lo pongas en controles enfocables ni en contenido que alguien necesite.

<span aria-hidden="true">★</span>

Atributo ARIA: aria-hidden

Enlace para saltar navegación

Un enlace al principio que lleva al contenido principal permite evitar repetir menús. Hazlo visible al recibir foco y apunta al id del main.

<a href="#contenido">Saltar al contenido</a>
<main id="contenido">...</main>

Patrón de navegación por teclado con href, id y main

Roles ARIA y elementos nativos

role cambia el rol que se expone a tecnologías de apoyo, pero no añade el comportamiento del elemento nativo. Siempre que exista una etiqueta HTML adecuada, como button o nav, es preferible usarla antes que reconstruirla con div role. 

<nav aria-label="Secciones">...</nav>

Atributo: role; úsalo solo cuando la semántica nativa no baste.

Orden de encabezados

Organiza los títulos según las secciones: no elijas un nivel solo por su tamaño, ni saltes niveles sin motivo. Un esquema claro ayuda a recorrer el documento y a entender su estructura. 

<h1>Guía</h1>
<h2>Primer tema</h2>
<h3>Detalle del tema</h3>

Elementos: h1–h6

Anuncios dinámicos: aria-live

Cuando JavaScript actualiza un contador o mensaje, aria-live puede pedir a la tecnología de apoyo que anuncie el cambio: polite espera un momento adecuado y assertive interrumpe, así que debe reservarse para mensajes urgentes. Para avisos breves también existen los roles status y alert. 

<p aria-live="polite">3 resultados</p>

Atributo: aria-live; no lo uses para anunciar cambios irrelevantes.

Indicar si algo está abierto: aria-expanded

En un botón que muestra u oculta un panel, aria-expanded indica si está abierto y aria-controls señala qué panel gobierna. Debes actualizar el valor con JavaScript.

<button aria-expanded="false" aria-controls="menu">Menú</button>
<ul id="menu" hidden>...</ul>

Atributos: aria-expanded, aria-controls

Página actual: aria-current

aria-current="page" marca el enlace de la página donde estás. Los lectores de pantalla lo anuncian y puedes usarlo como selector CSS.

<nav aria-label="Principal">
  <a href="/" aria-current="page">Inicio</a>
  <a href="/guias">Guías</a>
</nav>

Atributo: aria-current; valores: page, step, true...

Ayudas y errores asociados: aria-describedby

aria-describedby vincula un control con texto adicional (una ayuda o un error) mediante su id. El lector lo anuncia después del nombre del campo.

<label for="clave">Contraseña</label>
<input type="password" id="clave" aria-describedby="ayuda-clave">
<p id="ayuda-clave">Mínimo 12 caracteres.</p>

Atributo: aria-describedby

Campos con error: aria-invalid

Marca un campo con aria-invalid="true" cuando su valor no es válido y asocia el mensaje de error con aria-describedby. El error debe explicar cómo corregirlo, no basarse solo en un color.

<input id="correo" type="email" aria-invalid="true"
  aria-describedby="error-correo">
<p id="error-correo">Escribe un correo con el formato nombre@dominio.es</p>

Atributos: aria-invalid, aria-describedby

Mensajes importantes: role alert y status

role="status" anuncia mensajes de cortesía (confirmaciones) sin interrumpir; role="alert" los anuncia de inmediato y debe reservarse para errores urgentes.

<p role="status">Cambios guardados</p>
<p role="alert">No se pudo conectar con el servidor</p>

Roles: status, alert; el contenedor debe existir antes del mensaje.

Deshabilitar o marcar como no disponible: aria-disabled

El atributo disabled quita el control del orden de tabulación. Si quieres que siga siendo localizable y puedas explicar por qué no está disponible, puedes usar aria-disabled="true" y evitar la acción por código.

<button type="submit" aria-disabled="true">Enviar</button>

Atributo: aria-disabled; no bloquea la acción por sí solo.

Zonas táctiles y foco visible

Los botones y enlaces deben ser lo bastante grandes para pulsarse con el dedo (como referencia, unos 44 px) y mostrar con claridad el foco de teclado. No elimines outline sin ofrecer una alternativa.

button, a.boton {
  min-height: 44px;
  min-width: 44px;
}
:focus-visible {
  outline: 3px solid #bd573d;
  outline-offset: 3px;
}

Recomendación: objetivos amplios y foco claro (CSS).

No depender solo del color

Un estado (error, éxito, obligatorio) no debe indicarse únicamente con un color. Añade texto, un icono o un símbolo, y comprueba el contraste con el fondo.

<p class="error">
  <span aria-hidden="true">⚠</span>
  Error: falta el correo electrónico.
</p>

Contraste de texto recomendado: al menos 4,5:1.

Información adicional y escritura correcta

Atributos y caracteres

Identificador único: id

id identifica un elemento de forma única en el documento. Se utiliza para enlaces internos, etiquetas de formulario y selectores CSS; no repitas el mismo id.

<section id="contacto">...</section>

Atributo global: id

Clases: class

class asigna uno o varios nombres reutilizables. Se separan por espacios; sirven para CSS, JavaScript y organización semántica ligera.

<p class="aviso importante">Lee esto</p>

Atributo global: class

Atributos personalizados: data-*

Los atributos data-* guardan información propia asociada al elemento, accesible desde JavaScript. No son una alternativa para atributos estándar ya existentes.

<button data-producto="42">Ver</button>

Atributos globales: data-*

Atributo title

title aporta información adicional y algunos navegadores la muestran al pasar el ratón. No lo uses como único nombre de un control ni para información imprescindible, porque puede no aparecer en móviles o teclado.

<abbr title="HyperText Markup Language">HTML</abbr>

Atributo global: title

Ocultar contenido: hidden

hidden indica que un contenido no es relevante en ese momento y el navegador normalmente no lo muestra. Para mostrarlo de forma interactiva, cambia el estado con JavaScript. No lo uses para esconder contenido que debería seguir disponible.

<p hidden>Aún no disponible</p>

Atributo global booleano: hidden

Idioma de un fragmento: lang

lang puede declararse en la raíz y cambiarse en una palabra o frase en otro idioma. Los lectores de pantalla pueden cambiar pronunciación y los correctores el idioma de revisión. 

<p lang="en">Good morning</p>

Atributo global: lang

Dirección de escritura: dir

dir="ltr" indica izquierda a derecha; rtl, derecha a izquierda; auto deja inferirla del texto. Para contenido escrito en ambos sentidos, usa elementos apropiados y no simules dirección con espacios. 

<p dir="rtl">نص عربي</p>

Atributo global: dir

Contenido editable: contenteditable

contenteditable="true" permite editar contenido en el navegador, pero no lo guarda por sí solo ni lo envía a un servidor. Necesita una solución adicional para persistencia y manejo accesible.

<div contenteditable="true">
  Texto editable
</div>

Atributo global: contenteditable

Elegir teclado móvil: inputmode

inputmode sugiere qué teclado virtual mostrar, sin cambiar cómo se valida el campo. Por ejemplo, numeric sugiere números y email un teclado cómodo para direcciones. Si el dato tiene un tipo propio, elige primero el type adecuado.

<input type="text" inputmode="numeric" name="codigo">

Atributo de entrada: inputmode

Corrección ortográfica: spellcheck

spellcheck permite sugerir si el navegador revisa ortografía y gramática en un texto editable. Es una preferencia, no una garantía de validación lingüística.

<textarea spellcheck="true"></textarea>

Atributo global: spellcheck

Atributos globales

Muchos elementos admiten atributos como id, class, lang, dir, title, hidden, tabindex, style y data-*. Comprueba que el atributo sea válido para el uso concreto. 

<p id="nota" class="destacado" lang="es">
  Una nota
</p>

Atributos globales: reutilizables en gran parte de los elementos HTML

Caracteres reservados y entidades

Para mostrar caracteres que tienen significado en HTML, usa entidades: &amp; muestra &, &lt; muestra <, &gt; muestra > y &quot; muestra comillas dobles. UTF-8 permite escribir directamente muchos caracteres acentuados. 

&lt;p&gt; se muestra como <p>

Entidades con nombre y referencias numéricas

Comentarios HTML

Los comentarios son notas del código que no se muestran como contenido de la página. No coloques información secreta: cualquier visitante puede inspeccionar el HTML descargado.

<!-- Nota para quien mantiene el documento -->

Sintaxis: <!-- ... -->

Elementos vacíos

Algunos elementos no envuelven contenido y no tienen etiqueta de cierre: area, base, br, col, embed, hr, img, input, link, meta, param, source, track y wbr. En HTML, la barra final opcional no los convierte en XML. 

<img src="foto.jpg" alt="Vista">
<br>

No escribas etiquetas de cierre para elementos vacíos HTML.

Elementos arrastrables: draggable

draggable="true" permite arrastrar un elemento. La lógica de soltar se programa con los eventos de JavaScript (dragstart, dragover, drop).

<li draggable="true">Tarea 1</li>

Atributo: draggable; valores: true, false

Evitar la traducción automática: translate

translate="no" indica a los traductores automáticos que no traduzcan un fragmento, como el nombre de una marca o un fragmento de código.

<p>Visita <span translate="no">GitHub</span> para ver el código.</p>

Atributo: translate; valores: yes, no

Atajos de teclado: accesskey

accesskey asigna una tecla de atajo a un elemento. Su activación varía según navegador y sistema, y puede chocar con los atajos de otras herramientas, así que se usa poco.

<a href="#contenido" accesskey="s">Saltar al contenido</a>

Atributo: accesskey; úsalo con precaución.

Teclado móvil: enterkeyhint y autocapitalize

enterkeyhint cambia la etiqueta de la tecla de intro (ir, buscar, enviar...). autocapitalize controla si el teclado empieza en mayúsculas.

<input type="search" enterkeyhint="search">
<input name="usuario" autocapitalize="none" autocomplete="username">

Atributos: enterkeyhint, autocapitalize

Estilos en línea: style

El atributo style aplica CSS directamente a un elemento. Tiene mucha prioridad y mezcla contenido con diseño, así que conviene reservarlo para casos puntuales, como un valor calculado por JavaScript.

<p style="color: teal; font-weight: 700;">Texto</p>

Mejor práctica: usar clases y una hoja externa.

Conectar HTML con estilos, scripts y herramientas

CSS, JavaScript y validación

Conectar una hoja CSS

<link> enlaza recursos externos en head. Para CSS, usa rel="stylesheet" y una ruta válida en href. La separación permite mantener el contenido y el diseño por separado. 

<link rel="stylesheet" href="estilos.css">

Elemento vacío: <link>

CSS dentro de style

<style> contiene reglas CSS dentro del documento, normalmente en head. Para varios documentos suele ser más sencillo y mantenible una hoja externa. 

<style>
  p { color: teal; }
</style>

Elemento: <style>

Conectar JavaScript: script

<script> incluye o carga JavaScript. Un archivo externo se referencia con src; defer espera a que el HTML esté analizado. Los módulos usan type="module". 

<script src="app.js" defer></script>

Elemento: <script>; atributos: src, defer, type

Alternativa sin JavaScript: noscript

<noscript> contiene un mensaje o alternativa para navegadores que no ejecutan scripts. No es sustituto de asegurar que el contenido esencial esté disponible y que los controles tengan sentido.

<noscript>
  Activa JavaScript para usar esta función.
</noscript>

Elemento: <noscript>

URL base para rutas relativas

<base> define una URL base para los enlaces relativos del documento y opcionalmente un destino. Afecta a todas las rutas relativas; úsala con cuidado. Solo debe haber un elemento base y se coloca antes de URLs relativas en head.

<base href="https://ejemplo.test/docs/">

Elemento vacío: <base>

Icono de la pestaña: favicon

Un link con rel="icon" indica el icono asociado a la página. Puede enlazar un archivo PNG, SVG o ICO compatible.

<link rel="icon" href="icono.svg" type="image/svg+xml">

Elemento: link; relación: icon

Validar el documento

Un validador HTML detecta errores de sintaxis, anidamiento y atributos. Que el documento valide no garantiza por sí solo accesibilidad, buen contenido o funcionamiento; revisa también con teclado y pruebas reales.

<!-- Cierra los elementos en el orden correcto -->
<p><strong>Correcto</strong></p>

Comprobación recomendada durante el desarrollo.

Cargar scripts: async y defer

defer descarga el archivo en paralelo y lo ejecuta cuando el HTML ya se ha leído, manteniendo el orden de los scripts diferidos. async lo ejecuta tan pronto termina la descarga y no garantiza el orden. Para muchos scripts de página, defer es más previsible.

<script src="app.js" defer></script>

Atributos booleanos: defer, async

Priorizar un recurso: preload

rel="preload" pide descargar pronto un recurso que la página necesitará enseguida, como una fuente o imagen principal. Úsalo con moderación: precargar archivos innecesarios puede competir con recursos más importantes.

<link rel="preload" href="fuente.woff2"
  as="font" type="font/woff2" crossorigin>

Elemento: link; atributos: rel, as

Vista previa al compartir

Metadatos como og:title, og:description y og:image describen cómo presentar una página al compartirla. Son metadatos de Open Graph y se colocan en head. 

<meta property="og:title" content="Guía de rutas">
<meta property="og:description" content="Paseos por Galicia">

Elementos: meta; propiedades sociales: og:*

Atributos antiguos que conviene evitar

Atributos como bgcolor, align, font, width/height presentacionales y etiquetas como center están obsoletos para diseño. Usa HTML para estructura y significado; usa CSS para colores, alineación y tamaños. 

<p class="centrado">Texto</p>
/* En CSS: .centrado { text-align: center; } */

Preferir CSS moderno y elementos semánticos.

Conexión anticipada: preconnect y dns-prefetch

preconnect abre cuanto antes la conexión con otro dominio que vas a usar (fuentes, CDN). dns-prefetch solo resuelve su nombre y es más ligero.

<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link rel="dns-prefetch" href="https://cdn.ejemplo.test">

Úsalos con pocos dominios importantes.

Cargar páginas y módulos: prefetch y modulepreload

prefetch descarga con baja prioridad un recurso que probablemente se necesitará después (la página siguiente). modulepreload precarga un módulo de JavaScript y sus dependencias.

<link rel="prefetch" href="/siguiente.html">
<link rel="modulepreload" href="/app/main.js">

Relaciones: prefetch, modulepreload

Datos estructurados: JSON-LD

Un bloque script de tipo application/ld+json describe el contenido con vocabulario de schema.org, para que los buscadores lo entiendan mejor. No se muestra en la página.

<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Article",
  "headline": "Guía de HTML",
  "author": { "@type": "Person", "name": "Ana" }
}
</script>

Tipo de script: application/ld+json

Verificar recursos externos: integrity

Con integrity el navegador comprueba que un archivo cargado desde un CDN no ha cambiado: si su hash no coincide, no lo ejecuta. Requiere crossorigin.

<script src="https://cdn.ejemplo.test/lib.js"
  integrity="sha384-HASH_DEL_ARCHIVO"
  crossorigin="anonymous"></script>

Atributo: integrity; acompáñalo de crossorigin.

CSS según el medio: media en link

El atributo media de link carga una hoja solo cuando se cumple una condición, como imprimir o cierto ancho de pantalla.

<link rel="stylesheet" href="base.css">
<link rel="stylesheet" href="imprimir.css" media="print">
<link rel="stylesheet" href="grande.css"
  media="(min-width: 900px)">

Atributo: media

Versiones en otros idiomas: alternate

rel="alternate" con hreflang informa a los buscadores de las versiones de la misma página en otros idiomas. x-default es la versión por defecto.

<link rel="alternate" hreflang="es" href="https://ejemplo.test/es/">
<link rel="alternate" hreflang="en" href="https://ejemplo.test/en/">
<link rel="alternate" hreflang="x-default" href="https://ejemplo.test/">

Relación: alternate; atributo: hreflang

Módulos y mapas de importación

Con type="module" el navegador carga el script como un módulo de JavaScript (diferido por defecto y con alcance propio). importmap define alias para las rutas de importación.

<script type="importmap">
{ "imports": { "utiles": "/js/utiles.js" } }
</script>
<script type="module">
  import { saludar } from "utiles";
  saludar();
</script>

Tipos de script: module, importmap

Plantillas listas para usar

Plantilla de página básica

Un punto de partida completo: idioma, metadatos, estilos, enlace para saltar la navegación, regiones semánticas y script diferido.

<!doctype html>
<html lang="es">
<head>

  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Título de la página</title>

  <a class="saltar" href="#contenido">Saltar al contenido</a>

  <main id="contenido">...</main>
  <footer><p>&copy; 2026 Mi sitio</p></footer>
</body>
</html>

Úsala como base y quita lo que no necesites.

Formulario de contacto completo

Un formulario sencillo y accesible: cada campo con su etiqueta, tipos y validaciones adecuados, y un botón de envío claro.

<form action="/contacto" method="post">
  <p>
    <label for="nombre">Nombre</label>
    <input id="nombre" name="nombre" autocomplete="name" required>
  </p>
  <p>
    <label for="correo">Correo</label>
    <input id="correo" name="correo" type="email"
      autocomplete="email" required>
  </p>
  <p>
    <label for="mensaje">Mensaje</label>
    <textarea id="mensaje" name="mensaje" rows="5"
      maxlength="1000" required></textarea>
  </p>
  <p>
    <input id="acepto" name="acepto" type="checkbox" required>
    <label for="acepto">Acepto la política de privacidad</label>
  </p>
  <button type="submit">Enviar mensaje</button>
</form>

Elementos: form, label, input, textarea, button

Tarjeta de contenido

Una tarjeta que se entiende por sí sola es un article con su imagen, título, resumen y enlace.

<article class="tarjeta">
  <figure>
    <img src="ruta.jpg" alt="Sendero junto al mar"
      width="600" height="400" loading="lazy">
  </figure>
  <h3>Ruta de la costa</h3>
  <p>Un paseo de 8 km con vistas al Atlántico.</p>
  <a href="/rutas/costa">Ver la ruta de la costa</a>
</article>

Estructura: article > figure + h3 + p + a

Menú de navegación principal

Un menú de enlaces en forma de lista, con un nombre accesible y la página actual marcada.

<nav aria-label="Principal">
  <ul>
    <li><a href="/" aria-current="page">Inicio</a></li>
    <li><a href="/guias">Guías</a></li>
    <li><a href="/ejemplos">Ejemplos</a></li>
    <li><a href="/contacto">Contacto</a></li>
  </ul>
</nav>

Si hay varios nav, dale a cada uno un aria-label distinto.

Preguntas frecuentes desplegables

Una sección de preguntas frecuentes, sin JavaScript, con details y summary.

<section aria-labelledby="faq-titulo">
  <h2 id="faq-titulo">Preguntas frecuentes</h2>
  <details name="faq">
    <summary>¿Cómo empiezo?</summary>
    <p>Crea un archivo <code>index.html</code> y ábrelo en el navegador.</p>
  </details>
  <details name="faq">
    <summary>¿Necesito instalar algo?</summary>
    <p>Solo un editor de texto y un navegador.</p>
  </details>
</section>

Elementos: details, summary

Galería de imágenes

Una lista de figuras, cada una con su imagen y su pie. Los estilos de cuadrícula se añaden con CSS.

<ul class="galeria">
  <li>
    <figure>
      <img src="a.jpg" alt="Faro al atardecer" width="400" height="300">
      <figcaption>Faro al atardecer</figcaption>
    </figure>
  </li>
  <li>
    <figure>
      <img src="b.jpg" alt="Playa con marea baja" width="400" height="300">
      <figcaption>Marea baja</figcaption>
    </figure>
  </li>
</ul>

Elementos: figure, figcaption, img

Artículo con índice y secciones

Un artículo largo con un índice que enlaza a cada sección mediante identificadores.

<article>
  <h1>Guía de rutas</h1>
  <nav aria-label="Índice">
    <ol>
      <li><a href="#inicio">Inicio</a></li>
      <li><a href="#consejos">Consejos</a></li>
    </ol>
  </nav>
  <section id="inicio"><h2>Inicio</h2><p>...</p></section>
  <section id="consejos"><h2>Consejos</h2><p>...</p></section>
</article>

Cada sección enlazada necesita un id único.

No encuentro ese término

Prueba con otra palabra, por ejemplo: título, enlace, formulario, imagen, tabla, accesibilidad o plantilla.

Una última pista

Empieza por escribir el contenido con las etiquetas que expresan su significado: títulos para títulos, párrafos para párrafos, listas para listas, enlaces para navegar y botones para acciones. Después añade clases para personalizarlo con CSS. Una página bien estructurada es más fácil de mantener, entender y usar con teclado y tecnologías de apoyo.
