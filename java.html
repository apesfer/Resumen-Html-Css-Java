La idea básica: Java es un lenguaje de programación. El código se escribe en clases y métodos; las instrucciones suelen terminar en punto y coma. Java distingue entre mayúsculas y minúsculas: nombre y Nombre son identificadores distintos.
00

Preparar y entender un programa

Fundamentos

Programa mínimo

El método main es el punto de entrada habitual de una aplicación Java. La clase pública debe guardarse en un archivo con el mismo nombre.

public class Hola {
    public static void main(String[] args) {
        System.out.println("¡Hola!");
    }
}

Archivo: Hola.java

Comentarios

Los comentarios de una línea empiezan con //; los de varias líneas se escriben entre /* y */. Javadoc documenta clases y métodos. 

// Comentario breve
/**
 * Describe una clase.
 * @author Tu nombre
 */

Javadoc: /** ... */

Mostrar información

System.out.println escribe y termina la línea; System.out.print escribe sin añadir un salto de línea.

System.out.println("Resultado:");
System.out.print(2 + 3);

Salida estándar: System.out

Paquetes e imports

Un paquete agrupa clases relacionadas. La declaración package, si se usa, va al principio del archivo; import permite usar clases de otros paquetes.

package ejemplos;

import java.util.Scanner;

Paquetes: package e import

01

Guardar y representar datos

Variables y tipos

Declarar una variable

Una variable tiene un tipo y un nombre. Puedes asignarle un valor al declararla o después.

int edad = 20;
edad = 21;

Forma: tipo nombre = valor;

Tipos numéricos

byte, short, int y long representan enteros. float y double representan números decimales; para dinero suele ser más apropiado BigDecimal. 

int unidades = 12;
double precio = 4.99;
long poblacion = 8000000L;

Primitivos numéricos

Booleanos y caracteres

boolean solo admite true o false. char representa un carácter y se escribe entre comillas simples.

boolean activo = true;
char inicial = 'A';

Tipos: boolean y char

Cadenas de texto

String representa texto y se escribe entre comillas dobles. Es un objeto, no un tipo primitivo; sus operaciones habituales devuelven otra cadena.

String nombre = "Ana";
String saludo = "Hola, " + nombre;

Clase: String

Constantes con final

final impide asignar otro valor a una variable después de inicializarla. Por convención, las constantes se nombran en mayúsculas con guiones bajos.

final double IVA = 0.21;

Modificador: final

Convertir tipos

Algunas conversiones numéricas se hacen explícitamente con un cast. Para convertir texto a número, se usan métodos como Integer.parseInt.

double medida = 8.7;
int entera = (int) medida;
int cantidad = Integer.parseInt("12");

Conversión explícita: (tipo) valor

02

Calcular y comparar valores

Operadores

Operaciones aritméticas

Los operadores básicos son suma, resta, multiplicación, división y resto. La división entre enteros devuelve un entero.

int suma = 7 + 3;
int division = 7 / 3; // 2
int resto = 7 % 3;    // 1

Operadores: + - * / %

Comparar valores

Las comparaciones producen un booleano. Para comparar el contenido de cadenas, usa equals, no ==. 

boolean mayor = edad >= 18;
boolean mismoTexto = nombre.equals("Ana");

Comparación: == != < > <= >=

Operadores lógicos

&& significa «y», || significa «o» y ! niega una condición. Los operadores cortocircuitan cuando ya conocen el resultado.

boolean puedeEntrar = edad >= 18 && tieneEntrada;

Operadores: && || !

Actualizar una variable

Las asignaciones compuestas combinan una operación con la asignación. ++ aumenta una unidad y -- la reduce.

int puntos = 10;
puntos += 5;
puntos++;

Atajos: += -= *= /= ++ --

03

Elegir qué hacer y cuántas veces

Condiciones y bucles

Condición if / else

Ejecuta un bloque u otro según se cumpla una condición booleana.

if (edad >= 18) {
    System.out.println("Mayor de edad");
} else {
    System.out.println("Menor de edad");
}

Estructura: if y else

Varias opciones con switch

switch permite elegir entre varios casos. En la forma tradicional, break evita continuar al siguiente caso. 

switch (dia) {
    case 1:
        System.out.println("Lunes");
        break;
    default:
        System.out.println("Otro día");
}

Elementos: case, break, default

Bucle for

Usa for cuando la repetición tiene un contador o un número conocido de vueltas.

for (int i = 0; i < 5; i++) {
    System.out.println(i);
}

Partes: inicio, condición y actualización

Bucle while

while repite mientras la condición sea verdadera. Si es falsa desde el principio, el bloque no se ejecuta.

int intentos = 0;
while (intentos < 3) {
    intentos++;
}

Evalúa la condición antes de cada vuelta

Bucle do / while

El bloque se ejecuta al menos una vez, porque la condición se comprueba al final.

do {
    intentos++;
} while (intentos < 3);

Termina la condición con punto y coma

Controlar un bucle

break sale del bucle; continue omite el resto de la vuelta actual y pasa a la siguiente.

for (int i = 0; i < 10; i++) {
    if (i == 5) continue;
    if (i == 8) break;
}

Usa estos saltos con moderación para mantener claro el flujo

04

Reutilizar instrucciones

Métodos

Declarar y llamar a un método

Un método agrupa instrucciones con un nombre. Se ejecuta cuando se llama desde el programa.

static void saludar() {
    System.out.println("Hola");
}

saludar();

void indica que no devuelve un valor

Parámetros

Los parámetros reciben los datos que necesita el método. Al llamarlo, se pasan argumentos del tipo esperado.

static void saludar(String nombre) {
    System.out.println("Hola, " + nombre);
}

saludar("Ana");

Parámetro: String nombre

Devolver un resultado

El tipo antes del nombre indica qué devuelve el método. return entrega el resultado y termina la ejecución del método.

static int sumar(int a, int b) {
    return a + b;
}

El resultado debe coincidir con el tipo declarado

Sobrecarga

Puedes declarar métodos con el mismo nombre si sus listas de parámetros son diferentes. Cambiar solo el tipo devuelto no basta.

static int doble(int n) { return n * 2; }
static double doble(double n) { return n * 2; }

Se distingue por el nombre y los parámetros

05

Trabajar con secuencias de datos

Arrays y cadenas

Crear un array

Un array guarda varios valores del mismo tipo y tiene tamaño fijo. Sus posiciones empiezan en cero.

int[] notas = {7, 9, 8};
System.out.println(notas[0]); // 7

Tamaño: notas.length

Recorrer un array

Un for clásico permite usar el índice. El for-each recorre directamente cada elemento cuando no hace falta la posición.

for (int nota : notas) {
    System.out.println(nota);
}

Bucle: for (tipo elemento : colección)

Operaciones con String

length() devuelve la longitud; charAt obtiene un carácter y equals compara el contenido. Los índices empiezan en cero. 

String texto = "Java";
int longitud = texto.length();
boolean igual = texto.equals("Java");

Métodos: length(), charAt(), equals()

La referencia null

null indica que una variable de referencia no apunta a ningún objeto. Compruébala antes de llamar a métodos para evitar un NullPointerException.

if (nombre != null) {
    System.out.println(nombre.length());
}

Una referencia puede ser null; un primitivo no

06

Modelar conceptos con tipos propios

Clases y objetos

Crear una clase y un objeto

Una clase define datos y comportamientos. Un objeto es una instancia creada con new. 

class Persona {
    String nombre;
}

Persona persona = new Persona();

Clase: Persona; objeto: persona

Constructor

El constructor inicializa un objeto. Tiene el mismo nombre que la clase y no declara tipo de retorno.

class Persona {
    String nombre;
    Persona(String nombre) {
        this.nombre = nombre;
    }
}

this se refiere al objeto actual

Encapsulación

Los campos private solo se usan directamente dentro de la clase. Métodos públicos pueden ofrecer acceso controlado.

private int edad;
public int getEdad() {
    return edad;
}

Modificadores: private, public

Herencia

extends crea una clase basada en otra. La subclase hereda miembros accesibles y puede especializar el comportamiento.

class Animal {
    void hacerSonido() { }
}
class Perro extends Animal { }

Una clase Java solo puede extender una clase

Sobrescribir un método

Una subclase puede proporcionar su propia implementación. @Override ayuda a detectar errores al sobrescribir.

@Override
void hacerSonido() {
    System.out.println("Guau");
}

Anotación: @Override

Interfaces

Una interfaz define un contrato que una clase puede implementar. Una clase puede implementar varias interfaces.

interface Volador {
    void volar();
}
class Ave implements Volador {
    public void volar() {
        System.out.println("Despega");
    }
}

Palabras clave: interface, implements

07

Anticipar y gestionar problemas

Excepciones

Capturar una excepción

Un bloque try contiene una operación que puede fallar y catch gestiona una excepción concreta.

try {
    int numero = Integer.parseInt("42");
} catch (NumberFormatException error) {
    System.out.println("No es un número");
}

Control: try y catch

Bloque finally

finally se usa para acciones de limpieza que deben intentarse tanto si ocurre una excepción como si no.

try {
    // Operación
} catch (Exception error) {
    // Gestionar el error
} finally {
    // Limpieza
}

En muchos casos, try-with-resources es preferible para recursos

Declarar excepciones

throws declara que un método puede propagar una excepción comprobada. El código que lo llama deberá gestionarla o declararla también.

void leerArchivo() throws IOException {
    // Leer datos
}

Declaración: throws; lanzamiento: throw

Gestionar recursos

try-with-resources cierra automáticamente los recursos que implementan AutoCloseable. 

try (Scanner entrada = new Scanner(archivo)) {
    while (entrada.hasNextLine()) {
        System.out.println(entrada.nextLine());
    }
}

El recurso se declara entre paréntesis tras try

08

Guardar grupos de elementos

Colecciones

Lista dinámica: ArrayList

ArrayList permite guardar una lista cuyo tamaño puede cambiar. Usa tipos envoltorio, como Integer, en los genéricos.

List<String> nombres = new ArrayList<>();
nombres.add("Ana");
nombres.add("Luis");

Imports: java.util.List y java.util.ArrayList

Mapa de clave y valor

HashMap asocia claves con valores. Las claves son únicas; usa put para añadir o reemplazar y get para consultar.

Map<String, Integer> edades = new HashMap<>();
edades.put("Ana", 20);
int edad = edades.get("Ana");

Interfaz: Map<K, V>

Conjunto sin duplicados

Set representa una colección de elementos únicos. HashSet no garantiza un orden concreto al recorrer sus elementos.

Set<String> etiquetas = new HashSet<>();
etiquetas.add("Java");
etiquetas.add("Java"); // No duplica el valor

Interfaz: Set<E>

Genéricos

Los genéricos indican qué tipos acepta una colección y permiten detectar incompatibilidades antes de ejecutar el programa.

List<Integer> edades = new ArrayList<>();
edades.add(20);

Tipo de elemento: <Integer>

09

Pequeños patrones que aparecen a menudo

Ejemplos de uso frecuente

Leer texto con Scanner

Scanner permite leer lo que escribe la persona en la consola. nextLine() lee la línea completa, incluidos los espacios. Importa la clase desde java.util. 

import java.util.Scanner;

Scanner entrada = new Scanner(System.in);
System.out.print("¿Cómo te llamas? ");
String nombre = entrada.nextLine();
System.out.println("Hola, " + nombre);
entrada.close();

Al cerrar este Scanner también se cierra System.in. Hazlo solo cuando ya no necesites leer más datos de la consola.

El detalle de nextInt() y nextLine()

nextInt() lee el número, pero deja pendiente el salto de línea. Si después llamas a nextLine(), consume ese salto y parece que se salta la pregunta; lee una línea primero para descartarlo. 

System.out.print("Edad: ");
int edad = entrada.nextInt();
entrada.nextLine(); // Consume el salto pendiente
System.out.print("Nombre: ");
String nombre = entrada.nextLine();

Alternativa: leer todo con nextLine() y convertir el texto.

Comprobar que la entrada es un número

Usa hasNextInt() antes de nextInt() para comprobar la entrada. Si no es un entero, descarta esa línea antes de volver a preguntar.

while (!entrada.hasNextInt()) {
    System.out.println("Escribe un número entero.");
    entrada.nextLine();
}
int numero = entrada.nextInt();
entrada.nextLine();

Validación: hasNextInt()

Generar un número aleatorio

Con Random, nextInt(límite) genera valores desde cero hasta el límite sin incluirlo. Suma uno si quieres un dado del 1 al 6.

import java.util.Random;

Random azar = new Random();
int dado = azar.nextInt(6) + 1;

Para 1 hasta N: nextInt(N) + 1

Dar formato a la salida

printf permite controlar cómo se muestran los valores. %.2f muestra un número decimal con dos cifras decimales y %n añade un salto de línea.

double precio = 12.5;
System.out.printf("Precio: %.2f €%n", precio);

Formato habitual: %s texto, %d entero, %.2f decimal

Repetir un número de veces con for

El for es útil cuando sabes cuántas vueltas necesitas. Aquí i empieza en 1, el bucle continúa mientras sea menor o igual que 5, y aumenta en cada vuelta.

for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}

Muestra los números del 1 al 5; el contador cambia con i++.

Repetir mientras se cumpla una condición

while comprueba la condición antes de entrar. Si es verdadera, ejecuta el bloque y vuelve a comprobarla. Es importante actualizar el contador para que el bucle pueda terminar.

int cuenta = 3;
while (cuenta > 0) {
    System.out.println(cuenta);
    cuenta--;
}
System.out.println("¡Despegue!");

Muestra una cuenta atrás del 3 al 1 y luego «¡Despegue!».

Ejecutar al menos una vez con do / while

do / while ejecuta primero el bloque y comprueba la condición al final. Por eso se ejecuta al menos una vez, incluso si la condición comienza siendo falsa.

int numero = 1;
do {
    System.out.println(numero);
    numero++;
} while (numero <= 3);

Muestra los números del 1 al 3; recuerda el punto y coma tras while.

Una última pista

Empieza con programas pequeños: declara datos, muestra resultados y divide las tareas en métodos. Después organiza el código en clases y usa colecciones cuando necesites manejar grupos de elementos. Compila y prueba con frecuencia: los mensajes de error suelen indicar el archivo y la línea que debes revisar.
