Preparar y entender un programa

Fundamentos

Programa mínimo

El método main es el punto de entrada habitual de una aplicación Java. La clase pública debe guardarse en un archivo con el mismo nombre.

public class Hola {
    public static void main(String[] args) {
        System.out.println("¡Hola!");
    }
}

Archivo: Hola.java

Comentarios

Los comentarios de una línea empiezan con //; los de varias líneas se escriben entre /* y */. Javadoc documenta clases y métodos. 

// Comentario breve
/**
 * Describe una clase.
 * @author Tu nombre
 */

Javadoc: /** ... */

Mostrar información

System.out.println escribe y termina la línea; System.out.print escribe sin añadir un salto de línea.

System.out.println("Resultado:");
System.out.print(2 + 3);

Salida estándar: System.out

Paquetes e imports

Un paquete agrupa clases relacionadas. La declaración package, si se usa, va al principio del archivo; import permite usar clases de otros paquetes.

package ejemplos;

import java.util.Scanner;

Paquetes: package e import

Compilar y ejecutar desde la terminal

javac compila el código fuente (.java) y genera bytecode (.class); java ejecuta ese bytecode. Desde Java 11 también puedes ejecutar un archivo de una sola clase sin compilarlo antes.

javac Hola.java
java Hola

# Alternativa para un único archivo:
java Hola.java

Comandos: javac (compilar) y java (ejecutar). Al ejecutar no se escribe la extensión de la clase.

JDK, JRE y JVM

La JVM (máquina virtual de Java) ejecuta el bytecode y permite que el mismo programa funcione en distintos sistemas. El JDK incluye la JVM, el compilador javac y otras herramientas: es lo que necesitas para programar.

java -version
javac -version

Para desarrollar instala un JDK; ambos comandos deben mostrar una versión.

Convenciones de nombres

Java no obliga a ello, pero casi todo el mundo sigue las mismas reglas: las clases en PascalCase, las variables y métodos en camelCase, las constantes en MAYÚSCULAS con guiones bajos y los paquetes en minúsculas.

class CuentaBancaria { }          // clase
int saldoActual = 0;               // variable
void calcularInteres() { }         // método
static final int MAX_INTENTOS = 3; // constante
package com.ejemplo.tienda;        // paquete

Un buen nombre explica para qué sirve el dato o la acción.

Identificadores y palabras reservadas

Un identificador puede contener letras, dígitos, _ y $, pero no empezar por un dígito ni coincidir con una palabra reservada como class, int, if o static.

int edad2 = 20;      // válido
int _total = 5;      // válido
// int 2edad = 20;   // error: empieza por dígito
// int class = 1;    // error: palabra reservada

Java distingue mayúsculas de minúsculas: total y Total son distintos.

Argumentos de la línea de comandos

El parámetro args de main recoge los textos escritos tras el nombre de la clase al ejecutar el programa. Siempre son cadenas: si necesitas un número, conviértelo.

public class Saludo {
    public static void main(String[] args) {
        if (args.length > 0) {
            System.out.println("Hola, " + args[0]);
        }
    }
}
// java Saludo Marta  ->  Hola, Marta

Comprueba args.length antes de leer args[0].

Estructura de un proyecto Java

Un proyecto sencillo tiene una carpeta src con los paquetes y clases, y una carpeta de salida (bin o target) con los .class. Cada clase pública va en un archivo con su mismo nombre.

mi-proyecto/
├─ src/
│  └─ com/ejemplo/app/
│     ├─ Main.java
│     └─ Persona.java
└─ bin/

Una clase pública Persona → archivo Persona.java

Entornos de desarrollo (IDE)

Un IDE facilita escribir, compilar y depurar. Los más usados con Java son IntelliJ IDEA, Eclipse, NetBeans y Visual Studio Code con extensiones de Java.

IntelliJ IDEA  → muy completo (versión Community gratuita)
Eclipse        → clásico y gratuito
NetBeans       → gratuito, buen soporte de Java
VS Code        → ligero, con Extension Pack for Java

Atajo habitual para ejecutar: Mayús + F10 (IntelliJ), Ctrl + F11 (Eclipse)

Comentarios Javadoc

Los comentarios /** ... */ antes de una clase o método documentan su uso y permiten generar documentación HTML con la herramienta javadoc. Se usan etiquetas como @param, @return y @throws.

/**
 * Calcula el área de un rectángulo.
 *
 * @param ancho ancho en metros
 * @param alto  alto en metros
 * @return el área en metros cuadrados
 */
static double area(double ancho, double alto) {
    return ancho * alto;
}

Etiquetas: @param, @return, @throws, @author

Secuencias de escape

En una cadena, la barra invertida introduce caracteres especiales: \n (salto de línea), \t (tabulador), \" (comillas) y \\ (barra). También se admiten caracteres Unicode con \u.

System.out.println("Línea 1\nLínea 2");
System.out.println("Nombre:\tAna");
System.out.println("Dijo: \"Hola\"");
System.out.println("C:\\datos");
System.out.println("\u00A9 2026");

Secuencias: \n, \t, \", \\, \u

print, println y printf

print escribe sin salto de línea, println añade un salto y printf da formato con marcadores como %d, %s o %.2f.

System.out.print("Hola ");
System.out.println("mundo");
System.out.printf("%s tiene %d años y mide %.2f m%n", "Ana", 30, 1.68);

%n es el salto de línea portable.

Versiones de Java y LTS

Java publica una versión cada seis meses. Las versiones LTS (soporte a largo plazo) son las más usadas en empresas: 8, 11, 17, 21 y 25. Puedes comprobar la tuya con java -version.

java -version
javac -version

Elige una LTS para aprender y trabajar.

jshell: probar código sin crear archivos

jshell es una consola interactiva incluida en el JDK. Permite probar expresiones al instante.

$ jshell
jshell> 2 + 3
$1 ==> 5
jshell> "hola".toUpperCase()
$2 ==> "HOLA"
jshell> /exit

Comando: jshell

Errores de compilación habituales

Mensajes frecuentes: «cannot find symbol» (nombre mal escrito o sin importar), «incompatible types» (tipo incorrecto), «missing return statement» (falta return), «';' expected» (falta un punto y coma) y «class X is public, should be declared in a file named X.java».

int edad = "veinte";        // incompatible types
String s = nombre;          // cannot find symbol (¿no declarada?)
int f() { }                 // missing return statement

Lee el primer error: suele provocar los demás.

01

Guardar y representar datos

Variables y tipos

Declarar una variable

Una variable tiene un tipo y un nombre. Puedes asignarle un valor al declararla o después.

int edad = 20;
edad = 21;

Forma: tipo nombre = valor;

Tipos numéricos

byte, short, int y long representan enteros. float y double representan números decimales; para dinero suele ser más apropiado BigDecimal. 

int unidades = 12;
double precio = 4.99;
long poblacion = 8000000L;

Primitivos numéricos

Booleanos y caracteres

boolean solo admite true o false. char representa un carácter y se escribe entre comillas simples.

boolean activo = true;
char inicial = 'A';

Tipos: boolean y char

Cadenas de texto

String representa texto y se escribe entre comillas dobles. Es un objeto, no un tipo primitivo; sus operaciones habituales devuelven otra cadena.

String nombre = "Ana";
String saludo = "Hola, " + nombre;

Clase: String

Constantes con final

final impide asignar otro valor a una variable después de inicializarla. Por convención, las constantes se nombran en mayúsculas con guiones bajos.

final double IVA = 0.21;

Modificador: final

Convertir tipos

Algunas conversiones numéricas se hacen explícitamente con un cast. Para convertir texto a número, se usan métodos como Integer.parseInt.

double medida = 8.7;
int entera = (int) medida;
int cantidad = Integer.parseInt("12");

Conversión explícita: (tipo) valor

Inferencia de tipo con var

Desde Java 10, var permite que el compilador deduzca el tipo de una variable local a partir del valor inicial. La variable sigue teniendo un tipo fijo; solo te ahorras escribirlo.

var nombre = "Ana";            // String
var edad = 30;                 // int
var notas = new ArrayList<Integer>();

Solo en variables locales y siempre con valor inicial.

Literales y separadores numéricos

Un número entero con decimales es double por defecto; añade f para float y L para long. Puedes usar _ para leer mejor los números grandes y los prefijos 0x (hexadecimal) o 0b (binario).

long poblacion = 8_000_000_000L;
float precio = 9.99f;
int mascara = 0xFF;   // 255
int bits = 0b1010;    // 10

Sufijos: L (long), f (float), d (double).

Ámbito de una variable

Una variable solo existe dentro del bloque { } donde se declara. Fuera de él ya no se puede usar, y no puedes declarar otra con el mismo nombre dentro de un bloque anidado del mismo método.

for (int i = 0; i < 3; i++) {
    int doble = i * 2;
}
// System.out.println(i);     // error: i no existe aquí
// System.out.println(doble); // error: doble no existe aquí

Declara cada variable en el bloque más pequeño donde se necesite.

Clases envoltorio

Cada tipo primitivo tiene una clase envoltorio (Integer, Double, Boolean, Character...). Son necesarias en colecciones y permiten null. Java convierte entre ambos automáticamente (autoboxing).

Integer a = 5;            // autoboxing
int b = a;                // unboxing
int maximo = Integer.MAX_VALUE;
double d = Double.parseDouble("3.14");
Integer sinValor = null;  // un int no puede ser null

Desempaquetar un null provoca NullPointerException.

Desbordamiento de enteros

Los enteros tienen un rango limitado. Si una operación lo supera, el resultado «da la vuelta» sin avisar. Math.addExact y similares lanzan una excepción en lugar de ocultar el error.

int max = Integer.MAX_VALUE;     // 2147483647
System.out.println(max + 1);     // -2147483648
Math.addExact(max, 1);           // ArithmeticException

Para números muy grandes usa long o BigInteger.

Bloques de texto

Un bloque de texto, delimitado por tres comillas dobles, permite escribir varias líneas sin \n ni escapes para las comillas. Es cómodo para JSON, HTML o SQL.

String json = """
    {
      "nombre": "Ana",
      "edad": 30
    }
    """;

Disponible desde Java 15; la sangría común se elimina automáticamente.

Tipos primitivos y sus rangos

Java tiene ocho tipos primitivos: byte (8 bits), short (16), int (32), long (64), float (32), double (64), char (16) y boolean.

byte    -128 a 127
short   -32 768 a 32 767
int     -2 147 483 648 a 2 147 483 647
long    ±9 · 10^18 (sufijo L)
float   ~7 cifras decimales (sufijo f)
double  ~15 cifras decimales
char    un carácter Unicode ('A')
boolean true o false

Usa int y double por defecto.

Conversión explícita (casting)

Pasar de un tipo pequeño a uno mayor es automático (ampliación). Para pasar a uno menor hay que indicarlo con un casting entre paréntesis, y puede perderse información.

int a = 10;
double b = a;             // automático
double pi = 3.99;
int c = (int) pi;         // 3: se trunca, no se redondea
long grande = 5_000_000_000L;
int m = (int) grande;     // valor incorrecto por desbordamiento

Sintaxis: (tipo) valor

Promoción de tipos en operaciones

Al operar con tipos distintos, Java promociona al más grande: int + double da double. Con byte, short y char, el resultado de una operación es int.

int x = 5; double y = 2.0;
var r = x / y;            // double: 2.5
byte a = 10, b = 20;
// byte c = a + b;        // error: el resultado es int
byte c = (byte) (a + b);

Orden: byte → short → int → long → float → double

char y códigos Unicode

Un char es un número (su código Unicode) con aspecto de letra. Se puede operar con él y convertirlo.

char letra = 'A';
int codigo = letra;                 // 65
char siguiente = (char) (letra + 1); // 'B'
char minuscula = Character.toLowerCase(letra);
boolean esLetra = Character.isLetter('x');

Comillas simples para char, dobles para String.

Los String son inmutables

Un String nunca cambia: cada método devuelve uno nuevo. Los literales iguales comparten objeto (pool de cadenas), pero new String(...) crea otro distinto.

String a = "hola";
String b = "hola";
String c = new String("hola");
System.out.println(a == b);       // true (mismo objeto del pool)
System.out.println(a == c);       // false
System.out.println(a.equals(c));  // true

Compara contenido siempre con equals.

Tipos primitivos y de referencia

Una variable primitiva guarda directamente el valor. Una de referencia (objeto, array, String) guarda la dirección de un objeto, que puede ser null.

int a = 5;                    // valor
int[] datos = {1, 2, 3};      // referencia a un array
String s = null;              // no apunta a ningún objeto

Primitivos: nunca null.

Conversión entre texto y número

Integer.parseInt y Double.parseDouble convierten texto en número (lanzan NumberFormatException si no es válido); String.valueOf convierte a texto.

int n = Integer.parseInt("42");
double d = Double.parseDouble("3.14");
String t = String.valueOf(99);
String u = Integer.toString(7);
String v = "" + 5;

Valida la entrada antes de convertir.

Variables locales, de instancia y de clase

Las locales viven dentro de un método y no tienen valor por defecto; las de instancia pertenecen a cada objeto; las de clase (static) se comparten. Los atributos reciben un valor por defecto (0, false, null).

class Contador {
    static int total;      // de clase
    int cuenta;            // de instancia (por defecto 0)

    void sumar() {
        int paso = 1;      // local (hay que inicializarla)
        cuenta += paso;
        total++;
    }
}

Valores por defecto: 0, 0.0, false, '\u0000', null

Números enormes: BigInteger

BigInteger representa enteros de tamaño ilimitado. Se opera con métodos, no con operadores.

BigInteger a = new BigInteger("123456789012345678901234567890");
BigInteger b = BigInteger.valueOf(2);
System.out.println(a.multiply(b));
System.out.println(b.pow(100));

Métodos: add, subtract, multiply, divide, pow, mod

Caché de Integer y comparación de envoltorios

Los objetos Integer entre -128 y 127 se reutilizan, así que == parece funcionar, pero falla con valores mayores. Compara siempre con equals.

Integer a = 127, b = 127;
Integer c = 1000, d = 1000;
System.out.println(a == b);       // true
System.out.println(c == d);       // false
System.out.println(c.equals(d));  // true

Compara envoltorios con equals.

02

Calcular y comparar valores

Operadores

Operaciones aritméticas

Los operadores básicos son suma, resta, multiplicación, división y resto. La división entre enteros devuelve un entero.

int suma = 7 + 3;
int division = 7 / 3; // 2
int resto = 7 % 3;    // 1

Operadores: + - * / %

Comparar valores

Las comparaciones producen un booleano. Para comparar el contenido de cadenas, usa equals, no ==. 

boolean mayor = edad >= 18;
boolean mismoTexto = nombre.equals("Ana");

Comparación: == != < > <= >=

Operadores lógicos

&& significa «y», || significa «o» y ! niega una condición. Los operadores cortocircuitan cuando ya conocen el resultado.

boolean puedeEntrar = edad >= 18 && tieneEntrada;

Operadores: && || !

Actualizar una variable

Las asignaciones compuestas combinan una operación con la asignación. ++ aumenta una unidad y -- la reduce.

int puntos = 10;
puntos += 5;
puntos++;

Atajos: += -= *= /= ++ --

Operador ternario

El operador condición ? valorSiTrue : valorSiFalse es una forma compacta de elegir entre dos valores. Úsalo para decisiones sencillas; si se complica, es mejor un if.

int edad = 20;
String estado = edad >= 18 ? "adulto" : "menor";
System.out.println(estado);   // adulto

Devuelve un valor, por lo que se puede asignar o imprimir directamente.

Incremento prefijo y postfijo

i++ devuelve el valor actual y luego suma uno; ++i suma uno y devuelve el valor ya aumentado. Solos, en una instrucción independiente, dan el mismo resultado.

int i = 5;
int a = i++;   // a = 5, i = 6
int b = ++i;   // i = 7, b = 7

Evita mezclar ++ con otras operaciones en la misma línea.

División entera y resto

Dividir dos enteros descarta los decimales. Para obtener decimales, al menos uno de los operandos debe ser double. El operador % devuelve el resto. Dividir un entero entre cero lanza ArithmeticException.

System.out.println(7 / 2);     // 3
System.out.println(7 % 2);     // 1
System.out.println(7 / 2.0);   // 3.5
System.out.println(5.0 / 0);   // Infinity

Pares: n % 2 == 0.

Precedencia y paréntesis

Java evalúa primero la multiplicación, división y resto, y después la suma y resta; las comparaciones van después y && antes que ||. Los paréntesis hacen explícito el orden y mejoran la lectura.

int a = 2 + 3 * 4;      // 14
int b = (2 + 3) * 4;    // 20
boolean ok = x > 0 && y > 0 || z == 1;
boolean claro = (x > 0 && y > 0) || z == 1;

Ante la duda, añade paréntesis.

Evaluación en cortocircuito

Con &&, si el primer operando es falso, el segundo no se evalúa; con ||, si el primero es verdadero, tampoco. Se aprovecha para evitar errores, como comprobar null antes de usar un objeto.

String texto = null;
if (texto != null && texto.length() > 3) {
    System.out.println("Texto largo");
}

El orden importa: pon primero la comprobación de seguridad.

instanceof y patrones

instanceof comprueba si un objeto es de cierto tipo. Desde Java 16 puede declarar a la vez una variable ya convertida, sin necesidad de un cast aparte.

Object dato = "Hola";
if (dato instanceof String texto) {
    System.out.println(texto.toUpperCase());
}

Disponible desde Java 16.

Operadores de bits

Operan sobre los bits de un entero: AND (&), OR (|), XOR (^), NOT (~) y desplazamientos (<<, >>, >>>).

int a = 0b1100, b = 0b1010;
a & b;      // 0b1000
a | b;      // 0b1110
a ^ b;      // 0b0110
~a;         // invierte todos los bits
1 << 3;     // 8
16 >> 2;    // 4

Útiles para máscaras e indicadores.

Resto con números negativos y floorMod

El operador % conserva el signo del dividendo, por lo que con negativos puede dar un resultado negativo. Math.floorMod devuelve siempre un resto no negativo (con divisor positivo).

System.out.println(-7 % 3);                // -1
System.out.println(Math.floorMod(-7, 3));  // 2

Útil para índices circulares.

Comparar números decimales

No compares decimales con == porque pueden tener pequeños errores. Compara si la diferencia es menor que una tolerancia.

double a = 0.1 + 0.2;
System.out.println(a == 0.3);                      // false
System.out.println(Math.abs(a - 0.3) < 1e-9);      // true

Para dinero, usa BigDecimal.

Concatenar cadenas con +

El operador + une cadenas. Si uno de los operandos es texto, el otro se convierte. El orden de evaluación importa con números.

System.out.println("Total: " + 2 + 3);     // Total: 23
System.out.println("Total: " + (2 + 3));   // Total: 5
System.out.println(2 + 3 + " total");      // 5 total

Usa paréntesis para sumar antes de unir.

Asignaciones compuestas y casting implícito

Las asignaciones compuestas hacen un casting automático al tipo de la variable, a diferencia de la suma explícita.

byte b = 10;
b += 5;           // correcto (casting implícito)
// b = b + 5;     // error: int no cabe en byte
int x = 10;
x /= 4;           // 2 (división entera)

Operadores: +=, -=, *=, /=, %=, <<=, &=

Operador de redondeo: Math.round y compañía

Math.round redondea al entero más cercano, Math.floor hacia abajo y Math.ceil hacia arriba. Para redondear a dos decimales, multiplica, redondea y divide.

Math.round(2.5);        // 3
Math.round(-2.5);       // -2
Math.floor(-2.1);       // -3.0
Math.ceil(2.1);         // 3.0
Math.round(3.14159 * 100) / 100.0;   // 3.14

O usa String.format("%.2f", valor).

03

Elegir qué hacer y cuántas veces

Condiciones y bucles

Condición if / else

Ejecuta un bloque u otro según se cumpla una condición booleana.

if (edad >= 18) {
    System.out.println("Mayor de edad");
} else {
    System.out.println("Menor de edad");
}

Estructura: if y else

Varias opciones con switch

switch permite elegir entre varios casos. En la forma tradicional, break evita continuar al siguiente caso. 

switch (dia) {
    case 1:
        System.out.println("Lunes");
        break;
    default:
        System.out.println("Otro día");
}

Elementos: case, break, default

Bucle for

Usa for cuando la repetición tiene un contador o un número conocido de vueltas.

for (int i = 0; i < 5; i++) {
    System.out.println(i);
}

Partes: inicio, condición y actualización

Bucle while

while repite mientras la condición sea verdadera. Si es falsa desde el principio, el bloque no se ejecuta.

int intentos = 0;
while (intentos < 3) {
    intentos++;
}

Evalúa la condición antes de cada vuelta

Bucle do / while

El bloque se ejecuta al menos una vez, porque la condición se comprueba al final.

do {
    intentos++;
} while (intentos < 3);

Termina la condición con punto y coma

Controlar un bucle

break sale del bucle; continue omite el resto de la vuelta actual y pasa a la siguiente.

for (int i = 0; i < 10; i++) {
    if (i == 5) continue;
    if (i == 8) break;
}

Usa estos saltos con moderación para mantener claro el flujo

Recorrer con for-each

El bucle for mejorado recorre todos los elementos de un array o colección sin usar índices. Es la forma más clara cuando no necesitas la posición.

String[] frutas = {"pera", "uva", "kiwi"};
for (String fruta : frutas) {
    System.out.println(fruta);
}

Sintaxis: for (Tipo elemento : coleccion)

Bucles anidados

Un bucle dentro de otro repite el bucle interior completo en cada vuelta del exterior. Es típico para tablas, matrices y patrones.

for (int fila = 1; fila <= 3; fila++) {
    for (int col = 1; col <= 3; col++) {
        System.out.print(fila * col + "\t");
    }
    System.out.println();
}

Usa nombres de contador distintos en cada nivel.

Switch moderno con flechas

La sintaxis con flecha no necesita break y no «cae» en el caso siguiente. Además, el switch puede devolver un valor directamente y agrupar varios valores en un caso.

int dia = 3;
String nombre = switch (dia) {
    case 1, 7 -> "fin de semana";
    case 2, 3, 4, 5, 6 -> "laborable";
    default -> "desconocido";
};

Como expresión, debe cubrir todos los casos posibles.

Switch con patrones

En Java 21 un switch puede decidir según el tipo del objeto y declarar una variable por cada caso. Resulta muy claro cuando se trata de varias clases relacionadas.

static String describir(Object o) {
    return switch (o) {
        case Integer i -> "entero " + i;
        case String s -> "texto de " + s.length();
        case null -> "sin valor";
        default -> "otro tipo";
    };
}

Disponible de forma estable desde Java 21.

Bucle infinito con salida

while (true) repite sin fin hasta que un break (o un return) lo interrumpe. Es útil cuando la condición de salida se conoce en mitad del cuerpo, como en un menú.

Scanner entrada = new Scanner(System.in);
while (true) {
    System.out.print("Escribe 'fin' para salir: ");
    String texto = entrada.nextLine();
    if (texto.equals("fin")) {
        break;
    }
}

Asegúrate de que siempre existe una forma de salir.

break y continue con etiquetas

Una etiqueta permite que break o continue actúen sobre un bucle exterior, no solo sobre el más cercano. Úsalo con moderación.

externo:
for (int i = 0; i < 5; i++) {
    for (int j = 0; j < 5; j++) {
        if (i * j == 6) {
            break externo;  // sale de ambos bucles
        }
    }
}

Sintaxis: etiqueta: antes del bucle y break etiqueta;

if anidados y condiciones compuestas

Una condición compuesta combina comprobaciones con && y ||. Anidar if demasiado hace el código difícil de leer: usa condiciones compuestas o return temprano.

int nota = 7;
if (nota >= 0 && nota <= 10) {
    if (nota >= 5) System.out.println("Aprobado");
    else System.out.println("Suspenso");
} else {
    System.out.println("Nota no válida");
}

Operadores: &&, ||, !

switch con String y enum

switch admite String y enum, además de enteros y caracteres.

String dia = "lunes";
switch (dia) {
    case "sábado", "domingo" -> System.out.println("Descanso");
    case "lunes" -> System.out.println("Empieza la semana");
    default -> System.out.println("Día laborable");
}

Los case deben ser constantes.

yield en switch

En un switch con flechas, cuando un caso necesita varias instrucciones se usa un bloque y yield para devolver el valor.

int mes = 2;
int dias = switch (mes) {
    case 4, 6, 9, 11 -> 30;
    case 2 -> {
        boolean bisiesto = false;
        yield bisiesto ? 29 : 28;
    }
    default -> 31;
};

Palabra clave: yield

for con varias variables

Un for puede declarar y actualizar más de una variable, separadas por comas. Es útil para recorrer desde ambos extremos.

for (int i = 0, j = 9; i < j; i++, j--) {
    System.out.println(i + " - " + j);
}

Útil para invertir o comparar extremos.

Recorrer los caracteres de un String

Se puede usar un for con charAt o convertir la cadena en un array de caracteres.

String palabra = "Java";
for (int i = 0; i < palabra.length(); i++) {
    System.out.println(palabra.charAt(i));
}
for (char c : palabra.toCharArray()) {
    System.out.print(c + " ");
}

Métodos: charAt, length, toCharArray

Patrones: contador, acumulador, bandera y centinela

Cuatro patrones habituales en bucles: contar cuántos cumplen algo (contador), sumar valores (acumulador), recordar si ocurrió algo (bandera) y parar al leer un valor especial (centinela).

int contador = 0, suma = 0;
boolean hayNegativos = false;
for (int n : numeros) {
    if (n % 2 == 0) contador++;
    suma += n;
    if (n < 0) hayNegativos = true;
}

Casi todos los ejercicios usan alguno.

04

Reutilizar instrucciones

Métodos

Declarar y llamar a un método

Un método agrupa instrucciones con un nombre. Se ejecuta cuando se llama desde el programa.

static void saludar() {
    System.out.println("Hola");
}

saludar();

void indica que no devuelve un valor

Parámetros

Los parámetros reciben los datos que necesita el método. Al llamarlo, se pasan argumentos del tipo esperado.

static void saludar(String nombre) {
    System.out.println("Hola, " + nombre);
}

saludar("Ana");

Parámetro: String nombre

Devolver un resultado

El tipo antes del nombre indica qué devuelve el método. return entrega el resultado y termina la ejecución del método.

static int sumar(int a, int b) {
    return a + b;
}

El resultado debe coincidir con el tipo declarado

Sobrecarga

Puedes declarar métodos con el mismo nombre si sus listas de parámetros son diferentes. Cambiar solo el tipo devuelto no basta.

static int doble(int n) { return n * 2; }
static double doble(double n) { return n * 2; }

Se distingue por el nombre y los parámetros

Métodos estáticos y de instancia

Un método static pertenece a la clase y se llama sin crear un objeto. Uno de instancia necesita un objeto y puede usar sus atributos.

class Calculadora {
    static int doble(int n) { return n * 2; }
    int sumar(int a, int b) { return a + b; }
}

int x = Calculadora.doble(4);
Calculadora calc = new Calculadora();
int y = calc.sumar(2, 3);

Desde static no se accede directamente a miembros de instancia.

Número variable de argumentos

Un parámetro varargs (tipo...) acepta cero o más valores y dentro del método se trata como un array. Solo puede haber uno y debe ser el último.

static int sumar(int... numeros) {
    int total = 0;
    for (int n : numeros) total += n;
    return total;
}

sumar();          // 0
sumar(1, 2, 3);   // 6

Sintaxis: tipo... nombre

Paso por valor

Java siempre pasa una copia del argumento. Con tipos primitivos, el original no cambia. Con objetos se copia la referencia: el método puede modificar el objeto, pero no hacer que la variable original apunte a otro.

static void cambiar(int n, int[] datos) {
    n = 99;          // no afecta al original
    datos[0] = 99;   // sí modifica el array
}

Primitivos: copia del valor; objetos: copia de la referencia.

Recursión

Un método recursivo se llama a sí mismo. Necesita un caso base que detenga las llamadas y un paso que se acerque a él; si no, se produce StackOverflowError.

static long factorial(int n) {
    if (n <= 1) return 1;          // caso base
    return n * factorial(n - 1);   // llamada recursiva
}

Muchas recursiones se pueden escribir también con un bucle.

Métodos privados y auxiliares

Un método private solo se usa dentro de su clase. Sirve para dividir un método largo en partes y no exponer detalles internos.

public double precioFinal(double base) {
    return base + calcularIva(base);
}
private double calcularIva(double base) {
    return base * 0.21;
}

Modificador: private

Métodos genéricos

Un método genérico trabaja con cualquier tipo. Se declara con un parámetro de tipo entre <> antes del tipo de retorno.

static <T> void imprimir(List<T> lista) {
    for (T e : lista) System.out.println(e);
}
static <T extends Comparable<T>> T maximo(T a, T b) {
    return a.compareTo(b) >= 0 ? a : b;
}

Sintaxis: <T> tipo nombre(...)

Sobrecarga y sobrescritura: diferencias

Sobrecarga: varios métodos con el mismo nombre y distintos parámetros en la misma clase. Sobrescritura: una subclase redefine un método de su padre con la misma firma.

class A {
    void f(int x) { }
    void f(String s) { }          // sobrecarga
}
class B extends A {
    @Override void f(int x) { }   // sobrescritura
}

Usa @Override para que el compilador lo compruebe.

Devolver varios valores

Un método solo devuelve un valor, pero puede devolver un objeto o un record que agrupe varios.

record MinMax(int min, int max) { }

static MinMax limites(int[] n) {
    int min = n[0], max = n[0];
    for (int x : n) { min = Math.min(min, x); max = Math.max(max, x); }
    return new MinMax(min, max);
}

Alternativas: array, List, clase propia.

El método main en detalle

El punto de entrada clásico es public static void main(String[] args). Desde las últimas versiones, se permiten formas más simples (clases y main sin static ni public, como vista previa).

public class App {
    public static void main(String[] args) {
        System.out.println("Hola");
    }
}

public y static son necesarios en la forma clásica.

Fibonacci recursivo y su coste

Fibonacci recursivo es muy lento porque repite cálculos. Con memoización (guardar resultados) o con un bucle es mucho más rápido.

static long fib(int n) {
    return n < 2 ? n : fib(n - 1) + fib(n - 2);   // lento
}

static Map<Integer, Long> cache = new HashMap<>();
static long fibRapido(int n) {
    if (n < 2) return n;
    return cache.computeIfAbsent(n, k -> fibRapido(k - 1) + fibRapido(k - 2));
}

Nota: computeIfAbsent recursivo puede fallar en algunos mapas; usa un bucle si hace falta.

05

Trabajar con secuencias de datos

Arrays y cadenas

Crear un array

Un array guarda varios valores del mismo tipo y tiene tamaño fijo. Sus posiciones empiezan en cero.

int[] notas = {7, 9, 8};
System.out.println(notas[0]); // 7

Tamaño: notas.length

Recorrer un array

Un for clásico permite usar el índice. El for-each recorre directamente cada elemento cuando no hace falta la posición.

for (int nota : notas) {
    System.out.println(nota);
}

Bucle: for (tipo elemento : colección)

Operaciones con String

length() devuelve la longitud; charAt obtiene un carácter y equals compara el contenido. Los índices empiezan en cero. 

String texto = "Java";
int longitud = texto.length();
boolean igual = texto.equals("Java");

Métodos: length(), charAt(), equals()

La referencia null

null indica que una variable de referencia no apunta a ningún objeto. Compruébala antes de llamar a métodos para evitar un NullPointerException.

if (nombre != null) {
    System.out.println(nombre.length());
}

Una referencia puede ser null; un primitivo no

Arrays bidimensionales

Un array bidimensional es un array de arrays: se accede con dos índices (fila y columna). Cada fila puede tener su propia longitud.

int[][] tabla = {
    {1, 2, 3},
    {4, 5, 6}
};
System.out.println(tabla[1][2]);        // 6
System.out.println(tabla.length);       // 2 filas
System.out.println(tabla[0].length);    // 3 columnas

Declaración: tipo[][] nombre

Length, length() y size()

Tres formas de preguntar el tamaño según el tipo: los arrays usan el atributo length (sin paréntesis), las cadenas el método length() y las colecciones el método size().

int[] a = {1, 2, 3};
String s = "Hola";
List<Integer> l = List.of(1, 2);
a.length;    // 3
s.length();  // 4
l.size();    // 2

Es un error muy común confundirlos.

La clase Arrays

java.util.Arrays ofrece utilidades para trabajar con arrays: mostrarlos, ordenarlos, rellenarlos, compararlos y copiarlos.

int[] n = {5, 2, 9, 1};
Arrays.sort(n);
System.out.println(Arrays.toString(n));  // [1, 2, 5, 9]
Arrays.fill(n, 0);
int[] otro = Arrays.copyOf(n, 6);
boolean igual = Arrays.equals(n, otro);

Importa java.util.Arrays.

Copiar un array

Asignar un array a otra variable no lo copia: ambas apuntan al mismo array. Para duplicarlo usa clone(), Arrays.copyOf o Arrays.copyOfRange.

int[] a = {1, 2, 3};
int[] mismo = a;                 // misma referencia
int[] copia = Arrays.copyOf(a, a.length);
copia[0] = 99;                   // a no cambia

La copia es superficial si el array contiene objetos.

Comparar cadenas

Con objetos, == compara referencias, no el contenido. Para comparar texto usa equals, o equalsIgnoreCase si no importan las mayúsculas. compareTo sirve para ordenar alfabéticamente.

String a = new String("hola");
String b = new String("hola");
System.out.println(a == b);              // false
System.out.println(a.equals(b));         // true
System.out.println("Ana".compareTo("Beto") < 0);  // true

Para textos, usa siempre equals.

StringBuilder

Los String son inmutables: cada concatenación crea un objeto nuevo. Si construyes un texto por partes, sobre todo en bucles, StringBuilder es más eficiente.

StringBuilder sb = new StringBuilder();
for (int i = 1; i <= 3; i++) {
    sb.append(i).append(", ");
}
sb.setLength(sb.length() - 2);
System.out.println(sb);               // 1, 2, 3
System.out.println(sb.reverse());

Métodos habituales: append, insert, reverse, toString.

Dividir, unir y limpiar texto

split divide una cadena en partes según un separador; String.join hace lo contrario. strip elimina espacios de los extremos, isBlank comprueba si solo hay espacios y repeat repite un texto.

String[] partes = "rojo,verde,azul".split(",");
String unido = String.join(" - ", partes);
String limpio = "  hola  ".strip();
boolean vacio = "   ".isBlank();
String linea = "=".repeat(10);

Resultado de unido: rojo - verde - azul

Caracteres de una cadena

charAt(i) obtiene el carácter de una posición (empezando en 0) y toCharArray() convierte la cadena en un array de char. La clase Character ofrece métodos para clasificar caracteres.

String palabra = "Java";
char primera = palabra.charAt(0);   // 'J'
int letras = 0;
for (char c : palabra.toCharArray()) {
    if (Character.isLetter(c)) letras++;
}

Métodos: Character.isDigit, isLetter, isUpperCase, toLowerCase.

Buscar y reemplazar en un texto

contains, startsWith y endsWith comprueban el contenido; indexOf devuelve la posición (o -1); substring extrae una parte y replace sustituye fragmentos.

String t = "Aprender Java es divertido";
t.contains("Java");        // true
t.indexOf("Java");         // 9
t.substring(0, 8);         // "Aprender"
t.replace("Java", "POO");

substring(inicio, fin) incluye el inicio y excluye el final.

Arrays irregulares

En un array bidimensional, cada fila puede tener una longitud distinta.

int[][] tri = new int[3][];
for (int i = 0; i < tri.length; i++) {
    tri[i] = new int[i + 1];
}

Se crea primero el array de filas y luego cada fila.

Recorrer una matriz

Una matriz se recorre con dos bucles anidados: el exterior para las filas y el interior para las columnas.

int[][] m = {{1, 2, 3}, {4, 5, 6}};
int suma = 0;
for (int f = 0; f < m.length; f++) {
    for (int c = 0; c < m[f].length; c++) {
        suma += m[f][c];
    }
}
System.out.println(Arrays.deepToString(m));

Útil: Arrays.deepToString

Ordenar un array de objetos

Arrays.sort con un Comparator ordena un array de objetos por el criterio que elijas.

Persona[] gente = { new Persona("Luis", 30), new Persona("Ana", 25) };
Arrays.sort(gente, Comparator.comparingInt(Persona::edad));
Arrays.sort(gente, Comparator.comparing(Persona::nombre));

Métodos: Comparator.comparing, thenComparing

Buscar en un array

La búsqueda lineal recorre el array hasta encontrar el valor. La binaria, mucho más rápida, necesita el array ordenado.

int[] n = {2, 5, 8, 12, 20};
int pos = Arrays.binarySearch(n, 12);   // 3 (si no existe, negativo)

int buscado = 8, indice = -1;
for (int i = 0; i < n.length; i++) {
    if (n[i] == buscado) { indice = i; break; }
}

binarySearch requiere un array ordenado.

Expresiones regulares: Pattern y Matcher

String.matches comprueba si un texto cumple un patrón. Para buscar y extraer partes, se usan Pattern y Matcher.

boolean valido = "ana@ejemplo.es".matches("[\\w.]+@[\\w.]+\\.[a-z]{2,}");

Pattern p = Pattern.compile("(\\d{3})-(\\d{4})");
Matcher m = p.matcher("Llama al 600-1234 hoy");
if (m.find()) {
    System.out.println(m.group(1));   // 600
}

Recuerda doblar las barras: \\d

StringJoiner y String.join

StringJoiner une elementos con un separador, un prefijo y un sufijo. String.join es la versión corta.

StringJoiner sj = new StringJoiner(", ", "[", "]");
sj.add("a").add("b").add("c");
System.out.println(sj);                       // [a, b, c]
System.out.println(String.join("-", "x", "y"));  // x-y

Clases: StringJoiner, String.join

Vacío o solo espacios: isEmpty e isBlank

isEmpty es verdadero si la longitud es 0; isBlank también si solo hay espacios en blanco. Ninguno funciona con null.

"".isEmpty();       // true
"  ".isEmpty();     // false
"  ".isBlank();     // true
String s = null;
// s.isEmpty();     // NullPointerException

Comprueba s != null antes.

Formatear con String.format y formatted

String.format y formatted construyen texto con marcadores: %d (entero), %s (texto), %f (decimal), %b (booleano). Se pueden añadir ancho, relleno y decimales.

String.format("%5d|%-8s|%08.3f", 42, "ab", 3.14159);
String.format("%,d", 1234567);                  // 1,234,567
"%s tiene %d años".formatted("Ana", 30);

Ejemplos: %.2f, %05d, %-10s

Comparar y ordenar cadenas

compareTo devuelve un número negativo, cero o positivo según el orden alfabético. Para ignorar mayúsculas usa compareToIgnoreCase.

"ana".compareTo("beto");               // negativo
"Ana".compareToIgnoreCase("ana");      // 0
List<String> l = new ArrayList<>(List.of("b", "A", "c"));
l.sort(String.CASE_INSENSITIVE_ORDER);

Para idiomas con tildes, usa Collator.

Contar vocales y repeticiones de un carácter

Un recorrido de la cadena con un contador.

String t = "Programación en Java";
int vocales = 0;
for (char c : t.toLowerCase().toCharArray()) {
    if ("aeiouáéíóú".indexOf(c) >= 0) vocales++;
}

Truco: "aeiou".indexOf(c) >= 0

StringBuilder y StringBuffer

StringBuffer es la versión sincronizada (segura para varios hilos) y más lenta; StringBuilder es la normal para un solo hilo.

StringBuilder sb = new StringBuilder("ab");
sb.append("c").insert(0, "x").reverse();
sb.toString();

Usa StringBuilder salvo que compartas el objeto entre hilos.

Recorrer caracteres con chars() y codePoints()

chars() devuelve un IntStream con los caracteres; codePoints() maneja bien los caracteres fuera del plano básico (como los emojis).

"Hola mundo".chars().filter(Character::isLetter).count();   // 9
"a😀b".length();                 // 4 (😀 ocupa 2 unidades)
"a😀b".codePoints().count();     // 3

Métodos: chars, codePoints

Modelar conceptos con tipos propios

Clases y objetos

Crear una clase y un objeto

Una clase define datos y comportamientos. Un objeto es una instancia creada con new. 

class Persona {
    String nombre;
}

Persona persona = new Persona();

Clase: Persona; objeto: persona

Constructor

El constructor inicializa un objeto. Tiene el mismo nombre que la clase y no declara tipo de retorno.

class Persona {
    String nombre;
    Persona(String nombre) {
        this.nombre = nombre;
    }
}

this se refiere al objeto actual

Encapsulación

Los campos private solo se usan directamente dentro de la clase. Métodos públicos pueden ofrecer acceso controlado.

private int edad;
public int getEdad() {
    return edad;
}

Modificadores: private, public

Herencia

extends crea una clase basada en otra. La subclase hereda miembros accesibles y puede especializar el comportamiento.

class Animal {
    void hacerSonido() { }
}
class Perro extends Animal { }

Una clase Java solo puede extender una clase

Sobrescribir un método

Una subclase puede proporcionar su propia implementación. @Override ayuda a detectar errores al sobrescribir.

@Override
void hacerSonido() {
    System.out.println("Guau");
}

Anotación: @Override

Interfaces

Una interfaz define un contrato que una clase puede implementar. Una clase puede implementar varias interfaces.

interface Volador {
    void volar();
}
class Ave implements Volador {
    public void volar() {
        System.out.println("Despega");
    }
}

Palabras clave: interface, implements

La palabra this

this hace referencia al objeto actual. Se usa sobre todo para distinguir un atributo de un parámetro con el mismo nombre.

class Persona {
    private String nombre;

    Persona(String nombre) {
        this.nombre = nombre;
    }
}

this.nombre es el atributo; nombre es el parámetro.

Atributos y métodos static

Un atributo static es compartido por todos los objetos de la clase: existe una sola copia. Es útil para contadores y constantes.

class Pedido {
    static int total = 0;
    static final double IVA = 0.21;

    Pedido() {
        total++;
    }
}
// Pedido.total cuenta cuántos pedidos se han creado

Se accede con el nombre de la clase: Pedido.total

Modificadores de acceso

Controlan desde dónde se puede usar una clase, atributo o método: public (desde cualquier sitio), protected (mismo paquete y subclases), sin modificador (solo el mismo paquete) y private (solo la propia clase).

public class Cuenta {
    private double saldo;       // solo dentro de Cuenta
    protected String titular;   // paquete y subclases
    String oficina;             // solo el paquete
    public void ingresar(double c) { saldo += c; }
}

Regla práctica: atributos private, métodos públicos solo si hace falta.

Método toString

Si imprimes un objeto sin toString, verás algo como Persona@1b6d3586. Sobrescríbelo para devolver un texto útil.

class Persona {
    String nombre; int edad;

    @Override
    public String toString() {
        return nombre + " (" + edad + " años)";
    }
}

println y la concatenación llaman a toString automáticamente.

equals y hashCode

equals define cuándo dos objetos se consideran iguales por su contenido. Si lo sobrescribes, sobrescribe también hashCode, o HashMap y HashSet no funcionarán bien.

@Override
public boolean equals(Object o) {
    if (this == o) return true;
    if (!(o instanceof Persona p)) return false;
    return edad == p.edad && Objects.equals(nombre, p.nombre);
}

@Override
public int hashCode() {
    return Objects.hash(nombre, edad);
}

Los objetos iguales deben devolver el mismo hashCode.

Encadenar constructores

Un constructor puede llamar a otro de la misma clase con this(...) para no repetir código. Con super(...) se llama al constructor de la clase padre. Deben ser la primera instrucción.

class Producto {
    String nombre; double precio;

    Producto(String nombre, double precio) {
        this.nombre = nombre;
        this.precio = precio;
    }
    Producto(String nombre) {
        this(nombre, 0.0);
    }
}

this(...) y super(...) se usan solo dentro de constructores.

La palabra super

super hace referencia a la clase padre. Permite llamar a su constructor o a un método que has sobrescrito.

class Animal {
    void hablar() { System.out.println("..."); }
}
class Perro extends Animal {
    @Override
    void hablar() {
        super.hablar();
        System.out.println("Guau");
    }
}

super.metodo() ejecuta la versión de la clase padre.

Clases abstractas

Una clase abstract no se puede instanciar: sirve como base común. Puede declarar métodos abstractos (sin cuerpo) que cada subclase debe implementar.

abstract class Figura {
    abstract double area();
    void mostrar() { System.out.println(area()); }
}
class Cuadrado extends Figura {
    double lado = 2;
    double area() { return lado * lado; }
}

Una clase abstracta puede tener atributos y métodos con código.

Polimorfismo

Una variable de tipo padre o interfaz puede guardar objetos de cualquier subclase, y Java ejecuta la versión del método que corresponde al objeto real.

List<Figura> figuras = List.of(new Cuadrado(), new Circulo());
for (Figura f : figuras) {
    System.out.println(f.area());   // cada una usa su propio cálculo
}

Programa contra la interfaz o clase base, no contra la implementación.

Enumeraciones: enum

Un enum define un conjunto fijo de constantes con nombre. Es más seguro que usar números o cadenas sueltas y funciona muy bien con switch.

enum Dia { LUNES, MARTES, MIERCOLES }

Dia hoy = Dia.MARTES;
for (Dia d : Dia.values()) {
    System.out.println(d);
}
System.out.println(hoy.ordinal());   // 1

Un enum también puede tener atributos, constructor y métodos.

Registros: record

Un record es una forma breve de crear una clase inmutable que solo guarda datos. Java genera el constructor, los métodos de acceso, equals, hashCode y toString.

record Punto(int x, int y) { }

Punto p = new Punto(3, 4);
System.out.println(p.x());    // 3
System.out.println(p);        // Punto[x=3, y=4]

Disponible desde Java 16.

final en clases y métodos

final en una variable impide reasignarla; en un método, que se sobrescriba; en una clase, que se herede. String es un ejemplo de clase final.

final class Configuracion { }          // no se puede heredar

class Base {
    final void iniciar() { }            // no se puede sobrescribir
}

Una variable final con un objeto no impide modificar el objeto.

Composición frente a herencia

La herencia expresa «es un» y la composición «tiene un». Muchas veces es mejor componer objetos que heredar, porque hay menos acoplamiento.

class Motor { void arrancar() { } }
class Coche {
    private final Motor motor = new Motor();   // composición
    void arrancar() { motor.arrancar(); }
}

Preferir composición cuando no haya una relación «es un» clara.

Métodos default y static en interfaces

Desde Java 8 una interfaz puede tener métodos default (con implementación) y static. Permite añadir métodos sin romper las clases que ya la implementan.

interface Saludo {
    String nombre();
    default String saludar() { return "Hola, " + nombre(); }
    static Saludo de(String n) { return () -> n; }
}

Palabras clave: default, static

Interfaces funcionales propias

Una interfaz con un único método abstracto puede implementarse con una lambda. La anotación @FunctionalInterface lo comprueba.

@FunctionalInterface
interface Operacion { int aplicar(int a, int b); }

Operacion suma = (a, b) -> a + b;
System.out.println(suma.aplicar(2, 3));

Anotación: @FunctionalInterface

Clases anidadas y clases internas

Una clase puede declararse dentro de otra. La static (anidada) no necesita instancia de la externa; la interna sí y accede a sus miembros.

class Externa {
    private int x = 5;
    static class Anidada { }
    class Interna { int doble() { return x * 2; } }
}
Externa e = new Externa();
Externa.Interna i = e.new Interna();

Tipos: static nested, inner, local, anónima

Clases anónimas

Una clase anónima implementa una interfaz o extiende una clase al momento, sin darle nombre. Hoy suele sustituirse por lambdas.

Comparator<String> c = new Comparator<>() {
    @Override
    public int compare(String a, String b) { return a.length() - b.length(); }
};

Con interfaces funcionales, prefiere una lambda.

Clases selladas: sealed

Una clase o interfaz sealed indica exactamente qué clases pueden heredar de ella, con permits. Combinadas con switch con patrones, permiten comprobar que se cubren todos los casos.

sealed interface Figura permits Circulo, Cuadrado { }
record Circulo(double r) implements Figura { }
record Cuadrado(double l) implements Figura { }

double area(Figura f) {
    return switch (f) {
        case Circulo c -> Math.PI * c.r() * c.r();
        case Cuadrado q -> q.l() * q.l();
    };
}

Palabras clave: sealed, permits, non-sealed

Patrón Singleton

Garantiza que una clase solo tenga una instancia. La forma más sencilla y segura en Java es con un enum.

enum Configuracion {
    INSTANCIA;
    private String idioma = "es";
    public String idioma() { return idioma; }
}
Configuracion.INSTANCIA.idioma();

Alternativa: constructor private + método getInstance().

Patrón Builder

Construye objetos con muchos atributos de forma legible, encadenando métodos.

class Pizza {
    private final String masa; private final boolean queso;
    private Pizza(Builder b) { masa = b.masa; queso = b.queso; }
    static class Builder {
        private String masa = "fina"; private boolean queso;
        Builder masa(String m) { masa = m; return this; }
        Builder queso(boolean q) { queso = q; return this; }
        Pizza build() { return new Pizza(this); }
    }
}
Pizza p = new Pizza.Builder().masa("gruesa").queso(true).build();

Técnica: métodos que devuelven this.

Patrón Factory

Un método de fábrica decide qué clase crear sin que quien llama conozca los detalles.

interface Animal { String sonido(); }
record Perro() implements Animal { public String sonido() { return "Guau"; } }
record Gato()  implements Animal { public String sonido() { return "Miau"; } }

static Animal crear(String tipo) {
    return switch (tipo) {
        case "perro" -> new Perro();
        case "gato"  -> new Gato();
        default -> throw new IllegalArgumentException(tipo);
    };
}

Útil para ocultar la clase concreta.

Comparable y Comparator

Comparable define el orden natural de una clase (método compareTo). Comparator define criterios alternativos sin modificar la clase.

class Persona implements Comparable<Persona> {
    String nombre; int edad;
    public int compareTo(Persona o) { return Integer.compare(edad, o.edad); }
}
List<Persona> l = new ArrayList<>();
Collections.sort(l);                                       // orden natural
l.sort(Comparator.comparing(p -> p.nombre));               // otro criterio

Devuelve: negativo, 0 o positivo.

Inmutabilidad: clases que no cambian

Una clase inmutable no cambia tras crearse: atributos final, sin setters y sin exponer colecciones modificables. Son más seguras y fáciles de razonar.

public final class Punto {
    private final int x, y;
    public Punto(int x, int y) { this.x = x; this.y = y; }
    public Punto conX(int nuevoX) { return new Punto(nuevoX, y); }
}

Los record son inmutables por defecto.

Objects: utilidades para objetos

La clase Objects ofrece métodos seguros para comparar con null, calcular hashCode y validar argumentos.

Objects.equals(a, b);                 // seguro con null
Objects.hash(nombre, edad);
Objects.requireNonNull(valor, "No puede ser nulo");
Objects.toString(obj, "sin valor");

Métodos: equals, hash, requireNonNull, toString

Getters y setters

Los métodos get y set dan acceso controlado a atributos privados, permitiendo validar valores.

class Cuenta {
    private double saldo;
    public double getSaldo() { return saldo; }
    public void setSaldo(double s) {
        if (s < 0) throw new IllegalArgumentException("Saldo negativo");
        saldo = s;
    }
}

Convención: getX(), setX(), isX() para booleanos

Enum con atributos y métodos

Un enum puede tener atributos, constructor y métodos. Cada constante es un objeto.

enum Planeta {
    TIERRA(5.97e24), MARTE(6.42e23);
    private final double masa;
    Planeta(double masa) { this.masa = masa; }
    double masa() { return masa; }
}
Planeta p = Planeta.valueOf("MARTE");
for (Planeta x : Planeta.values()) System.out.println(x + " " + x.masa());

Métodos: values(), valueOf(), ordinal(), name()

Casting de objetos y instanceof

Convertir a la clase padre (upcast) es automático; convertir a una subclase (downcast) requiere casting y puede fallar. Comprueba antes con instanceof.

Animal a = new Perro();                 // upcast
if (a instanceof Perro p) {             // comprobación + conversión
    p.ladrar();
}
Perro d = (Perro) a;                    // downcast explícito

Un casting erróneo lanza ClassCastException.

Variables de clase y bloques static

Un bloque static se ejecuta una sola vez al cargar la clase. Sirve para inicializar atributos estáticos complejos.

class Config {
    static final Map<String, String> VALORES = new HashMap<>();
    static {
        VALORES.put("idioma", "es");
    }
}

Se ejecuta antes de usar la clase.

Qué es un objeto y qué es null

Un objeto es una instancia de una clase creada con new. Una variable de objeto guarda una referencia; si vale null, no apunta a ningún objeto y usarla lanza NullPointerException. Cuando nadie referencia un objeto, el recolector de basura lo libera.

Persona p = new Persona("Ana");
Persona q = p;        // dos referencias al mismo objeto
p = null;             // q sigue apuntando al objeto

No hace falta liberar memoria manualmente.

Comodines genéricos: ? extends y ? super

Un comodín (?) representa un tipo desconocido. ? extends T acepta T y sus subtipos (para leer); ? super T acepta T y sus supertipos (para escribir). Regla PECS: Producer Extends, Consumer Super.

static double suma(List<? extends Number> n) {
    double s = 0; for (Number x : n) s += x.doubleValue(); return s;
}
static void rellenar(List<? super Integer> l) { l.add(1); }
suma(List.of(1, 2.5));

Sintaxis: <?>, <? extends T>, <? super T>

Clonar objetos: Cloneable y constructor de copia

clone() está pensado para copiar objetos, pero tiene muchos problemas. Un constructor de copia o un método de fábrica es más claro.

class Punto {
    int x, y;
    Punto(int x, int y) { this.x = x; this.y = y; }
    Punto(Punto otro) { this(otro.x, otro.y); }     // constructor de copia
}

Copia profunda: copia también los objetos interiores.

Crear tu propio Iterable

Una clase que implementa Iterable<T> puede usarse en un for-each. Debe devolver un Iterator.

class Rango implements Iterable<Integer> {
    private final int a, b;
    Rango(int a, int b) { this.a = a; this.b = b; }
    public Iterator<Integer> iterator() {
        return new Iterator<>() {
            int i = a;
            public boolean hasNext() { return i <= b; }
            public Integer next() { return i++; }
        };
    }
}
for (int n : new Rango(1, 3)) System.out.println(n);

Interfaces: Iterable, Iterator

finalize y el recolector de basura

Java libera la memoria de los objetos no referenciados mediante el recolector de basura. finalize() está obsoleto: para liberar recursos usa try-with-resources (AutoCloseable) o Cleaner.

class Recurso implements AutoCloseable {
    @Override public void close() { System.out.println("Liberado"); }
}
try (Recurso r = new Recurso()) { }

No dependas de System.gc().

Herencia múltiple con interfaces

Una clase solo hereda de una clase, pero puede implementar varias interfaces. Si dos interfaces tienen el mismo método default, la clase debe resolver el conflicto.

interface A { default String hola() { return "A"; } }
interface B { default String hola() { return "B"; } }
class C implements A, B {
    public String hola() { return A.super.hola(); }
}

Sintaxis: Interfaz.super.metodo()

Anticipar y gestionar problemas

Excepciones

Capturar una excepción

Un bloque try contiene una operación que puede fallar y catch gestiona una excepción concreta.

try {
    int numero = Integer.parseInt("42");
} catch (NumberFormatException error) {
    System.out.println("No es un número");
}

Control: try y catch

Bloque finally

finally se usa para acciones de limpieza que deben intentarse tanto si ocurre una excepción como si no.

try {
    // Operación
} catch (Exception error) {
    // Gestionar el error
} finally {
    // Limpieza
}

En muchos casos, try-with-resources es preferible para recursos

Declarar excepciones

throws declara que un método puede propagar una excepción comprobada. El código que lo llama deberá gestionarla o declararla también.

void leerArchivo() throws IOException {
    // Leer datos
}

Declaración: throws; lanzamiento: throw

Gestionar recursos

try-with-resources cierra automáticamente los recursos que implementan AutoCloseable. 

try (Scanner entrada = new Scanner(archivo)) {
    while (entrada.hasNextLine()) {
        System.out.println(entrada.nextLine());
    }
}

El recurso se declara entre paréntesis tras try

Lanzar una excepción

throw lanza una excepción cuando detectas una situación inválida. Es la forma habitual de validar los datos que recibe un método.

static void establecerEdad(int edad) {
    if (edad < 0) {
        throw new IllegalArgumentException("La edad no puede ser negativa");
    }
}

Usa un mensaje que explique qué ha fallado.

Crear una excepción propia

Puedes definir tus propias excepciones heredando de Exception (comprobada) o RuntimeException (no comprobada). Dan nombre a los errores propios de tu programa.

class SaldoInsuficienteException extends Exception {
    SaldoInsuficienteException(String mensaje) {
        super(mensaje);
    }
}

Por convención, el nombre termina en Exception.

Varios catch y multi-catch

Puedes encadenar varios catch: pon primero los más específicos y al final los generales. Si dos excepciones se tratan igual, sepáralas con |.

try {
    // código
} catch (NumberFormatException | ArithmeticException e) {
    System.out.println("Dato incorrecto: " + e.getMessage());
} catch (Exception e) {
    System.out.println("Error inesperado");
}

Un catch general no debe ir antes que uno específico.

Excepciones comprobadas y no comprobadas

Las comprobadas (como IOException) obligan a capturarlas o declararlas con throws. Las no comprobadas (subclases de RuntimeException) indican normalmente un fallo de programación y no obligan a nada.

// Comprobada: el compilador lo exige
try { Files.readString(Path.of("a.txt")); }
catch (IOException e) { }

// No comprobada: no se exige capturarla
int[] a = new int[2];
a[5] = 1;   // ArrayIndexOutOfBoundsException

Jerarquía: Throwable → Exception → RuntimeException.

Excepciones más frecuentes

NullPointerException (usar una referencia nula), ArrayIndexOutOfBoundsException (índice fuera de rango), NumberFormatException (texto que no es un número), ClassCastException (conversión de tipo incorrecta) e InputMismatchException (dato inesperado en Scanner).

String s = null;
s.length();                  // NullPointerException
int[] a = new int[3];
a[3] = 1;                    // ArrayIndexOutOfBoundsException
Integer.parseInt("abc");     // NumberFormatException

Lee el mensaje: indica la clase de error y la línea donde ocurrió.

Leer un mensaje de error

Una traza de pila muestra la excepción y, línea a línea, el recorrido de llamadas. Empieza por la primera línea de tu propio código: ahí suele estar el problema.

try {
    Integer.parseInt("x");
} catch (NumberFormatException e) {
    System.out.println(e.getMessage());
    e.printStackTrace();
}

Métodos útiles: getMessage() y printStackTrace().

Errores de sintaxis, de ejecución y de lógica

Los errores de sintaxis los detecta el compilador; los de ejecución (excepciones) ocurren al correr el programa; los de lógica no dan error pero producen resultados incorrectos y son los más difíciles de encontrar.

int x = 5            // sintaxis: falta ;
int y = 10 / 0;      // ejecución: ArithmeticException
double media = a + b / 2;   // lógica: falta paréntesis

Depura con println o con el depurador del IDE.

Excepción con causa

Al relanzar una excepción, pasa la original como causa para no perder información.

try {
    Files.readString(Path.of("a.txt"));
} catch (IOException e) {
    throw new IllegalStateException("No se pudo cargar la configuración", e);
}

Método: getCause()

Aserciones: assert

assert comprueba una condición durante el desarrollo; está desactivada por defecto y se activa con java -ea.

int edad = 20;
assert edad >= 0 : "La edad no puede ser negativa";

No uses assert para validar datos de entrada.

Registro de eventos: logging

En lugar de System.out.println, los programas reales usan un sistema de registro con niveles (INFO, WARNING, SEVERE...).

import java.util.logging.*;

Logger log = Logger.getLogger(Main.class.getName());
log.info("Programa iniciado");
log.warning("Quedan pocos recursos");
log.log(Level.SEVERE, "Fallo", excepcion);

Librerías populares: SLF4J, Log4j2, Logback

StackOverflowError y OutOfMemoryError

Son errores (no excepciones) de la JVM: StackOverflowError por recursión sin fin y OutOfMemoryError por falta de memoria. No se suelen capturar: se corrige la causa.

static void infinito() { infinito(); }   // StackOverflowError

Clase base: Error, distinta de Exception.

Validar datos de entrada

Antes de usar un dato, comprueba que es válido y lanza una excepción clara o pide de nuevo el valor.

static int leerEdad(Scanner in) {
    while (true) {
        try {
            int e = Integer.parseInt(in.nextLine().trim());
            if (e >= 0 && e <= 120) return e;
            System.out.println("Fuera de rango");
        } catch (NumberFormatException ex) {
            System.out.println("Escribe un número");
        }
    }
}

Patrón: bucle hasta que el dato sea válido.

Guardar grupos de elementos

Colecciones

Lista dinámica: ArrayList

ArrayList permite guardar una lista cuyo tamaño puede cambiar. Usa tipos envoltorio, como Integer, en los genéricos.

List<String> nombres = new ArrayList<>();
nombres.add("Ana");
nombres.add("Luis");

Imports: java.util.List y java.util.ArrayList

Mapa de clave y valor

HashMap asocia claves con valores. Las claves son únicas; usa put para añadir o reemplazar y get para consultar.

Map<String, Integer> edades = new HashMap<>();
edades.put("Ana", 20);
int edad = edades.get("Ana");

Interfaz: Map<K, V>

Conjunto sin duplicados

Set representa una colección de elementos únicos. HashSet no garantiza un orden concreto al recorrer sus elementos.

Set<String> etiquetas = new HashSet<>();
etiquetas.add("Java");
etiquetas.add("Java"); // No duplica el valor

Interfaz: Set<E>

Genéricos

Los genéricos indican qué tipos acepta una colección y permiten detectar incompatibilidades antes de ejecutar el programa.

List<Integer> edades = new ArrayList<>();
edades.add(20);

Tipo de elemento: <Integer>

Recorrer un mapa

Para recorrer un Map puedes iterar sobre sus entradas (pares clave-valor), sobre las claves o solo sobre los valores.

Map<String, Integer> edades = new HashMap<>();
edades.put("Ana", 30);
edades.put("Luis", 25);

for (Map.Entry<String, Integer> e : edades.entrySet()) {
    System.out.println(e.getKey() + " -> " + e.getValue());
}

Otras vistas: keySet() y values().

Ordenar una lista

Collections.sort o lista.sort ordenan en orden natural. Con un Comparator puedes elegir el criterio, incluso encadenar varios.

List<String> nombres = new ArrayList<>(List.of("Luis", "Ana", "Beto"));
Collections.sort(nombres);
nombres.sort(Comparator.comparing(String::length));
nombres.sort(Comparator.reverseOrder());

Para tus propias clases, usa Comparator o implementa Comparable.

Colas y pilas

Una cola (Queue) funciona como una fila: el primero en entrar es el primero en salir. ArrayDeque también sirve como pila (push y pop).

Queue<String> cola = new LinkedList<>();
cola.offer("A"); cola.offer("B");
System.out.println(cola.poll());   // A

Deque<Integer> pila = new ArrayDeque<>();
pila.push(1); pila.push(2);
System.out.println(pila.pop());    // 2

poll devuelve null si la cola está vacía.

Programar contra la interfaz

Declara la variable con la interfaz (List, Set, Map) y crea el objeto con la implementación. Así podrás cambiar de ArrayList a LinkedList sin tocar el resto del código.

List<String> lista = new ArrayList<>();
Set<String> conjunto = new HashSet<>();
Map<String, Integer> mapa = new HashMap<>();

El operador diamante <> evita repetir el tipo genérico.

HashMap, LinkedHashMap y TreeMap

HashMap no garantiza ningún orden; LinkedHashMap mantiene el orden de inserción; TreeMap ordena por clave. Lo mismo ocurre con HashSet, LinkedHashSet y TreeSet.

Map<String, Integer> m = new TreeMap<>();
m.put("pera", 2);
m.put("manzana", 5);
System.out.println(m);   // {manzana=5, pera=2}

Elige según necesites orden o máxima velocidad.

Colecciones inmutables

List.of, Set.of y Map.of crean colecciones que no se pueden modificar: añadir o eliminar elementos lanza UnsupportedOperationException.

List<String> dias = List.of("L", "M", "X");
// dias.add("J");   // UnsupportedOperationException
List<String> editable = new ArrayList<>(dias);
editable.add("J");

Para modificarlas, copia su contenido en un ArrayList.

Eliminar mientras recorres

Eliminar elementos dentro de un for-each provoca ConcurrentModificationException. Usa removeIf o un Iterator.

List<Integer> n = new ArrayList<>(List.of(1, 2, 3, 4));
n.removeIf(x -> x % 2 == 0);
System.out.println(n);   // [1, 3]

Alternativa clásica: Iterator con it.remove().

Utilidades de Collections

La clase Collections incluye métodos para buscar el máximo y el mínimo, invertir, mezclar o contar repeticiones.

List<Integer> n = new ArrayList<>(List.of(4, 1, 7, 1));
Collections.max(n);            // 7
Collections.min(n);            // 1
Collections.frequency(n, 1);   // 2
Collections.reverse(n);
Collections.shuffle(n);

No confundir Collection (interfaz) con Collections (utilidades).

Contar con un mapa: merge

Un Map sirve para contar repeticiones. getOrDefault y merge evitan comprobar si la clave existe.

Map<String, Integer> conteo = new HashMap<>();
for (String p : new String[]{"a", "b", "a"}) {
    conteo.merge(p, 1, Integer::sum);
}
System.out.println(conteo);   // {a=2, b=1}

Equivalente: conteo.put(p, conteo.getOrDefault(p, 0) + 1)

Operaciones con conjuntos

Con Set se pueden hacer operaciones de conjuntos: unión (addAll), intersección (retainAll) y diferencia (removeAll).

Set<Integer> a = new HashSet<>(List.of(1, 2, 3));
Set<Integer> b = new HashSet<>(List.of(2, 3, 4));

Set<Integer> union = new HashSet<>(a);   union.addAll(b);      // 1,2,3,4
Set<Integer> inter = new HashSet<>(a);   inter.retainAll(b);   // 2,3
Set<Integer> dif   = new HashSet<>(a);   dif.removeAll(b);     // 1

Copia el conjunto antes de modificarlo.

PriorityQueue: cola con prioridad

Una PriorityQueue devuelve siempre el elemento de mayor prioridad (por defecto, el menor).

PriorityQueue<Integer> pq = new PriorityQueue<>();
pq.add(5); pq.add(1); pq.add(3);
System.out.println(pq.poll());   // 1

PriorityQueue<Integer> mayor = new PriorityQueue<>(Comparator.reverseOrder());

Métodos: add, peek, poll

Iterator: recorrer y eliminar

Un Iterator permite recorrer una colección y eliminar elementos de forma segura.

Iterator<Integer> it = lista.iterator();
while (it.hasNext()) {
    if (it.next() % 2 == 0) it.remove();
}

Métodos: hasNext, next, remove

ArrayList frente a LinkedList

ArrayList accede muy rápido por posición pero es más lento al insertar en medio; LinkedList inserta rápido en los extremos pero es lenta por posición. En la práctica, ArrayList es casi siempre la mejor opción.

List<String> a = new ArrayList<>();    // acceso rápido por índice
List<String> b = new LinkedList<>();   // buena para colas

Regla: usa ArrayList salvo que necesites una cola o pila.

Convertir entre array, lista y conjunto

Se puede pasar de un tipo de colección a otro con constructores o métodos de utilidad.

String[] arr = {"a", "b", "a"};
List<String> lista = new ArrayList<>(Arrays.asList(arr));
Set<String> conjunto = new HashSet<>(lista);
String[] otra = lista.toArray(new String[0]);
List<Integer> n = Arrays.stream(new int[]{1, 2}).boxed().toList();

Métodos: Arrays.asList, toArray, List.copyOf

remove: por índice o por valor

En una List<Integer>, remove(int) elimina por posición y remove(Object) por valor. Para borrar el valor 5, hay que pasar un objeto.

List<Integer> l = new ArrayList<>(List.of(10, 20, 5));
l.remove(1);                    // quita la posición 1 (20)
l.remove(Integer.valueOf(5));   // quita el valor 5

Cuidado con remove(int) frente a remove(Object).

Trozos de una lista: subList

subList(desde, hasta) devuelve una vista de una parte de la lista (el final es exclusivo). Los cambios en la vista afectan a la original.

List<Integer> n = new ArrayList<>(List.of(1, 2, 3, 4, 5));
List<Integer> parte = n.subList(1, 4);     // [2, 3, 4]
List<Integer> copia = new ArrayList<>(parte);

Haz una copia si no quieres vincularla.

computeIfAbsent, getOrDefault y putIfAbsent

Métodos del Map que evitan comprobar si la clave existe. computeIfAbsent es ideal para mapas de listas.

Map<String, List<String>> grupos = new HashMap<>();
grupos.computeIfAbsent("A", k -> new ArrayList<>()).add("Ana");
int n = conteo.getOrDefault("x", 0);
mapa.putIfAbsent("k", 1);

Métodos: computeIfAbsent, getOrDefault, putIfAbsent

TreeMap y TreeSet: orden y navegación

Mantienen sus elementos ordenados y ofrecen métodos para navegar: primero, último, anterior y siguiente.

TreeSet<Integer> t = new TreeSet<>(List.of(10, 20, 30, 40));
t.first();        // 10
t.last();         // 40
t.floor(25);      // 20 (mayor que cumple <= 25)
t.ceiling(25);    // 30
t.headSet(30);    // [10, 20]

Métodos: first, last, floor, ceiling, higher, lower

EnumMap y EnumSet

Colecciones especializadas y muy eficientes cuando las claves son valores de un enum.

Clases: EnumMap, EnumSet

Deque: pila y cola de doble extremo

Deque<Integer> d = new ArrayDeque<>();

d.pollFirst();     // 1
d.pollLast();      // 2

Métodos: addFirst, addLast, pollFirst, pollLast, peekFirst

ListIterator: recorrer en ambos sentidos

ListIterator permite recorrer una lista hacia delante y hacia atrás, y modificarla mientras se recorre.

ListIterator<String> it = lista.listIterator();

    String s = it.next();
    if (s.isEmpty()) it.remove();
    else it.set(s.toUpperCase());
}

Métodos: hasPrevious, previous, set, add

// Antiguo

Código más corto y expresivo

Lambdas y streams

Expresiones lambda

Una lambda es una función breve sin nombre: parámetros, flecha y cuerpo. Se usa donde se espera una interfaz funcional, como en forEach, removeIf o Comparator.

List<String> nombres = List.of("Ana", "Luis", "Eva");
nombres.forEach(n -> System.out.println(n));

Comparator<String> porLongitud = (a, b) -> a.length() - b.length();

Sintaxis: (parámetros) -> expresión o (parámetros) -> { cuerpo }

Interfaces funcionales

Una interfaz funcional tiene un único método abstracto. El paquete java.util.function incluye las más comunes: Predicate (devuelve booleano), Function (transforma), Consumer (consume) y Supplier (produce).

Predicate<Integer> esPar = n -> n % 2 == 0;
Function<String, Integer> longitud = String::length;
Consumer<String> mostrar = System.out::println;
Supplier<Double> azar = Math::random;

esPar.test(4);            // true
longitud.apply("Java");   // 4

Cada una tiene su método: test, apply, accept, get.

Referencias a métodos

Cuando una lambda solo llama a un método existente, puedes escribir una referencia con ::, que es más corta y legible.

nombres.forEach(System.out::println);
// equivale a: n -> System.out.println(n)
nombres.stream().map(String::toUpperCase).toList();

Formas: Clase::método, objeto::método, Clase::new

Streams: filtrar y transformar

Un stream procesa los datos de una colección como una cadena de pasos: filtrar, transformar y recoger el resultado. No modifica la colección original.

List<Integer> numeros = List.of(1, 2, 3, 4, 5, 6);
List<Integer> doblesPares = numeros.stream()
    .filter(n -> n % 2 == 0)
    .map(n -> n * 2)
    .toList();
System.out.println(doblesPares);   // [4, 8, 12]

toList() está disponible desde Java 16.

Operaciones finales de stream

Tras filtrar o transformar, una operación final produce el resultado: contar, sumar, calcular la media, comprobar condiciones o buscar el primer elemento. Otras operaciones intermedias: sorted, distinct y limit.

long cuantos = numeros.stream().filter(n -> n > 2).count();
int suma = numeros.stream().mapToInt(Integer::intValue).sum();
boolean hayPares = numeros.stream().anyMatch(n -> n % 2 == 0);
var primero = numeros.stream().findFirst();

Un stream solo puede consumirse una vez.

Agrupar con streams

La clase Collectors permite agrupar elementos por un criterio, contarlos o unirlos en un texto.

List<String> palabras = List.of("sol", "mar", "cielo", "luna");

Map<Integer, List<String>> porLongitud = palabras.stream()
    .collect(Collectors.groupingBy(String::length));

String texto = palabras.stream().collect(Collectors.joining(", "));

Resultado de porLongitud: {3=[sol, mar], 5=[cielo], 4=[luna]}

Optional

Optional representa un valor que puede estar o no. Obliga a pensar en el caso «no hay resultado» y evita devolver null.

Optional<String> primero = nombres.stream()
    .filter(n -> n.startsWith("L"))
    .findFirst();

System.out.println(primero.orElse("ninguno"));
primero.ifPresent(System.out::println);

Métodos: isPresent, orElse, ifPresent, map.

Streams: sorted, distinct, limit, skip

Operaciones intermedias frecuentes: sorted (ordenar), distinct (quitar repetidos), limit (primeros n) y skip (saltar n).

List<Integer> r = Stream.of(5, 3, 5, 1, 9)
    .distinct()
    .sorted()
    .skip(1)
    .limit(2)
    .toList();       // [3, 5]

Son perezosas: no se ejecutan sin operación final.

flatMap: aplanar listas

flatMap convierte cada elemento en un stream y los une en uno solo. Sirve para aplanar listas de listas.

List<List<Integer>> grupos = List.of(List.of(1, 2), List.of(3), List.of(4, 5));
List<Integer> planas = grupos.stream().flatMap(List::stream).toList();

Resultado: [1, 2, 3, 4, 5]

Collectors: toMap, partitioningBy, counting

Collectors ofrece muchas formas de recoger resultados: mapas, particiones en dos grupos, conteos, sumas y medias.

Map<String, Integer> longitudes = palabras.stream()
    .collect(Collectors.toMap(p -> p, String::length));

Map<Boolean, List<Integer>> parImpar = numeros.stream()
    .collect(Collectors.partitioningBy(n -> n % 2 == 0));

Map<Integer, Long> porLongitud = palabras.stream()
    .collect(Collectors.groupingBy(String::length, Collectors.counting()));

Colectores: toMap, partitioningBy, counting, summingInt

IntStream y rangos

IntStream.range genera una secuencia de números. mapToInt convierte un stream de objetos en uno de enteros, con métodos como sum, average o summaryStatistics.

IntStream.rangeClosed(1, 5).sum();            // 15
IntStream.range(0, 3).forEach(System.out::println);
IntSummaryStatistics st = lista.stream().mapToInt(Integer::intValue).summaryStatistics();
st.getMax(); st.getAverage();

Métodos: range, rangeClosed, sum, average, max

Predicate y Function: combinar

Las interfaces funcionales se pueden combinar: and, or y negate en Predicate; andThen y compose en Function.

Predicate<Integer> par = n -> n % 2 == 0;
Predicate<Integer> mayor10 = n -> n > 10;
Predicate<Integer> ambos = par.and(mayor10);
Predicate<Integer> impar = par.negate();

Function<Integer, Integer> doble = n -> n * 2;
Function<Integer, Integer> masUno = n -> n + 1;
doble.andThen(masUno).apply(5);   // 11

Métodos: and, or, negate, andThen, compose

Optional: map, filter y orElseThrow

Optional admite transformaciones encadenadas y diferentes formas de obtener el valor o actuar si no existe.

String nombre = Optional.ofNullable(usuario)
    .map(Usuario::nombre)
    .filter(n -> !n.isBlank())
    .orElse("Anónimo");

Optional<String> o = Optional.of("x");
o.ifPresentOrElse(System.out::println, () -> System.out.println("vacío"));
String v = o.orElseThrow();

Métodos: map, filter, orElse, orElseThrow, ifPresentOrElse

reduce y collect: resultados finales

reduce combina todos los elementos en uno; collect los recoge en una colección o texto.

int suma = Stream.of(1, 2, 3).reduce(0, Integer::sum);
Optional<Integer> max = Stream.of(4, 9, 2).reduce(Integer::max);
String texto = Stream.of("a", "b").collect(Collectors.joining(", ", "[", "]"));

Operaciones finales: reduce, collect, forEach, count

Leer texto con Scanner

El detalle de nextInt() y nextLine()

nextInt() lee el número, pero deja pendiente el salto de línea. Si después llamas a nextLine(), consume ese salto y parece que se salta la pregunta; lee una línea primero para descartarlo. 

System.out.print("Edad: ");
int edad = entrada.nextInt();
entrada.nextLine(); // Consume el salto pendiente
System.out.print("Nombre: ");
String nombre = entrada.nextLine();

Alternativa: leer todo con nextLine() y convertir el texto.

Comprobar que la entrada es un número

Usa hasNextInt() antes de nextInt() para comprobar la entrada. Si no es un entero, descarta esa línea antes de volver a preguntar.

while (!entrada.hasNextInt()) {
    System.out.println("Escribe un número entero.");
    entrada.nextLine();
}
int numero = entrada.nextInt();
entrada.nextLine();

Generar un número aleatorio

El algoritmo de Euclides calcula el MCD; el MCM se obtiene a partir de él.

static boolean perfecto(int n) {

    for (int i = 1; i < n; i++) if (n % i == 0) suma += i;
    return n > 1 && suma == n;
}

Ordenación de burbuja

Compara pares contiguos y los intercambia si están desordenados; se repite hasta que no hay cambios.

static void burbuja(int[] a) {
    for (int i = 0; i < a.length - 1; i++) {
        for (int j = 0; j < a.length - 1 - i; j++) {
            if (a[j] > a[j + 1]) {
                int t = a[j]; a[j] = a[j + 1]; a[j + 1] = t;
            }
        }
    }
}

Complejidad: O(n²). En la práctica, usa Arrays.sort.

Búsqueda binaria

En un array ordenado, se compara con el elemento central y se descarta la mitad en cada paso.

static int buscar(int[] a, int x) {
    int ini = 0, fin = a.length - 1;
    while (ini <= fin) {
        int m = (ini + fin) >>> 1;
        if (a[m] == x) return m;
        if (a[m] < x) ini = m + 1; else fin = m - 1;
    }
    return -1;
}

Complejidad: O(log n)

wait y notify: coordinar hilos

Dentro de un bloque synchronized, wait() suspende el hilo hasta que otro llama a notify(). Es el mecanismo clásico productor-consumidor (hoy se prefiere BlockingQueue).

synchronized (cola) {
    while (cola.isEmpty()) cola.wait();
    var dato = cola.remove();
}
synchronized (cola) { cola.add(1); cola.notifyAll(); }

Alternativa: BlockingQueue

Cola bloqueante: productor y consumidor

BlockingQueue bloquea al consumidor si está vacía y al productor si está llena, sin necesidad de wait/notify.

BlockingQueue<Integer> q = new LinkedBlockingQueue<>(10);
new Thread(() -> { try { for (int i = 0; i < 5; i++) q.put(i); } catch (InterruptedException e) { } }).start();
new Thread(() -> { try { while (true) System.out.println(q.take()); } catch (InterruptedException e) { } }).start();

Métodos: put, take, offer, poll

Bloqueos explícitos: ReentrantLock

ReentrantLock ofrece más control que synchronized: intentar bloquear sin esperar, con tiempo límite o de forma interrumpible. Siempre se libera en un finally.

Lock l = new ReentrantLock();
l.lock();
try { /* sección crítica */ }
finally { l.unlock(); }

if (l.tryLock(1, TimeUnit.SECONDS)) { try { } finally { l.unlock(); } }

Métodos: lock, unlock, tryLock

CountDownLatch latch = new CountDownLatch(3);

Principios SOLID

Cinco principios de diseño orientado a objetos: responsabilidad única, abierto/cerrado, sustitución de Liskov, segregación de interfaces e inversión de dependencias.

S  una clase, una responsabilidad
O  abierta a extensión, cerrada a modificación
L  una subclase puede sustituir a su padre
I  interfaces pequeñas y específicas

Cómo organizar datos y resolver problemas

Estructuras de datos y algoritmos

Notación Big O: complejidad

La notación Big O describe cómo crece el coste de un algoritmo con el tamaño de los datos: O(1) constante, O(log n) logarítmico, O(n) lineal, O(n log n) y O(n²) cuadrático.

O(1)        acceder a array[i]
O(log n)    búsqueda binaria
O(n)        recorrer una lista
O(n log n)  ordenar con merge sort
O(n²)       bucles anidados (burbuja)

Menor crecimiento = más escalable.

Lista enlazada propia

Una lista enlazada se compone de nodos, cada uno con un dato y una referencia al siguiente.

class Nodo<T> { T dato; Nodo<T> sig; Nodo(T d) { dato = d; } }

class Lista<T> {
    private Nodo<T> cabeza;
    void añadirAlFinal(T d) {
        Nodo<T> n = new Nodo<>(d);
        if (cabeza == null) { cabeza = n; return; }
        Nodo<T> a = cabeza;
        while (a.sig != null) a = a.sig;
        a.sig = n;
    }
}

Insertar al principio: O(1); acceder por posición: O(n)

Pila propia con array

Una pila (LIFO) se puede implementar con un array y un índice al tope.

class Pila {
    private final int[] datos = new int[100];
    private int tope = 0;
    void push(int x) { datos[tope++] = x; }
    int pop() { return datos[--tope]; }
    int peek() { return datos[tope - 1]; }
    boolean vacia() { return tope == 0; }
}

Usos: deshacer, paréntesis balanceados, recursión.

Paréntesis balanceados con una pila

Un clásico: comprobar que cada paréntesis, corchete o llave se cierra correctamente.

static boolean balanceado(String s) {
    Deque<Character> p = new ArrayDeque<>();
    for (char c : s.toCharArray()) {
        if ("([{".indexOf(c) >= 0) p.push(c);
        else if (")]}".indexOf(c) >= 0) {
            if (p.isEmpty()) return false;
            char a = p.pop();
            if ("([{".indexOf(a) != ")]}".indexOf(c)) return false;
        }
    }
    return p.isEmpty();
}

Estructura clave: pila.

Cola circular con array

Una cola circular reutiliza el espacio del array usando el operador módulo.

class Cola {
    private final int[] d = new int[5];
    private int ini = 0, n = 0;
    void encolar(int x) { d[(ini + n++) % d.length] = x; }
    int desencolar() { int x = d[ini]; ini = (ini + 1) % d.length; n--; return x; }
}

Operador clave: % longitud

Árbol binario de búsqueda

En un árbol binario de búsqueda, los valores menores van a la izquierda y los mayores a la derecha.

class Nodo { int v; Nodo izq, der; Nodo(int v) { this.v = v; } }

static Nodo insertar(Nodo r, int x) {
    if (r == null) return new Nodo(x);
    if (x < r.v) r.izq = insertar(r.izq, x);
    else if (x > r.v) r.der = insertar(r.der, x);
    return r;
}
static boolean buscar(Nodo r, int x) {
    if (r == null) return false;
    return x == r.v || (x < r.v ? buscar(r.izq, x) : buscar(r.der, x));
}

Búsqueda: O(log n) si el árbol está equilibrado.

Recorridos de un árbol: inorden, preorden y postorden

Inorden (izquierda, raíz, derecha) en un árbol de búsqueda da los valores ordenados.

static void inorden(Nodo r) {
    if (r == null) return;
    inorden(r.izq);
    System.out.print(r.v + " ");
    inorden(r.der);
}
// preorden: raíz, izq, der · postorden: izq, der, raíz

Por niveles: usa una cola.

g.computeIfAbsent("A", k -> new ArrayList<>()).add("B");
g.computeIfAbsent("A", k -> new ArrayList<>()).add("C");
g.computeIfAbsent("B", k -> new ArrayList<>()).add("D");

Alternativa: matriz de adyacencia.

Recorrido de grafos: BFS y DFS

BFS (en anchura) usa una cola y encuentra el camino con menos pasos; DFS (en profundidad) usa una pila o recursión.

static void bfs(Map<String, List<String>> g, String ini) {
    Set<String> vistos = new HashSet<>(Set.of(ini));
    Queue<String> q = new ArrayDeque<>(List.of(ini));
    while (!q.isEmpty()) {
        String n = q.poll();
        System.out.println(n);
        for (String v : g.getOrDefault(n, List.of()))
            if (vistos.add(v)) q.add(v);
    }
}

Marca los nodos visitados para no repetir.

Ordenación por selección

Busca el menor elemento del resto y lo coloca en su posición.

static void seleccion(int[] a) {
    for (int i = 0; i < a.length - 1; i++) {
        int m = i;
        for (int j = i + 1; j < a.length; j++) if (a[j] < a[m]) m = j;
        int t = a[i]; a[i] = a[m]; a[m] = t;
    }
}

Complejidad: O(n²)

Ordenación por inserción

Va construyendo una parte ordenada insertando cada elemento en su sitio. Es eficiente con listas casi ordenadas.

static void insercion(int[] a) {
    for (int i = 1; i < a.length; i++) {
        int x = a[i], j = i - 1;
        while (j >= 0 && a[j] > x) { a[j + 1] = a[j]; j--; }
        a[j + 1] = x;
    }
}

Complejidad: O(n²), O(n) si ya está ordenado.

Ordenación por mezcla: merge sort

Divide el array en mitades, las ordena recursivamente y las mezcla.

static int[] mergeSort(int[] a) {
    if (a.length < 2) return a;
    int[] izq = mergeSort(Arrays.copyOfRange(a, 0, a.length / 2));
    int[] der = mergeSort(Arrays.copyOfRange(a, a.length / 2, a.length));
    int[] r = new int[a.length];
    int i = 0, j = 0, k = 0;
    while (i < izq.length && j < der.length) r[k++] = izq[i] <= der[j] ? izq[i++] : der[j++];
    while (i < izq.length) r[k++] = izq[i++];
    while (j < der.length) r[k++] = der[j++];
    return r;
}

Complejidad: O(n log n)

Ordenación rápida: quicksort

Elige un pivote, coloca los menores a un lado y los mayores a otro, y repite en cada parte.

static void quick(int[] a, int lo, int hi) {
    if (lo >= hi) return;
    int p = a[hi], i = lo;
    for (int j = lo; j < hi; j++)
        if (a[j] < p) { int t = a[i]; a[i] = a[j]; a[j] = t; i++; }
    int t = a[i]; a[i] = a[hi]; a[hi] = t;
    quick(a, lo, i - 1); quick(a, i + 1, hi);
}

Promedio: O(n log n); peor caso: O(n²)

Torres de Hanoi

Un problema clásico de recursión: mover n discos de una varilla a otra usando una auxiliar.

static void hanoi(int n, char a, char b, char c) {
    if (n == 0) return;
    hanoi(n - 1, a, c, b);
    System.out.println("Mover disco " + n + " de " + a + " a " + c);
    hanoi(n - 1, b, a, c);
}
hanoi(3, 'A', 'B', 'C');     // 2^n - 1 movimientos

Movimientos necesarios: 2ⁿ − 1

Backtracking: problema de las N reinas

El backtracking prueba una opción, avanza y, si falla, deshace y prueba otra.

static boolean valido(int[] col, int fila, int c) {
    for (int i = 0; i < fila; i++)
        if (col[i] == c || Math.abs(col[i] - c) == fila - i) return false;
    return true;
}
static int reinas(int[] col, int fila) {
    if (fila == col.length) return 1;
    int n = 0;
    for (int c = 0; c < col.length; c++)
        if (valido(col, fila, c)) { col[fila] = c; n += reinas(col, fila + 1); }
    return n;
}

Para 8 reinas hay 92 soluciones.

Programación dinámica: cambio de monedas y mochila

Se guarda la solución de los subproblemas para no recalcularla.

static int minMonedas(int[] monedas, int total) {
    int[] dp = new int[total + 1];
    Arrays.fill(dp, Integer.MAX_VALUE);
    dp[0] = 0;
    for (int t = 1; t <= total; t++)
        for (int m : monedas)
            if (m <= t && dp[t - m] != Integer.MAX_VALUE) dp[t] = Math.min(dp[t], dp[t - m] + 1);
    return dp[total] == Integer.MAX_VALUE ? -1 : dp[total];
}

Idea: tabla de resultados parciales.

Tablas hash: cómo funciona un HashMap

Un HashMap calcula el hashCode de la clave para decidir en qué «cubo» guardarla. Si dos claves caen en el mismo cubo (colisión), se comparan con equals. Por eso equals y hashCode deben ser coherentes.

int cubo = (clave.hashCode() & 0x7fffffff) % 16;
