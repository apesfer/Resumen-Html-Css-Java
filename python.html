Fundamentos

Qué es Python y para qué sirve

Python es un lenguaje interpretado, de sintaxis clara y tipado dinámico. Se usa en automatización, web, análisis de datos, inteligencia artificial y enseñanza.

print("Hola, mundo")

Creado por Guido van Rossum; extensión de archivo: .py

Instalar Python y comprobar la versión

Descarga Python desde python.org o usa el gestor de tu sistema. Comprueba la instalación desde la terminal.

python --version      # o python3 --version
pip --version

En Linux y macOS suele ser python3.

Ejecutar un programa y el intérprete interactivo

Un archivo se ejecuta con python archivo.py. Sin argumentos, python abre el intérprete interactivo (REPL).

python hola.py

Comentarios y docstrings

Los comentarios empiezan con #. Un texto entre triples comillas al inicio de una función o clase es un docstring, que help() muestra.

# Esto es un comentario
def area(r):
    """Devuelve el área de un círculo de radio r."""
    return 3.14159 * r ** 2

help(area)

Estilo de docstring: PEP 257

Indentación: los bloques se marcan con espacios

Python no usa llaves: los bloques se definen con la sangría (4 espacios por convención) tras los dos puntos. Mezclar tabuladores y espacios provoca errores.

if True:
    print("dentro del if")
    if False:
        print("más anidado")
print("fuera")

Error típico: IndentationError

Mostrar datos: print

print muestra valores separados por espacios. Los parámetros sep y end cambian el separador y el final de línea.

print("a", "b", "c")                  # a b c
print("a", "b", sep="-")              # a-b
print("sin salto", end="")
print("Total:", 5 + 3)

Parámetros: sep, end, file

Leer datos del teclado: input

input() devuelve siempre texto (str): si esperas un número, conviértelo.

nombre = input("¿Cómo te llamas? ")
edad = int(input("Edad: "))
print(f"Hola, {nombre}. Tienes {edad} años.")

Conversión: int(), float()

El estilo PEP 8

PEP 8 es la guía de estilo oficial: nombres en snake_case, clases en PascalCase, constantes en MAYÚSCULAS, 4 espacios de sangría y líneas de unos 79 caracteres. Herramientas: black, ruff, flake8.

nombre_usuario = "ana"          # variable
MAX_INTENTOS = 3                # constante
class CuentaBancaria: ...       # clase
def calcular_total(): ...       # función

Formateador automático: black

Guardar y convertir datos

Variables y tipos

Variables y asignación

Una variable se crea al asignarle un valor y no necesita declarar el tipo. Se pueden asignar varias a la vez.

edad = 30
nombre = "Ana"
a, b = 1, 2
x = y = 0
a, b = b, a          # intercambio

Python distingue mayúsculas de minúsculas.

Tipos básicos: int, float, str, bool y None

Los tipos básicos son int (enteros de tamaño ilimitado), float (decimales), str (texto), bool (True/False) y NoneType (None, ausencia de valor).

type(5)            # <class 'int'>
type(3.14)         # <class 'float'>
type("hola")       # <class 'str'>
type(True)         # <class 'bool'>
isinstance(5, int) # True

Funciones: type(), isinstance()

Conversión de tipos

Las funciones con el nombre del tipo convierten valores. Si el texto no es válido, se lanza ValueError.

int("42")          # 42
float("3.5")       # 3.5
str(100)           # "100"
bool(0)            # False
list("abc")        # ['a', 'b', 'c']
int("hola")        # ValueError

Valores falsos: 0, "", [], {}, None

Números: operaciones y funciones

Funciones integradas para trabajar con números: abs, round, pow, divmod, sum, min y max.

abs(-5)            # 5
round(3.14159, 2)  # 3.14
pow(2, 10)         # 1024
divmod(17, 5)      # (3, 2)
sum([1, 2, 3])     # 6
max(4, 9, 2)       # 9

round usa redondeo bancario (2.5 → 2).

Precisión de decimales: Decimal y Fraction

Los float tienen errores de representación. Para dinero se usa Decimal; para fracciones exactas, Fraction.

0.1 + 0.2                          # 0.30000000000000004
from decimal import Decimal
Decimal("0.1") + Decimal("0.2")    # Decimal('0.3')
from fractions import Fraction
Fraction(1, 3) + Fraction(1, 6)    # Fraction(1, 2)

Módulos: decimal, fractions

Números grandes y notación

Se pueden separar cifras con _ y escribir en otras bases con prefijos.

1_000_000          # un millón
0xFF               # 255
0b1010             # 10
0o17               # 15
1.5e3              # 1500.0
bin(10), hex(255)  # ('0b1010', '0xff')

Prefijos: 0x, 0b, 0o

Booleanos y valores verdaderos o falsos

En una condición, se consideran falsos False, None, 0, 0.0, las cadenas y colecciones vacías. Todo lo demás es verdadero.

if []:      print("no entra")
if "hola":  print("entra")
bool("")    # False
bool(" ")   # True

Función: bool()

None: ausencia de valor

None representa «sin valor». Se compara con is, no con ==. Una función sin return devuelve None.

resultado = None
if resultado is None:
    print("sin resultado")
def f(): pass
print(f())       # None

Usa is None / is not None.

Identidad frente a igualdad: is y ==

== compara el valor; is comprueba si son el mismo objeto en memoria. Para comparar valores usa ==.

a = [1, 2]
b = [1, 2]
a == b      # True
a is b      # False
id(a), id(b)

is se reserva para None, True y False.

Mutables e inmutables

Los tipos inmutables (int, str, tuple, frozenset) no cambian; los mutables (list, dict, set) sí. Asignar una lista no la copia: ambas variables apuntan al mismo objeto.

a = [1, 2]
b = a
b.append(3)
print(a)             # [1, 2, 3]
c = a.copy()         # copia independiente

Copia profunda: copy.deepcopy()

Constantes y nombres especiales

Python no tiene constantes reales; por convención se escriben en mayúsculas. Un guion bajo inicial (_x) indica uso interno.

PI = 3.14159
_cache = {}
if __name__ == "__main__":
    print("Se ejecuta como programa principal")

Idioma habitual: if __name__ == "__main__":

Calcular, comparar y decidir

Operadores

Operadores aritméticos

Además de + - * / hay división entera (//), resto (%) y potencia (**). La división / siempre devuelve float.

7 / 2        # 3.5
7 // 2       # 3
7 % 2        # 1
2 ** 10      # 1024
-7 // 2      # -4 (hacia abajo)

Operadores: + - * / // % **

Operadores de asignación

Las asignaciones compuestas combinan una operación con la asignación. El operador morsa := asigna dentro de una expresión.

n = 10
n += 5          # 15
n *= 2          # 30
if (m := len("hola")) > 3:
    print(m)

No existen ++ ni -- en Python.

Operadores de comparación y encadenados

Python permite encadenar comparaciones de forma natural.

x = 5
1 < x < 10          # True
x == 5 and x != 3
"a" < "b"           # True (orden alfabético)

Operadores: == != < > <= >=

Operadores lógicos: and, or y not

and, or y not se escriben en inglés y funcionan en cortocircuito. Devuelven uno de los operandos, no necesariamente un booleano.

edad = 20
edad >= 18 and edad < 65
not edad
nombre = "" or "Anónimo"       # "Anónimo"
usuario and usuario.nombre

or se usa para valores por defecto.

Pertenencia: in y not in

in comprueba si un elemento está en una colección o una subcadena en un texto.

3 in [1, 2, 3]            # True
"ho" in "hola"            # True
"a" in {"a": 1}           # True (busca claves)
5 not in (1, 2, 3)        # True

Es muy rápido en set y dict.

Operadores de bits

Operan sobre los bits de los enteros: AND &, OR |, XOR ^, NOT ~ y desplazamientos << y >>.

0b1100 & 0b1010     # 8
0b1100 | 0b1010     # 14
5 ^ 3               # 6
1 << 4              # 16
~5                  # -6

Útiles para banderas y máscaras.

Operador ternario

Una expresión condicional elige entre dos valores en una línea.

edad = 20
estado = "adulto" if edad >= 18 else "menor"

Sintaxis: valor_si if condición else valor_no

Precedencia de operadores

De mayor a menor prioridad: paréntesis, **, signos unarios, * / // %, + -, comparaciones, not, and, or.

2 + 3 * 4        # 14
(2 + 3) * 4      # 20
-2 ** 2          # -4
not True or True # True

Ante la duda, usa paréntesis.

03

Trabajar con texto

Cadenas de texto

Cadenas: crear y comillas

Las cadenas pueden ir entre comillas simples, dobles o triples (varias líneas). Un prefijo r desactiva las secuencias de escape.

a = 'hola'
b = "Dijo: \"hola\""
c = """Línea 1
Línea 2"""
ruta = r"C:\nuevo\carpeta"

Escapes: \n, \t, \\, \"

f-strings: formatear texto

Los f-strings insertan expresiones dentro de la cadena y admiten formato.

nombre, nota = "Ana", 8.456
f"Hola, {nombre}"
f"Nota: {nota:.1f}"              # 8.5
f"{1234567:,}"                   # 1,234,567
f"{'x':>5}|{'x':<5}|{'x':^5}"
f"{nombre=}"                     # nombre='Ana'

Formatos: :.2f, :,, :>10, :05d, :%

Indexar y trocear cadenas (slicing)

Los índices empiezan en 0 y los negativos cuentan desde el final. [inicio:fin:paso] extrae trozos (el final es exclusivo).

s = "Python"
s[0]          # 'P'
s[-1]         # 'n'
s[1:4]        # 'yth'
s[:2]         # 'Py'
s[::-1]       # 'nohtyP'
s[::2]        # 'Pto'

Funciona igual en listas y tuplas.

Métodos de cadenas: mayúsculas, espacios y búsqueda

Las cadenas son inmutables: los métodos devuelven una nueva.

t = "  Hola Mundo  "
t.strip()                  # 'Hola Mundo'
t.upper(); t.lower(); t.title()
"a,b,c".split(",")         # ['a', 'b', 'c']
"-".join(["a", "b"])       # 'a-b'
"hola".replace("o", "0")
"hola".find("l")           # 2 (o -1)
"hola".startswith("ho")

Métodos: strip, split, join, replace, find

Comprobar el contenido: isdigit, isalpha y similares

Métodos que devuelven True o False según el contenido del texto.

"123".isdigit()      # True
"abc".isalpha()      # True
"abc1".isalnum()     # True
"   ".isspace()      # True
"HOLA".isupper()     # True

Útiles para validar entradas.

Formato antiguo y str.format

Antes de los f-strings se usaban str.format y el operador %. Los verás en código antiguo.

"{} tiene {} años".format("Ana", 30)
"{0} {1} {0}".format("a", "b")
"{n}".format(n=5)
"%s tiene %d años" % ("Ana", 30)

Hoy se prefiere f-string.

Caracteres y códigos: ord y chr

ord devuelve el código de un carácter y chr el carácter de un código.

ord("A")      # 65
chr(66)       # 'B'
chr(ord("a") + 1)   # 'b'

Funciones: ord, chr

Texto con varias líneas: splitlines y textwrap

splitlines divide por saltos de línea; textwrap ajusta textos largos a un ancho.

texto = "uno\ndos\ntres"
texto.splitlines()           # ['uno', 'dos', 'tres']
import textwrap
textwrap.fill("Una frase muy larga…", width=20)

Módulo: textwrap

Codificación: bytes y UTF-8

Un str es texto Unicode; bytes son datos binarios. Se convierten con encode y decode.

b = "ñandú".encode("utf-8")      # b'\xc3\xb1and\xc3\xba'
b.decode("utf-8")                # 'ñandú'
len("ñ"), len("ñ".encode())     # (1, 2)

Usa siempre UTF-8.

Cadenas: errores frecuentes

Para concatenar texto y números hay que convertir el número (o usar f-strings). Las cadenas no se pueden modificar por índice.

"edad: " + 30          # TypeError
"edad: " + str(30)     # correcto
f"edad: {30}"
s = "hola"; s[0] = "H" # TypeError

Error: TypeError: can only concatenate str

Decidir y repetir

Condiciones y bucles

Condicionales: if, elif y else

if ejecuta un bloque si la condición es verdadera; elif añade alternativas y else, el caso final.

nota = 7
if nota >= 9:
    print("Sobresaliente")
elif nota >= 5:
    print("Aprobado")
else:
    print("Suspenso")

Los dos puntos y la sangría son obligatorios.

match: coincidencia de patrones

Desde Python 3.10, match compara un valor con varios patrones (como un switch mucho más potente).

def respuesta(codigo):
    match codigo:
        case 200: return "OK"
        case 404: return "No encontrado"
        case 500 | 503: return "Error de servidor"
        case _: return "Desconocido"

Comodín: _

Bucle for y range

for recorre cualquier iterable. range(inicio, fin, paso) genera números (el final es exclusivo).

for i in range(3):             # 0, 1, 2
    print(i)
for i in range(1, 10, 2):      # 1, 3, 5, 7, 9
    print(i)
for letra in "hola":
    print(letra)

range no incluye el valor final.

Bucle while

while repite mientras la condición sea verdadera. Asegúrate de que algo cambie para terminar.

n = 3
while n > 0:
    print(n)
    n -= 1

while True:
    r = input("Escribe 'salir': ")
    if r == "salir":
        break

Palabras clave: break, continue

break, continue, pass y else en bucles

break sale del bucle; continue salta a la siguiente vuelta; pass no hace nada. El else de un bucle se ejecuta si no hubo break.

for n in range(2, 10):
    for d in range(2, n):
        if n % d == 0:
            break
    else:
        print(n, "es primo")

def pendiente(): pass

else en bucles: se ejecuta si no hay break.

enumerate y zip

enumerate da el índice junto al valor; zip recorre varias secuencias a la vez.

for i, fruta in enumerate(["pera", "uva"], start=1):
    print(i, fruta)

for nombre, edad in zip(["Ana", "Luis"], [30, 25]):
    print(nombre, edad)

dict(zip(["a", "b"], [1, 2]))

zip se detiene en la secuencia más corta.

Recorrer al revés y ordenado: reversed y sorted

reversed recorre en orden inverso y sorted recorre una versión ordenada sin modificar el original.

for x in reversed([1, 2, 3]): print(x)
for x in sorted([3, 1, 2], reverse=True): print(x)

Funciones: reversed, sorted

Bucles anidados

Un bucle dentro de otro repite el interior completo en cada vuelta del exterior.

for i in range(1, 4):
    for j in range(1, 4):
        print(i * j, end="\t")
    print()

Útil para tablas y matrices.

Valores iterables: any, all, min, max y sum

Funciones integradas que trabajan con cualquier iterable.

nums = [3, 8, 2]
any(n > 5 for n in nums)      # True
all(n > 0 for n in nums)      # True
min(nums), max(nums), sum(nums), len(nums)

Funciones: any, all, min, max, sum

05

Agrupar y reutilizar código

Funciones

Definir una función

Una función se define con def. Sin return devuelve None.

def sumar(a, b):
    return a + b

sumar(2, 3)         # 5

Palabra clave: def

Parámetros por defecto y con nombre

Un parámetro puede tener valor por defecto, y los argumentos pueden pasarse por nombre en cualquier orden.

def saludar(nombre, saludo="Hola"):
    return f"{saludo}, {nombre}"

saludar("Ana")
saludar(saludo="Buenas", nombre="Luis")

Los parámetros con defecto van al final.

*args y **kwargs

*args recoge argumentos posicionales extra en una tupla; **kwargs, los nombrados en un diccionario.

def f(*args, **kwargs):
    print(args, kwargs)

f(1, 2, a=3)               # (1, 2) {'a': 3}
numeros = [1, 2, 3]
print(*numeros)            # desempaquetar

Orden: posicionales, *args, nombrados, **kwargs

Parámetros solo posicionales y solo con nombre

En la firma, / marca los parámetros solo posicionales y * los que deben pasarse por nombre.

def f(a, b, /, c, *, d):
    return a + b + c + d

f(1, 2, 3, d=4)
f(1, 2, c=3, d=4)

Separadores: / y *

Valores de retorno múltiples

Una función puede devolver varios valores: en realidad es una tupla.

def limites(datos):
    return min(datos), max(datos)

menor, mayor = limites([3, 9, 1])

Se desempaqueta al recibirlos.

Funciones lambda

Una lambda es una función anónima de una sola expresión.

doble = lambda x: x * 2
doble(4)                                   # 8
personas.sort(key=lambda p: p["edad"])
sorted(["bb", "a", "ccc"], key=len)

Sintaxis: lambda parámetros: expresión

map, filter y reduce

map aplica una función a cada elemento y filter se queda con los que cumplen una condición. reduce acumula.

list(map(lambda x: x * 2, [1, 2, 3]))        # [2, 4, 6]
list(filter(lambda x: x % 2 == 0, range(6))) # [0, 2, 4]
from functools import reduce
reduce(lambda a, b: a + b, [1, 2, 3, 4])     # 10

Suelen sustituirse por comprensiones.

Ámbito: local, global y nonlocal

Las variables asignadas dentro de una función son locales. Para modificar una global se declara con global; en funciones anidadas, nonlocal.

contador = 0
def incrementar():
    global contador
    contador += 1

def externa():
    n = 0
    def interna():
        nonlocal n
        n += 1
    return interna

Regla LEGB: Local, Enclosing, Global, Built-in

Funciones anidadas y clausuras

Una función interna recuerda las variables de la externa aunque esta ya haya terminado.

def multiplicador(n):
    def por(x):
        return x * n
    return por

doble = multiplicador(2)
doble(10)                # 20

Base de los decoradores.

Recursión

Una función recursiva se llama a sí misma. Necesita un caso base; Python limita la profundidad (unas 1000 llamadas).

def factorial(n):
    return 1 if n <= 1 else n * factorial(n - 1)

import sys
sys.getrecursionlimit()

Error: RecursionError

Argumento mutable por defecto: error clásico

Un valor por defecto mutable se crea una sola vez y se comparte entre llamadas. Usa None y crea la lista dentro.

def mal(x, lista=[]):
    lista.append(x); return lista
mal(1); mal(2)          # [1, 2] (¡compartida!)

def bien(x, lista=None):
    if lista is None:
        lista = []
    lista.append(x); return lista

Nunca uses [] o {} como valor por defecto.

Anotaciones de tipo

Las anotaciones indican los tipos esperados. No se comprueban al ejecutar, pero ayudan al editor y a herramientas como mypy.

def saludar(nombre: str, veces: int = 1) -> str:
    return (f"Hola, {nombre}. " * veces).strip()

edades: dict[str, int] = {"Ana": 30}
def buscar(id: int) -> str | None: ...

Módulo: typing; herramienta: mypy

Funciones integradas más útiles

Algunas funciones disponibles sin importar nada: len, range, sorted, reversed, enumerate, zip, any, all, sum, min, max, abs, round, isinstance, open, print, input, type, dir, help.

dir("texto")          # métodos disponibles
help(len)
callable(print)       # True

Explora con dir() y help().

06

Colecciones ordenadas

Listas y tuplas

Listas: crear y acceder

Una lista es una secuencia ordenada y mutable que puede mezclar tipos.

frutas = ["pera", "uva", "kiwi"]
frutas[0]            # 'pera'
frutas[-1]           # 'kiwi'
frutas[1:]           # ['uva', 'kiwi']
len(frutas)          # 3
frutas[0] = "manzana"

Se crea con [] o list().

Añadir, quitar y buscar en listas

Métodos principales para modificar listas.

l = [1, 2, 3]
l.append(4)             # [1, 2, 3, 4]
l.insert(0, 0)          # al principio
l.extend([5, 6])
l.remove(3)             # por valor
x = l.pop()             # quita y devuelve el último
del l[0]                # por posición
l.index(2); l.count(2)

Métodos: append, insert, extend, remove, pop

Ordenar listas: sort y sorted

lista.sort() ordena la propia lista; sorted(lista) devuelve una nueva. El parámetro key define el criterio.

n = [3, 1, 2]
n.sort()                         # modifica
sorted(n, reverse=True)          # copia
palabras = ["bb", "a", "ccc"]
sorted(palabras, key=len)
personas.sort(key=lambda p: (p["ciudad"], p["edad"]))

Parámetros: key, reverse

Copiar, unir y repetir listas

Asignar una lista no la copia. Para hacerlo: copy(), list() o un trozo completo.

a = [1, 2]
b = a.copy()          # o list(a), a[:]
c = a + [3, 4]        # [1, 2, 3, 4]
d = [0] * 3           # [0, 0, 0]
import copy
copy.deepcopy([[1], [2]])

Cuidado: [[0]] * 3 repite la misma sublista.

Comprensiones de listas

Una comprensión crea una lista a partir de otra en una sola línea, con filtro opcional.

cuadrados = [x ** 2 for x in range(5)]
pares = [x for x in range(10) if x % 2 == 0]
etiquetas = ["par" if x % 2 == 0 else "impar" for x in range(4)]
pares_de = [(a, b) for a in range(2) for b in range(2)]

Sintaxis: [expresión for x in iterable if condición]

Listas de listas (matrices)

Una matriz es una lista de listas. Crea cada fila por separado para evitar compartirlas.

m = [[0] * 3 for _ in range(3)]
m[1][2] = 5
for fila in m:
    print(fila)
traspuesta = [list(f) for f in zip(*m)]

No uses [[0] * 3] * 3.

Tuplas: secuencias inmutables

Una tupla es como una lista que no se puede modificar. Se usa para datos fijos y como clave de diccionario.

punto = (3, 4)
x, y = punto
una = (5,)                 # coma obligatoria
a, *resto = (1, 2, 3, 4)   # a=1, resto=[2, 3, 4]

Métodos especiales: __str__, __repr__ y otros

Los métodos con doble guion bajo («dunder») personalizan el comportamiento de los objetos.

class Punto:
    def __init__(self, x, y): self.x, self.y = x, y
    def __str__(self): return f"({self.x}, {self.y})"
    def __repr__(self): return f"Punto({self.x}, {self.y})"
    def __eq__(self, o): return (self.x, self.y) == (o.x, o.y)
    def __add__(self, o): return Punto(self.x + o.x, self.y + o.y)
    def __len__(self): return 2

Métodos de clase y estáticos

Decoradores

Un decorador es una función que recibe otra función y devuelve una versión modificada. Se aplica con @.

import functools, time

def cronometrar(f):
    @functools.wraps(f)
    def envoltura(*args, **kwargs):
        t = time.perf_counter()
        r = f(*args, **kwargs)
        print(f"{f.__name__}: {time.perf_counter() - t:.3f}s")
        return r
    return envoltura

@cronometrar
def lento(): time.sleep(0.2)

Ordenación de burbuja

Compara pares contiguos y los intercambia si están desordenados.

def burbuja(l):
    l = l[:]
    for i in range(len(l) - 1):
        for j in range(len(l) - 1 - i):
            if l[j] > l[j + 1]:
                l[j], l[j + 1] = l[j + 1], l[j]
    return l

En la práctica, usa sorted.

Búsqueda binaria

En una lista ordenada se descarta la mitad en cada paso.

def buscar(l, x):
    ini, fin = 0, len(l) - 1
    while ini <= fin:
        m = (ini + fin) // 2
        if l[m] == x: return m
        if l[m] < x: ini = m + 1
        else: fin = m - 1
    return -1

Complejidad: O(log n)

Merge sort y quicksort

Dos algoritmos eficientes de ordenación basados en dividir.

def quick(l):
    if len(l) < 2: return l
    p, *resto = l
    return quick([x for x in resto if x < p]) + [p] + quick([x for x in resto if x >= p])

def merge_sort(l):
    if len(l) < 2: return l
    m = len(l) // 2
    a, b = merge_sort(l[:m]), merge_sort(l[m:])
    r = []
    while a and b: r.append((a if a[0] <= b[0] else b).pop(0))
    return r + a + b

Complejidad media: O(n log n)
