La idea básica: CSS le dice al navegador cómo presentar el HTML. Una regla suele tener esta forma: selector { propiedad: valor; }. El selector elige qué elemento cambiar; la propiedad dice qué aspecto tocar; el valor concreta el cambio. Esta guía explica las opciones más habituales y sus valores; usa el buscador para encontrar tanto el nombre técnico como una palabra cotidiana.
00

Antes de tocar propiedades

Lo básico de CSS

Cómo se escribe una regla

Primero se elige qué elemento cambiar; entre llaves se escriben los cambios. Cada línea suele terminar en punto y coma.

p {
  color: navy;
  font-weight: bold;
}

Forma: selector { propiedad: valor; }

Dónde escribir CSS

Puede ir en un archivo .css enlazado al HTML, dentro de una etiqueta <style> o en el atributo style de un elemento. 

<link rel="stylesheet" href="estilos.css">
<style> p { color: navy; } </style>
<p style="color: navy">Texto</p>

En los ejercicios aparecen las tres formas.

Comentarios

Son notas para quien lee el archivo. El navegador las ignora.

/* Esto es un comentario */

Se abren con /* y se cierran con */.

Cascada y prioridad

Si varias reglas cambian lo mismo, el navegador decide cuál gana según su prioridad y especificidad; si empatan, normalmente gana la última.

p { color: navy; }
.aviso { color: tomato; }

Consejo: usa el selector más sencillo que te sirva.

Herencia

Algunas opciones, como el color o la fuente, suelen pasar del elemento padre a sus hijos. Otras, como el margen, no se heredan normalmente.

body { color: #333; }
/* El texto interior suele heredar ese color. */

La herencia ayuda a no repetir reglas.

Unidades de medida y tamaños flexibles

px es una unidad fija de CSS; % depende del contexto; em depende de la letra del elemento y rem de la raíz. vw/vh son porcentajes de la ventana; vmin/vmax toman el lado menor/mayor. dvh sigue la altura visible dinámica en móviles. ch aproxima el ancho del carácter cero. cm, mm, in, pt y pc son unidades físicas. fr se usa en Grid. El cero puede escribirse sin unidad. 

width: min(100%, 60rem);
font-size: clamp(1rem, 2vw, 1.5rem);

Funciones: calc() para operar; min()/max() eligen límites; clamp(mínimo, preferido, máximo) limita un valor.

Especificidad: qué regla gana

Si dos declaraciones compiten, primero cuentan origen, capa y !important; luego especificidad; al final, si empatan, gana la regla posterior. Como orientación, un #id pesa más que una clase, y una clase más que una etiqueta. No abuses de !important: dificulta sobrescribir estilos. 

p { color: navy; }
.aviso { color: tomato; }

Selectores y cascada. !important se escribe al final del valor, por ejemplo color: red !important.

Capas de cascada

@layer agrupa reglas y establece prioridades claras sin subir la especificidad. En reglas normales, las capas declaradas después tienen prioridad; las reglas sin capa ganan a las reglas normales dentro de capas. En reglas importantes se invierte el orden.

@layer base, componentes;
@layer base { p { color: #333; } }
@layer componentes { .aviso { color: teal; } }

Regla: @layer. Útil para hojas grandes o estilos de terceros.

Importar otra hoja de estilos

@import carga otra hoja CSS. Debe aparecer antes de las reglas normales (salvo otras instrucciones de organización). Para proyectos comunes, suele ser más sencillo enlazar cada hoja con <link> en HTML.

@import url("colores.css");

Regla: @import

Valores globales de CSS

inherit fuerza heredar del padre; initial usa el valor inicial definido por CSS; unset hereda si esa propiedad normalmente se hereda y, si no, usa su valor inicial; revert vuelve a la cascada de un origen anterior; revert-layer retrocede la capa actual. No son lo mismo que auto. 

.hijo { color: inherit; }

Valores globales: disponibles para cualquier propiedad CSS

Variables CSS y valor alternativo

Una variable personalizada empieza con dos guiones y respeta la cascada/herencia. var(--nombre, alternativa) usa el segundo valor si la variable no está definida o no es válida para esa propiedad. Las variables almacenan texto/valores CSS, no son variables de preprocesador. 

:root { --acento: teal; }
a { color: var(--acento, navy); }

Funciones y sintaxis: --nombre, var()

01

Las letras y cómo se leen

Texto

Grosor de la letra

normal suele ser 400 y bold suele ser 700. También puedes usar números del 1 al 1000 (los más comunes son 100, 300, 400, 500, 600, 700, 800 y 900). bolder y lighter eligen un peso relativo al del elemento padre. La fuente debe disponer de ese grosor para que se vea diferente.

font-weight: 700;

Propiedad: font-weight

Estilo de letra

normal muestra el diseño normal; italic usa la cursiva diseñada por la fuente; oblique inclina la letra y admite un ángulo en fuentes que lo soporten. La cursiva semántica suele marcarse con HTML y luego se presenta con CSS.

font-style: italic;

Propiedad: font-style

Tipo de letra

Escribe primero la fuente preferida y luego alternativas. Las familias genéricas funcionan como último recurso: serif (remates), sans-serif (sin remates), monospace (ancho fijo), cursive, fantasy y system-ui (letra del sistema). Si el nombre contiene espacios, ponlo entre comillas. 

font-family: Arial, "Trebuchet MS", sans-serif;

Propiedad: font-family

Cargar una fuente propia

@font-face registra un archivo de fuente para poder usarlo con su nombre. woff2 es el formato web habitual. Comprueba licencias y rutas de los archivos, y ofrece una fuente alternativa para cuando no cargue. 

@font-face {
  font-family: "MiFuente";
  src: url("mi-fuente.woff2") format("woff2");
  font-display: swap;
}

Regla: @font-face. font-display: swap muestra una fuente alternativa mientras se carga.

Tamaño de letra

Puede usarse una medida como 18px, 1.2rem o un porcentaje; small, large, smaller y larger son tamaños relativos predefinidos. rem depende de la raíz y suele ser cómodo para adaptar la página. 

font-size: 1.125rem;

Propiedad: font-size

Color de letra

Cambia el color del texto. Puedes usar nombres, códigos hexadecimales o valores RGB.

color: #245b49;

Propiedad: color

Alinear el texto: valores habituales

left alinea a la izquierda y right a la derecha; center centra cada línea; justify estira los espacios para que ambos bordes queden alineados. start y end siguen el sentido de escritura (recomendados para idiomas que pueden ir de derecha a izquierda). match-parent toma el sentido del padre. justify-all también justifica la última línea; se usa poco. El valor inicial es start.

text-align: center;

Propiedad: text-align. Alinea texto y contenido en línea; no centra por sí sola una caja de bloque.

Subrayado y otras líneas

text-decoration-line admite underline (debajo), overline (encima), line-through (tachado), combinaciones o none. El atajo text-decoration puede añadir color, estilo (solid, wavy, dotted, dashed, double) y grosor. No quites el subrayado de enlaces sin ofrecer otra señal visible. 

text-decoration: underline wavy tomato;

Propiedades: text-decoration, text-decoration-line, text-decoration-style, text-decoration-color

Mayúsculas y minúsculas

uppercase pasa a mayúsculas; lowercase, a minúsculas; capitalize, a iniciales mayúsculas; none mantiene el texto. full-width y full-size-kana son opciones tipográficas para escrituras de Asia oriental. 

text-transform: uppercase;

Propiedad: text-transform

Separación entre letras o palabras

Aumenta o reduce el hueco entre letras o entre palabras.

letter-spacing: 2px;
word-spacing: 4px;

Propiedades: letter-spacing y word-spacing

Interlineado

normal deja que el navegador elija; un número como 1.6 multiplica el tamaño de letra y suele ser la opción más flexible; también acepta longitudes y porcentajes. Un interlineado mayor suele facilitar la lectura; evita porcentajes rígidos si el tamaño de letra puede cambiar.

line-height: 1.6;

Propiedad: line-height

Texto demasiado largo y puntos suspensivos

text-overflow: ellipsis muestra puntos suspensivos cuando el texto queda recortado. No recorta por sí sola: normalmente necesita una caja limitada, overflow: hidden y white-space: nowrap. clip recorta sin puntos. 

.titulo {
  overflow: hidden;
  white-space: nowrap;
  text-overflow: ellipsis;
}

Propiedad: text-overflow

Partir palabras y direcciones largas

word-break: normal usa las reglas del idioma; break-all puede cortar en cualquier punto; keep-all evita cortes entre caracteres de escrituras CJK. Para URL largas suele convenir overflow-wrap: anywhere, que solo rompe cuando hace falta. 

.url { overflow-wrap: anywhere; }

Propiedades: word-break, overflow-wrap

Guiones al final de línea

hyphens: auto permite al navegador cortar palabras con guion según el idioma indicado en el HTML; manual solo corta donde hay un guion blando explícito; none lo desactiva. El idioma correcto es importante para una separación silábica adecuada. 

p { hyphens: auto; }

Propiedad: hyphens

Texto en varias columnas

column-count sugiere cuántas columnas; column-width sugiere el ancho mínimo y el navegador calcula cuántas caben. column-gap separa; column-rule dibuja una línea; column-span: all permite que un título cruce todas. 

.articulo {
  columns: 18rem 2;
  column-gap: 2rem;
}

Atajo columns y propiedades column-*

Dirección y escritura vertical

writing-mode define la orientación del texto: horizontal-tb (habitual), vertical-rl o vertical-lr. Junto con direction influye en qué significa inicio y final; los idiomas se declaran en HTML con el atributo dir. 

writing-mode: vertical-rl;

Propiedades: writing-mode, direction, text-orientation

Atajo para varias opciones de letra

font puede reunir grosor, tamaño, interlineado y familia en una sola declaración. 

font: bold 16px/1.5 Arial, sans-serif;

Propiedad abreviada: font

Versalitas

Muestra las letras minúsculas con forma de mayúsculas pequeñas.

font-variant: small-caps;

Propiedad: font-variant

Sombra del texto

El orden es desplazamiento horizontal, desplazamiento vertical, desenfoque (opcional) y color (opcional). Un desplazamiento negativo mueve la sombra hacia arriba o a la izquierda. Se pueden separar varias sombras con comas; none las quita. No tiene opción inset. 

text-shadow: 2px 3px 4px #0008, -1px 0 #fff;

Propiedad: text-shadow

Dirección del texto

Indica el sentido de escritura: ltr va de izquierda a derecha y rtl, de derecha a izquierda.

direction: rtl;

Propiedad: direction

Grosor y distancia del subrayado

Permite ajustar la línea decorativa de un enlace para que quede más fina, gruesa, cerca o lejos del texto.

text-decoration-thickness: 2px;
text-underline-offset: 4px;

Propiedades: text-decoration-thickness y text-underline-offset

Alinear la última línea y sangrar párrafos

text-align-last alinea únicamente la última línea; admite auto, start, end, left, right, center y justify. text-indent desplaza la primera línea. Para diseños adaptables, suele convenir start y end antes que izquierda/derecha. 

text-align-last: center;
text-indent: 2em;

Propiedades: text-align-last y text-indent

02

El color de los elementos y del lienzo

Colores y fondos

Color de fondo y formatos de color

Pinta el fondo. Los colores pueden escribirse por nombre (tomato), hexadecimal (#245b49 o #fff), RGB (rgb(36 91 73)), HSL (hsl(155 43% 25%)) o con transparencia, por ejemplo rgb(0 0 0 / 50%). transparent significa transparente; currentColor reutiliza el valor de color. 

background-color: #e1eadf;

Propiedades y formatos: background-color, rgb(), hsl(), hexadecimal y nombres

Imagen de fondo

Coloca una imagen detrás del contenido. La ruta dentro de url(...) indica dónde está el archivo.

background-image: url("fondo.jpg");

Propiedad: background-image

Tamaño de una imagen de fondo

cover cubre toda la caja y puede recortar; contain muestra la imagen entera y puede dejar huecos; auto conserva su tamaño original. También puedes indicar medidas o porcentajes. Se pueden poner varias imágenes separadas por comas.

background-size: cover;

Propiedad: background-size

Transparencia

La transparencia puede escribirse en el color (rgb(0 0 0 / 50%)) o aplicarse al elemento entero con opacity. En RGB con canal alfa, 0 o 0% es transparente y 1 o 100% es opaco. opacity: .5 también vuelve semitransparentes los hijos; un color con alfa solo afecta a ese color.

background: rgb(0 0 0 / 50%);
opacity: .8;

Valores: de transparent a totalmente opaco

Variables de color

Guarda un valor con un nombre para reutilizarlo y cambiarlo desde un solo lugar.

:root {
  --verde: #245b49;
}
h1 { color: var(--verde); }

Sintaxis: --nombre y var()

Colocación de una imagen de fondo

Elige qué zona de la imagen queda visible cuando no cabe entera.

background-position: center;

Propiedad: background-position

Repetir o no el fondo

Controla si una imagen de fondo se repite como un mosaico.

background-repeat: no-repeat;

Propiedad: background-repeat

Degradados

linear-gradient() mezcla en una dirección (por ejemplo to right o un ángulo); radial-gradient() sale desde un punto en forma circular/elíptica; conic-gradient() mezcla alrededor de un centro. Las versiones repeating-* repiten el patrón. Indica paradas de color para controlar dónde empieza cada tono. 

background: linear-gradient(90deg, navy, teal);

Funciones: linear-gradient(), radial-gradient(), conic-gradient() y versiones repeating-

Filtros y desenfoque

filter afecta al elemento: blur() desenfoca; brightness() aclara/oscurece; contrast() cambia contraste; grayscale() quita color; sepia() da tono sepia; saturate() intensifica color; hue-rotate() gira tonos; invert() invierte; opacity() ajusta transparencia; drop-shadow() añade sombra a la silueta. backdrop-filter afecta a lo que se ve detrás, si el fondo deja verlo. 

filter: blur(2px);
backdrop-filter: blur(8px);

Propiedades: filter y backdrop-filter

Repetición, posición y capas del fondo

background-repeat: repeat repite, no-repeat no repite, repeat-x/repeat-y repiten en un eje y space/round distribuyen o ajustan las copias. background-position acepta center, top, left o medidas. background-attachment usa scroll (normal), fixed (respecto a la ventana) o local (con el contenido que se desplaza). También existen background-origin y background-clip para elegir desde dónde se mide y hasta dónde se pinta. 

background: url("fondo.jpg") center / cover no-repeat;

Atajo: background. Cada capa puede tener su propia imagen, posición, tamaño y repetición separados por comas.

03

El espacio que ocupa cada cosa

Tamaño, espacio y bordes

Ancho

Define cuánto mide un elemento de lado a lado.

width: 300px;
max-width: 100%;

Propiedades: width y max-width

Alto

Define la altura. Para imágenes, height: auto conserva sus proporciones originales. 

height: auto;
min-height: 200px;

Propiedades: height y min-height

Margen: espacio de fuera

Separa un elemento de los vecinos. Atajo de 1 valor: los 4 lados; 2: arriba/abajo y derecha/izquierda; 3: arriba, lados, abajo; 4: arriba, derecha, abajo, izquierda (sentido horario). auto puede repartir el espacio sobrante en horizontal. Los márgenes verticales de bloques a veces se colapsan.

margin: 10px 20px 30px 40px;

Propiedades: margin, margin-top/right/bottom/left

Relleno: espacio de dentro

Deja aire entre contenido y borde. Usa la misma regla de 1, 2, 3 o 4 valores que margin. El relleno no acepta valores negativos; se pinta con el fondo del elemento. No es lo mismo que el margen, que queda fuera. 

padding: 12px 20px;

Propiedades: padding, padding-top/right/bottom/left

Borde y estilos de línea

El atajo combina grosor, estilo y color. Estilos frecuentes: solid (continuo), dashed (guiones), dotted (puntos), double (doble), groove/ridge (relieve), inset/outset (hundido/levantado), none (sin borde). hidden se usa sobre todo en tablas. 

border: 2px dashed #245b49;

Propiedades: border, border-width, border-style, border-color

Esquinas redondeadas

Un valor aplica a las cuatro esquinas; con cuatro valores se recorren en sentido horario desde arriba a la izquierda. Puedes usar porcentajes (100% puede formar un círculo si la caja es cuadrada) y una barra para separar radios horizontales y verticales. Cada esquina también se puede ajustar por separado.

border-radius: 12px 0 12px 0;

Propiedades: border-radius, border-top-left-radius, border-top-right-radius, etc.

Sombra de una caja: sintaxis

La forma frecuente es desplazamiento horizontal, vertical, desenfoque (opcional), expansión (opcional) y color (opcional). El desplazamiento puede ser negativo. inset dibuja la sombra dentro de la caja; sin él queda fuera. none quita la sombra. El desenfoque no puede ser negativo; la expansión sí puede.

box-shadow: 0 4px 12px 2px #0003;

Propiedad: box-shadow. La sombra no cambia el espacio que ocupa el elemento.

Varias sombras y sombra interior

Se pueden superponer varias sombras separándolas con comas. La primera se dibuja encima de las siguientes. Puedes mezclar sombras exteriores e interiores con inset; none indica que no haya ninguna. 

box-shadow: 0 2px 6px #0003, inset 0 0 0 1px #fff;

Una lista de sombras en box-shadow

box-shadow o drop-shadow

box-shadow sombrea el rectángulo de la caja, incluidas sus esquinas redondeadas. filter: drop-shadow() sigue la silueta visible (útil en imágenes PNG transparentes o formas recortadas). Son efectos distintos. 

filter: drop-shadow(3px 4px 5px #0006);

Funciones de sombra: box-shadow y drop-shadow()

Cómo se calcula el tamaño

content-box (predeterminado) suma ancho + relleno + borde. Con border-box, el ancho declarado ya los incluye; suele hacer más fácil controlar medidas. 

* { box-sizing: border-box; }

Propiedad: box-sizing

Proporción de caja o imagen

Fija la relación entre ancho y alto: por ejemplo, 4 unidades de ancho por 3 de alto.

aspect-ratio: 4 / 3;

Propiedad: aspect-ratio

Elegir qué parte de la imagen se ve

Con object-position decides qué zona conservar cuando la imagen se recorta con object-fit: cover. 

object-position: center top;

Propiedad: object-position

Borde de un solo lado

Aplica una línea solo en un lado. El color, grosor y estilo también se pueden cambiar por separado.

border-bottom: 1px solid #ccc;
border-left: 4px solid teal;

Variantes: border-top, border-right, border-bottom, border-left y border-color

Color del borde inferior

Cambia solo el color del borde de abajo, conservando su grosor y estilo.

border-bottom-color: tomato;

Propiedad: border-bottom-color

Bordes y distribución de tablas

border-collapse une o separa los bordes de las celdas; border-spacing define su separación y table-layout ayuda a distribuir el ancho.

border-collapse: collapse;
border-spacing: 0;
table-layout: fixed;

Propiedades de tabla.

Contorno de foco

Dibuja una marca por fuera del borde, útil para indicar dónde está el foco del teclado.

outline: 2px solid coral;
outline-offset: 3px;

Propiedades: outline y outline-offset

Contenido que no cabe

visible deja que sobresalga; hidden recorta y permite desplazamiento programático; clip recorta sin crear una zona de scroll; scroll muestra zona desplazable siempre; auto muestra barras solo cuando hacen falta. Se puede controlar cada eje por separado.

overflow-x: auto;
overflow-y: hidden;

Propiedades: overflow, overflow-x, overflow-y, overflow: clip

Romper palabras largas

Permite partir una palabra o dirección larga para que no ensanche la página.

overflow-wrap: anywhere;

Propiedad: overflow-wrap

Espacios y saltos de línea

normal combina espacios y permite saltos; nowrap combina espacios pero mantiene el texto en una línea; pre conserva espacios y saltos escritos; pre-wrap los conserva y permite ajustar líneas; pre-line conserva saltos y combina espacios; break-spaces conserva incluso los espacios finales y permite cortar. 

white-space: pre-wrap;

Propiedad: white-space

Desplazamiento a secciones

scroll-behavior suaviza los saltos a una sección. scroll-margin-top deja espacio antes del título de destino.

html { scroll-behavior: smooth; }
section { scroll-margin-top: 20px; }

Propiedades: scroll-behavior y scroll-margin-top

Márgenes por lado

El espacio exterior se puede controlar para cada lado por separado.

margin-top: 8px;
margin-right: 12px;
margin-bottom: 16px;
margin-left: 20px;

Propiedades: margin-top, margin-right, margin-bottom, margin-left

Relleno por lado

El espacio interior también puede tener una medida distinta en cada lado.

padding-top: 8px;
padding-right: 12px;
padding-bottom: 16px;
padding-left: 20px;

Propiedades: padding-top, padding-right, padding-bottom, padding-left

Alinear verticalmente

En celdas de tabla: top, middle, bottom, baseline. En elementos en línea también admite sub, super, text-top, text-bottom, porcentajes y medidas. No centra verticalmente cualquier bloque: para eso suele usarse Flex o Grid. 

vertical-align: middle;

Propiedad: vertical-align

Límites de tamaño

Los mínimos y máximos permiten que una caja se ajuste sin quedar demasiado pequeña o grande.

min-width: 320px;
max-height: 500px;

También existen min-height y max-width.

Tamaños automáticos según el contenido

auto deja participar a las reglas normales de diseño. min-content es el menor tamaño sin desbordar palabras; max-content ocupa lo necesario para una línea; fit-content ajusta el contenido sin superar el espacio disponible. Se usan en ancho/alto, Grid y otras propiedades de tamaño. 

width: fit-content;

Palabras clave de tamaño intrínseco: min-content, max-content, fit-content

Propiedades lógicas: inicio y final

En vez de izquierda/derecha/arriba/abajo, CSS puede usar la dirección del texto: margin-inline (eje en línea), margin-block (eje de bloque), padding-inline-start, border-block-end, inset-inline, inline-size y block-size. Así los estilos se adaptan a idiomas de derecha a izquierda y escritura vertical. 

margin-inline: auto;
padding-block: 1rem;

Sufijos lógicos: -inline, -block, -start, -end

Permitir cambiar el tamaño

resize define si la persona puede redimensionar un elemento que admite ese comportamiento (por ejemplo, un área de texto): none, both, horizontal o vertical. both suele ser el valor inicial en textarea. 

textarea { resize: vertical; }

Propiedad: resize

Partes y estilos del contorno

outline es una línea externa que no ocupa espacio. Se configura con grosor, estilo y color. Los estilos incluyen solid, dashed, dotted, double y none. Mantén un indicador de foco visible y con buen contraste para navegación con teclado. 

outline: 3px solid #bd573d;
outline-offset: 3px;

Propiedades: outline, outline-width, outline-style, outline-color, outline-offset

04

Cómo se colocan y ordenan los elementos

Disposición

Display: valores principales

block ocupa una fila disponible; inline fluye dentro del texto y no acepta ancho/alto como una caja normal; inline-block fluye en línea y sí acepta medidas. flex organiza hijos con Flexbox y grid con filas y columnas; inline-flex/inline-grid hacen que el contenedor fluya en línea. table crea una tabla y inline-table una tabla que fluye en línea. none quita la caja del diseño y normalmente del árbol de accesibilidad. 

display: block;

Propiedad: display. El valor inicial depende del tipo de elemento HTML.

Float: hacer que el texto rodee una imagen

Pega un elemento a un lado y deja que el texto fluya a su alrededor. Se usa sobre todo para imágenes; para columnas de una página suele ser más cómodo Flex o Grid.

img {
  float: left;
  margin-right: 16px;
}

Valores habituales: left, right, none. Es una propiedad CSS válida aunque no aparezca en las hojas actuales.

Clear: dejar de rodear un float

Hace que el elemento empiece debajo de las cajas flotantes anteriores, en vez de quedarse a su lado.

.despues { clear: both; }

Valores: left, right, both o none.

Flex: colocar en fila o columna

Reparte los elementos de un contenedor en una fila o columna y ayuda a alinearlos.

.menu {
  display: flex;
  align-items: center;
  gap: 16px;
}

Propiedades: display, align-items y gap

Grid: crear una cuadrícula

Divide el espacio en filas y columnas; viene bien para organizar tarjetas o secciones.

.rejilla {
  display: grid;
  grid-template-columns: 1fr 1fr;
  gap: 20px;
}

Propiedades: display y grid-template-columns

Otros valores de display

list-item añade marcador de lista; flow-root contiene sus flotantes; contents elimina la caja pero conserva los hijos (con posibles diferencias de accesibilidad). Para tablas están table-row-group, table-header-group, table-footer-group, table-row, table-cell, table-column-group, table-column y table-caption. Para anotaciones ruby: ruby, ruby-base, ruby-text, ruby-base-container y ruby-text-container. run-in no tiene soporte interoperable para uso general. Los valores compuestos como inline flow-root indican tipo exterior/interior de caja; también existen inline list-item y inline ruby. 

.contenedor { display: flow-root; }

Valores destacados: list-item, flow-root, contents y familias table-*/ruby-*.

Hueco entre elementos

gap crea espacio entre elementos de Flex o Grid, sin tener que poner márgenes en cada uno.

gap: 12px 24px;

Propiedad: gap

Position: normal, relativa, absoluta, fija o sticky

static es el flujo normal y no responde a top/right/bottom/left. relative conserva su hueco y permite desplazarlo; también crea referencia para hijos absolutos. absolute sale del flujo y se coloca respecto al ancestro posicionado más cercano. fixed se fija normalmente a la ventana. sticky se comporta normal hasta llegar al límite indicado; suele necesitar top y un contenedor con espacio de desplazamiento. 

position: sticky;
top: 0;

Valores de position: static, relative, absolute, fixed, sticky

Mostrar u ocultar

display: none quita el elemento de la página; no deja hueco en su lugar.

.oculto { display: none; }

Propiedad: display

Ocultar conservando el hueco

visibility: hidden no muestra el elemento, pero conserva el espacio que ocupaba. visible lo muestra; collapse se usa especialmente en filas o columnas de tablas. A diferencia de display: none, el elemento invisible sigue ocupando sitio. 

visibility: hidden;

Propiedad: visibility

Centrar una caja

Si la caja tiene un ancho limitado, margin: auto reparte el espacio sobrante a ambos lados.

.contenido {
  max-width: 900px;
  margin: 0 auto;
}

Atajo habitual: margin: 0 auto

Viñetas y numeración

disc, circle y square son viñetas; decimal numera 1, 2, 3; decimal-leading-zero usa 01, 02; lower/upper-alpha usa letras y lower/upper-roman números romanos. none quita el marcador. list-style-position puede ser inside o outside. 

list-style-type: square;

Atajo: list-style; propiedades: list-style-type, list-style-position, list-style-image

Dirección, salto y reparto en Flex

flex-direction: row (fila), row-reverse, column (columna) o column-reverse. flex-wrap: nowrap (una línea), wrap (salta) o wrap-reverse. En cada hijo, flex-grow controla cuánto crece, flex-shrink cuánto se encoge y flex-basis su tamaño base. El atajo flex combina estos tres valores. 

.fila { flex-flow: row wrap; }
.hijo { flex: 1 1 12rem; }

Propiedades: flex-direction, flex-wrap, flex-flow, flex-grow, flex-shrink, flex-basis, flex

Alinear y repartir en Flex y Grid

justify-content y align-content alinean o reparten el conjunto: start, end, center, space-between, space-around, space-evenly (y stretch donde corresponda). align-items/justify-items alinean los hijos: start, end, center, stretch, baseline. align-self/justify-self ajustan un hijo. place-items y place-content son atajos para los dos ejes. En Flex, justify-items no suele tener efecto. 

justify-content: space-between;
align-items: center;

Recuerda: el eje principal de Flex cambia con flex-direction.

Columnas Grid que se adaptan solas

fr reparte el espacio disponible. repeat() repite columnas; minmax() define su mínimo y máximo. auto-fit y auto-fill calculan cuántas caben: auto-fit colapsa columnas vacías; auto-fill conserva su espacio. 

grid-template-columns:
  repeat(auto-fit, minmax(220px, 1fr));

Funciones: repeat() y minmax(); unidad flexible: fr

Filas, áreas y colocación automática en Grid

grid-template-rows define filas; grid-template-areas nombra zonas; grid-area coloca un hijo nombrado o indica su posición. grid-auto-rows/grid-auto-columns dimensionan pistas creadas automáticamente y grid-auto-flow controla el llenado (row, column, opcionalmente dense). 

grid-template-areas: "menu contenido";
grid-auto-flow: row;

Familias de propiedades: grid-template-*, grid-auto-* y grid-area

Colocar algo dentro de Grid

Permite decir qué columnas o filas debe ocupar un elemento de la cuadrícula.

grid-column: 1 / 3;
grid-row: 2;

Propiedades: grid-column y grid-row

Cambiar el orden visual

Reordena un elemento en Flex o Grid sin moverlo en el HTML. Un número menor aparece antes.

.primero { order: -1; }

Propiedad: order

Separar solo las columnas

column-gap controla el espacio entre columnas. gap puede controlar filas y columnas a la vez.

column-gap: 24px;

Propiedad: column-gap

Atajo de posición para los cuatro lados

inset es una forma corta de indicar los límites superior, derecho, inferior e izquierdo de un elemento posicionado.

position: absolute;
inset: 0;

Atajo de top, right, bottom y left.

Ajustar el desplazamiento a secciones

scroll-snap-type activa puntos de ajuste en un contenedor desplazable; scroll-snap-align marca dónde debe encajar cada hijo (start, center, end); mandatory exige ajuste y proximity ajusta si se queda cerca. Usa proximity con cuidado para no quitar control del desplazamiento. 

.carrusel { overflow-x: auto; scroll-snap-type: x proximity; }
.tarjeta { scroll-snap-align: start; }

Propiedades: scroll-snap-type, scroll-snap-align, scroll-snap-stop

Evitar que el scroll se propague

overscroll-behavior controla qué pasa al llegar al borde de una zona desplazable: auto permite que el desplazamiento continúe en el padre; contain lo detiene en esa zona; none también elimina efectos de rebote del navegador donde aplique. 

.panel { overscroll-behavior: contain; }

Propiedades: overscroll-behavior, overscroll-behavior-x, overscroll-behavior-y

05

Elegir qué parte de la página recibe el estilo

Selectores

Por nombre de etiqueta

Afecta a todas las etiquetas de ese tipo. Aquí se aplica a todos los párrafos.

p {
  color: #555;
}

Selector: p

Por clase

El punto delante indica una clase. Se puede reutilizar en varios elementos HTML.

.especial {
  font-weight: bold;
}

Selector: .nombre-clase

Por identificador

La almohadilla selecciona un id, normalmente único en esa página.

#principal {
  padding: 20px;
}

Selector: #nombre-id

Elemento dentro de otro

Un espacio significa «busca este elemento dentro de aquel». El ejemplo selecciona los párrafos que estén dentro de .normal.

.normal p { color: navy; }

Combinador: espacio

El siguiente elemento

El signo + selecciona el elemento que está justo después de otro, al mismo nivel. 

h1 + h2 { color: seagreen; }

Combinador: +

Aplicar lo mismo a varios

Separa selectores con comas para compartir las mismas reglas.

h1, h2, h3 {
  font-family: Georgia, serif;
}

Separador: coma

Todos los elementos

El asterisco selecciona todos los elementos de la página.

* { box-sizing: border-box; }

Selector universal: *

Buscar por atributo

Los corchetes permiten seleccionar por un atributo. *= significa que el valor contiene ese texto.

a[href*="ejemplo"] {
  font-style: italic;
}

Selector de atributo: [atributo]

Estados del elemento

Las pseudoclases, que empiezan con dos puntos, seleccionan estados como enlace visitado, puntero encima, clic o foco del teclado.

a:hover { color: tomato; }
a:visited { color: purple; }

También: :link, :active, :focus, :focus-visible, :focus-within, :checked.

Añadir decoración antes o después

::before y ::after crean una pieza decorativa. Necesitan la propiedad content, aunque el contenido sea una cadena vacía. 

.marca::after {
  content: "";
  height: 2px;
}

Pseudo-elementos: ::before y ::after

Seleccionar por posición

Elige hijos por el lugar que ocupan: el primero, el último, los impares, etc.

li:nth-child(odd) {
  background: #eee;
}

Pseudoclases: :first-child, :last-child, :nth-child(), :not()

Contenido decorativo y contadores

content inserta texto o símbolos en ::before/::after; no lo uses para información esencial que deba estar en HTML. Los contadores CSS se crean con counter-reset, avanzan con counter-increment y se muestran con counter(). 

ol { counter-reset: paso; }
li::before {
  counter-increment: paso;
  content: counter(paso) ". ";
}

Propiedades y función: content, counter-reset, counter-increment, counter()

Hijos directos y hermanos

A > B selecciona solo hijos directos; A ~ B selecciona hermanos posteriores del mismo nivel. A diferencia del espacio, no busca descendientes a cualquier profundidad.

ul > li { margin-block: .5rem; }
h2 ~ p { color: #555; }

Combinadores: > y ~

Combinar condiciones con pseudoclases

:is() agrupa alternativas y conserva la especificidad más alta de su lista; :where() agrupa con especificidad cero; :not() excluye; :has() selecciona un elemento según lo que contiene o su relación con otros elementos. 

:where(article, section) > h2 { color: teal; }
article:has(img) { padding: 1rem; }

Pseudoclases: :is(), :where(), :not(), :has()

Estilizar marcadores y partes

::placeholder cambia el texto de ayuda de un campo; ::marker, las viñetas y números; ::first-letter, la primera letra; ::first-line, la primera línea. Usa el contenido HTML para información importante y pseudoelementos sobre todo para presentación.

input::placeholder { color: #687; }
li::marker { color: tomato; }

Pseudo-elementos: ::placeholder, ::marker, ::first-letter, ::first-line

06

Qué pasa cuando usamos la página

Interacción

Al pasar el ratón

:hover cambia el aspecto mientras el puntero está encima del elemento.

a:hover {
  color: tomato;
}

Estado: :hover

Mientras se pulsa

:active aplica el estilo durante el clic o la pulsación.

button:active {
  transform: translateY(1px);
}

Estado: :active

Enlace visitado o sin visitar

:link representa un enlace no visitado; :visited, uno que ya se abrió. 

a:link { color: navy; }
a:visited { color: purple; }

Estados: :link y :visited

Al llegar con el teclado

:focus-visible muestra una señal cuando una persona llega al elemento usando el teclado.

a:focus-visible {
  outline: 3px solid coral;
}

Estado: :focus-visible

Cambio suave (transition)

El atajo reúne propiedad que cambia, duración, curva de velocidad y retraso. all anima todas las propiedades animables; es más eficiente y predecible indicar solo la propiedad necesaria. none desactiva transiciones.

transition: color .2s ease .1s;

Propiedades: transition, transition-property, transition-duration, transition-timing-function, transition-delay

Forma del cursor

auto deja elegir al navegador; default es la flecha; pointer la mano de enlace; text indica texto; wait/progress espera; help ayuda; not-allowed acción no disponible; grab/grabbing arrastre; crosshair mira. También hay cursores para cambiar el tamaño, como ew-resize y ns-resize. 

cursor: pointer;

Propiedad: cursor

Selección de texto e interacción táctil

::selection cambia el aspecto del texto que se selecciona. pointer-events controla si el puntero puede interactuar con el elemento. 

::selection { background: gold; }
pointer-events: none;

En algunos navegadores también hay ajustes de toque con prefijo -webkit-.

Duración de una transición

Controla cuánto tarda un cambio suave. Puede ir dentro del atajo transition o por separado.

transition-duration: .3s;

Propiedad: transition-duration

Curvas de velocidad

linear mantiene la misma velocidad. ease empieza y acaba suavemente; ease-in empieza despacio; ease-out acaba despacio; ease-in-out suaviza ambos extremos. cubic-bezier() define una curva propia y steps() crea cambios a saltos. 

transition-timing-function: ease-out;

Propiedad: transition-timing-function; también se usa en animaciones.

Color de controles de formulario

accent-color cambia el color de acento de casillas, botones de opción, barras de rango y algunos controles. appearance controla el aspecto nativo del sistema; none lo quita, pero entonces debes diseñar estados de foco y uso claramente. 

input[type="checkbox"] { accent-color: teal; }

Propiedades: accent-color, appearance

Cursor de escritura

caret-color cambia el color de la barra que parpadea en campos de texto y zonas editables. No cambia el color del texto ni el cursor del ratón (cursor).

input { caret-color: tomato; }

Propiedad: caret-color

Gestos táctiles

touch-action indica qué gestos del navegador se permiten: auto deja los predeterminados; none los desactiva; pan-x/pan-y permiten desplazamiento en un eje; manipulation permite desplazamiento y zoom. No lo desactives sin una necesidad concreta de interacción.

.mapa { touch-action: pan-x pan-y; }

Propiedad: touch-action

Permitir seleccionar texto

user-select: text permite seleccionar texto; none lo impide; all selecciona todo el contenido al hacer clic; auto deja decidir al navegador. Evita bloquear selección en contenido que las personas puedan querer copiar. 

.boton-icono { user-select: none; }

Propiedad: user-select

07

Que se vea bien en distintas pantallas y para distintas personas

Adaptación y accesibilidad

Adaptar a móvil

Una media query aplica reglas solo cuando se cumple una condición, por ejemplo que la pantalla sea estrecha.

@media (max-width: 700px) {
  .rejilla { grid-template-columns: 1fr; }
}

Regla: @media

Ajustar una imagen sin deformarla

fill estira para llenar; contain muestra la imagen completa y puede dejar hueco; cover llena el espacio y recorta lo que sobra; none conserva el tamaño original; scale-down elige el resultado menor entre none y contain. 

img {
  width: 100%;
  object-fit: cover;
}

Propiedad: object-fit

Imagen flexible

Evita que la imagen se salga de su contenedor y conserva su proporción original.

img {
  max-width: 100%;
  height: auto;
}

Propiedades: max-width y height

Respetar el movimiento reducido

Algunas personas prefieren que la página no tenga animaciones. Esta regla permite reducirlas según la preferencia del sistema.

@media (prefers-reduced-motion: reduce) {
  .elemento { animation: none; }
}

Regla: prefers-reduced-motion

Preferencia de tema del navegador

color-scheme informa al navegador si la página está pensada para un tema claro, oscuro o ambos.

:root { color-scheme: light; }

Propiedad: color-scheme

Ancho mínimo

Impide que el elemento se haga más estrecho que el valor indicado. Úsalo con cuidado para no provocar desplazamiento horizontal en móviles.

min-width: 320px;

Propiedad: min-width

Consultas al tamaño del contenedor

@container adapta un componente según el espacio de su contenedor, no el ancho total de la ventana. Primero se declara un contenedor con nombre y tipo de consulta; después se cambian estilos si alcanza cierto ancho.

.panel { container-type: inline-size; }
@container (inline-size > 35rem) {
  .tarjeta { display: grid; }
}

Propiedades: container-type, container-name, container; regla @container

Aplicar CSS si el navegador soporta una función

@supports comprueba si el navegador entiende una propiedad/valor y permite añadir una mejora progresiva. No detecta el modelo, la versión ni el dispositivo: solo soporte de CSS. 

@supports (display: grid) {
  .rejilla { display: grid; }
}

Regla condicional: @supports

Estilos para imprimir

@media print aplica reglas al imprimir o guardar como PDF. Se suelen ocultar menús y botones, quitar fondos oscuros y evitar que una tarjeta se parta entre páginas. break-before, break-after y break-inside controlan saltos. 

@media print {
  nav, button { display: none; }
  article { break-inside: avoid; }
}

Regla: @media print; saltos: break-*

Preferencias de color del sistema

prefers-color-scheme puede ser light u dark; prefers-contrast puede solicitar más/menos contraste; forced-colors detecta modos de color forzados. Respeta estas preferencias sin quitar las señales esenciales de contraste o foco. 

@media (prefers-color-scheme: dark) {
  body { background: #18201c; color: #f5f5ef; }
}

Consultas de medios: preferencias del usuario

Aislar el diseño para optimizar

contain informa al navegador que el elemento limita ciertos efectos: layout, paint, size o combinaciones como content y strict. Puede mejorar rendimiento en componentes grandes, pero cambia cómo interactúan con el resto del diseño; no se debe aplicar a ciegas. 

.widget { contain: content; }

Propiedades: contain, container

08

Efectos que cambian con el tiempo

Movimiento y capas

Animación

@keyframes describe los pasos de un movimiento y animation indica cuánto dura y cómo aplicarlo.

@keyframes aparecer {
  from { opacity: 0; }
  to { opacity: 1; }
}
.caja { animation: aparecer .5s ease; }

Reglas: @keyframes y animation

Mover, girar y escalar

translate()/translateX/Y() desplaza; rotate() gira; scale() cambia tamaño; skew() inclina; matrix() combina transformaciones. Puedes encadenarlas. La transformación visual no cambia el espacio original del elemento; también puede crear un contexto de apilamiento. 

transform: translateY(-4px) rotate(2deg) scale(1.02);

Propiedad: transform; relacionadas: translate, rotate, scale

Punto de giro

Elige desde qué punto se gira o cambia de tamaño el elemento.

transform-origin: center bottom;

Propiedad: transform-origin

Delante o detrás (z-index)

Un entero mayor suele dibujarse encima de uno menor; también acepta valores negativos y auto. No es una competición global: contextos de apilamiento (por ejemplo, creados por ciertas posiciones, transformaciones u opacidad) mantienen juntas sus capas. En Flex/Grid, un hijo también puede usar z-index sin posicionamiento. 

position: relative;
z-index: 2;

Propiedad: z-index

Duración de una animación

Indica cuánto tarda en completarse una vuelta de la animación.

animation-duration: 1s;

Propiedad: animation-duration

Retrasar una animación

Espera un tiempo antes de empezar a animar.

animation-delay: .2s;

Propiedad: animation-delay

Repeticiones de una animación

animation-iteration-count indica cuántas vueltas da: un número o infinite. animation-direction admite normal, reverse, alternate y alternate-reverse. animation-fill-mode determina si conserva los estilos de antes/después (none, forwards, backwards, both); animation-play-state es running o paused. 

animation-direction: alternate;
animation-fill-mode: both;

Propiedades: animation-iteration-count, animation-direction, animation-fill-mode, animation-play-state

Aislar capas

isolation: isolate crea un contexto independiente para apilar elementos y efectos. 

.portada { isolation: isolate; }

Propiedad: isolation

Máscaras y forma visible

mask-image usa transparencia o luminancia de una imagen/degradado para ocultar partes. clip-path recorta con formas predefinidas o funciones como circle(), ellipse(), inset() y polygon(). clip es una propiedad antigua; prefiere clip-path. 

clip-path: circle(45% at center);

Propiedades: mask-image, mask-size, clip-path

Animaciones basadas en desplazamiento

Las líneas de tiempo de scroll pueden vincular una animación al desplazamiento de la página o de un contenedor. Es una función moderna: si se usa en una página importante, ofrece una alternativa sin animación y comprueba compatibilidad en los navegadores objetivo.

@supports (animation-timeline: scroll()) {
  .barra { animation-timeline: scroll(); }
}

Conceptos modernos: animation-timeline, scroll(), view()

Propiedades con prefijo

Algunas opciones llevan -webkit- para compatibilidad o efectos propios de ciertos navegadores. No hace falta usar el prefijo en todas las reglas.

-webkit-font-smoothing: antialiased;
-webkit-tap-highlight-color: transparent;

Prefijo de navegador: -webkit-

No encuentro ese término

Prueba con otra palabra, por ejemplo: letra, color, espacio, borde, ratón o móvil.

Una última pista

Si buscas poner texto en negrita, escribe negrita arriba. La respuesta es font-weight: bold;. Puedes escribir esta regla dentro del selector que quieras cambiar, por ejemplo p { font-weight: bold; } para poner en negrita todos los párrafos.
