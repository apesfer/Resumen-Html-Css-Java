La idea básica: CSS le dice al navegador cómo presentar el HTML. Una regla suele tener esta forma: selector { propiedad: valor; }. El selector elige qué elemento cambiar; la propiedad dice qué aspecto tocar; el valor concreta el cambio. Esta guía explica las opciones más habituales y sus valores; usa el buscador para encontrar tanto el nombre técnico como una palabra cotidiana.

Antes de tocar propiedades

Lo básico de CSS

Cómo se escribe una regla

Primero se elige qué elemento cambiar; entre llaves se escriben los cambios. Cada línea suele terminar en punto y coma.

p {
  color: navy;
  font-weight: bold;
}

Forma: selector { propiedad: valor; }

Dónde escribir CSS

Puede ir en un archivo .css enlazado al HTML, dentro de una etiqueta <style> o en el atributo style de un elemento. 

<link rel="stylesheet" href="estilos.css">
<style> p { color: navy; } </style>
<p style="color: navy">Texto</p>

En los ejercicios aparecen las tres formas.

Comentarios

Son notas para quien lee el archivo. El navegador las ignora.

/* Esto es un comentario */

Se abren con /* y se cierran con */.

Cascada y prioridad

Si varias reglas cambian lo mismo, el navegador decide cuál gana según su prioridad y especificidad; si empatan, normalmente gana la última.

p { color: navy; }
.aviso { color: tomato; }

Consejo: usa el selector más sencillo que te sirva.

Herencia

Algunas opciones, como el color o la fuente, suelen pasar del elemento padre a sus hijos. Otras, como el margen, no se heredan normalmente.

body { color: #333; }
/* El texto interior suele heredar ese color. */

La herencia ayuda a no repetir reglas.

Unidades de medida y tamaños flexibles

px es una unidad fija de CSS; % depende del contexto; em depende de la letra del elemento y rem de la raíz. vw/vh son porcentajes de la ventana; vmin/vmax toman el lado menor/mayor. dvh sigue la altura visible dinámica en móviles. ch aproxima el ancho del carácter cero. cm, mm, in, pt y pc son unidades físicas. fr se usa en Grid. El cero puede escribirse sin unidad. 

width: min(100%, 60rem);
font-size: clamp(1rem, 2vw, 1.5rem);

Funciones: calc() para operar; min()/max() eligen límites; clamp(mínimo, preferido, máximo) limita un valor.

Especificidad: qué regla gana

Si dos declaraciones compiten, primero cuentan origen, capa y !important; luego especificidad; al final, si empatan, gana la regla posterior. Como orientación, un #id pesa más que una clase, y una clase más que una etiqueta. No abuses de !important: dificulta sobrescribir estilos. 

p { color: navy; }
.aviso { color: tomato; }

Selectores y cascada. !important se escribe al final del valor, por ejemplo color: red !important.

Capas de cascada

@layer agrupa reglas y establece prioridades claras sin subir la especificidad. En reglas normales, las capas declaradas después tienen prioridad; las reglas sin capa ganan a las reglas normales dentro de capas. En reglas importantes se invierte el orden.

@layer base, componentes;
@layer base { p { color: #333; } }
@layer componentes { .aviso { color: teal; } }

Regla: @layer. Útil para hojas grandes o estilos de terceros.

Importar otra hoja de estilos

@import carga otra hoja CSS. Debe aparecer antes de las reglas normales (salvo otras instrucciones de organización). Para proyectos comunes, suele ser más sencillo enlazar cada hoja con <link> en HTML.

@import url("colores.css");

Regla: @import

Valores globales de CSS

inherit fuerza heredar del padre; initial usa el valor inicial definido por CSS; unset hereda si esa propiedad normalmente se hereda y, si no, usa su valor inicial; revert vuelve a la cascada de un origen anterior; revert-layer retrocede la capa actual. No son lo mismo que auto. 

.hijo { color: inherit; }

Valores globales: disponibles para cualquier propiedad CSS

Variables CSS y valor alternativo

Una variable personalizada empieza con dos guiones y respeta la cascada/herencia. var(--nombre, alternativa) usa el segundo valor si la variable no está definida o no es válida para esa propiedad. Las variables almacenan texto/valores CSS, no son variables de preprocesador. 

:root { --acento: teal; }
a { color: var(--acento, navy); }

Funciones y sintaxis: --nombre, var()

Anidamiento de reglas

CSS permite escribir reglas dentro de otras, sin necesidad de un preprocesador. & representa al selector padre. Agrupa los estilos de un componente y evita repetir el nombre de la clase.

.tarjeta {
  padding: 1rem;

  h3 { margin: 0; }

  &:hover { background: #f4f4f4; }

  .destacada & { border-color: gold; }
}

Símbolo: &; disponible en los navegadores actuales.

Propiedades personalizadas registradas: @property

@property declara una variable CSS con tipo, valor inicial y herencia. Gracias al tipo, el navegador puede animarla (por ejemplo, un ángulo de un degradado).

@property --angulo {
  syntax: "<angle>";
  inherits: false;
  initial-value: 0deg;
}

.rueda {
  background: conic-gradient(from var(--angulo), red, blue);
  transition: --angulo .5s;
}
.rueda:hover { --angulo: 180deg; }

At-rule: @property; descriptores: syntax, inherits, initial-value

Limitar estilos a una zona: @scope

@scope aplica reglas solo dentro de una parte del documento y, si quieres, deja fuera una zona interior con to. Evita nombres de clase muy largos para no pisar otros estilos.

@scope (.tarjeta) to (.contenido) {
  h3 { color: teal; }
  a  { text-decoration: none; }
}

Comprueba el soporte del navegador antes de usarlo en producción.

Restablecer todas las propiedades: all

all aplica un valor global (initial, inherit, unset, revert) a todas las propiedades a la vez. Es útil para aislar un componente de estilos heredados.

.aislado {
  all: revert;
}

Propiedad: all; no afecta a direction ni a unicode-bidi.

Prefijos de navegador

Los prefijos (-webkit-, -moz-, -ms-, -o-) se usaban con propiedades todavía experimentales. El navegador aplica las líneas que entiende e ignora las demás, así que se escribían primero las versiones con prefijo y, al final, la estándar. Hoy casi ninguna propiedad los necesita: consulta caniuse.com y, si trabajas con herramientas de compilación, usa Autoprefixer para que los añada solo cuando hagan falta.

.columnas {
  -webkit-column-count: 2;
  -moz-column-count: 2;
  column-count: 2;      /* la estándar, siempre la última */
}

Prefijos: -webkit- (Chrome, Safari), -moz- (Firefox), -ms- (IE antiguo), -o- (Opera antiguo)

Reiniciar estilos: reset y normalize

Cada navegador aplica estilos por defecto (márgenes, tamaños de títulos). Un reset mínimo los uniformiza al empezar un proyecto.

*, *::before, *::after { box-sizing: border-box; }
body { margin: 0; line-height: 1.5; }
img, svg, video { max-width: 100%; height: auto; display: block; }
button, input, select, textarea { font: inherit; }

Hojas conocidas: normalize.css, modern-normalize

!important

!important hace que una declaración gane sobre las demás de su mismo origen. Úsalo solo en casos excepcionales (por ejemplo, utilidades): complica el mantenimiento.

.oculto { display: none !important; }

Mejor ajustar la especificidad o usar capas (@layer).

Orígenes de los estilos

Los estilos provienen de tres orígenes: la hoja por defecto del navegador, las preferencias de la persona usuaria y la hoja del autor (la tuya). La cascada los combina: normalmente gana la del autor.

/* Navegador: h1 { font-size: 2em; margin: .67em 0 }
   Autor:     h1 { font-size: 3rem; }   <- esta gana */

Orden de prioridad (sin !important): autor > usuario > navegador

Funciones de CSS: resumen

CSS incluye funciones que calculan o generan valores: calc(), min(), max(), clamp(), var(), attr(), url(), rgb(), hsl(), repeat(), minmax(), env(), counter(), linear-gradient().

width: calc(100% - 2rem);
font-size: clamp(1rem, 2.5vw, 2rem);
padding: max(1rem, 3vw);
color: var(--marca, teal);
grid-template-columns: repeat(auto-fit, minmax(14rem, 1fr));

Sintaxis: nombre(argumentos)

Tipografía fluida con clamp

clamp(mínimo, preferido, máximo) hace que el tamaño de letra crezca con la pantalla, sin pasar de un mínimo y un máximo.

h1 { font-size: clamp(2rem, 1.2rem + 3vw, 4rem); }
p  { font-size: clamp(1rem, .95rem + .3vw, 1.2rem); }

Combina rem con vw para respetar el zoom.

Metodología BEM

BEM (Bloque, Elemento, Modificador) es una convención para nombrar clases de forma predecible: bloque__elemento--modificador.

.tarjeta { }
.tarjeta__titulo { }
.tarjeta--destacada { }

/* <article class="tarjeta tarjeta--destacada">
     <h3 class="tarjeta__titulo">…</h3> */

Evita selectores muy anidados y especificidad alta.

Organizar un archivo CSS

Un orden habitual: variables y reset, tipografía, diseño general, componentes y utilidades, y al final las media queries. Dentro de cada regla, agrupa propiedades por tipo (posición, caja, tipografía, color, efectos).

/* 1. Variables y reset */
/* 2. Base: body, títulos, enlaces */
/* 3. Layout: cabecera, rejilla, pie */
/* 4. Componentes: botón, tarjeta, menú */
/* 5. Utilidades */
/* 6. Media queries */

Comentarios de sección facilitan la lectura.

Preprocesadores: Sass

Sass amplía CSS con variables, anidamiento, mixins y funciones, y se compila a CSS normal. Hoy CSS ya incluye variables y anidamiento nativos, por lo que su uso es menos necesario.

$marca: #245b78;
.boton {
  background: $marca;
  &:hover { background: darken($marca, 10%); }
}

Extensiones de archivo: .scss, .sass

Frameworks CSS: Bootstrap y Tailwind

Bootstrap ofrece componentes ya hechos (botones, tarjetas, rejilla). Tailwind propone clases de utilidad pequeñas que se combinan en el HTML. Conviene dominar CSS antes de usarlos.

<!-- Bootstrap -->
<button class="btn btn-primary">Enviar</button>

<!-- Tailwind -->
<button class="rounded bg-blue-600 px-4 py-2 text-white">Enviar</button>

Un framework acelera, pero no sustituye entender CSS.

Depurar CSS con las herramientas del navegador

En el inspector (F12) puedes ver qué reglas se aplican a un elemento, cuáles se anulan (tachadas), el valor calculado, el modelo de caja y editar los valores en vivo.

F12 → Elementos → seleccionar nodo
Panel Estilos: reglas aplicadas, tachadas = anuladas
Panel Calculado: valores finales
Diagrama de caja: margen, borde, relleno, contenido

Tip: muestra insignias de Grid y Flex en el árbol.

Validar CSS

El validador de CSS del W3C (jigsaw) detecta errores de sintaxis y propiedades inexistentes. Los errores de un valor invalidan solo esa declaración; el resto de la hoja sigue funcionando.

color: #zzz;          /* inválido: se ignora esta línea */
colour: red;          /* propiedad inexistente */

Herramienta: jigsaw.w3.org/css-validator

Unidades de CSS: absolutas y relativas

Las absolutas (px, cm, mm, pt) tienen un tamaño fijo. Las relativas dependen de otra cosa: em (tamaño de letra del elemento), rem (de la raíz), % (del contenedor), vw/vh (de la ventana), ch (ancho del cero).

font-size: 1.125rem;
padding: 2em;
width: 50%;
height: 100vh;
max-width: 65ch;

Para accesibilidad, prefiere rem y em en tipografía.

Ángulos, tiempos y otras unidades

Además de longitudes hay otras unidades: ángulos (deg, rad, turn), tiempos (s, ms), resolución (dpi, dppx) y fracciones de Grid (fr).

transform: rotate(.25turn);
transition: opacity 300ms;
@media (min-resolution: 2dppx) { }
grid-template-columns: 1fr 2fr;

Unidades: deg, turn, ms, dppx, fr

Texto solo para lectores de pantalla (sr-only)

Oculta un elemento a la vista, pero lo mantiene accesible para los lectores de pantalla. No uses display: none ni visibility: hidden, que también lo esconden a las tecnologías de apoyo.

.sr-only {
  position: absolute;
  width: 1px; height: 1px;
  margin: -1px; padding: 0;
  overflow: hidden;
  clip-path: inset(50%);
  white-space: nowrap;
  border: 0;
}

Clase habitual: .sr-only o .visually-hidden

Funciones matemáticas: round, mod, rem, sin, cos, pow, sqrt, abs, sign

CSS incluye funciones matemáticas modernas dentro de calc() o por sí solas: round(), mod(), rem(), abs(), sign(), pow(), sqrt(), hypot() y trigonométricas.

width: round(up, 100%, 10px);
height: abs(-20px);
rotate: calc(sin(30deg) * 90deg);
padding: calc(sqrt(16) * 1px);
margin: mod(17px, 5px);

Soporte reciente: usa @supports si lo necesitas.

Sintaxis de color relativa

Permite derivar un color a partir de otro, modificando sus canales. Es útil para generar variantes sin escribir cada valor.

.boton { --marca: #245b78; }
.boton:hover {
  background: hsl(from var(--marca) h s calc(l - 10));
}
.tenue { background: rgb(from var(--marca) r g b / 20%); }

Palabra clave: from

Leer y cambiar variables CSS con JavaScript

Las variables CSS se pueden leer y modificar desde JavaScript, lo que permite temas y valores dinámicos.

document.documentElement.style.setProperty("--marca", "tomato");
getComputedStyle(document.documentElement).getPropertyValue("--marca");

Métodos: setProperty, getPropertyValue, removeProperty

Unidades lh, rlh y svw

lh equivale a la altura de línea del elemento y rlh a la de la raíz; sirven para alinear con el ritmo vertical. svw, lvw y dvw son las versiones de ancho de ventana pequeño, grande y dinámico.

p { margin-block: 1lh; }
textarea { min-height: 5lh; }

Unidades: lh, rlh, cap, ex, ic

Capas en @import

@import admite asignar la hoja importada a una capa de cascada y condicionarla.

@import url("reset.css") layer(base);
@import url("tema.css") layer(tema) supports(display: grid);
@import url("print.css") print;

Debe ir antes del resto de reglas.

Contar con counter-set y counter-increment

Los contadores CSS numeran elementos automáticamente: counter-reset crea uno, counter-increment lo aumenta y counter-set fija su valor.

body { counter-reset: capitulo; }
h2::before { counter-increment: capitulo; content: "Capítulo " counter(capitulo) ". "; }

Funciones: counter(), counters()

Las letras y cómo se leen

Texto

Grosor de la letra

normal suele ser 400 y bold suele ser 700. También puedes usar números del 1 al 1000 (los más comunes son 100, 300, 400, 500, 600, 700, 800 y 900). bolder y lighter eligen un peso relativo al del elemento padre. La fuente debe disponer de ese grosor para que se vea diferente.

font-weight: 700;

Propiedad: font-weight

Estilo de letra

normal muestra el diseño normal; italic usa la cursiva diseñada por la fuente; oblique inclina la letra y admite un ángulo en fuentes que lo soporten. La cursiva semántica suele marcarse con HTML y luego se presenta con CSS.

font-style: italic;

Propiedad: font-style

Tipo de letra

Escribe primero la fuente preferida y luego alternativas. Las familias genéricas funcionan como último recurso: serif (remates), sans-serif (sin remates), monospace (ancho fijo), cursive, fantasy y system-ui (letra del sistema). Si el nombre contiene espacios, ponlo entre comillas. 

font-family: Arial, "Trebuchet MS", sans-serif;

Propiedad: font-family

Cargar una fuente propia

@font-face registra un archivo de fuente para poder usarlo con su nombre. woff2 es el formato web habitual. Comprueba licencias y rutas de los archivos, y ofrece una fuente alternativa para cuando no cargue. 

@font-face {
  font-family: "MiFuente";
  src: url("mi-fuente.woff2") format("woff2");
  font-display: swap;
}

Regla: @font-face. font-display: swap muestra una fuente alternativa mientras se carga.

Tamaño de letra

Puede usarse una medida como 18px, 1.2rem o un porcentaje; small, large, smaller y larger son tamaños relativos predefinidos. rem depende de la raíz y suele ser cómodo para adaptar la página. 

font-size: 1.125rem;

Propiedad: font-size

Color de letra

Cambia el color del texto. Puedes usar nombres, códigos hexadecimales o valores RGB.

color: #245b49;

Propiedad: color

Alinear el texto: valores habituales

left alinea a la izquierda y right a la derecha; center centra cada línea; justify estira los espacios para que ambos bordes queden alineados. start y end siguen el sentido de escritura (recomendados para idiomas que pueden ir de derecha a izquierda). match-parent toma el sentido del padre. justify-all también justifica la última línea; se usa poco. El valor inicial es start.

text-align: center;

Propiedad: text-align. Alinea texto y contenido en línea; no centra por sí sola una caja de bloque.

Subrayado y otras líneas

text-decoration-line admite underline (debajo), overline (encima), line-through (tachado), combinaciones o none. El atajo text-decoration puede añadir color, estilo (solid, wavy, dotted, dashed, double) y grosor. No quites el subrayado de enlaces sin ofrecer otra señal visible. 

text-decoration: underline wavy tomato;

Propiedades: text-decoration, text-decoration-line, text-decoration-style, text-decoration-color

Mayúsculas y minúsculas

uppercase pasa a mayúsculas; lowercase, a minúsculas; capitalize, a iniciales mayúsculas; none mantiene el texto. full-width y full-size-kana son opciones tipográficas para escrituras de Asia oriental. 

text-transform: uppercase;

Propiedad: text-transform

Separación entre letras o palabras

Aumenta o reduce el hueco entre letras o entre palabras.

letter-spacing: 2px;
word-spacing: 4px;

Propiedades: letter-spacing y word-spacing

Interlineado

normal deja que el navegador elija; un número como 1.6 multiplica el tamaño de letra y suele ser la opción más flexible; también acepta longitudes y porcentajes. Un interlineado mayor suele facilitar la lectura; evita porcentajes rígidos si el tamaño de letra puede cambiar.

line-height: 1.6;

Propiedad: line-height

Texto demasiado largo y puntos suspensivos

text-overflow: ellipsis muestra puntos suspensivos cuando el texto queda recortado. No recorta por sí sola: normalmente necesita una caja limitada, overflow: hidden y white-space: nowrap. clip recorta sin puntos. 

.titulo {
  overflow: hidden;
  white-space: nowrap;
  text-overflow: ellipsis;
}

Propiedad: text-overflow

Partir palabras y direcciones largas

word-break: normal usa las reglas del idioma; break-all puede cortar en cualquier punto; keep-all evita cortes entre caracteres de escrituras CJK. Para URL largas suele convenir overflow-wrap: anywhere, que solo rompe cuando hace falta. 

.url { overflow-wrap: anywhere; }

Propiedades: word-break, overflow-wrap

Guiones al final de línea

hyphens: auto permite al navegador cortar palabras con guion según el idioma indicado en el HTML; manual solo corta donde hay un guion blando explícito; none lo desactiva. El idioma correcto es importante para una separación silábica adecuada. 

p { hyphens: auto; }

Propiedad: hyphens

Texto en varias columnas

column-count sugiere cuántas columnas; column-width sugiere el ancho mínimo y el navegador calcula cuántas caben. column-gap separa; column-rule dibuja una línea; column-span: all permite que un título cruce todas. 

.articulo {
  columns: 18rem 2;
  column-gap: 2rem;
}

Atajo columns y propiedades column-*

Dirección y escritura vertical

writing-mode define la orientación del texto: horizontal-tb (habitual), vertical-rl o vertical-lr. Junto con direction influye en qué significa inicio y final; los idiomas se declaran en HTML con el atributo dir. 

writing-mode: vertical-rl;

Propiedades: writing-mode, direction, text-orientation

Atajo para varias opciones de letra

font puede reunir grosor, tamaño, interlineado y familia en una sola declaración. 

font: bold 16px/1.5 Arial, sans-serif;

Propiedad abreviada: font

Versalitas

Muestra las letras minúsculas con forma de mayúsculas pequeñas.

font-variant: small-caps;

Propiedad: font-variant

Sombra del texto

El orden es desplazamiento horizontal, desplazamiento vertical, desenfoque (opcional) y color (opcional). Un desplazamiento negativo mueve la sombra hacia arriba o a la izquierda. Se pueden separar varias sombras con comas; none las quita. No tiene opción inset. 

text-shadow: 2px 3px 4px #0008, -1px 0 #fff;

Propiedad: text-shadow

Dirección del texto

Indica el sentido de escritura: ltr va de izquierda a derecha y rtl, de derecha a izquierda.

direction: rtl;

Propiedad: direction

Grosor y distancia del subrayado

Permite ajustar la línea decorativa de un enlace para que quede más fina, gruesa, cerca o lejos del texto.

text-decoration-thickness: 2px;
text-underline-offset: 4px;

Propiedades: text-decoration-thickness y text-underline-offset

Alinear la última línea y sangrar párrafos

text-align-last alinea únicamente la última línea; admite auto, start, end, left, right, center y justify. text-indent desplaza la primera línea. Para diseños adaptables, suele convenir start y end antes que izquierda/derecha. 

text-align-last: center;
text-indent: 2em;

Propiedades: text-align-last y text-indent

Equilibrar títulos: text-wrap

text-wrap: balance reparte las palabras de un texto corto entre sus líneas para evitar una última línea con una sola palabra. pretty mejora el reparto en párrafos largos.

h1, h2 { text-wrap: balance; }
p { text-wrap: pretty; }

Propiedad: text-wrap; valores: balance, pretty, nowrap

Limitar un texto a unas líneas

line-clamp corta el texto tras un número de líneas y añade puntos suspensivos. Es útil en resúmenes o tarjetas.

.resumen {
  display: -webkit-box;
  -webkit-box-orient: vertical;
  -webkit-line-clamp: 3;
  line-clamp: 3;
  overflow: hidden;
}

Propiedades: line-clamp, -webkit-line-clamp

Fuentes variables

Una fuente variable contiene muchos pesos o anchuras en un solo archivo. Se controlan con font-weight y con font-variation-settings para los ejes personalizados.

@font-face {
  font-family: "Inter";
  src: url("inter-var.woff2") format("woff2");
  font-weight: 100 900;
}
.titulo { font-weight: 650; }
.ancho  { font-variation-settings: "wdth" 110; }

Propiedad: font-variation-settings; el rango de pesos se declara en @font-face.

Ancho de las tabulaciones: tab-size

tab-size define cuántos espacios ocupa una tabulación en un bloque pre o en texto con espacios conservados.

pre {
  tab-size: 2;
}

Propiedad: tab-size

Subíndices y superíndices con CSS

font-variant-position pide al navegador las variantes tipográficas de subíndice (sub) o superíndice (super) de la fuente, pero su compatibilidad es limitada. Para el caso habitual es más fiable usar las etiquetas sub y sup, o vertical-align con un tamaño menor.

.quimica { font-variant-position: sub; }   /* soporte limitado */

.indice {
  vertical-align: sub;       /* o: super */
  font-size: .75em;
}

Propiedades: font-variant-position (normal, sub, super), vertical-align

Texto de recorte personalizado

Además de clip y ellipsis, text-overflow admite una cadena propia como marca de recorte, pero solo algunos navegadores la entienden, así que debes tener un valor de respaldo.

.nota {
  width: 12rem;
  overflow: hidden;
  white-space: nowrap;
  text-overflow: ellipsis;       /* respaldo */
  text-overflow: " [y más..]";   /* solo donde se admite */
}

Valores: clip, ellipsis, "cadena"

word-wrap: el nombre antiguo

word-wrap es el nombre antiguo de overflow-wrap. Con el valor break-word, una palabra demasiado larga para su caja se parte en lugar de desbordarla. Los dos nombres funcionan, pero conviene usar el nuevo.

.comentario {
  word-wrap: break-word;       /* nombre antiguo */
  overflow-wrap: break-word;   /* nombre actual */
}

Propiedades: word-wrap, overflow-wrap

Varias sombras en un texto: efectos

Separando sombras con comas se logran efectos como un resplandor de neón o llamas. Las sombras se apilan: la primera queda arriba. Mejor sobre fondo oscuro y cuidando la legibilidad. Usar texto con sombras en lugar de imágenes ahorra descargas, mejora la accesibilidad y permite ampliar sin pixelar.

.fuego {
  background: #000;
  color: #fff;
  text-shadow:
    0 0 4px #fff,
    0 -5px 4px #ff3,
    2px -10px 6px #fd3,
    -2px -15px 11px #f80,
    2px -25px 18px #f20;
}
.neon { text-shadow: 0 0 6px #0ff, 0 0 18px #0ff; }

Cada sombra: desplazamientoX desplazamientoY desenfoque color

Familias de fuentes genéricas y system-ui

Termina siempre la lista de fuentes con una familia genérica: serif, sans-serif, monospace, cursive o system-ui. system-ui usa la fuente del sistema operativo, rápida y sin descargar nada.

body { font-family: system-ui, -apple-system, "Segoe UI", Roboto, sans-serif; }
code { font-family: ui-monospace, Consolas, monospace; }
h1 { font-family: Georgia, "Times New Roman", serif; }

Propiedad: font-family

Texto con degradado

Para rellenar un texto con un degradado se recorta el fondo con la forma del texto.

.titulo {
  background: linear-gradient(90deg, #f7df1e, #e44d26);
  -webkit-background-clip: text;
  background-clip: text;
  color: transparent;
}

Propiedades: background-clip: text, color: transparent

Contorno del texto

-webkit-text-stroke dibuja un contorno alrededor de las letras (compatible con todos los navegadores actuales a pesar del prefijo).

.contorno {
  color: transparent;
  -webkit-text-stroke: 2px #222;
}

Propiedad: -webkit-text-stroke

Ligaduras y características tipográficas

Las fuentes OpenType incluyen ligaduras, cifras tabulares y otras variantes que se activan con font-variant-* o font-feature-settings.

.precio { font-variant-numeric: tabular-nums; }
.titulo { font-variant-ligatures: common-ligatures; font-kerning: normal; }
.codigo { font-feature-settings: "liga" 0; }

Propiedades: font-variant-numeric, font-kerning, font-feature-settings

Comillas tipográficas: quotes

quotes define qué comillas usan los elementos q y los pseudoelementos con open-quote y close-quote.

q { quotes: "«" "»" "“" "”"; }
blockquote::before { content: open-quote; }
blockquote::after  { content: close-quote; }

Propiedad: quotes

Mostrar fuente mientras carga: font-display

font-display indica cómo mostrar el texto mientras se descarga una fuente propia. swap muestra primero una fuente de respaldo y cambia cuando llega la propia.

@font-face {
  font-family: "Mi fuente";
  src: url("mi-fuente.woff2") format("woff2");
  font-display: swap;
}

Valores: auto, block, swap, fallback, optional

Medida de línea óptima

Para leer cómodo, una línea debería tener entre 45 y 75 caracteres. La unidad ch permite limitar el ancho del texto en función de ello.

.articulo {
  max-width: 65ch;
  line-height: 1.6;
  margin-inline: auto;
}

Unidad: ch

Letra capital con initial-letter

initial-letter crea una letra capitular (más grande, ocupando varias líneas). Su compatibilidad es limitada, por lo que a menudo se usa float con ::first-letter como alternativa.

p::first-letter {
  initial-letter: 3;
}
/* Alternativa */
p::first-letter { float: left; font-size: 3em; line-height: 1; padding-right: .1em; }

Propiedad: initial-letter

Cursor de texto y selección: caret y user-select

caret-color cambia el color del cursor de escritura en los campos. user-select permite o impide seleccionar texto.

input { caret-color: crimson; }
.no-copiar { user-select: none; }
.todo-seleccionable { user-select: all; }

Propiedades: caret-color, user-select

Hacer que un texto no se desborde: overflow-wrap

overflow-wrap: break-word o anywhere parte palabras muy largas (como URLs) para que no se salgan de su caja. En elementos flex, a veces hace falta min-width: 0.

.comentario { overflow-wrap: anywhere; }
.flex-hijo { min-width: 0; }

Propiedades: overflow-wrap, min-width

Estilos de contador propios: @counter-style

@counter-style define un sistema de numeración o viñetas propio para list-style-type y los contadores.

@counter-style estrellas {
  system: cyclic;
  symbols: "★";
  suffix: " ";
}
ul.valoracion { list-style: estrellas; }

Descriptores: system, symbols, suffix

Énfasis del texto: text-emphasis

text-emphasis añade marcas (puntos, círculos, estrellas) sobre o bajo cada carácter, habitual en la tipografía de Asia oriental.

.enfasis { text-emphasis: filled circle crimson; text-emphasis-position: over right; }

Propiedades: text-emphasis-style, text-emphasis-color

Propiedades de fuente avanzadas: stretch, optical-sizing y synthesis

font-stretch elige variantes más estrechas o anchas (si la fuente las incluye); font-optical-sizing ajusta el diseño según el tamaño; font-synthesis controla si el navegador puede inventar negritas y cursivas.

.condensada { font-stretch: 75%; }
.titulo { font-optical-sizing: auto; }
.sin-falsas { font-synthesis: none; }

Propiedades: font-stretch, font-optical-sizing, font-synthesis

Justificación y saltos de línea: text-justify y line-break

text-justify elige cómo se reparte el espacio al justificar; line-break ajusta las reglas de salto de línea (importante en chino y japonés); hanging-punctuation deja las comillas fuera de la caja de texto.

p { text-align: justify; text-justify: inter-word; hyphens: auto; }
blockquote { hanging-punctuation: first; }

Propiedades: text-justify, line-break, hanging-punctuation

Saltar los descendentes al subrayar: text-decoration-skip-ink

Por defecto el subrayado se interrumpe donde las letras bajan (g, p, y). Con none se dibuja continuo.

a { text-decoration-skip-ink: auto; }
.continuo { text-decoration-skip-ink: none; }

Valores: auto, none, all

Recortar el espacio del texto: text-box-trim

text-box-trim elimina el espacio extra por encima y por debajo del texto, para que las cajas se alineen con las letras (soporte reciente).

h1 { text-box: trim-both cap alphabetic; }

Propiedades: text-box-trim, text-box-edge

Posición del título de una tabla y celdas vacías

caption-side coloca el título arriba o abajo de la tabla; empty-cells oculta o muestra los bordes de celdas vacías.

caption { caption-side: bottom; }
table { empty-cells: hide; }

Propiedades: caption-side, empty-cells

El color de los elementos y del lienzo

Colores y fondos

Color de fondo y formatos de color

Pinta el fondo. Los colores pueden escribirse por nombre (tomato), hexadecimal (#245b49 o #fff), RGB (rgb(36 91 73)), HSL (hsl(155 43% 25%)) o con transparencia, por ejemplo rgb(0 0 0 / 50%). transparent significa transparente; currentColor reutiliza el valor de color. 

background-color: #e1eadf;

Propiedades y formatos: background-color, rgb(), hsl(), hexadecimal y nombres

Imagen de fondo

Coloca una imagen detrás del contenido. La ruta dentro de url(...) indica dónde está el archivo.

background-image: url("fondo.jpg");

Propiedad: background-image

Tamaño de una imagen de fondo

cover cubre toda la caja y puede recortar; contain muestra la imagen entera y puede dejar huecos; auto conserva su tamaño original. También puedes indicar medidas o porcentajes. Se pueden poner varias imágenes separadas por comas.

background-size: cover;

Propiedad: background-size

Transparencia

La transparencia puede escribirse en el color (rgb(0 0 0 / 50%)) o aplicarse al elemento entero con opacity. En RGB con canal alfa, 0 o 0% es transparente y 1 o 100% es opaco. opacity: .5 también vuelve semitransparentes los hijos; un color con alfa solo afecta a ese color.

background: rgb(0 0 0 / 50%);
opacity: .8;

Valores: de transparent a totalmente opaco

Variables de color

Guarda un valor con un nombre para reutilizarlo y cambiarlo desde un solo lugar.

:root {
  --verde: #245b49;
}
h1 { color: var(--verde); }

Sintaxis: --nombre y var()

Colocación de una imagen de fondo

Elige qué zona de la imagen queda visible cuando no cabe entera.

background-position: center;

Propiedad: background-position

Repetir o no el fondo

Controla si una imagen de fondo se repite como un mosaico.

background-repeat: no-repeat;

Propiedad: background-repeat

Degradados

linear-gradient() mezcla en una dirección (por ejemplo to right o un ángulo); radial-gradient() sale desde un punto en forma circular/elíptica; conic-gradient() mezcla alrededor de un centro. Las versiones repeating-* repiten el patrón. Indica paradas de color para controlar dónde empieza cada tono. 

background: linear-gradient(90deg, navy, teal);

Funciones: linear-gradient(), radial-gradient(), conic-gradient() y versiones repeating-

Filtros y desenfoque

filter afecta al elemento: blur() desenfoca; brightness() aclara/oscurece; contrast() cambia contraste; grayscale() quita color; sepia() da tono sepia; saturate() intensifica color; hue-rotate() gira tonos; invert() invierte; opacity() ajusta transparencia; drop-shadow() añade sombra a la silueta. backdrop-filter afecta a lo que se ve detrás, si el fondo deja verlo. 

filter: blur(2px);
backdrop-filter: blur(8px);

Propiedades: filter y backdrop-filter

Repetición, posición y capas del fondo

background-repeat: repeat repite, no-repeat no repite, repeat-x/repeat-y repiten en un eje y space/round distribuyen o ajustan las copias. background-position acepta center, top, left o medidas. background-attachment usa scroll (normal), fixed (respecto a la ventana) o local (con el contenido que se desplaza). También existen background-origin y background-clip para elegir desde dónde se mide y hasta dónde se pinta. 

background: url("fondo.jpg") center / cover no-repeat;

Atajo: background. Cada capa puede tener su propia imagen, posición, tamaño y repetición separados por comas.

Mezclar colores: color-mix

color-mix() calcula un color mezclando otros dos en un porcentaje. Sirve para generar variantes (más claras, más oscuras o semitransparentes) a partir de una sola variable.

:root { --marca: #245b78; }
.boton:hover {
  background: color-mix(in srgb, var(--marca) 80%, black);
}
.tenue {
  background: color-mix(in srgb, var(--marca) 20%, transparent);
}

Función: color-mix(in espacio, color1 %, color2)

Colores modernos: oklch

oklch(luminosidad croma matiz) describe el color de forma más intuitiva y uniforme para el ojo que hsl, y permite colores más vivos en pantallas modernas.

.a { color: oklch(60% 0.15 250); }
.b { color: oklch(60% 0.15 30); }
.c { color: oklch(60% 0.15 140 / 50%); }

Funciones: oklch(), oklab(), lch(), hwb()

Modo claro y oscuro: light-dark

light-dark(claro, oscuro) elige un color según el esquema activo. Necesita declarar color-scheme para que el navegador sepa qué modos admites.

:root { color-scheme: light dark; }
body {
  background: light-dark(#fff, #14181a);
  color: light-dark(#222, #eee);
}

Propiedades: color-scheme y la función light-dark()

El color actual: currentColor

currentColor toma el valor de la propiedad color del elemento. Permite que bordes, sombras o iconos SVG sigan el color del texto sin repetirlo.

.enlace {
  color: teal;
  border-bottom: 2px solid currentColor;
}
svg { fill: currentColor; }

Palabra clave: currentColor

Mezcla de capas: mix-blend-mode

mix-blend-mode combina un elemento con lo que hay detrás (multiply, screen, overlay...). background-blend-mode hace lo mismo entre las capas de fondo de un elemento.

.sello { mix-blend-mode: multiply; }

.portada {
  background: url("foto.jpg") center/cover, #245b78;
  background-blend-mode: multiply;
}

Propiedades: mix-blend-mode, background-blend-mode

background-clip: hasta dónde llega el fondo

Por defecto el fondo se extiende hasta el borde exterior (border-box), por lo que se ve debajo de un borde semitransparente. Con padding-box el fondo llega solo hasta el relleno y con content-box, solo al contenido, de modo que el borde transparente deja ver lo que hay detrás.

.transparente {
  background: #fff;
  border: 20px solid rgb(0 190 0 / 50%);
  padding: 10px;
  background-clip: padding-box;
}

Valores: border-box, padding-box, content-box (y text, con prefijo en algunos navegadores)

Varias imágenes de fondo

En una misma propiedad se pueden poner varias imágenes separadas por comas. La primera queda encima y la última, al fondo. Cada capa puede tener su propia posición, repetición y tamaño. Para navegadores que no admiten varias imágenes, se puede escribir antes una declaración con una sola.

.escena {
  background: url("azulejo.png");     /* respaldo para navegadores antiguos */
  background:
    url("principe.png") 0% 5px no-repeat,
    url("rana.png") 100% 5px no-repeat,
    url("azulejo.png");
  background-size: auto, auto, 50% 100%;   /* un tamaño por capa */
}

Propiedades por capa: background-position, background-repeat, background-size

Fondo en mosaico sin cortar la imagen

Una imagen de fondo que se repite puede quedar cortada si su tamaño no divide el de la caja. Con background-size se ajusta: un valor y auto mantienen la proporción; los porcentajes se calculan sobre la caja, no sobre la imagen.

.mosaico {
  width: 600px;
  height: 350px;
  background-image: url("azulejo.png");   /* 125 x 125 px */
  background-size: 50px auto;             /* 50 px de ancho, alto proporcional */
}
.dos-mitades { background-size: 50% 100%; }   /* dos columnas de imagen */

Propiedad: background-size; auto conserva las proporciones.

Formas de escribir un color

Un color puede darse con nombre (tomato), hexadecimal (#ff6347), rgb(), hsl() o hwb(). La transparencia se añade como cuarto valor.

color: tomato;
color: #ff6347;
color: rgb(255 99 71);
color: rgb(255 99 71 / 50%);
color: hsl(9 100% 64%);

Formatos: nombre, #hex, rgb(), hsl(), hwb(), oklch()

Opacidad: opacity frente a color transparente

opacity afecta a todo el elemento, incluidos sus hijos. Con un color con canal alfa solo se hace transparente ese color.

.caja-a { opacity: .5; }                      /* todo el elemento */
.caja-b { background: rgb(0 0 0 / 50%); }     /* solo el fondo */

Propiedad: opacity (0 a 1)

Degradados: lineal, radial y cónico

Los degradados son imágenes generadas por CSS: linear-gradient (en línea), radial-gradient (desde un punto) y conic-gradient (alrededor de un centro). Las versiones repeating-* los repiten.

.a { background: linear-gradient(to right, #f7df1e, #e44d26); }
.b { background: radial-gradient(circle at 30% 30%, white, #245b78); }
.c { background: conic-gradient(red, yellow, green, blue, red); }
.d { background: repeating-linear-gradient(45deg, #ddd 0 10px, #fff 10px 20px); }

Se usan en background o background-image.

Efecto cristal: backdrop-filter

backdrop-filter aplica un filtro a lo que hay detrás del elemento, como un desenfoque. Necesita un fondo semitransparente.

.panel {
  background: rgb(255 255 255 / 40%);
  backdrop-filter: blur(10px);
  border: 1px solid rgb(255 255 255 / 30%);
}

Propiedad: backdrop-filter

Fondo fijo y efecto parallax

Con background-attachment: fixed la imagen de fondo se queda quieta mientras el contenido se desplaza, dando efecto de profundidad. En móviles suele estar desactivado.

.portada {
  background: url("paisaje.jpg") center / cover no-repeat;
  background-attachment: fixed;
  min-height: 60vh;
}

Propiedad: background-attachment

Dónde empieza el fondo: background-origin

background-origin define desde dónde se calcula la posición de la imagen de fondo: el borde, el relleno o el contenido.

.caja {
  background: url("trama.png") no-repeat left top;
  background-origin: content-box;
  padding: 20px;
}

Valores: padding-box (por defecto), border-box, content-box

Atajo background completo

El atajo background reúne color, imagen, posición, tamaño (tras /), repetición, anclaje, origen y recorte.

.hero {
  background: #123 url("foto.jpg") center / cover no-repeat;
}

Orden orientativo: color imagen posición / tamaño repetición

Sombras de colores y brillo

Una sombra no tiene por qué ser gris: con un color y desenfoque grande se logra un brillo.

.brilla {
  box-shadow: 0 0 20px 4px rgb(0 200 255 / 60%);
}
.icono { filter: drop-shadow(0 0 6px gold); }

Propiedades: box-shadow, filter: drop-shadow()

Contraste de color y accesibilidad

El texto necesita suficiente contraste con su fondo (mínimo 4,5:1 para texto normal). Además no dependas solo del color para transmitir información: añade texto o iconos.

.error { color: #b00020; border-left: 4px solid #b00020; }
.error::before { content: "⚠ "; }

Pautas: WCAG 2.2 nivel AA

Tema de colores con variables

Definir los colores como variables facilita cambiar de tema: basta con redefinirlas.

:root {
  --fondo: #fff;
  --texto: #222;
  --marca: #245b78;
}
@media (prefers-color-scheme: dark) {
  :root { --fondo: #14181a; --texto: #eee; --marca: #7cc0e0; }
}
body { background: var(--fondo); color: var(--texto); }

Variables: --nombre y var(--nombre)

Máscaras de imagen: mask

mask-image oculta partes de un elemento según la transparencia de una imagen o degradado, por ejemplo para desvanecer un borde.

.difuminado {
  mask-image: linear-gradient(to bottom, black 70%, transparent);
}

Propiedades: mask-image, mask-size, mask-repeat

El espacio que ocupa cada cosa

Tamaño, espacio y bordes

Ancho

Define cuánto mide un elemento de lado a lado.

width: 300px;
max-width: 100%;

Propiedades: width y max-width

Alto

Define la altura. Para imágenes, height: auto conserva sus proporciones originales. 

height: auto;
min-height: 200px;

Propiedades: height y min-height

Margen: espacio de fuera

Separa un elemento de los vecinos. Atajo de 1 valor: los 4 lados; 2: arriba/abajo y derecha/izquierda; 3: arriba, lados, abajo; 4: arriba, derecha, abajo, izquierda (sentido horario). auto puede repartir el espacio sobrante en horizontal. Los márgenes verticales de bloques a veces se colapsan.

margin: 10px 20px 30px 40px;

Propiedades: margin, margin-top/right/bottom/left

Relleno: espacio de dentro

Deja aire entre contenido y borde. Usa la misma regla de 1, 2, 3 o 4 valores que margin. El relleno no acepta valores negativos; se pinta con el fondo del elemento. No es lo mismo que el margen, que queda fuera. 

padding: 12px 20px;

Propiedades: padding, padding-top/right/bottom/left

Borde y estilos de línea

El atajo combina grosor, estilo y color. Estilos frecuentes: solid (continuo), dashed (guiones), dotted (puntos), double (doble), groove/ridge (relieve), inset/outset (hundido/levantado), none (sin borde). hidden se usa sobre todo en tablas. 

border: 2px dashed #245b49;

Propiedades: border, border-width, border-style, border-color

Esquinas redondeadas

Un valor aplica a las cuatro esquinas; con cuatro valores se recorren en sentido horario desde arriba a la izquierda. Puedes usar porcentajes (100% puede formar un círculo si la caja es cuadrada) y una barra para separar radios horizontales y verticales. Cada esquina también se puede ajustar por separado.

border-radius: 12px 0 12px 0;

Propiedades: border-radius, border-top-left-radius, border-top-right-radius, etc.

Sombra de una caja: sintaxis

La forma frecuente es desplazamiento horizontal, vertical, desenfoque (opcional), expansión (opcional) y color (opcional). El desplazamiento puede ser negativo. inset dibuja la sombra dentro de la caja; sin él queda fuera. none quita la sombra. El desenfoque no puede ser negativo; la expansión sí puede.

box-shadow: 0 4px 12px 2px #0003;

Propiedad: box-shadow. La sombra no cambia el espacio que ocupa el elemento.

Varias sombras y sombra interior

Se pueden superponer varias sombras separándolas con comas. La primera se dibuja encima de las siguientes. Puedes mezclar sombras exteriores e interiores con inset; none indica que no haya ninguna. 

box-shadow: 0 2px 6px #0003, inset 0 0 0 1px #fff;

Una lista de sombras en box-shadow

box-shadow o drop-shadow

box-shadow sombrea el rectángulo de la caja, incluidas sus esquinas redondeadas. filter: drop-shadow() sigue la silueta visible (útil en imágenes PNG transparentes o formas recortadas). Son efectos distintos. 

filter: drop-shadow(3px 4px 5px #0006);

Funciones de sombra: box-shadow y drop-shadow()

Cómo se calcula el tamaño

content-box (predeterminado) suma ancho + relleno + borde. Con border-box, el ancho declarado ya los incluye; suele hacer más fácil controlar medidas. 

* { box-sizing: border-box; }

Propiedad: box-sizing

Proporción de caja o imagen

Fija la relación entre ancho y alto: por ejemplo, 4 unidades de ancho por 3 de alto.

aspect-ratio: 4 / 3;

Propiedad: aspect-ratio

Elegir qué parte de la imagen se ve

Con object-position decides qué zona conservar cuando la imagen se recorta con object-fit: cover. 

object-position: center top;

Propiedad: object-position

Borde de un solo lado

Aplica una línea solo en un lado. El color, grosor y estilo también se pueden cambiar por separado.

border-bottom: 1px solid #ccc;
border-left: 4px solid teal;

Variantes: border-top, border-right, border-bottom, border-left y border-color

Color del borde inferior

Cambia solo el color del borde de abajo, conservando su grosor y estilo.

border-bottom-color: tomato;

Propiedad: border-bottom-color

Bordes y distribución de tablas

border-collapse une o separa los bordes de las celdas; border-spacing define su separación y table-layout ayuda a distribuir el ancho.

border-collapse: collapse;
border-spacing: 0;
table-layout: fixed;

Propiedades de tabla.

Contorno de foco

Dibuja una marca por fuera del borde, útil para indicar dónde está el foco del teclado.

outline: 2px solid coral;
outline-offset: 3px;

Propiedades: outline y outline-offset

Contenido que no cabe

visible deja que sobresalga; hidden recorta y permite desplazamiento programático; clip recorta sin crear una zona de scroll; scroll muestra zona desplazable siempre; auto muestra barras solo cuando hacen falta. Se puede controlar cada eje por separado.

overflow-x: auto;
overflow-y: hidden;

Propiedades: overflow, overflow-x, overflow-y, overflow: clip

Romper palabras largas

Permite partir una palabra o dirección larga para que no ensanche la página.

overflow-wrap: anywhere;

Propiedad: overflow-wrap

Espacios y saltos de línea

normal combina espacios y permite saltos; nowrap combina espacios pero mantiene el texto en una línea; pre conserva espacios y saltos escritos; pre-wrap los conserva y permite ajustar líneas; pre-line conserva saltos y combina espacios; break-spaces conserva incluso los espacios finales y permite cortar. 

white-space: pre-wrap;

Propiedad: white-space

Desplazamiento a secciones

scroll-behavior suaviza los saltos a una sección. scroll-margin-top deja espacio antes del título de destino.

html { scroll-behavior: smooth; }
section { scroll-margin-top: 20px; }

Propiedades: scroll-behavior y scroll-margin-top

Márgenes por lado

El espacio exterior se puede controlar para cada lado por separado.

margin-top: 8px;
margin-right: 12px;
margin-bottom: 16px;
margin-left: 20px;

Propiedades: margin-top, margin-right, margin-bottom, margin-left

Relleno por lado

El espacio interior también puede tener una medida distinta en cada lado.

padding-top: 8px;
padding-right: 12px;
padding-bottom: 16px;
padding-left: 20px;

Propiedades: padding-top, padding-right, padding-bottom, padding-left

Alinear verticalmente

En celdas de tabla: top, middle, bottom, baseline. En elementos en línea también admite sub, super, text-top, text-bottom, porcentajes y medidas. No centra verticalmente cualquier bloque: para eso suele usarse Flex o Grid. 

vertical-align: middle;

Propiedad: vertical-align

Límites de tamaño

Los mínimos y máximos permiten que una caja se ajuste sin quedar demasiado pequeña o grande.

min-width: 320px;
max-height: 500px;

También existen min-height y max-width.

Tamaños automáticos según el contenido

auto deja participar a las reglas normales de diseño. min-content es el menor tamaño sin desbordar palabras; max-content ocupa lo necesario para una línea; fit-content ajusta el contenido sin superar el espacio disponible. Se usan en ancho/alto, Grid y otras propiedades de tamaño. 

width: fit-content;

Palabras clave de tamaño intrínseco: min-content, max-content, fit-content

Propiedades lógicas: inicio y final

En vez de izquierda/derecha/arriba/abajo, CSS puede usar la dirección del texto: margin-inline (eje en línea), margin-block (eje de bloque), padding-inline-start, border-block-end, inset-inline, inline-size y block-size. Así los estilos se adaptan a idiomas de derecha a izquierda y escritura vertical. 

margin-inline: auto;
padding-block: 1rem;

Sufijos lógicos: -inline, -block, -start, -end

Permitir cambiar el tamaño

resize define si la persona puede redimensionar un elemento que admite ese comportamiento (por ejemplo, un área de texto): none, both, horizontal o vertical. both suele ser el valor inicial en textarea. 

textarea { resize: vertical; }

Propiedad: resize

Partes y estilos del contorno

outline es una línea externa que no ocupa espacio. Se configura con grosor, estilo y color. Los estilos incluyen solid, dashed, dotted, double y none. Mantén un indicador de foco visible y con buen contraste para navegación con teclado. 

outline: 3px solid #bd573d;
outline-offset: 3px;

Propiedades: outline, outline-width, outline-style, outline-color, outline-offset

Barras de desplazamiento

scrollbar-width y scrollbar-color cambian el grosor y los colores de la barra sin trucos específicos de cada navegador. scrollbar-gutter reserva su espacio para que el contenido no se mueva.

.panel {
  overflow-y: auto;
  scrollbar-width: thin;
  scrollbar-color: #245b78 #e0ebee;
  scrollbar-gutter: stable;
}

Propiedades: scrollbar-width, scrollbar-color, scrollbar-gutter

Texto alrededor de una forma: shape-outside

shape-outside hace que el texto rodee un float siguiendo una forma (círculo, polígono o la transparencia de una imagen), en lugar de un rectángulo.

.foto {
  float: left;
  width: 200px;
  height: 200px;
  shape-outside: circle(50%);
  shape-margin: 1rem;
  border-radius: 50%;
}

Propiedades: shape-outside, shape-margin

Imágenes pixeladas: image-rendering

image-rendering controla cómo se escala una imagen. Con pixelated los píxeles se mantienen nítidos, útil para pixel art o códigos QR.

.sprite {
  width: 128px;
  image-rendering: pixelated;
}

Propiedad: image-rendering

Colapso de márgenes

Los márgenes verticales de bloques adyacentes se fusionan: se aplica el mayor, no la suma. También puede ocurrir entre padre e hijo. No ocurre en Flex ni en Grid.

p { margin: 20px 0; }
/* Entre dos párrafos hay 20px, no 40px */

Solución: display: flow-root, relleno o bordes en el padre.

Margen automático: centrar

margin-inline: auto en un bloque con ancho definido lo centra horizontalmente. En contenedores flex, un margen automático empuja al elemento hacia el lado opuesto.

.contenido { max-width: 60rem; margin-inline: auto; }

.barra { display: flex; }
.barra .salir { margin-left: auto; }

Valor: auto

Márgenes negativos

Un margen negativo acerca el elemento a otro o lo superpone. Es útil con moderación.

.titulo { margin-top: -1rem; }
.sobresale { margin-inline: -1rem; }

Pueden causar solapamientos inesperados.

Contorno frente a borde

El contorno (outline) se dibuja fuera del borde, no ocupa espacio ni afecta a la maquetación, y sigue la forma del elemento. Es ideal para el foco.

button:focus-visible {
  outline: 3px solid #bd573d;
  outline-offset: 3px;
}

No lo elimines sin ofrecer una alternativa visible.

Estilos de borde: solid, dashed, dotted, double...

border-style define el trazo: solid, dashed, dotted, double, groove, ridge, inset, outset, none y hidden.

.a { border: 2px solid #333; }
.b { border: 2px dashed #333; }
.c { border: 4px double #333; }
.d { border-bottom: 3px dotted tomato; }

Propiedades: border-style, border-width, border-color

Círculos, óvalos y píldoras

Con border-radius: 50% un cuadrado se convierte en un círculo y un rectángulo, en un óvalo. Un valor muy grande crea los extremos de una píldora.

.avatar { width: 80px; height: 80px; border-radius: 50%; }
.boton  { padding: .5rem 1.25rem; border-radius: 999px; }

Propiedad: border-radius

Borde con degradado

border-image permite usar una imagen o un degradado como borde.

.marco {
  border: 6px solid;
  border-image: linear-gradient(45deg, #f7df1e, #e44d26) 1;
}

Propiedad: border-image (no admite border-radius)

display: contents

display: contents hace que el elemento desaparezca de la maquetación y sus hijos se comporten como si fueran hijos de su abuelo. Útil con Grid y Flex.

.envoltorio { display: contents; }

Cuidado con la accesibilidad en algunos elementos (botones, listas).

Estilizar botones

Un botón bien estilizado tiene tamaño cómodo, estados de foco visibles y un aspecto claro cuando está desactivado.

.boton {
  padding: .6rem 1.2rem;
  border: 0;
  border-radius: .5rem;
  background: #245b78;
  color: #fff;
  font: inherit;
  cursor: pointer;
}
.boton:hover { background: #1b455c; }
.boton:focus-visible { outline: 3px solid #f0c36e; outline-offset: 2px; }
.boton:disabled { opacity: .5; cursor: not-allowed; }

Selectores: :hover, :focus-visible, :disabled

Estilizar campos de formulario

Los campos heredan poco del resto de la página: indica la fuente, el tamaño y el estado de foco.

input, select, textarea {
  font: inherit;
  padding: .5rem .75rem;
  border: 1px solid #999;
  border-radius: .375rem;
  width: 100%;
}
input:focus-visible { outline: 3px solid #245b78; outline-offset: 1px; }
input::placeholder { color: #777; }

Pseudoelemento: ::placeholder

Estilizar tablas

Para tablas legibles: bordes colapsados, relleno en celdas, filas alternas y una cabecera fija al desplazar.

table { border-collapse: collapse; width: 100%; }
th, td { padding: .6rem .8rem; text-align: left; border-bottom: 1px solid #ddd; }
thead th { position: sticky; top: 0; background: #fff; }
tbody tr:nth-child(even) { background: #f6f6f6; }

Propiedades: border-collapse, position: sticky

Menú de navegación horizontal

Un menú es una lista de enlaces; con Flexbox se coloca en horizontal.

nav ul { display: flex; gap: 1rem; list-style: none; margin: 0; padding: 0; }
nav a { text-decoration: none; padding: .5rem .75rem; border-radius: .375rem; }
nav a[aria-current="page"] { background: #245b78; color: #fff; }

Estructura: nav > ul > li > a

Iconos con CSS y SVG

Los iconos SVG en línea heredan el color del texto con currentColor y se dimensionan con em para que escalen con la letra.

.icono { width: 1em; height: 1em; fill: currentColor; vertical-align: -.125em; }

Propiedades: fill, stroke, currentColor

Evitar saltos de contenido al cargar: overflow-anchor

El navegador ajusta el desplazamiento cuando se añade contenido por encima, para que no «salte» lo que lees. overflow-anchor: none lo desactiva en una zona.

.lista-infinita { overflow-anchor: none; }

Propiedad: overflow-anchor

Cursor personalizado con imagen

cursor: url() permite usar una imagen como cursor, con un punto activo y un cursor de respaldo.

.lupa { cursor: url("lupa.svg") 8 8, zoom-in; }

Valores: url(imagen) x y, respaldo

Orientación de las imágenes: image-orientation

image-orientation controla si se respeta la orientación guardada en los metadatos EXIF de una foto.

img { image-orientation: from-image; }

Valores: from-image, none

Mostrar u ocultar colores forzados y de impresión

forced-color-adjust: none excluye un elemento del modo de colores forzados; print-color-adjust: exact obliga a imprimir fondos y colores tal cual.

.logo { forced-color-adjust: none; }
.fondo-tabla { print-color-adjust: exact; }

Propiedades: forced-color-adjust, print-color-adjust

04

Cómo se colocan y ordenan los elementos

Disposición

Display: valores principales

block ocupa una fila disponible; inline fluye dentro del texto y no acepta ancho/alto como una caja normal; inline-block fluye en línea y sí acepta medidas. flex organiza hijos con Flexbox y grid con filas y columnas; inline-flex/inline-grid hacen que el contenedor fluya en línea. table crea una tabla y inline-table una tabla que fluye en línea. none quita la caja del diseño y normalmente del árbol de accesibilidad. 

display: block;

Propiedad: display. El valor inicial depende del tipo de elemento HTML.

Float: hacer que el texto rodee una imagen

Pega un elemento a un lado y deja que el texto fluya a su alrededor. Se usa sobre todo para imágenes; para columnas de una página suele ser más cómodo Flex o Grid.

img {
  float: left;
  margin-right: 16px;
}

Valores habituales: left, right, none. Es una propiedad CSS válida aunque no aparezca en las hojas actuales.

Clear: dejar de rodear un float

Hace que el elemento empiece debajo de las cajas flotantes anteriores, en vez de quedarse a su lado.

.despues { clear: both; }

Valores: left, right, both o none.

Flex: colocar en fila o columna

Reparte los elementos de un contenedor en una fila o columna y ayuda a alinearlos.

.menu {
  display: flex;
  align-items: center;
  gap: 16px;
}

Propiedades: display, align-items y gap

Grid: crear una cuadrícula

Divide el espacio en filas y columnas; viene bien para organizar tarjetas o secciones.

.rejilla {
  display: grid;
  grid-template-columns: 1fr 1fr;
  gap: 20px;
}

Propiedades: display y grid-template-columns

Otros valores de display

list-item añade marcador de lista; flow-root contiene sus flotantes; contents elimina la caja pero conserva los hijos (con posibles diferencias de accesibilidad). Para tablas están table-row-group, table-header-group, table-footer-group, table-row, table-cell, table-column-group, table-column y table-caption. Para anotaciones ruby: ruby, ruby-base, ruby-text, ruby-base-container y ruby-text-container. run-in no tiene soporte interoperable para uso general. Los valores compuestos como inline flow-root indican tipo exterior/interior de caja; también existen inline list-item y inline ruby. 

.contenedor { display: flow-root; }

Valores destacados: list-item, flow-root, contents y familias table-*/ruby-*.

Hueco entre elementos

gap crea espacio entre elementos de Flex o Grid, sin tener que poner márgenes en cada uno.

gap: 12px 24px;

Propiedad: gap

Position: normal, relativa, absoluta, fija o sticky

static es el flujo normal y no responde a top/right/bottom/left. relative conserva su hueco y permite desplazarlo; también crea referencia para hijos absolutos. absolute sale del flujo y se coloca respecto al ancestro posicionado más cercano. fixed se fija normalmente a la ventana. sticky se comporta normal hasta llegar al límite indicado; suele necesitar top y un contenedor con espacio de desplazamiento. 

position: sticky;
top: 0;

Valores de position: static, relative, absolute, fixed, sticky

Mostrar u ocultar

display: none quita el elemento de la página; no deja hueco en su lugar.

.oculto { display: none; }

Propiedad: display

Ocultar conservando el hueco

visibility: hidden no muestra el elemento, pero conserva el espacio que ocupaba. visible lo muestra; collapse se usa especialmente en filas o columnas de tablas. A diferencia de display: none, el elemento invisible sigue ocupando sitio. 

visibility: hidden;

Propiedad: visibility

Centrar una caja

Si la caja tiene un ancho limitado, margin: auto reparte el espacio sobrante a ambos lados.

.contenido {
  max-width: 900px;
  margin: 0 auto;
}

Atajo habitual: margin: 0 auto

Viñetas y numeración

disc, circle y square son viñetas; decimal numera 1, 2, 3; decimal-leading-zero usa 01, 02; lower/upper-alpha usa letras y lower/upper-roman números romanos. none quita el marcador. list-style-position puede ser inside o outside. 

list-style-type: square;

Atajo: list-style; propiedades: list-style-type, list-style-position, list-style-image

Dirección, salto y reparto en Flex

flex-direction: row (fila), row-reverse, column (columna) o column-reverse. flex-wrap: nowrap (una línea), wrap (salta) o wrap-reverse. En cada hijo, flex-grow controla cuánto crece, flex-shrink cuánto se encoge y flex-basis su tamaño base. El atajo flex combina estos tres valores. 

.fila { flex-flow: row wrap; }
.hijo { flex: 1 1 12rem; }

Propiedades: flex-direction, flex-wrap, flex-flow, flex-grow, flex-shrink, flex-basis, flex

Alinear y repartir en Flex y Grid

justify-content y align-content alinean o reparten el conjunto: start, end, center, space-between, space-around, space-evenly (y stretch donde corresponda). align-items/justify-items alinean los hijos: start, end, center, stretch, baseline. align-self/justify-self ajustan un hijo. place-items y place-content son atajos para los dos ejes. En Flex, justify-items no suele tener efecto. 

justify-content: space-between;
align-items: center;

Recuerda: el eje principal de Flex cambia con flex-direction.

Columnas Grid que se adaptan solas

fr reparte el espacio disponible. repeat() repite columnas; minmax() define su mínimo y máximo. auto-fit y auto-fill calculan cuántas caben: auto-fit colapsa columnas vacías; auto-fill conserva su espacio. 

grid-template-columns:
  repeat(auto-fit, minmax(220px, 1fr));

Funciones: repeat() y minmax(); unidad flexible: fr

Filas, áreas y colocación automática en Grid

grid-template-rows define filas; grid-template-areas nombra zonas; grid-area coloca un hijo nombrado o indica su posición. grid-auto-rows/grid-auto-columns dimensionan pistas creadas automáticamente y grid-auto-flow controla el llenado (row, column, opcionalmente dense). 

grid-template-areas: "menu contenido";
grid-auto-flow: row;

Familias de propiedades: grid-template-*, grid-auto-* y grid-area

Colocar algo dentro de Grid

Permite decir qué columnas o filas debe ocupar un elemento de la cuadrícula.

grid-column: 1 / 3;
grid-row: 2;

Propiedades: grid-column y grid-row

Cambiar el orden visual

Reordena un elemento en Flex o Grid sin moverlo en el HTML. Un número menor aparece antes.

.primero { order: -1; }

Propiedad: order

Separar solo las columnas

column-gap controla el espacio entre columnas. gap puede controlar filas y columnas a la vez.

column-gap: 24px;

Propiedad: column-gap

Atajo de posición para los cuatro lados

inset es una forma corta de indicar los límites superior, derecho, inferior e izquierdo de un elemento posicionado.

position: absolute;
inset: 0;

Atajo de top, right, bottom y left.

Ajustar el desplazamiento a secciones

scroll-snap-type activa puntos de ajuste en un contenedor desplazable; scroll-snap-align marca dónde debe encajar cada hijo (start, center, end); mandatory exige ajuste y proximity ajusta si se queda cerca. Usa proximity con cuidado para no quitar control del desplazamiento. 

.carrusel { overflow-x: auto; scroll-snap-type: x proximity; }
.tarjeta { scroll-snap-align: start; }

Propiedades: scroll-snap-type, scroll-snap-align, scroll-snap-stop

Evitar que el scroll se propague

overscroll-behavior controla qué pasa al llegar al borde de una zona desplazable: auto permite que el desplazamiento continúe en el padre; contain lo detiene en esa zona; none también elimina efectos de rebote del navegador donde aplique. 

.panel { overscroll-behavior: contain; }

Propiedades: overscroll-behavior, overscroll-behavior-x, overscroll-behavior-y

Subgrid

Con subgrid, una cuadrícula interior reutiliza las filas o columnas de la cuadrícula padre. Sirve para que partes internas de varias tarjetas (título, texto, botón) queden alineadas entre sí.

.lista {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
}
.tarjeta {
  display: grid;
  grid-row: span 3;
  grid-template-rows: subgrid;
}

Valores: subgrid en grid-template-rows o grid-template-columns

Atajos de alineación: place-items y place-content

place-items combina align-items y justify-items; place-content y place-self hacen lo mismo con sus equivalentes. display: grid; place-items: center es la forma más corta de centrar.

.centrado {
  display: grid;
  place-items: center;
  min-height: 100vh;
}

Atajos: place-items, place-content, place-self

Medidas relativas al contenedor: cqw

Dentro de un contenedor con container-type, las unidades cqw, cqi... valen un 1 % del tamaño de ese contenedor, no de la ventana.

.zona { container-type: inline-size; }
.zona h2 {
  font-size: clamp(1rem, 6cqi, 2.5rem);
}

Unidades: cqw, cqh, cqi, cqb, cqmin, cqmax

Posición anclada a otro elemento

El posicionamiento por ancla coloca un elemento (tooltip, menú) junto a otro sin JavaScript. El elemento de referencia recibe un anchor-name; el otro lo usa para situarse.

.boton { anchor-name: --boton; }
.aviso {
  position: fixed;
  position-anchor: --boton;
  top: anchor(bottom);
  left: anchor(left);
}

Soporte reciente: comprueba la compatibilidad antes de usarlo.

Altura que se ajusta al contenido: field-sizing

field-sizing: content hace que un textarea o un input crezca según lo que se escribe, sin JavaScript.

textarea {
  field-sizing: content;
  min-height: 3lh;
  max-height: 12lh;
}

Soporte limitado: úsalo como mejora progresiva.

Esquemas de posicionamiento

Los elementos son cajas rectangulares y su colocación depende del esquema de posicionamiento. En el normal (por defecto) siguen el orden del código: los de bloque ocupan todo el ancho y los de línea fluyen dentro del texto. En el flotante (float) se desplazan a un lado y el texto los rodea. En el absoluto (position) se sacan del flujo y se colocan con coordenadas.

.normal   { }                 /* flujo normal */
.flotante { float: left; }    /* esquema flotante */
.absoluto { position: absolute; top: 10px; left: 10px; }

Propiedades: float, position; hoy se maqueta sobre todo con Flex y Grid.

Elementos de bloque y de línea

Un elemento de bloque ocupa todo el ancho de su contenedor y empieza en una línea nueva; uno en línea ocupa solo lo que necesita y fluye con el texto. Cada etiqueta tiene un valor de display por defecto, que puedes cambiar con CSS.

/* Bloque: main, header, footer, aside, section, article, div, p,
           h1…h6, ul, ol, li */
/* Línea:  em, strong, time, a, img, span, input, button, select */

span.caja { display: block; }
li.menu   { display: inline-block; }

Propiedad: display; valores habituales: block, inline, inline-block

Varias cajas flotantes

Las cajas flotantes tienen en cuenta a las anteriores: se colocan a continuación una de otra y, si no caben en la línea, pasan a la siguiente. Para que varias cajas floten en fila hay que darles un ancho. Cuando un contenedor solo tiene hijos flotantes, no abarca su altura salvo que lo contengas.

.caja { float: left; width: 30%; margin-right: 3%; }

.contenedor { display: flow-root; }   /* contiene los flotantes */

Valores de float: left, right, none

Position relative en detalle

Con position: relative la caja se desplaza desde su posición original, pero conserva su hueco y no mueve a las demás, así que puede solaparlas. Un valor positivo en top la baja, en bottom la sube, en left la mueve a la derecha y en right, a la izquierda; los valores negativos hacen lo contrario.

.caja2 {
  position: relative;
  top: 20px;      /* baja 20px */
  left: 30px;     /* se mueve 30px a la derecha */
}

Propiedades: position: relative, top, right, bottom, left

Position absolute dentro de un contenedor

Una caja absoluta sale del flujo: los demás elementos la ignoran y ocupan su hueco. Se coloca respecto al ancestro posicionado más cercano (uno con position distinto de static). Para colocarla dentro de un contenedor concreto, basta con darle a ese contenedor position: relative.

.tarjeta { position: relative; }
.etiqueta {
  position: absolute;
  top: 8px;
  right: 8px;     /* esquina superior derecha de .tarjeta */
}

Si no hay ancestro posicionado, se coloca respecto al bloque inicial de la página.

Position fixed: elementos fijos en la ventana

Un elemento fixed se coloca respecto a la ventana y permanece en su sitio aunque se desplace la página. No deja hueco donde estaría normalmente. Es típico en cabeceras y botones flotantes; cuida que no tape contenido.

.subir {
  position: fixed;
  right: 16px;
  bottom: 16px;
  z-index: 10;
}

Propiedades: position: fixed, top, right, bottom, left, z-index

Flexbox: contenedor, elementos y ejes

Flexbox organiza los hijos directos de un contenedor flexible (display: flex) a lo largo de un eje principal, con un eje transversal perpendicular. Con row el principal es horizontal; con column, vertical. Unas propiedades van en el contenedor y otras en los elementos hijos.

/* Contenedor */
display, flex-direction, flex-wrap, flex-flow,
justify-content, align-items, align-content, gap

/* Elementos */
align-self, flex-grow, flex-shrink, flex-basis, flex, order

justify-* trabaja en el eje principal y align-*, en el transversal.

justify-content en detalle

Reparte los elementos a lo largo del eje principal: flex-start (valor por defecto), flex-end, center, space-between (primero y último pegados a los bordes), space-around (espacio igual alrededor de cada uno) y space-evenly (mismo espacio entre todos y en los extremos).

.fila {
  display: flex;
  justify-content: space-between;
}
/* otras opciones: flex-start | flex-end | center | space-around | space-evenly */

Propiedad del contenedor: justify-content

align-items en detalle

Alinea los elementos en el eje transversal: stretch (por defecto, los estira), flex-start, flex-end, center y baseline (alinea las líneas base de sus textos). Con justify-content: center y align-items: center se centra un elemento en ambos ejes.

.centrar {
  display: flex;
  justify-content: center;
  align-items: center;
  min-height: 100vh;
}

Propiedad del contenedor: align-items

align-content: varias líneas en Flex

Cuando los elementos ocupan varias líneas (flex-wrap: wrap), align-content reparte esas líneas en el eje transversal. No tiene efecto con una sola línea ni si el contenedor no tiene altura sobrante. Sus valores son stretch (por defecto), flex-start, flex-end, center, space-between, space-around y space-evenly.

.cajas {
  display: flex;
  flex-wrap: wrap;
  height: 300px;
  align-content: space-between;
}

Propiedad del contenedor: align-content; align-items alinea dentro de cada línea.

align-self: un elemento distinto

Permite que un solo elemento se alinee de forma diferente a los demás en el eje transversal, sobrescribiendo el align-items del contenedor. Acepta auto (por defecto), stretch, flex-start, flex-end, center y baseline.

.contenedor { display: flex; align-items: center; }
.desplazado { align-self: flex-start; }

Propiedad del elemento: align-self

flex-grow: repartir el espacio sobrante

flex-grow indica cuánto crece un elemento para ocupar el espacio libre del contenedor. El valor por defecto es 0 (no crece). Se reparte en proporción: con valores 1 y 3, uno recibe una parte del espacio sobrante y el otro tres.

.crece  { flex-grow: 1; }
.crece3 { flex-grow: 3; }   /* recibe el triple del espacio libre */

Propiedad del elemento: flex-grow

flex-shrink: quién se encoge

flex-shrink indica cuánto se encoge un elemento cuando no caben todos. Por defecto vale 1 (todos se reducen). Con 0 no se encoge nunca; con valores mayores se encoge más que los demás.

.caja  { width: 30%; }            /* 5 cajas = 150%: no caben */
.fija  { flex-shrink: 0; }        /* no se reduce */
.cede  { flex-shrink: 3; }        /* se reduce más que el resto */

Propiedad del elemento: flex-shrink

flex-basis: tamaño inicial

flex-basis fija el tamaño inicial de un elemento en el eje principal, antes de repartir espacio con flex-grow o flex-shrink. Es el ancho en una fila y el alto en una columna. Su valor por defecto es auto, que usa width o height.

.fila { display: flex; }
.item { flex-basis: 25%; }       /* parte de un 25% */
.texto { flex-basis: content; }  /* según su contenido */

Propiedad del elemento: flex-basis

flex: el atajo

flex reúne flex-grow, flex-shrink y flex-basis. El valor por defecto es 0 1 auto. Los atajos más usados son flex: 1 (equivale a 1 1 0%, repartir por igual), flex: auto (1 1 auto) y flex: none (0 0 auto, tamaño fijo).

.item     { flex: 0 1 auto; }    /* valor por defecto */
.reparte  { flex: 1; }           /* todos el mismo ancho */
.rigido   { flex: none; }        /* no crece ni se encoge */
.flexible { flex: 1 1 12rem; }

Propiedad del elemento: flex

Grid: líneas y posición con grid-column y grid-row

Una cuadrícula de 3 columnas tiene 4 líneas, numeradas desde 1. Cada hijo se coloca indicando la línea donde empieza y donde acaba. grid-column: 1 / 3 equivale a grid-column-start: 1; grid-column-end: 3. Con span se indica cuántas pistas ocupa y -1 es la última línea.

.cabecera { grid-column: 1 / 4; }       /* de la línea 1 a la 4 */
.lateral  { grid-row: 1 / 4; }
.ancho    { grid-column: span 2; }      /* ocupa dos columnas */
.todo     { grid-column: 1 / -1; }      /* hasta la última línea */

Propiedades: grid-column, grid-row, grid-column-start|end, grid-row-start|end

Grid: ejemplo de maquetación por líneas

Un contenedor define el número y tamaño de columnas y filas; cada hijo indica qué celdas ocupa, y el HTML no cambia. Este ejemplo coloca cuatro cajas en una cuadrícula de 2 columnas y 3 filas.

#tablero {
  display: grid;
  grid-template-columns: 300px 500px;
  grid-template-rows: 200px 100px 500px;
}
#amarillo { grid-column: 1 / 2; grid-row: 1 / 4; }  /* toda la primera columna */
#rojo     { grid-column: 2 / 3; grid-row: 1 / 2; }
#azul     { grid-column: 2 / 3; grid-row: 2 / 3; }
#verde    { grid-column: 2 / 3; grid-row: 3 / 4; }

Contenedor: display: grid; hijos: grid-column y grid-row

Grid: unidad fr y huecos

fr reparte el espacio libre de la cuadrícula en fracciones: 1fr 2fr 1fr hace la columna central el doble de ancha. Se puede mezclar con medidas fijas. gap separa filas y columnas; también existen row-gap y column-gap (los nombres antiguos grid-gap, grid-row-gap y grid-column-gap siguen funcionando).

.rejilla {
  display: grid;
  grid-template-columns: 1fr 2fr 1fr;
  gap: 1rem 2rem;          /* filas y columnas */
}
.con-lateral { grid-template-columns: 240px 1fr; }

Propiedades: gap, row-gap, column-gap; unidad: fr

Centrar de todas las formas

Hay una técnica para cada caso: texto en línea con text-align, un bloque con margin-inline: auto, y en ambos ejes con Grid o Flex.

.texto { text-align: center; }
.bloque { width: 20rem; margin-inline: auto; }
.ambos  { display: grid; place-items: center; min-height: 100vh; }
.flex   { display: flex; justify-content: center; align-items: center; }
.abs    { position: absolute; inset: 0; margin: auto; width: 10rem; height: 5rem; }

Lo más corto: display: grid; place-items: center

Pie de página pegado abajo

Si el contenido es corto, el pie debe quedar al final de la ventana. Con Flex en el body se consigue en pocas líneas.

body { min-height: 100dvh; display: flex; flex-direction: column; }
main { flex: 1; }

Propiedades: min-height, flex: 1

Maquetación clásica con Grid: cabecera, menú, contenido y pie

grid-template-areas permite dibujar la página con nombres. Cada hijo se asigna a un área con grid-area.

body {
  display: grid;
  grid-template-columns: 220px 1fr;
  grid-template-areas:
    "cabecera cabecera"
    "menu     contenido"
    "pie      pie";
  min-height: 100dvh;
}
header { grid-area: cabecera; }
nav    { grid-area: menu; }
main   { grid-area: contenido; }
footer { grid-area: pie; }

Propiedades: grid-template-areas, grid-area

Cabecera fija con sticky

position: sticky se comporta como normal hasta que alcanza el umbral indicado y entonces se queda pegado. Necesita top (u otro lado) y no funciona si un ancestro tiene overflow raro.

header {
  position: sticky;
  top: 0;
  z-index: 10;
  background: #fff;
}

Propiedad: position: sticky

Rejilla de tarjetas sin media queries

repeat(auto-fit, minmax(14rem, 1fr)) crea tantas columnas como caben, con un ancho mínimo, sin usar media queries. auto-fill mantiene las columnas vacías y auto-fit las colapsa.

.tarjetas {
  display: grid;
  gap: 1rem;
  grid-template-columns: repeat(auto-fit, minmax(14rem, 1fr));
}

Funciones: repeat(), minmax()

Flex: columnas iguales y reparto

Con flex: 1 los hijos se reparten el ancho por igual; flex-wrap permite que bajen de línea y gap los separa.

.fila { display: flex; flex-wrap: wrap; gap: 1rem; }
.fila > * { flex: 1 1 14rem; }

Atajo útil: flex: 1 1 14rem

Limpiar flotantes: clearfix y flow-root

Un contenedor cuyos hijos flotan colapsa a altura cero. display: flow-root crea un contexto que contiene los flotantes sin trucos.

.contenedor { display: flow-root; }

/* Técnica antigua */
.clearfix::after { content: ""; display: table; clear: both; }

Valor moderno: display: flow-root

Superposición y modal con CSS

Un modal es una capa fija que cubre la pantalla y un contenedor centrado encima.

.capa {
  position: fixed;
  inset: 0;
  display: grid;
  place-items: center;
  background: rgb(0 0 0 / 60%);
  z-index: 100;
}
.ventana { background: #fff; padding: 1.5rem; border-radius: .75rem; max-width: 30rem; }

Mejor usar dialog + ::backdrop.

Contexto de apilamiento y z-index

z-index solo compara elementos dentro del mismo contexto de apilamiento. Algunas propiedades (position con z-index, opacity menor que 1, transform, isolation: isolate) crean uno nuevo.

.tarjeta { isolation: isolate; }          /* nuevo contexto */
.tarjeta .etiqueta { position: relative; z-index: 1; }

Propiedad útil: isolation: isolate

Grid: áreas con nombre

Con grid-template-areas se dibuja la estructura con palabras; un punto (.) representa una celda vacía.

.pagina {
  display: grid;
  grid-template-columns: 1fr 3fr;
  grid-template-areas:
    "titulo titulo"
    "lateral texto"
    ".       pie";
}
.titulo { grid-area: titulo; }

Propiedades: grid-template-areas, grid-area

Grid: filas y columnas automáticas

Las filas y columnas implícitas (las que se crean al sobrar elementos) se controlan con grid-auto-rows y grid-auto-columns. grid-auto-flow: dense rellena huecos.

.galeria {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  grid-auto-rows: 120px;
  grid-auto-flow: dense;
}
.grande { grid-column: span 2; grid-row: span 2; }

Propiedades: grid-auto-rows, grid-auto-flow

Grid: justify-items y alinear dentro de celdas

En Grid, justify-items alinea los elementos en horizontal dentro de su celda y align-items en vertical; justify-self y align-self lo hacen para uno solo.

.rejilla { display: grid; justify-items: center; align-items: start; }
.caja { justify-self: end; }

Propiedades: justify-items, justify-self, align-self

Columnas tipo revista: masonry con columns

Con column-count y break-inside: avoid se logra un diseño tipo mosaico con elementos de distinta altura.

.galeria { column-count: 3; column-gap: 1rem; }
.galeria figure { break-inside: avoid; margin: 0 0 1rem; }

Propiedades: column-count, break-inside

Dos columnas: contenido y barra lateral

El diseño más común: un contenido principal y una barra lateral, que se apila en pantallas estrechas.

.pagina { display: grid; gap: 2rem; }
@media (min-width: 800px) {
  .pagina { grid-template-columns: 1fr 18rem; }
}

Mobile first: apilado por defecto.

Contención de estilos: contain

contain le dice al navegador que un elemento es independiente del resto, lo que le permite optimizar el cálculo del diseño.

.widget { contain: layout paint; }
.pesado { contain: strict; width: 300px; height: 200px; }

Valores: layout, paint, size, style, content, strict

Estilos para impresión: @page

@page configura el tamaño, la orientación y los márgenes de las páginas impresas.

@page { size: A4; margin: 2cm; }
@page :first { margin-top: 4cm; }
@media print { nav, footer { display: none; } }

Regla: @page; propiedades: size, margin

Saltos de página: break-before, break-after y break-inside

Controlan cómo se parte el contenido entre páginas o columnas: forzar un salto antes de un título o evitar que una tarjeta se divida.

h2 { break-before: page; }
figure, table { break-inside: avoid; }
h3 { break-after: avoid; }

Valores: auto, avoid, page, column

Líneas huérfanas y viudas: orphans y widows

orphans y widows indican el número mínimo de líneas de un párrafo que deben quedar al final o al principio de una página o columna.

p { orphans: 3; widows: 3; }

Propiedades: orphans, widows

Posición alternativa: position-try y fallbacks

Con el posicionamiento por ancla, position-try-fallbacks define posiciones alternativas si el elemento no cabe (por ejemplo, dar la vuelta a un menú) (soporte reciente).

.menu {
  position: fixed;
  position-anchor: --boton;
  top: anchor(bottom);
  position-try-fallbacks: flip-block;
}

Propiedades: position-try-fallbacks, position-area

Tamaño de línea: calc-size y sibling-index

Funciones nuevas: calc-size() permite operar con auto; sibling-index() y sibling-count() devuelven la posición de un elemento entre sus hermanos, útil para retrasos escalonados (soporte reciente).

li { transition-delay: calc(sibling-index() * 50ms); }
.panel { height: calc-size(auto, size + 20px); }

Comprueba la compatibilidad antes de usarlas.

Selectores

Por nombre de etiqueta

Afecta a todas las etiquetas de ese tipo. Aquí se aplica a todos los párrafos.

p {
  color: #555;
}

Selector: p

Por clase

El punto delante indica una clase. Se puede reutilizar en varios elementos HTML.

.especial {
  font-weight: bold;
}

Selector: .nombre-clase

Por identificador

La almohadilla selecciona un id, normalmente único en esa página.

#principal {
  padding: 20px;
}

Selector: #nombre-id

Elemento dentro de otro

Un espacio significa «busca este elemento dentro de aquel». El ejemplo selecciona los párrafos que estén dentro de .normal.

.normal p { color: navy; }

Combinador: espacio

El siguiente elemento

El signo + selecciona el elemento que está justo después de otro, al mismo nivel. 

h1 + h2 { color: seagreen; }

Combinador: +

Aplicar lo mismo a varios

Separa selectores con comas para compartir las mismas reglas.

h1, h2, h3 {
  font-family: Georgia, serif;
}

Separador: coma

Todos los elementos

El asterisco selecciona todos los elementos de la página.

* { box-sizing: border-box; }

Selector universal: *

Buscar por atributo

Los corchetes permiten seleccionar por un atributo. *= significa que el valor contiene ese texto.

a[href*="ejemplo"] {
  font-style: italic;
}

Selector de atributo: [atributo]

Estados del elemento

Las pseudoclases, que empiezan con dos puntos, seleccionan estados como enlace visitado, puntero encima, clic o foco del teclado.

a:hover { color: tomato; }
a:visited { color: purple; }

También: :link, :active, :focus, :focus-visible, :focus-within, :checked.

Añadir decoración antes o después

::before y ::after crean una pieza decorativa. Necesitan la propiedad content, aunque el contenido sea una cadena vacía. 

.marca::after {
  content: "";
  height: 2px;
}

Pseudo-elementos: ::before y ::after

Seleccionar por posición

Elige hijos por el lugar que ocupan: el primero, el último, los impares, etc.

li:nth-child(odd) {
  background: #eee;
}

Pseudoclases: :first-child, :last-child, :nth-child(), :not()

Contenido decorativo y contadores

content inserta texto o símbolos en ::before/::after; no lo uses para información esencial que deba estar en HTML. Los contadores CSS se crean con counter-reset, avanzan con counter-increment y se muestran con counter(). 

ol { counter-reset: paso; }
li::before {
  counter-increment: paso;
  content: counter(paso) ". ";
}

Propiedades y función: content, counter-reset, counter-increment, counter()

Hijos directos y hermanos

A > B selecciona solo hijos directos; A ~ B selecciona hermanos posteriores del mismo nivel. A diferencia del espacio, no busca descendientes a cualquier profundidad.

ul > li { margin-block: .5rem; }
h2 ~ p { color: #555; }

Combinadores: > y ~

Combinar condiciones con pseudoclases

:is() agrupa alternativas y conserva la especificidad más alta de su lista; :where() agrupa con especificidad cero; :not() excluye; :has() selecciona un elemento según lo que contiene o su relación con otros elementos. 

:where(article, section) > h2 { color: teal; }
article:has(img) { padding: 1rem; }

Pseudoclases: :is(), :where(), :not(), :has()

Estilizar marcadores y partes

::placeholder cambia el texto de ayuda de un campo; ::marker, las viñetas y números; ::first-letter, la primera letra; ::first-line, la primera línea. Usa el contenido HTML para información importante y pseudoelementos sobre todo para presentación.

input::placeholder { color: #687; }
li::marker { color: tomato; }

Pseudo-elementos: ::placeholder, ::marker, ::first-letter, ::first-line

Elemento al que apunta el enlace: :target

:target selecciona el elemento cuyo id coincide con el fragmento de la URL (#seccion). Permite resaltar la sección a la que se ha saltado.

:target {
  outline: 3px solid gold;
  scroll-margin-top: 1rem;
}

Pseudoclase: :target

Elementos vacíos y primer o último hijo

:empty selecciona elementos sin contenido; :first-child, :last-child y :only-child seleccionan según su posición entre hermanos.

p:empty { display: none; }
li:first-child { font-weight: 700; }
li:last-child  { border-bottom: 0; }

Pseudoclases: :empty, :first-child, :last-child, :only-child

Estados de formularios

Hay pseudoclases para estilizar campos según su estado: :checked, :disabled, :required, :placeholder-shown, :valid e :invalid. :user-invalid solo se aplica tras interactuar, evitando mostrar errores antes de tiempo.

input:required { border-left: 3px solid orange; }
input:user-invalid { border-color: crimson; }
input:disabled { opacity: .5; }
input:checked + label { font-weight: 700; }

Pseudoclases: :checked, :disabled, :invalid, :user-invalid

Variantes con el selector &

Con el anidamiento, & puede ir antes, después o dentro de un selector para crear variantes sin repetir el nombre de la clase.

.boton {
  &.grande { padding: 1rem 2rem; }
  &:not(:disabled):hover { filter: brightness(1.1); }
  & + & { margin-left: .5rem; }
}

& equivale al selector exterior.

Pseudoclases de enlace y orden LVHA

Los enlaces tienen cuatro estados clásicos: :link (sin visitar), :visited (visitado), :hover (puntero encima) y :active (mientras se pulsa). Si se escriben en ese orden, y con :focus antes de :hover, las reglas posteriores no se anulan entre sí. Una pseudoclase se puede combinar con una clase.

a:link    { color: #c00; }
a:visited { color: #609; }
a:focus   { outline: 3px solid gold; }
a:hover   { color: #f0f; }
a:active  { color: #00f; }

a.rojo:visited { color: red; }   /* solo enlaces con class="rojo" ya visitados */

Regla mnemotécnica: LoVe-HAte (link, visited, hover, active)

Posición con :nth-child y fórmulas

:nth-child() selecciona hijos por su posición, contando desde 1. Acepta un número, las palabras even (pares) y odd (impares), o una fórmula an+b donde n es un contador que empieza en 0.

p:nth-child(2)    { }   /* el segundo hijo, si es un p */
p:nth-child(even) { color: blue; }   /* 2, 4, 6... */
p:nth-child(odd)  { color: teal; }   /* 1, 3, 5... */
p:nth-child(3n)   { }   /* 3, 6, 9... */
p:nth-child(3n+1) { }   /* 1, 4, 7... */
p:nth-child(n+3)  { }   /* del tercero en adelante */
p:nth-child(-n+3) { }   /* solo los tres primeros */

Pseudoclase: :nth-child(an+b)

Contar desde el final: :nth-last-child

:nth-last-child(n) funciona como :nth-child pero cuenta desde el último hijo hacia atrás. :nth-last-child(1) equivale a :last-child.

li:nth-last-child(2) { font-weight: 700; }   /* el penúltimo */
li:nth-last-child(-n+3) { }                  /* los tres últimos */

Pseudoclases: :nth-last-child(), :last-child

Posición dentro de su tipo: of-type

Las variantes of-type cuentan solo los hermanos que tienen la misma etiqueta. Son útiles cuando mezclas distintos elementos dentro de un mismo contenedor, por ejemplo un título y varios párrafos.

/* <div><h2>…</h2><p>1</p><p>2</p><p>3</p></div> */
p:nth-of-type(2)  { color: blue; }   /* el segundo párrafo */
p:first-of-type   { font-weight: 700; }
p:last-of-type    { margin-bottom: 0; }
img:only-of-type  { float: none; }   /* único img entre sus hermanos */

Pseudoclases: :nth-of-type(), :nth-last-of-type(), :first-of-type, :last-of-type, :only-of-type

Primer hijo de un contenedor concreto

:first-child se combina con otros selectores para precisar qué primer hijo quieres. El combinador > limita la regla a hijos directos; sin él, se aplica a cualquier descendiente.

p:first-child { color: blue; }            /* cualquier p que sea primer hijo */
div > p:first-child { color: blue; }      /* solo si su padre es un div */
p:first-child em { color: blue; }         /* em dentro de un p que es primer hijo */
a:only-child { text-decoration: none; }   /* enlace que es hijo único */

Combinadores: espacio (descendiente) y > (hijo directo)

Controles activados y desactivados

:enabled y :disabled seleccionan controles de formulario según estén disponibles o no; :checked los marcados. Con :read-only y :read-write se distinguen los campos editables.

input:enabled  { background: #fff; }
input:disabled { background: #eee; cursor: not-allowed; }
input:checked + label { font-weight: 700; }
input:read-only { border-style: dashed; }

Pseudoclases: :enabled, :disabled, :checked, :read-only, :read-write

Selección por idioma: :lang() y [lang|=]

:lang(es) selecciona los elementos cuyo idioma es el español, incluso si lo heredan de un elemento superior (por ejemplo, <body lang="es">). [lang|="es"] solo selecciona los elementos que tienen ellos mismos ese atributo con el valor es o que empiezan por es-.

p:lang(es) { color: red; }          /* body y p dentro de lang="es" */
*[lang|="es"] { }                   /* solo el elemento que tiene el atributo */

/* <body lang="es"><p>Hola</p></body>
   :lang(es)  -> body y p
   [lang|=es] -> solo body */

Pseudoclase: :lang(); selector de atributo: [lang|=valor]

Primera letra y primera línea

::first-letter da estilo a la primera letra de un bloque de texto y ::first-line a su primera línea (la que quepa en cada momento). Solo admiten algunas propiedades de texto, fuente, color y fondo, entre otras.

p::first-letter {
  float: left;
  font-size: 3em;
  line-height: 1;
  color: crimson;
  margin-right: .1em;
}
p::first-line { font-variant: small-caps; }

Pseudoelementos: ::first-letter, ::first-line (en CSS3 se escriben con dos puntos)

Insertar texto o imagen con content

Con ::before y ::after puedes insertar una cadena, una imagen (url()) o el valor de un atributo (attr()) antes o después del contenido de un elemento. No es contenido real: no se puede seleccionar bien ni lo leen todos los lectores de pantalla, así que no pongas ahí información importante.

h2::before { content: "Capítulo - "; }
p::after   { content: "."; }
h1::before { content: url("logo.svg"); }
a[href^="http"]::after { content: " (" attr(href) ")"; }

Propiedad: content; pseudoelementos: ::before, ::after

Selector de atributo: variantes

Hay varias formas de buscar atributos: existencia, valor exacto, que empiece (^=), termine ($=) o contenga (*=) un texto. Añadiendo i se ignoran las mayúsculas.

a[target]            { }   /* tiene el atributo */
a[href="/inicio"]    { }   /* valor exacto */
a[href^="https"]     { }   /* empieza por */
a[href$=".pdf"]      { }   /* termina en */
a[href*="ejemplo"]   { }   /* contiene */
input[type="TEXT" i] { }

Selectores: [a], [a=v], [a^=v], [a$=v], [a*=v]

Combinadores: espacio, >, + y ~

Los combinadores relacionan elementos: espacio (descendiente), > (hijo directo), + (hermano siguiente) y ~ (cualquier hermano posterior).

article p   { }   /* cualquier p dentro de article */
article > p { }   /* solo hijos directos */
h2 + p      { }   /* el p justo después de h2 */
h2 ~ p      { }   /* todos los p tras h2 (mismos padres) */

Símbolos: , >, +, ~

Selección múltiple y de clases combinadas

Separar con comas aplica la misma regla a varios selectores. Pegar clases (.a.b) exige que el elemento tenga ambas.

h1, h2, h3 { font-family: Georgia, serif; }
.boton.grande { padding: 1rem 2rem; }
.boton:not(.grande) { padding: .5rem 1rem; }

.a.b (y) frente a .a, .b (o)

Selector :has: seleccionar al padre

:has() selecciona un elemento según lo que contiene o lo que le sigue. Permite estilizar al padre en función de sus hijos.

.tarjeta:has(img) { display: grid; }
form:has(input:invalid) .enviar { opacity: .5; }
label:has(+ input:required)::after { content: " *"; }

Pseudoclase: :has()

:is() y :where() para abreviar

:is() y :where() agrupan selectores para escribir menos. La diferencia es la especificidad: :where() siempre aporta cero.

:is(h1, h2, h3):hover { color: crimson; }
:where(article, section) p { margin-block: 1em; }

:where() facilita sobrescribir estilos.

Foco: :focus, :focus-visible y :focus-within

:focus se activa con cualquier foco. :focus-visible solo cuando el navegador considera que debe mostrarse (teclado). :focus-within se activa en un contenedor cuando algún descendiente tiene el foco.

a:focus-visible { outline: 3px solid #bd573d; }
.campo:focus-within { box-shadow: 0 0 0 3px #bcd; }

Pseudoclases: :focus, :focus-visible, :focus-within

Placeholder, marcadores y selección

Pseudoelementos para partes especiales: ::placeholder (texto de ayuda), ::marker (viñeta), ::selection (texto seleccionado), ::backdrop (fondo de un modal) y ::file-selector-button (botón de un campo de archivo).

::placeholder { color: #888; }
li::marker { color: tomato; }
::selection { background: #ffe58a; color: #000; }
dialog::backdrop { background: rgb(0 0 0 / 50%); }
input[type=file]::file-selector-button { border-radius: .4rem; }

Pseudoelementos con ::

Rango y estado de entradas: in-range, required, optional

Otras pseudoclases de formularios: :required, :optional, :in-range, :out-of-range, :placeholder-shown, :default e :indeterminate.

input:required { border-left: 4px solid orange; }
input:out-of-range { border-color: crimson; }
input:placeholder-shown { background: #fafafa; }

Pseudoclases: :required, :in-range, :placeholder-shown

Pseudoclase :root

:root selecciona el elemento raíz del documento (html) con mayor especificidad. Es el lugar habitual para definir variables CSS globales.

:root {
  --marca: #245b78;
  font-family: system-ui, sans-serif;
}

Pseudoclase: :root

Especificidad: ejemplos de cálculo

La especificidad se cuenta como tres números: identificadores, clases/atributos/pseudoclases y etiquetas/pseudoelementos. Gana la más alta; si empatan, la última escrita.

p                 /* 0,0,1 */
.aviso            /* 0,1,0 */
p.aviso           /* 0,1,1 */
#menu .item a     /* 1,1,1 */
a:hover           /* 0,1,1 */

El estilo en línea y !important quedan por encima.

Estilizar componentes web: :host, ::slotted y ::part

Dentro de un Shadow DOM, :host selecciona el propio componente y ::slotted() los elementos que se insertan en un slot. Desde fuera se accede a las partes expuestas con ::part().

/* dentro del componente */
:host { display: block; border: 1px solid #ccc; }
:host(.destacado) { border-color: gold; }
::slotted(p) { margin: 0; }

/* fuera */
mi-tarjeta::part(titulo) { color: teal; }

Selectores: :host, :host(), ::slotted(), ::part()

Pseudoclases de diálogos y popovers

:modal selecciona los elementos en modo modal; :popover-open los popovers abiertos. dialog[open] sigue funcionando para cualquier diálogo abierto.

dialog:modal { border: 0; border-radius: .75rem; }
[popover]:popover-open { padding: 1rem; }
dialog::backdrop { background: rgb(0 0 0 / 50%); }

Pseudoclases: :modal, :popover-open

Consultas de contenedor por estilo

Además de por tamaño, un contenedor puede consultarse por el valor de sus variables CSS con style() (soporte parcial).

.tarjeta { --destacada: true; }
@container style(--destacada: true) {
  .titulo { color: crimson; }
}

Función: style() dentro de @container

Qué pasa cuando usamos la página

Interacción

Al pasar el ratón

:hover cambia el aspecto mientras el puntero está encima del elemento.

a:hover {
  color: tomato;
}

Estado: :hover

Mientras se pulsa

:active aplica el estilo durante el clic o la pulsación.

button:active {
  transform: translateY(1px);
}

Estado: :active

Enlace visitado o sin visitar

:link representa un enlace no visitado; :visited, uno que ya se abrió. 

a:link { color: navy; }
a:visited { color: purple; }

Estados: :link y :visited

Al llegar con el teclado

:focus-visible muestra una señal cuando una persona llega al elemento usando el teclado.

a:focus-visible {
  outline: 3px solid coral;
}

Estado: :focus-visible

Cambio suave (transition)

El atajo reúne propiedad que cambia, duración, curva de velocidad y retraso. all anima todas las propiedades animables; es más eficiente y predecible indicar solo la propiedad necesaria. none desactiva transiciones.

transition: color .2s ease .1s;

Propiedades: transition, transition-property, transition-duration, transition-timing-function, transition-delay

Forma del cursor

auto deja elegir al navegador; default es la flecha; pointer la mano de enlace; text indica texto; wait/progress espera; help ayuda; not-allowed acción no disponible; grab/grabbing arrastre; crosshair mira. También hay cursores para cambiar el tamaño, como ew-resize y ns-resize. 

cursor: pointer;

Propiedad: cursor

Selección de texto e interacción táctil

::selection cambia el aspecto del texto que se selecciona. pointer-events controla si el puntero puede interactuar con el elemento. 

::selection { background: gold; }
pointer-events: none;

En algunos navegadores también hay ajustes de toque con prefijo -webkit-.

Duración de una transición

Controla cuánto tarda un cambio suave. Puede ir dentro del atajo transition o por separado.

transition-duration: .3s;

Propiedad: transition-duration

Curvas de velocidad

linear mantiene la misma velocidad. ease empieza y acaba suavemente; ease-in empieza despacio; ease-out acaba despacio; ease-in-out suaviza ambos extremos. cubic-bezier() define una curva propia y steps() crea cambios a saltos. 

transition-timing-function: ease-out;

Propiedad: transition-timing-function; también se usa en animaciones.

Color de controles de formulario

accent-color cambia el color de acento de casillas, botones de opción, barras de rango y algunos controles. appearance controla el aspecto nativo del sistema; none lo quita, pero entonces debes diseñar estados de foco y uso claramente. 

input[type="checkbox"] { accent-color: teal; }

Propiedades: accent-color, appearance

Cursor de escritura

caret-color cambia el color de la barra que parpadea en campos de texto y zonas editables. No cambia el color del texto ni el cursor del ratón (cursor).

input { caret-color: tomato; }

Propiedad: caret-color

Gestos táctiles

touch-action indica qué gestos del navegador se permiten: auto deja los predeterminados; none los desactiva; pan-x/pan-y permiten desplazamiento en un eje; manipulation permite desplazamiento y zoom. No lo desactives sin una necesidad concreta de interacción.

.mapa { touch-action: pan-x pan-y; }

Propiedad: touch-action

Permitir seleccionar texto

user-select: text permite seleccionar texto; none lo impide; all selecciona todo el contenido al hacer clic; auto deja decidir al navegador. Evita bloquear selección en contenido que las personas puedan querer copiar. 

.boton-icono { user-select: none; }

Propiedad: user-select

Efectos solo con ratón: hover

@media (hover: hover) se cumple cuando el dispositivo principal puede pasar el cursor. Así evitas efectos que en pantallas táctiles se quedan «pegados».

@media (hover: hover) {
  .tarjeta:hover { transform: translateY(-4px); }
}
@media (pointer: coarse) {
  .boton { min-height: 44px; }
}

Características: hover, pointer, any-hover, any-pointer

Animar la aparición: @starting-style

@starting-style define el estado inicial de un elemento recién mostrado, de modo que una transición pueda animar su entrada. Con transition-behavior: allow-discrete también se anima el cambio de display.

dialog[open] {
  opacity: 1;
  transition: opacity .3s, display .3s allow-discrete;
}
@starting-style {
  dialog[open] { opacity: 0; }
}
dialog { opacity: 0; }

Útil con dialog, popover y elementos que aparecen al cambiar display.

Transiciones entre páginas o estados: view transitions

Las transiciones de vista animan el cambio entre dos estados del documento. El navegador captura el estado anterior y el nuevo, y los funde; se personaliza con pseudoelementos.

@view-transition { navigation: auto; }

::view-transition-old(root) { animation: salir .3s; }
::view-transition-new(root) { animation: entrar .3s; }

Compatibilidad variable según el tipo (misma página o entre páginas).

Avisar de cambios: will-change

will-change anuncia al navegador qué propiedad va a cambiar para que se prepare. Úsalo solo cuando detectes un problema real y quítalo al terminar: abusar de él consume memoria.

.menu { will-change: transform; }

Propiedad: will-change

transition-property: qué propiedades animar

transition-property indica qué propiedades se animan: none (ninguna), all (todas las animables) o una lista separada por comas. Solo se pueden animar propiedades con valores intermedios, como números, medidas, colores o tiempos; display no suele poder animarse. Además, hace falta un cambio de valor (con :hover, una clase o JavaScript).

.boton {
  background: teal;
  width: 80px;
  transition-property: background-color, width;
  transition-duration: .3s;
}
.boton:hover { background: tomato; width: 240px; }

Propiedad: transition-property

transition-delay: retrasar el inicio

transition-delay espera el tiempo indicado antes de empezar la transición, en segundos (s) o milisegundos (ms). Un valor negativo la empieza ya avanzada.

.tarjeta {
  transition: opacity .4s ease 1s;   /* empieza 1 s después */
}
.tarjeta:hover { opacity: .3; }

Propiedad: transition-delay; es el segundo valor de tiempo en el atajo transition.

transition con varias propiedades

El atajo transition admite una transición por propiedad, separadas por comas. Cada una sigue el orden: propiedad, duración, curva de velocidad y retraso. Solo la propiedad y la duración son imprescindibles.

#capa2 {
  width: 80px;
  background-color: fuchsia;
  opacity: 1;
  transition:
    width 2s,
    background-color 3s linear,
    opacity 3s ease-out 3s;
}
#capa2:hover { width: 240px; background-color: green; opacity: .2; }

Orden: propiedad duración curva retraso

Animación con @keyframes

@keyframes define los pasos de una animación; animation la aplica a un elemento. Los fotogramas se indican con from/to o con porcentajes.

@keyframes latido {
  0%, 100% { transform: scale(1); }
  50%      { transform: scale(1.15); }
}
.corazon { animation: latido 1s ease-in-out infinite; }

Propiedad: animation; regla: @keyframes

Dirección y relleno de una animación

animation-direction define el sentido (normal, reverse, alternate). animation-fill-mode: forwards mantiene el estado final al terminar y backwards aplica el inicial durante el retraso.

.aparece {
  animation: entrar .6s ease-out both;
}
.vaiven {
  animation: mover 2s ease-in-out infinite alternate;
}

Propiedades: animation-direction, animation-fill-mode

Pausar una animación: animation-play-state

animation-play-state permite pausar y reanudar una animación con CSS, por ejemplo al pasar el ratón.

.carrusel { animation: girar 10s linear infinite; }
.carrusel:hover { animation-play-state: paused; }

Valores: running, paused

Animación por pasos: steps()

steps(n) divide la animación en saltos discretos en lugar de un movimiento continuo. Sirve para efectos de máquina de escribir o sprites.

.escribiendo {
  width: 20ch;
  overflow: hidden;
  white-space: nowrap;
  border-right: 2px solid;
  animation: escribir 3s steps(20) forwards;
}
@keyframes escribir { from { width: 0; } }

Función: steps(n, jump)

Spinner de carga

.spinner {

  border-top-color: #245b78;

Añade role="status" y un texto alternativo.

@keyframes entrar {

Combina opacity y transform.

.interruptor { appearance: none; width: 3rem; height: 1.6rem; border-radius: 1rem;

Pseudoclase: :target

Animar la altura: de 0 a auto

.acordeon { display: grid; grid-template-rows: 0fr; transition: grid-template-rows .3s; }

.acordeon > div { overflow: hidden; }

Animaciones ligadas al scroll: scroll-timeline y view-timeline

.barra { animation: crecer linear; animation-timeline: scroll(); }
@keyframes crecer { from { scale: 0 1; } to { scale: 1 1; } }

.aparece { animation: entrar linear both; animation-timeline: view(); animation-range: entry 0% cover 40%; }

07

Que se vea bien en distintas pantallas y para distintas personas

Adaptación y accesibilidad

Adaptar a móvil

Una media query aplica reglas solo cuando se cumple una condición, por ejemplo que la pantalla sea estrecha.

@media (max-width: 700px) {
  .rejilla { grid-template-columns: 1fr; }
}

Regla: @media

Ajustar una imagen sin deformarla

fill estira para llenar; contain muestra la imagen completa y puede dejar hueco; cover llena el espacio y recorta lo que sobra; none conserva el tamaño original; scale-down elige el resultado menor entre none y contain. 

img {
  width: 100%;
  object-fit: cover;
}

Propiedad: object-fit

Imagen flexible

Evita que la imagen se salga de su contenedor y conserva su proporción original.

img {
  max-width: 100%;
  height: auto;
}

Propiedades: max-width y height

Respetar el movimiento reducido

Algunas personas prefieren que la página no tenga animaciones. Esta regla permite reducirlas según la preferencia del sistema.

@media (prefers-reduced-motion: reduce) {
  .elemento { animation: none; }
}

Regla: prefers-reduced-motion

Preferencia de tema del navegador

color-scheme informa al navegador si la página está pensada para un tema claro, oscuro o ambos.

:root { color-scheme: light; }

Propiedad: color-scheme

Ancho mínimo

Impide que el elemento se haga más estrecho que el valor indicado. Úsalo con cuidado para no provocar desplazamiento horizontal en móviles.

min-width: 320px;

Propiedad: min-width

Consultas al tamaño del contenedor

@container adapta un componente según el espacio de su contenedor, no el ancho total de la ventana. Primero se declara un contenedor con nombre y tipo de consulta; después se cambian estilos si alcanza cierto ancho.

.panel { container-type: inline-size; }
@container (inline-size > 35rem) {
  .tarjeta { display: grid; }
}

Propiedades: container-type, container-name, container; regla @container

Aplicar CSS si el navegador soporta una función

@supports comprueba si el navegador entiende una propiedad/valor y permite añadir una mejora progresiva. No detecta el modelo, la versión ni el dispositivo: solo soporte de CSS. 

@supports (display: grid) {
  .rejilla { display: grid; }
}

Regla condicional: @supports

Estilos para imprimir

@media print aplica reglas al imprimir o guardar como PDF. Se suelen ocultar menús y botones, quitar fondos oscuros y evitar que una tarjeta se parta entre páginas. break-before, break-after y break-inside controlan saltos. 

@media print {
  nav, button { display: none; }
  article { break-inside: avoid; }
}

Regla: @media print; saltos: break-*

Preferencias de color del sistema

prefers-color-scheme puede ser light u dark; prefers-contrast puede solicitar más/menos contraste; forced-colors detecta modos de color forzados. Respeta estas preferencias sin quitar las señales esenciales de contraste o foco. 

@media (prefers-color-scheme: dark) {
  body { background: #18201c; color: #f5f5ef; }
}

Consultas de medios: preferencias del usuario

Aislar el diseño para optimizar

contain informa al navegador que el elemento limita ciertos efectos: layout, paint, size o combinaciones como content y strict. Puede mejorar rendimiento en componentes grandes, pero cambia cómo interactúan con el resto del diseño; no se debe aplicar a ciegas. 

.widget { contain: content; }

Propiedades: contain, container

Zonas seguras de pantallas con muescas

En móviles con muescas o barras del sistema, env(safe-area-inset-*) indica cuánto espacio dejar para no tapar el contenido. Requiere viewport-fit=cover en el meta viewport.

<meta name="viewport"
  content="width=device-width, initial-scale=1, viewport-fit=cover">

.barra {
  padding-bottom: env(safe-area-inset-bottom, 0px);
}

Función: env(); valores: safe-area-inset-top|right|bottom|left

Rangos en media queries

Las consultas de medios admiten operadores de comparación, más legibles que min-width y max-width.

@media (width >= 768px) { ... }
@media (400px <= width <= 900px) { ... }
@media (orientation: landscape) { ... }

Operadores: <, <=, >, >=, =

Contraste alto y colores forzados

prefers-contrast detecta si se prefiere más contraste; forced-colors se activa cuando el sistema impone su paleta (modo de alto contraste de Windows). Conviene probar que bordes y estados siguen siendo visibles.

@media (prefers-contrast: more) {
  .tarjeta { border: 2px solid; }
}
@media (forced-colors: active) {
  .boton { border: 1px solid ButtonText; }
}

Características: prefers-contrast, forced-colors

Diseño responsive y diseño adaptativo

Ambos buscan que la web se vea bien en cualquier dispositivo, pero de forma distinta. El diseño responsive se ajusta de forma continua al ancho disponible (medidas flexibles, imágenes fluidas y media queries). El diseño adaptativo prepara varios diseños fijos (móvil, tableta, escritorio) y elige el que corresponde.

/* Responsive: la rejilla se adapta sola */
.rejilla {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(14rem, 1fr));
  gap: 1rem;
}

La base del diseño responsive son las media queries y las unidades flexibles.

Puntos de ruptura (breakpoints)

Un breakpoint es el ancho en el que la estructura de la página cambia. Como referencia se usan unos 320-480 px (móvil), 600-800 px (tableta pequeña), 768-1024 px (tableta) y más de 1224 px (escritorio), aunque a menudo basta un único punto en 768 px. Lo ideal es ponerlos donde el contenido empieza a verse mal, no según un dispositivo concreto.

/* Referencia habitual */
/*  móvil          320 – 480 px
    tableta peq.   600 – 800 px
    tableta        768 – 1024 px
    escritorio     > 1224 px
    pantallas grandes > 1824 px  */

@media (min-width: 768px) { /* a partir de tableta */ }

Cambia el diseño cuando el contenido lo pida.

Hoja de estilos según el medio: link media

El atributo media de la etiqueta link carga una hoja de estilos solo cuando se cumple una condición. La hoja se descarga siempre, pero únicamente se aplica cuando coincide.

<link rel="stylesheet" href="base.css">
<link rel="stylesheet" href="movil.css" media="screen and (max-width: 640px)">
<link rel="stylesheet" href="imprimir.css" media="print">

Se aplica la hoja movil.css en ventanas de hasta 640 px de ancho.

Tipos de medio

El tipo de medio indica en qué soporte se muestra el documento: all (por defecto, todos), screen (pantallas), print (impresión y vista previa) y speech (sintetizadores de voz). Otros tipos antiguos, como braille, embossed, handheld o tv, están obsoletos.

@media all    { }
@media screen { body { font-size: 1rem; } }
@media print  { nav { display: none; } }
@media speech { .decorativo { speak: never; } }

Tipos vigentes: all, screen, print, speech

Media queries: tamaño, orientación y proporción

Las condiciones de tamaño se refieren a la ventana: width y height, con sus variantes min- y max-. orientation vale portrait (vertical) o landscape (apaisado) y aspect-ratio compara la proporción, como 16/9.

@media (max-width: 480px) { }
@media (min-height: 800px) { }
@media (orientation: landscape) { }
@media (min-aspect-ratio: 16/9) { }
@media (min-width: 600px) and (max-width: 900px) { }

Características: width, height, orientation, aspect-ratio (y sus min-/max-)

Media queries: resolución, color y dispositivo

Otras condiciones útiles: resolution (densidad de píxeles, en dpi o dppx), color (bits por color), monochrome, scan (progressive o interlace), hover y pointer (capacidades del dispositivo). Las variantes device-width y device-height están obsoletas: usa width y height.

@media (min-resolution: 2dppx) { }   /* pantallas de alta densidad */
@media print and (color) { }         /* impresión a color */
@media (monochrome) { }
@media (hover: none) and (pointer: coarse) { }   /* táctil */

Características: resolution, color, monochrome, scan, hover, pointer

Operadores de media queries: and, coma, not y only

and exige que se cumplan todas las condiciones; una coma equivale a «o»; not niega toda la consulta; only oculta la regla a navegadores muy antiguos que no entienden las media queries, aunque hoy rara vez hace falta.

@media screen and (min-width: 600px) and (orientation: landscape) { }
@media (max-width: 480px), print { }          /* móvil O impresión */
@media not print { }
@media only screen and (max-width: 768px) { }

Operadores: and, , (o), not, only

Dos rangos sin solaparse

Si defines rangos con max-width y min-width, deja un píxel de diferencia para que no se solapen. Otra estrategia es «mobile first»: se escribe primero el diseño del móvil y se añaden mejoras con min-width para pantallas mayores.

@media only screen and (max-width: 480px) { /* móvil */ }
@media only screen and (min-width: 481px) and (max-width: 768px) { /* tableta */ }

/* Mobile first */
.menu { display: block; }
@media (min-width: 768px) { .menu { display: flex; } }

Con mobile first, el CSS base ya es el del móvil y es más sencillo de mantener.

Viewport y meta viewport

Sin el meta viewport, los móviles muestran la página como si fuera de escritorio. Esta línea en el head es la base del diseño adaptable.

<meta name="viewport" content="width=device-width, initial-scale=1">

No bloquees el zoom (user-scalable=no).

Imágenes adaptables con CSS

Para que las imágenes nunca se salgan de su contenedor, limita su ancho máximo y mantén su proporción.

img { max-width: 100%; height: auto; display: block; }
.portada { width: 100%; aspect-ratio: 16 / 9; object-fit: cover; }

Propiedades: max-width, height: auto, object-fit

Menú responsive: de horizontal a apilado

En pantallas estrechas el menú se apila; en anchas, se coloca en horizontal.

.menu { display: flex; flex-direction: column; gap: .5rem; }
@media (min-width: 700px) {
  .menu { flex-direction: row; gap: 1.5rem; }
}

Mobile first: lo básico fuera de la media query.

Unidades de ventana: vw, vh, vmin y vmax

vw y vh son el 1 % del ancho y alto de la ventana; vmin y vmax, del menor y mayor de los dos. En móviles, dvh se ajusta a la barra del navegador.

.portada { min-height: 100vh; min-height: 100dvh; }
h1 { font-size: clamp(2rem, 6vw, 4rem); }

Unidades: vw, vh, vmin, vmax, dvh

Pantallas de alta densidad: imágenes 2x

En pantallas de alta densidad conviene servir imágenes con el doble de píxeles. En HTML se hace con srcset; en CSS, con image-set().

.logo {
  background-image: image-set("logo.png" 1x, "logo@2x.png" 2x);
}

Función: image-set()

Orientación del dispositivo

La media query orientation permite adaptar el diseño cuando el dispositivo está en vertical o apaisado.

@media (orientation: landscape) { .cabecera { height: 3rem; } }
@media (orientation: portrait)  { .cabecera { height: 5rem; } }

Valores: portrait, landscape

Lista de comprobación de un diseño responsive

Antes de dar por bueno un diseño: meta viewport, medidas flexibles, imágenes fluidas, texto legible sin zoom, objetivos táctiles de al menos 44 px, nada que desborde horizontalmente y pruebas en móvil real y en el modo móvil del navegador.

html, body { overflow-x: hidden; }   /* ¡solo si sabes por qué lo necesitas! */
button, a { min-height: 44px; min-width: 44px; }

Prueba con el modo dispositivo de las herramientas de desarrollo.

Más preferencias del usuario: transparencia, colores invertidos y script

Otras características de media queries: prefers-reduced-transparency, inverted-colors, scripting (si JavaScript está disponible), color-gamut, dynamic-range y overflow-block (cómo se muestra el desbordamiento en impresión o pantalla).

@media (prefers-reduced-transparency: reduce) { .panel { backdrop-filter: none; background: #fff; } }
@media (scripting: none) { .necesita-js { display: none; } }
@media (color-gamut: p3) { :root { --marca: color(display-p3 0 .5 1); } }
@media (dynamic-range: high) { }

Características: prefers-reduced-transparency, scripting, color-gamut

08

Efectos que cambian con el tiempo

Movimiento y capas

Animación

@keyframes describe los pasos de un movimiento y animation indica cuánto dura y cómo aplicarlo.

@keyframes aparecer {
  from { opacity: 0; }
  to { opacity: 1; }
}
.caja { animation: aparecer .5s ease; }

Reglas: @keyframes y animation

Mover, girar y escalar

translate()/translateX/Y() desplaza; rotate() gira; scale() cambia tamaño; skew() inclina; matrix() combina transformaciones. Puedes encadenarlas. La transformación visual no cambia el espacio original del elemento; también puede crear un contexto de apilamiento. 

transform: translateY(-4px) rotate(2deg) scale(1.02);

Propiedad: transform; relacionadas: translate, rotate, scale

Punto de giro

Elige desde qué punto se gira o cambia de tamaño el elemento.

transform-origin: center bottom;

Propiedad: transform-origin

Delante o detrás (z-index)

Un entero mayor suele dibujarse encima de uno menor; también acepta valores negativos y auto. No es una competición global: contextos de apilamiento (por ejemplo, creados por ciertas posiciones, transformaciones u opacidad) mantienen juntas sus capas. En Flex/Grid, un hijo también puede usar z-index sin posicionamiento. 

position: relative;
z-index: 2;

Propiedad: z-index

Duración de una animación

Indica cuánto tarda en completarse una vuelta de la animación.

animation-duration: 1s;

Propiedad: animation-duration

Retrasar una animación

Espera un tiempo antes de empezar a animar.

animation-delay: .2s;

Propiedad: animation-delay

Repeticiones de una animación

animation-iteration-count indica cuántas vueltas da: un número o infinite. animation-direction admite normal, reverse, alternate y alternate-reverse. animation-fill-mode determina si conserva los estilos de antes/después (none, forwards, backwards, both); animation-play-state es running o paused. 

animation-direction: alternate;
animation-fill-mode: both;

Propiedades: animation-iteration-count, animation-direction, animation-fill-mode, animation-play-state

Aislar capas

isolation: isolate crea un contexto independiente para apilar elementos y efectos. 

.portada { isolation: isolate; }

Propiedad: isolation

Máscaras y forma visible

mask-image usa transparencia o luminancia de una imagen/degradado para ocultar partes. clip-path recorta con formas predefinidas o funciones como circle(), ellipse(), inset() y polygon(). clip es una propiedad antigua; prefiere clip-path. 

clip-path: circle(45% at center);

Propiedades: mask-image, mask-size, clip-path

Animaciones basadas en desplazamiento

Las líneas de tiempo de scroll pueden vincular una animación al desplazamiento de la página o de un contenedor. Es una función moderna: si se usa en una página importante, ofrece una alternativa sin animación y comprueba compatibilidad en los navegadores objetivo.

@supports (animation-timeline: scroll()) {
  .barra { animation-timeline: scroll(); }
}

Conceptos modernos: animation-timeline, scroll(), view()

Propiedades con prefijo

Algunas opciones llevan -webkit- para compatibilidad o efectos propios de ciertos navegadores. No hace falta usar el prefijo en todas las reglas.

-webkit-font-smoothing: antialiased;
-webkit-tap-highlight-color: transparent;

Prefijo de navegador: -webkit-

Transformaciones individuales

translate, rotate y scale son propiedades independientes: puedes cambiar una sin reescribir las demás, como ocurría con transform.

.icono {
  translate: 10px 0;
  rotate: 15deg;
  scale: 1.2;
  transition: rotate .3s;
}
.icono:hover { rotate: 90deg; }

Propiedades: translate, rotate, scale

Efectos en tres dimensiones

perspective da profundidad a los elementos hijos. Con transform-style: preserve-3d y backface-visibility se pueden construir tarjetas que giran.

.escena { perspective: 800px; }
.carta {
  transform-style: preserve-3d;
  transition: transform .6s;
}
.carta:hover { transform: rotateY(180deg); }
.cara { backface-visibility: hidden; }

Propiedades: perspective, transform-style, backface-visibility

Curvas de animación personalizadas: linear()

La función linear() define una curva de velocidad con varios puntos, lo que permite efectos como rebotes o muelles que no se logran con cubic-bezier().

.pelota {
  transition: translate .8s
    linear(0, 0.6 20%, 1 40%, 0.85 55%, 1 70%, 0.95 85%, 1);
}

Funciones: linear(), cubic-bezier(), steps()

Mover por un recorrido: offset-path

offset-path define un trayecto (por ejemplo, una curva) y offset-distance indica en qué punto está el elemento, de 0 % a 100 %. Animándolo se logra un movimiento a lo largo de la línea.

.avion {
  offset-path: path("M0 0 C 100 0, 100 100, 200 100");
  animation: viaje 3s linear infinite;
}
@keyframes viaje {
  to { offset-distance: 100%; }
}

Propiedades: offset-path, offset-distance, offset-rotate

No dibujar lo que no se ve: content-visibility

content-visibility: auto evita calcular y pintar secciones que están fuera de pantalla. contain-intrinsic-size reserva un tamaño aproximado para que la barra de desplazamiento no salte.

.seccion-larga {
  content-visibility: auto;
  contain-intrinsic-size: auto 600px;
}

Propiedades: content-visibility, contain-intrinsic-size

translate: mover un elemento

translate(x, y) desplaza el elemento en horizontal (x, hacia la derecha) y vertical (y, hacia abajo) respecto a su posición original. Los valores negativos lo mueven al lado contrario. translateX() y translateY() mueven en un solo eje. Los porcentajes se calculan sobre el propio tamaño del elemento.

.capa1 { transform: translate(150px, 20px); }
.sube  { transform: translateY(-10px); }
.centro { transform: translate(-50%, -50%); }

Funciones: translate(), translateX(), translateY()

rotate: girar un elemento

rotate() gira el elemento alrededor de su punto de giro (por defecto, el centro). El ángulo puede darse en grados (deg), radianes (rad), gradianes (grad) o vueltas (turn). Un valor positivo gira en el sentido de las agujas del reloj y uno negativo, al contrario.

.capa2 { transform: rotate(30deg); }
.inverso { transform: rotate(-15deg); }
.vuelta { transform: rotate(.25turn); }   /* 90° */

Función: rotate(ángulo)

scale: ampliar y reducir

scale(x, y) cambia el tamaño en cada eje: 1 es el tamaño original, más de 1 amplía y menos de 1 reduce. Con un solo valor escala ambos ejes. scaleX() y scaleY() actúan en un eje, y un valor negativo voltea el elemento.

.capa3 { transform: scale(1.2, 0.8); }
.zoom  { transform: scale(1.1); }
.espejo { transform: scaleX(-1); }

Funciones: scale(), scaleX(), scaleY()

skew: inclinar un elemento

skew(x, y) inclina el elemento según dos ángulos: el primero en horizontal y el segundo en vertical, hasta convertirlo en un romboide. skewX() y skewY() lo inclinan solo en un eje.

.capa4 { transform: skew(10deg, 15deg); }
.cinta { transform: skewX(-12deg); }

Funciones: skew(), skewX(), skewY()

Combinar transformaciones: el orden importa

Después de transform puedes poner varias funciones separadas por espacios. Se aplican de derecha a izquierda sobre el sistema de coordenadas del elemento, así que el orden cambia el resultado: girar y luego mover no es lo mismo que mover y luego girar.

.capa6 { transform: scale(1.5, 0.5) rotate(45deg); }

.a { transform: rotate(45deg) translateX(100px); }
.b { transform: translateX(100px) rotate(45deg); }   /* otro resultado */

Propiedad: transform

Transformar al pasar el ratón

Combinando transform con :hover (o :focus) un elemento reacciona a la interacción. Sin transition, el cambio es instantáneo; con ella, se anima de forma suave y vuelve a su estado al retirar el puntero.

#principal {
  transition: transform .3s ease;
}
#principal:hover,
#principal:focus-visible {
  transform: rotate(5deg);
}

Pseudoclases: :hover, :focus-visible; propiedad: transition

matrix: la transformación completa

matrix(a, b, c, d, tx, ty) es la forma general de todas las transformaciones 2D. Se usa raramente a mano; las demás funciones son más legibles.

.igual { transform: matrix(1, 0, 0, 1, 0, 0); }       /* sin cambio */
.mover { transform: matrix(1, 0, 0, 1, 50, 20); }       /* translate(50px, 20px) */

Función: matrix()

Origen de la perspectiva: perspective-origin

perspective-origin desplaza el punto de vista desde el que se ve un contenedor con perspectiva 3D.

.escena { perspective: 800px; perspective-origin: 20% 80%; }

Propiedad: perspective-origin

Efecto parallax con CSS

El parallax mueve las capas a distinta velocidad al desplazar. Puede lograrse con background-attachment: fixed o con perspectiva 3D. Cuida el rendimiento y la accesibilidad.

.fondo { background: url("monte.jpg") center / cover fixed; }

@media (prefers-reduced-motion: reduce) {
  .fondo { background-attachment: scroll; }
}

Respeta el movimiento reducido.

Animar con transform y opacity: buen rendimiento

Las animaciones de transform y opacity son las más eficientes porque no obligan a recalcular el diseño. Evita animar width, height, top o left.

/* Eficiente */
.panel { transition: transform .3s, opacity .3s; }

/* Costoso */
.panel { transition: left .3s, width .3s; }

Anima transform y opacity.

Voltear un elemento

Para reflejar un elemento se usa una escala negativa.

.espejo-h { transform: scaleX(-1); }
.espejo-v { transform: scaleY(-1); }

Funciones: scaleX(-1), scaleY(-1)
