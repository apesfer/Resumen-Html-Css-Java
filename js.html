00

Preparar y entender un programa

Fundamentos

Añadir JavaScript a una página

El código se incluye con la etiqueta script. Lo habitual es un archivo externo con defer, que espera a que el HTML esté leído antes de ejecutarse, de modo que ya puedes acceder a los elementos de la página.

<script src="app.js" defer></script>

Elemento: <script>; atributos: src, defer, type="module"

Mostrar mensajes: console.log

console.log escribe un valor en la consola del navegador (F12 → Consola). Es la forma más rápida de comprobar qué contiene una variable. Acepta varios valores a la vez.

console.log("Hola, mundo");
console.log("Total:", 3 + 4);
console.warn("Aviso");
console.error("Error");

Variantes: log, info, warn, error, table

Comentarios

Los comentarios de una línea empiezan con //; los de varias líneas van entre /* y */. El navegador los ignora.

// Comentario de una línea

/* Comentario
   de varias líneas */

Comenta el porqué de una decisión, no lo que ya dice el código.

Ejecutar JavaScript fuera del navegador: Node.js

Node.js permite ejecutar JavaScript en tu ordenador, sin navegador. Es la base de muchas herramientas de desarrollo y de servidores.

node --version
node programa.js

Con Node no existen document ni window: son del navegador.

Sintaxis básica

JavaScript distingue mayúsculas de minúsculas (nombre y Nombre son distintos). El punto y coma al final de cada instrucción es opcional pero recomendable. Los nombres se escriben en camelCase.

let precioFinal = 10;
let PrecioFinal = 20;   // otra variable distinta

Los nombres no pueden empezar por un número ni ser palabras reservadas.

Modo estricto

El modo estricto convierte errores silenciosos en errores visibles (por ejemplo, usar una variable sin declarar). Los módulos y las clases ya lo usan por defecto.

"use strict";
nombre = "Ana";   // ReferenceError: no se ha declarado

Se activa con la cadena "use strict" al inicio del archivo o función.

01

Guardar y convertir datos

Variables y tipos

Declarar con let y const

let declara una variable cuyo valor puede cambiar; const una que no se puede reasignar. Usa const por defecto y let solo cuando necesites cambiar el valor.

let contador = 0;
contador = contador + 1;

const IVA = 0.21;
// IVA = 0.1;   // TypeError

Un objeto const no se puede reasignar, pero sí modificar por dentro.

Por qué evitar var

var es la forma antigua: tiene ámbito de función (no de bloque) y se «eleva» al inicio, lo que causa errores difíciles de ver. En código moderno se usa let y const.

if (true) {
  var a = 1;
  let b = 2;
}
console.log(a);   // 1  (se ve fuera del bloque)
// console.log(b); // ReferenceError

Preferir: const y let.

Tipos de datos

Los tipos primitivos son string, number, boolean, undefined, null, bigint y symbol. Todo lo demás (arrays, funciones, objetos) es un objeto.

const texto = "Hola";
const numero = 42;
const decimal = 3.14;
const activo = true;
let sinValor;          // undefined
const vacio = null;

JavaScript tiene un único tipo numérico para enteros y decimales.

Comprobar el tipo: typeof

typeof devuelve el tipo de un valor como texto. Tiene dos rarezas: typeof null es "object" y los arrays también son "object"; para ellos usa Array.isArray.

typeof "hola";          // "string"
typeof 5;               // "number"
typeof undefined;       // "undefined"
typeof null;            // "object"  (rareza histórica)
Array.isArray([1, 2]);  // true

Operador: typeof

Plantillas de texto

Entre comillas invertidas puedes insertar valores con ${...} y escribir varias líneas sin símbolos de concatenación.

const nombre = "Ana";
const edad = 30;
console.log(`Hola, ${nombre}. El año que viene tendrás ${edad + 1}.`);

const html = `
  <p>${nombre}</p>
`;

Se escriben con el acento grave (`), no con comillas simples.

undefined y null

undefined significa «aún no tiene valor» (variable sin inicializar, propiedad inexistente). null es un valor que se asigna a propósito para indicar «vacío».

let a;
console.log(a);          // undefined
const b = null;
const persona = {};
console.log(persona.edad); // undefined

Comprobar ambos a la vez: valor == null, o mejor valor ?? defecto.

Convertir tipos

Number() convierte un texto completo en número (o NaN); parseInt y parseFloat leen el principio del texto; String() y .toString() convierten a texto.

Number("42");        // 42
Number("42px");      // NaN
parseInt("42px");    // 42
parseFloat("3.5kg"); // 3.5
String(123);         // "123"
Boolean("");         // false

Un campo de formulario siempre devuelve texto, aunque sea un número.

NaN y números especiales

NaN («no es un número») es el resultado de una operación numérica inválida y no es igual ni a sí mismo. Se comprueba con Number.isNaN. También existen Infinity y -Infinity.

const x = Number("hola");
console.log(x === NaN);        // false
console.log(Number.isNaN(x));  // true
console.log(1 / 0);            // Infinity

Funciones: Number.isNaN, Number.isFinite, Number.isInteger

Decimales y precisión

Los números usan coma flotante, así que algunos decimales no son exactos. Para mostrar dos decimales usa toFixed (devuelve texto). Para dinero, trabaja con céntimos enteros.

console.log(0.1 + 0.2);        // 0.30000000000000004
console.log((0.1 + 0.2).toFixed(2));   // "0.30"
const centimos = 1999;         // 19,99 €

toFixed devuelve un texto, no un número.

Valores verdaderos y falsos

En una condición, estos valores cuentan como falsos: false, 0, "", null, undefined y NaN. Todo lo demás es verdadero, incluso [] y {}.

if ("") { }          // no entra
if ("hola") { }      // entra
if ([]) { }          // entra (un array vacío es verdadero)
Boolean(0);          // false

Cuidado: 0 es falso aunque a veces sea un valor válido.

02

Calcular, comparar y decidir valores

Operadores

Operadores aritméticos

Los operadores básicos son +, -, *, / y % (resto). ** eleva a una potencia. ++ y -- suman o restan uno.

7 + 2;    // 9
7 / 2;    // 3.5  (no es división entera)
7 % 2;    // 1
2 ** 3;   // 8
let i = 0;
i++;      // 1

Para quedarte con la parte entera: Math.trunc(7 / 2).

Operadores de asignación

Las asignaciones compuestas combinan una operación con la asignación. ??=, ||= y &&= asignan solo según el estado del valor actual.

let total = 10;
total += 5;       // 15
total *= 2;       // 30

let nombre;
nombre ??= "Anónimo";   // asigna solo si es null o undefined

Operadores: +=, -=, *=, /=, %=, **=, ??=

Igualdad estricta: === y ==

=== compara valor y tipo; == convierte los tipos antes de comparar y da resultados sorprendentes. Usa siempre === y !==.

5 === "5";         // false
5 == "5";          // true  (convierte)
0 == "";           // true  (sorprendente)
null == undefined; // true
null === undefined; // false

Regla práctica: usa === y !==.

Operadores de comparación

>, <, >= y <= comparan números y también textos (por orden alfabético de los códigos de carácter). No mezcles tipos.

5 > 3;           // true
"a" < "b";       // true
"10" < "9";      // true  (se comparan como texto)
10 < 9;          // false

Convierte a número antes de comparar valores que vienen de formularios.

Operadores lógicos

&& (y), || (o) y ! (no). Devuelven uno de los operandos, no necesariamente un booleano, y se evalúan en cortocircuito: se detienen en cuanto se conoce el resultado.

const edad = 20;
edad >= 18 && edad < 65;      // true
!edad;                        // false

const usuario = null;
const nombre = usuario && usuario.nombre;   // null

|| devuelve el primer valor verdadero; &&, el primer falso.

Valor por defecto: ?? y ||

?? usa el valor de la derecha solo si el de la izquierda es null o undefined. || lo usa con cualquier valor falso, incluidos 0 y "", que a veces son válidos.

const cantidad = 0;
cantidad || 10;   // 10  (descarta el 0)
cantidad ?? 10;   // 0   (respeta el 0)

Casi siempre es mejor ?? para valores por defecto.

Encadenamiento opcional: ?.

?. detiene la expresión y devuelve undefined si lo que hay a la izquierda es null o undefined, en vez de lanzar un error. Sirve para propiedades, métodos y posiciones de un array.

const usuario = { perfil: null };
console.log(usuario.perfil?.nombre);        // undefined
console.log(usuario.saludar?.());           // undefined
console.log(usuario.amigos?.[0]);           // undefined

Combínalo con ??: usuario.perfil?.nombre ?? "Anónimo"

Operador ternario

condición ? siVerdadero : siFalso elige entre dos valores en una sola expresión. Úsalo para decisiones simples.

const edad = 17;
const estado = edad >= 18 ? "adulto" : "menor";
console.log(`Eres ${estado}`);

No anides varios ternarios: pierde legibilidad.

Operador spread y rest: ...

Los tres puntos expanden un array u objeto en sus elementos (spread) o agrupan los que sobran en un array (rest). Son clave para copiar y combinar datos sin modificar los originales.

const a = [1, 2];
const b = [...a, 3];            // [1, 2, 3]
const o = { x: 1 };
const o2 = { ...o, y: 2 };      // { x: 1, y: 2 }

function sumar(...numeros) { return numeros.length; }

Símbolo: ...

03

Decidir y repetir

Condiciones y bucles

Condicional if / else

if ejecuta un bloque cuando la condición es verdadera; else if y else añaden alternativas. Las llaves son recomendables aunque haya una sola instrucción.

const nota = 7;
if (nota >= 9) {
  console.log("Sobresaliente");
} else if (nota >= 5) {
  console.log("Aprobado");
} else {
  console.log("Suspenso");
}

Se evalúa en orden y se ejecuta solo el primer bloque que cumple.

Varias opciones: switch

switch compara un valor con varios casos usando ===. Sin break, la ejecución continúa en el caso siguiente.

const dia = 3;
switch (dia) {
  case 1:
  case 7:
    console.log("Fin de semana");
    break;
  case 3:
    console.log("Miércoles");
    break;
  default:
    console.log("Otro día");
}

Palabras clave: case, default, break

Bucle for

for tiene tres partes: inicio, condición y avance. Es ideal cuando sabes cuántas veces repetir.

for (let i = 0; i < 3; i++) {
  console.log("Vuelta", i);
}

Sintaxis: for (inicio; condición; avance)

Bucle while y do...while

while repite mientras se cumpla la condición; do...while ejecuta el cuerpo al menos una vez antes de comprobarla.

let n = 3;
while (n > 0) {
  console.log(n);
  n--;
}

do {
  console.log("Se ejecuta una vez");
} while (false);

Asegúrate de que algo cambia dentro del bucle para que termine.

Recorrer valores: for...of

for...of recorre los valores de un array, una cadena, un Map o un Set. Es la forma más clara de recorrer una colección.

const frutas = ["pera", "uva", "kiwi"];
for (const fruta of frutas) {
  console.log(fruta);
}

for (const [i, fruta] of frutas.entries()) {
  console.log(i, fruta);
}

Para índice y valor: array.entries()

Recorrer propiedades: for...in

for...in recorre las claves de un objeto. No lo uses con arrays: usa for...of. Para objetos suele ser más claro Object.entries.

const persona = { nombre: "Ana", edad: 30 };
for (const clave in persona) {
  console.log(clave, persona[clave]);
}

Alternativa: for (const [k, v] of Object.entries(obj))

break y continue

break termina el bucle; continue salta a la siguiente vuelta.

for (let i = 1; i <= 10; i++) {
  if (i % 2 === 0) continue;   // salta los pares
  if (i > 7) break;            // termina el bucle
  console.log(i);              // 1, 3, 5, 7
}

Palabras clave: break, continue

04

Agrupar y reutilizar código

Funciones

Declarar una función

Una función agrupa instrucciones reutilizables. Recibe parámetros y devuelve un valor con return. Las declaraciones con function se pueden usar antes de definirse en el archivo.

function sumar(a, b) {
  return a + b;
}
console.log(sumar(2, 3));   // 5

Una función sin return devuelve undefined.

Funciones flecha

Las funciones flecha son una forma breve de escribir funciones. Si el cuerpo es una sola expresión, el return es implícito. No tienen su propio this.

const doble = (n) => n * 2;
const saludar = nombre => `Hola, ${nombre}`;
const sumar = (a, b) => {
  const total = a + b;
  return total;
};

Sintaxis: (parámetros) => expresión

Expresiones de función

Una función puede guardarse en una variable. A diferencia de la declaración, no se puede usar antes de la línea donde se define.

const multiplicar = function (a, b) {
  return a * b;
};

Prefiere const para no reasignarla por accidente.

Parámetros por defecto

Si un argumento no se pasa (o es undefined), se usa el valor por defecto indicado.

function saludar(nombre = "invitado") {
  return `Hola, ${nombre}`;
}
saludar();         // "Hola, invitado"
saludar("Ana");    // "Hola, Ana"

Sintaxis: parametro = valor

Número variable de argumentos: rest

El parámetro ...nombre recoge todos los argumentos restantes en un array real. Debe ser el último.

function sumar(...numeros) {
  return numeros.reduce((acc, n) => acc + n, 0);
}
sumar(1, 2, 3, 4);   // 10

Sustituye al antiguo objeto arguments.

Objeto como parámetro

Cuando una función recibe muchos datos, es más claro pasar un objeto y desestructurarlo en los parámetros, con valores por defecto.

function crearUsuario({ nombre, edad = 18, activo = true }) {
  return { nombre, edad, activo };
}
crearUsuario({ nombre: "Ana" });

Evita recordar el orden de muchos argumentos.

Funciones como valores: callbacks

Las funciones son valores: se pueden guardar en variables, pasar como argumento y devolver desde otras funciones. Una función que se pasa para que otra la llame se llama callback.

function repetir(veces, accion) {
  for (let i = 0; i < veces; i++) accion(i);
}
repetir(3, (n) => console.log("Vuelta", n));

Los métodos map, filter o addEventListener reciben callbacks.

Clausuras (closures)

Una función recuerda las variables del lugar donde se creó, incluso después de que ese lugar haya terminado. Permite crear datos privados.

function crearContador() {
  let cuenta = 0;
  return () => ++cuenta;
}
const contador = crearContador();
contador();   // 1
contador();   // 2

La variable cuenta no es accesible desde fuera.

Ámbito de las variables

Las variables declaradas con let y const existen solo dentro del bloque { } donde se crean. Las del nivel superior son globales, y conviene evitarlas.

const global = "visible en todas partes";

function prueba() {
  const local = "solo aquí";
  if (true) {
    const bloque = "solo en este bloque";
  }
}

Declara las variables en el ámbito más pequeño posible.

Recursión

Una función recursiva se llama a sí misma. Necesita un caso base que detenga las llamadas.

function factorial(n) {
  if (n <= 1) return 1;
  return n * factorial(n - 1);
}
factorial(5);   // 120

Sin caso base, el programa lanza RangeError (pila desbordada).

La palabra this

this depende de cómo se llama una función: en un método apunta al objeto, y en una función suelta suele ser undefined (modo estricto). Las funciones flecha heredan el this del lugar donde se definen.

const persona = {
  nombre: "Ana",
  saludar() {
    return `Hola, soy ${this.nombre}`;
  }
};
persona.saludar();   // "Hola, soy Ana"

Fijar this: bind, call, apply.

Función de ejecución inmediata (IIFE)

Una función que se define y se ejecuta al instante crea un ámbito propio. Hoy se usa menos, porque los módulos y los bloques cumplen esa función.

(() => {
  const secreto = 42;
  console.log("Se ejecuta ahora");
})();

Patrón: (función)()

05

Trabajar con listas de datos

Arrays

Crear un array

Un array guarda una lista ordenada de valores. Se accede por posición, empezando en 0, y length indica cuántos elementos tiene. at(-1) obtiene el último.

const frutas = ["pera", "uva", "kiwi"];
frutas[0];          // "pera"
frutas.length;      // 3
frutas.at(-1);      // "kiwi"
frutas[10];         // undefined

Propiedad: length; método: at()

Añadir y quitar elementos

push y pop trabajan al final del array; unshift y shift, al principio. Todos modifican el array original.

const lista = [2, 3];
lista.push(4);        // [2, 3, 4]
lista.unshift(1);     // [1, 2, 3, 4]
lista.pop();          // quita 4
lista.shift();        // quita 1

pop y shift devuelven el elemento eliminado.

Recorrer con forEach

forEach ejecuta una función por cada elemento. No devuelve nada y no se puede interrumpir con break.

["a", "b"].forEach((letra, i) => {
  console.log(i, letra);
});

Para transformar datos usa map; para filtrar, filter.

Transformar: map

map crea un array nuevo aplicando una función a cada elemento. El array original no cambia.

const numeros = [1, 2, 3];
const dobles = numeros.map(n => n * 2);   // [2, 4, 6]

const nombres = usuarios.map(u => u.nombre);

Devuelve un array de la misma longitud.

Filtrar: filter

filter devuelve un array nuevo con los elementos para los que la función devuelve verdadero.

const numeros = [1, 2, 3, 4, 5, 6];
const pares = numeros.filter(n => n % 2 === 0);   // [2, 4, 6]

Si ninguno cumple, devuelve [].

Reducir a un valor: reduce

reduce recorre el array acumulando un resultado. Recibe una función con el acumulador y el elemento actual, y un valor inicial.

const precios = [10, 20, 5];
const total = precios.reduce((acc, p) => acc + p, 0);   // 35

Indica siempre el valor inicial (segundo argumento).

Buscar en un array: find e includes

find devuelve el primer elemento que cumple una condición (o undefined); findIndex, su posición; includes comprueba si existe un valor; some y every comprueban si alguno o todos cumplen.

const n = [3, 8, 12];
n.find(x => x > 5);         // 8
n.findIndex(x => x > 5);    // 1
n.includes(12);             // true
n.some(x => x > 10);        // true
n.every(x => x > 1);        // true

Métodos: find, findIndex, includes, some, every

Ordenar: sort

Por defecto, sort ordena como texto y modifica el array. Para números, pasa un comparador. toSorted devuelve una copia ordenada sin tocar el original.

const n = [10, 9, 1];
n.sort();                  // [1, 10, 9]  (como texto)
n.sort((a, b) => a - b);   // [1, 9, 10]

const copia = n.toSorted((a, b) => b - a);

Comparador: negativo (antes), positivo (después), 0 (igual).

Extraer y modificar partes: slice y splice

slice(inicio, fin) devuelve una copia de una parte, sin modificar el original. splice elimina o inserta elementos modificando el array.

const l = [1, 2, 3, 4, 5];
l.slice(1, 3);         // [2, 3]
l.splice(1, 2);        // quita 2 y 3 -> l = [1, 4, 5]
l.splice(1, 0, "x");   // inserta "x" en la posición 1

slice no modifica; splice sí.

Unir y copiar arrays

Usa el operador spread para copiar o combinar arrays. Con Set se eliminan duplicados.

const a = [1, 2];
const b = [3, 4];
const unido = [...a, ...b];      // [1, 2, 3, 4]
const copia = [...a];
const unicos = [...new Set([1, 1, 2, 3, 3])];   // [1, 2, 3]

Una asignación const b = a no copia, solo apunta al mismo array.

De array a texto y viceversa: join y split

join une los elementos de un array en un texto; split divide un texto en un array según un separador.

["a", "b", "c"].join("-");     // "a-b-c"
"uno,dos,tres".split(",");     // ["uno", "dos", "tres"]
"hola".split("");              // ["h", "o", "l", "a"]

Métodos: join (array → texto), split (texto → array)

Desestructuración de arrays

Permite extraer valores de un array en variables con una sola línea. También sirve para intercambiar dos variables.

const [primero, segundo, ...resto] = [10, 20, 30, 40];
// primero = 10, segundo = 20, resto = [30, 40]

let a = 1, b = 2;
[a, b] = [b, a];   // intercambio

Sintaxis: const [a, b] = array

Crear y aplanar arrays

Array.from crea arrays a partir de otros datos o con una longitud dada. flat aplana arrays anidados y flatMap combina map y flat.

Array.from({ length: 5 }, (_, i) => i);   // [0, 1, 2, 3, 4]
new Array(3).fill(0);                      // [0, 0, 0]
[[1, 2], [3]].flat();                      // [1, 2, 3]

Métodos: Array.from, fill, flat, flatMap

Arrays de objetos: patrones habituales

Los datos reales suelen ser listas de objetos. Se combinan filter, map y sort encadenados para obtener justo lo que necesitas.

const productos = [
  { nombre: "Pan", precio: 1.2 },
  { nombre: "Leche", precio: 0.9 },
  { nombre: "Queso", precio: 4.5 },
];

const baratos = productos
  .filter(p => p.precio < 2)
  .map(p => p.nombre);          // ["Pan", "Leche"]

Encadenar métodos hace el código fácil de leer.

06

Organizar información con claves

Objetos y colecciones

Crear un objeto

Un objeto agrupa pares clave-valor. Se accede con punto (objeto.clave) o con corchetes (objeto["clave"]), que permiten usar claves dinámicas.

const persona = {
  nombre: "Ana",
  edad: 30,
  "codigo postal": "15001",
};
persona.nombre;               // "Ana"
persona["codigo postal"];     // "15001"

Usa corchetes cuando la clave tiene espacios o está en una variable.

Añadir, modificar y borrar propiedades

Se pueden añadir o cambiar propiedades asignándolas. delete elimina una y in o Object.hasOwn comprueban si existe.

const p = { nombre: "Ana" };
p.edad = 30;              // añadir
p.nombre = "Eva";         // modificar
delete p.edad;            // borrar
"nombre" in p;            // true
Object.hasOwn(p, "edad"); // false

Un const permite modificar el contenido, pero no reasignar la variable.

Claves, valores y entradas

Object.keys, Object.values y Object.entries convierten un objeto en arrays que puedes recorrer o transformar. Object.fromEntries hace el camino contrario.

const precios = { pan: 1, leche: 2 };
Object.keys(precios);      // ["pan", "leche"]
Object.values(precios);    // [1, 2]
Object.entries(precios);   // [["pan", 1], ["leche", 2]]

Object.fromEntries(
  Object.entries(precios).map(([k, v]) => [k, v * 2])
);

Útiles junto a map, filter y for...of.

Desestructuración de objetos

Extrae propiedades de un objeto en variables. Puedes renombrarlas y dar valores por defecto.

const usuario = { nombre: "Ana", edad: 30, ciudad: "Vigo" };

const { nombre, edad } = usuario;
const { ciudad: localidad = "Sin ciudad", pais = "ES" } = usuario;

Sintaxis: const { propiedad } = objeto

Abreviaturas en objetos

Si la variable se llama igual que la clave, basta con escribirla una vez. Los métodos no necesitan function y las claves pueden calcularse entre corchetes.

const nombre = "Ana";
const campo = "edad";

const persona = {
  nombre,                 // nombre: nombre
  [campo]: 30,            // edad: 30
  saludar() { return "Hola"; },
};

Sintaxis: { nombre }, { [clave]: valor }

Copiar objetos

Asignar un objeto a otra variable no lo copia. El spread hace una copia superficial (los objetos interiores se comparten); structuredClone hace una copia profunda.

const original = { a: 1, interior: { b: 2 } };
const referencia = original;                 // mismo objeto
const superficial = { ...original };
const profunda = structuredClone(original);

Copia profunda: structuredClone; no admite funciones.

Objetos inmutables: Object.freeze

Object.freeze impide añadir, modificar o borrar propiedades de un objeto (solo en su primer nivel).

const config = Object.freeze({ tema: "claro" });
config.tema = "oscuro";   // se ignora (o lanza error en modo estricto)

Es superficial: no congela los objetos interiores.

Datos en texto: JSON

JSON es un formato de texto para intercambiar datos. JSON.stringify convierte un valor en texto y JSON.parse lo convierte de nuevo en un valor.

const datos = { nombre: "Ana", edad: 30 };
const texto = JSON.stringify(datos);       // '{"nombre":"Ana","edad":30}'
const bonito = JSON.stringify(datos, null, 2);
const objeto = JSON.parse(texto);

JSON.parse lanza un error si el texto no es JSON válido.

Mapas: Map

Map guarda pares clave-valor y, a diferencia de un objeto, admite claves de cualquier tipo y recuerda el orden de inserción.

const edades = new Map();
edades.set("Ana", 30);
edades.set("Luis", 25);
edades.get("Ana");     // 30
edades.has("Eva");     // false
edades.size;           // 2
for (const [nombre, edad] of edades) { }

Métodos: set, get, has, delete, size

Conjuntos: Set

Set guarda valores únicos: añadir uno repetido no tiene efecto. Es ideal para eliminar duplicados o comprobar pertenencia rápidamente.

const etiquetas = new Set(["a", "b", "a"]);
etiquetas.add("c");
etiquetas.has("a");    // true
etiquetas.size;        // 3
[...etiquetas];        // ["a", "b", "c"]

Métodos: add, has, delete, size

Agrupar datos

Object.groupBy agrupa los elementos de una lista según un criterio y devuelve un objeto de arrays. Si tu entorno no lo admite, se puede hacer con reduce.

const palabras = ["sol", "mar", "cielo"];
const porLongitud = Object.groupBy(palabras, p => p.length);
// { 3: ["sol", "mar"], 5: ["cielo"] }

Comprueba la compatibilidad de los navegadores que necesitas.

07

Cadenas, matemáticas y fechas

Texto, números y fechas

Métodos de texto básicos

Las cadenas tienen métodos para cambiar mayúsculas, limpiar espacios y comprobar su contenido. Los textos son inmutables: cada método devuelve uno nuevo.

const t = "  Hola Mundo ";
t.trim();                  // "Hola Mundo"
t.toUpperCase();
t.length;                  // 13
t.includes("Mundo");       // true
t.startsWith("  H");       // true

Métodos: trim, toUpperCase, toLowerCase, includes

Extraer y reemplazar texto

slice extrae una parte, indexOf devuelve la posición (o -1), replace sustituye la primera coincidencia y replaceAll, todas.

const t = "Aprender JavaScript";
t.slice(0, 8);                    // "Aprender"
t.indexOf("Java");                // 9
t.replace("Aprender", "Dominar");
"a-b-c".replaceAll("-", "+");     // "a+b+c"

slice(inicio, fin) incluye el inicio y excluye el final.

Rellenar y repetir

padStart y padEnd rellenan un texto hasta una longitud dada; repeat lo repite. Son muy útiles para dar formato a horas y números.

String(7).padStart(2, "0");    // "07"
"=".repeat(10);                // "=========="

const hora = `${String(9).padStart(2, "0")}:${String(5).padStart(2, "0")}`;

Métodos: padStart, padEnd, repeat

Expresiones regulares básicas

Una expresión regular describe un patrón de texto. test comprueba si hay coincidencia; match devuelve las coincidencias y replace puede usarlas.

const correo = /^[^\s@]+@[^\s@]+\.[a-z]{2,}$/i;
correo.test("ana@ejemplo.es");        // true

"Tel: 600123456".match(/\d+/);        // ["600123456"]
"a1b2".replace(/\d/g, "#");           // "a#b#"

Banderas: g (global), i (sin distinguir mayúsculas)

La clase Math

Math ofrece funciones matemáticas. Para obtener el mayor de un array, usa spread con Math.max.

Math.round(2.5);       // 3
Math.floor(2.9);       // 2
Math.ceil(2.1);        // 3
Math.abs(-4);          // 4
Math.max(...[3, 9, 2]); // 9
Math.random();         // entre 0 y 1

Métodos: round, floor, ceil, trunc, max, min, random

Número aleatorio entre dos valores

Math.random() devuelve un decimal entre 0 (incluido) y 1 (excluido). Para un entero en un rango, multiplica y redondea hacia abajo.

function entero(min, max) {
  return Math.floor(Math.random() * (max - min + 1)) + min;
}
entero(1, 6);   // dado de seis caras

No es válido para contraseñas ni seguridad: usa crypto.getRandomValues.

Dar formato a números y moneda: Intl

Intl.NumberFormat presenta números según el idioma y país: separadores de miles, decimales y moneda.

const euros = new Intl.NumberFormat("es-ES", {
  style: "currency",
  currency: "EUR",
});
euros.format(1234.5);      // "1234,50 €"
(0.256).toLocaleString("es-ES", { style: "percent" });  // "26 %"

API: Intl.NumberFormat, toLocaleString

Fechas: Date

new Date() crea la fecha actual o una fecha concreta. Cuidado: los meses empiezan en 0 (enero = 0).

const hoy = new Date();
hoy.getFullYear();               // 2026
hoy.getMonth();                  // 0 = enero ... 11 = diciembre
hoy.getDate();                   // día del mes
const navidad = new Date(2026, 11, 25);
hoy.toISOString();               // "2026-11-05T..." (UTC)

Los días de la semana empiezan en domingo = 0.

Formatear y calcular fechas

toLocaleDateString y Intl.DateTimeFormat muestran la fecha según el idioma. Para calcular diferencias, resta fechas: el resultado está en milisegundos.

const f = new Date(2026, 11, 25);
f.toLocaleDateString("es-ES", {
  weekday: "long", day: "numeric", month: "long", year: "numeric",
});   // "viernes, 25 de diciembre de 2026"

const dias = Math.round((f - new Date()) / 86_400_000);

1 día = 86 400 000 ms

08

Plantillas para crear objetos

Clases

Clases y objetos

Una clase es una plantilla para crear objetos. constructor inicializa cada objeto y new lo crea. Los métodos se escriben dentro de la clase.

class Persona {
  constructor(nombre, edad) {
    this.nombre = nombre;
    this.edad = edad;
  }
  saludar() {
    return `Hola, soy ${this.nombre}`;
  }
}
const ana = new Persona("Ana", 30);
ana.saludar();

Las clases siempre se ejecutan en modo estricto.

Herencia: extends y super

extends crea una clase que hereda de otra. En el constructor de la subclase hay que llamar a super(...) antes de usar this.

class Animal {
  constructor(nombre) { this.nombre = nombre; }
  hablar() { return "..."; }
}
class Perro extends Animal {
  hablar() { return `${this.nombre} dice guau`; }
}
new Perro("Toby").hablar();

super.metodo() llama a la versión de la clase padre.

Campos y métodos privados

Un nombre que empieza por # es privado: solo puede usarse dentro de la clase. Protege los datos internos.

class Cuenta {
  #saldo = 0;
  ingresar(cantidad) { this.#saldo += cantidad; }
  get saldo() { return this.#saldo; }
}
const c = new Cuenta();
c.ingresar(50);
// c.#saldo;   // SyntaxError

Sintaxis: #nombre

Getters y setters

Un get permite leer un valor calculado como si fuera una propiedad; un set, validar o transformar el valor antes de guardarlo.

class Rectangulo {
  constructor(ancho, alto) { this.ancho = ancho; this.alto = alto; }
  get area() { return this.ancho * this.alto; }
  set lado(v) { this.ancho = this.alto = v; }
}
const r = new Rectangulo(2, 3);
r.area;      // 6 (sin paréntesis)

Palabras clave: get, set

Miembros estáticos

Un miembro static pertenece a la clase, no a cada objeto: se llama con el nombre de la clase.

class Utiles {
  static duplicar(n) { return n * 2; }
}
Utiles.duplicar(4);   // 8

Ejemplos del lenguaje: Math.max, Array.isArray, Object.keys

Comprobar el tipo de objeto: instanceof

instanceof comprueba si un objeto se ha creado con cierta clase (o una clase heredada).

const p = new Perro("Toby");
p instanceof Perro;    // true
p instanceof Animal;   // true
p instanceof Date;     // false

Operador: instanceof

09

Controlar la página desde el código

DOM y eventos

Seleccionar elementos

querySelector devuelve el primer elemento que coincide con un selector CSS (o null); querySelectorAll devuelve todos. getElementById busca por id.

const titulo = document.querySelector("h1");
const botones = document.querySelectorAll(".boton");
const caja = document.getElementById("caja");

botones.forEach(b => console.log(b.textContent));

Comprueba que el resultado no es null antes de usarlo.

Cambiar el texto: textContent e innerHTML

textContent cambia el texto tal cual, sin interpretar HTML. innerHTML interpreta etiquetas: nunca lo uses con texto escrito por usuarios, porque permite inyectar código (XSS).

const caja = document.querySelector("#caja");
caja.textContent = "Hola <b>mundo</b>";   // se muestra literal
caja.innerHTML = "<strong>Hola</strong>";  // solo con contenido propio

Con datos de personas, usa siempre textContent.

Crear y añadir elementos

createElement crea un nodo; append y prepend lo insertan; remove lo elimina.

const li = document.createElement("li");
li.textContent = "Nueva tarea";
document.querySelector("ul").append(li);

li.remove();

Métodos: append, prepend, before, after, remove, replaceWith

Clases CSS: classList

classList añade, quita o alterna clases CSS. Es la forma recomendada de cambiar el aspecto: define el estilo en CSS y activa la clase desde JavaScript.

const panel = document.querySelector(".panel");
panel.classList.add("abierto");
panel.classList.remove("abierto");
panel.classList.toggle("oculto");
panel.classList.contains("oculto");

Métodos: add, remove, toggle, contains

Atributos y datos personalizados

Los atributos se leen y modifican con getAttribute y setAttribute. Los atributos data-* están disponibles en dataset.

const img = document.querySelector("img");
img.setAttribute("alt", "Un faro");
img.getAttribute("src");

// <button data-id="42" data-accion="borrar">
const b = document.querySelector("button");
b.dataset.id;        // "42"
b.dataset.accion;    // "borrar"

Para booleanos, usa propiedades: elemento.hidden = true

Estilos desde JavaScript: style

elemento.style modifica estilos en línea. Las propiedades se escriben en camelCase. setProperty sirve para variables CSS.

const caja = document.querySelector(".caja");
caja.style.backgroundColor = "teal";
caja.style.setProperty("--tamano", "20px");

getComputedStyle(caja).width;

Mejor: cambia clases en lugar de estilos individuales.

Escuchar eventos: addEventListener

addEventListener asocia una función a un evento (click, input, submit, keydown...). El objeto event informa de lo ocurrido.

const boton = document.querySelector("#boton");
boton.addEventListener("click", (e) => {
  console.log("Pulsado", e.target);
});

document.addEventListener("keydown", (e) => {
  if (e.key === "Escape") cerrar();
});

Opciones: { once: true } ejecuta el manejador solo una vez.

Delegación de eventos

En lugar de poner un manejador en cada elemento, pon uno en el contenedor y averigua qué elemento lo disparó con e.target.closest(...). Funciona también con elementos añadidos más tarde.

document.querySelector("ul").addEventListener("click", (e) => {
  const item = e.target.closest("li");
  if (!item) return;
  item.classList.toggle("hecho");
});

Métodos clave: event.target, closest

Formularios: submit y FormData

En el evento submit se llama a preventDefault() para evitar que la página se recargue. FormData recoge todos los campos con name.

const form = document.querySelector("form");
form.addEventListener("submit", (e) => {
  e.preventDefault();
  const datos = new FormData(form);
  const valores = Object.fromEntries(datos);
  console.log(valores);   // { nombre: "Ana", correo: "..." }
});

Los valores de los campos siempre son texto.

Leer un campo de entrada

value contiene el texto de un campo; checked, el estado de una casilla. El evento input se dispara al escribir y change al confirmar el cambio.

const campo = document.querySelector("#edad");
campo.addEventListener("input", () => {
  const edad = campo.valueAsNumber;   // número, no texto
  console.log(edad);
});

document.querySelector("#acepto").checked;

valueAsNumber funciona con type="number" y range.

Evitar el comportamiento por defecto

preventDefault cancela la acción habitual de un evento (seguir un enlace, enviar un formulario). stopPropagation evita que el evento suba a los elementos padre.

enlace.addEventListener("click", (e) => {
  e.preventDefault();
  mostrarModal();
});

Úsalos con moderación: pueden romper el comportamiento esperado.

Esperar a que cargue la página

Si el script se carga con defer, el DOM ya está disponible. Si no, espera al evento DOMContentLoaded.

document.addEventListener("DOMContentLoaded", () => {
  console.log("El DOM está listo");
});

Eventos: DOMContentLoaded (HTML listo), load (todo cargado)

Observar si algo es visible: IntersectionObserver

IntersectionObserver avisa cuando un elemento entra o sale de la zona visible, sin escuchar el scroll constantemente. Sirve para cargas perezosas y animaciones de entrada.

const observador = new IntersectionObserver((entradas) => {
  entradas.forEach(e => {
    if (e.isIntersecting) e.target.classList.add("visible");
  });
});
document.querySelectorAll(".aparece").forEach(el => observador.observe(el));

Mucho más eficiente que calcular posiciones en cada scroll.

10

Esperar datos sin bloquear la página

Asincronía y red

Retrasar y repetir: setTimeout y setInterval

setTimeout ejecuta una función una vez tras un retraso en milisegundos; setInterval la repite. Ambos devuelven un identificador que se usa para cancelarlos.

const id = setTimeout(() => console.log("Pasaron 2 s"), 2000);
clearTimeout(id);

const reloj = setInterval(() => console.log("tic"), 1000);
clearInterval(reloj);

Siempre cancela los intervalos que ya no necesites.

Promesas

Una promesa representa un resultado que llegará en el futuro. then recibe el valor, catch los errores y finally se ejecuta siempre.

const esperar = (ms) => new Promise((resolve) => setTimeout(resolve, ms));

esperar(1000)
  .then(() => console.log("Listo"))
  .catch(err => console.error(err))
  .finally(() => console.log("Fin"));

Estados: pendiente, cumplida o rechazada.

async y await

Una función async siempre devuelve una promesa. Dentro de ella, await pausa la función hasta que la promesa se resuelve, con un estilo parecido al código normal.

async function cargar() {
  await esperar(1000);
  return "datos";
}

const resultado = await cargar();   // en un módulo
cargar().then(console.log);

await solo funciona dentro de async o de módulos.

Pedir datos: fetch

fetch hace una petición HTTP y devuelve una promesa. No se rechaza con errores como 404 o 500: hay que comprobar response.ok.

async function cargarUsuarios() {
  const respuesta = await fetch("https://ejemplo.test/api/usuarios");
  if (!respuesta.ok) {
    throw new Error(`Error ${respuesta.status}`);
  }
  return await respuesta.json();
}

Métodos de lectura: json(), text(), blob()

Enviar datos con fetch (POST)

Para enviar datos se indica el método, las cabeceras y el cuerpo (body). Si es JSON, convierte el objeto con JSON.stringify.

const respuesta = await fetch("/api/mensajes", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ texto: "Hola" }),
});

Opciones: method, headers, body

Gestionar errores asíncronos

Con async/await, los errores se capturan con try/catch, igual que en código normal. Muestra siempre un mensaje útil a la persona.

async function cargar() {
  try {
    const datos = await cargarUsuarios();
    mostrar(datos);
  } catch (error) {
    console.error(error);
    mostrarMensaje("No se pudieron cargar los datos.");
  } finally {
    ocultarCargando();
  }
}

finally es ideal para ocultar indicadores de carga.

Varias promesas a la vez: Promise.all

Promise.all espera a que se cumplan todas las promesas (falla si una falla). Promise.allSettled espera a todas y devuelve el resultado de cada una. Promise.race devuelve la primera en terminar.

const [usuarios, pedidos] = await Promise.all([
  fetch("/api/usuarios").then(r => r.json()),
  fetch("/api/pedidos").then(r => r.json()),
]);

Lanzar las peticiones en paralelo es más rápido que una tras otra.

Cancelar una petición: AbortController

Un AbortController permite cancelar un fetch en curso, por ejemplo cuando la persona sigue escribiendo en un buscador.

const control = new AbortController();
fetch("/api/buscar?q=ana", { signal: control.signal })
  .catch(err => {
    if (err.name === "AbortError") console.log("Cancelada");
  });

control.abort();

Error resultante: AbortError

Orden de ejecución: el bucle de eventos

JavaScript ejecuta una cosa a la vez. Las tareas diferidas esperan en colas: las promesas (microtareas) se ejecutan antes que los temporizadores.

console.log("1");
setTimeout(() => console.log("3 (temporizador)"), 0);
Promise.resolve().then(() => console.log("2 (promesa)"));
console.log("1b");
// Orden: 1, 1b, 2, 3

El código síncrono siempre termina antes que el asíncrono.

11

Dividir el código y usar el navegador

Módulos y APIs del navegador

Módulos: import y export

Los módulos dividen el código en archivos. export publica lo que otros archivos pueden usar e import lo trae. Se cargan con type="module".

// utiles.js
export const IVA = 0.21;
export function sumar(a, b) { return a + b; }
export default function saludar() { return "Hola"; }

// app.js
import saludar, { IVA, sumar } from "./utiles.js";

Los módulos necesitan un servidor local; no funcionan abriendo el archivo directamente.

Cargar un módulo bajo demanda

import() carga un módulo solo cuando hace falta y devuelve una promesa. Reduce lo que se descarga al abrir la página.

boton.addEventListener("click", async () => {
  const { abrirEditor } = await import("./editor.js");
  abrirEditor();
});

Función: import("ruta")

Guardar datos en el navegador: localStorage

localStorage guarda pares de texto que se conservan al cerrar el navegador; sessionStorage, solo mientras dura la pestaña. Solo almacenan texto: usa JSON para objetos.

localStorage.setItem("tema", "oscuro");
localStorage.getItem("tema");         // "oscuro"
localStorage.removeItem("tema");

const tareas = [{ id: 1, texto: "Estudiar" }];
localStorage.setItem("tareas", JSON.stringify(tareas));
const guardadas = JSON.parse(localStorage.getItem("tareas") ?? "[]");

No guardes contraseñas ni datos sensibles.

Leer parámetros de la URL

URL y URLSearchParams leen y construyen direcciones. location contiene la dirección actual de la página.

const params = new URLSearchParams(location.search);
params.get("pagina");        // "2" si la URL es ?pagina=2

const url = new URL("https://ejemplo.test/buscar");
url.searchParams.set("q", "javascript");
url.toString();

Propiedades de location: href, pathname, search, hash

Copiar al portapapeles

navigator.clipboard.writeText copia un texto al portapapeles. Devuelve una promesa y solo funciona en páginas seguras (HTTPS) y tras una acción de la persona, como un clic.

boton.addEventListener("click", async () => {
  try {
    await navigator.clipboard.writeText("Texto copiado");
    boton.textContent = "¡Copiado!";
  } catch {
    boton.textContent = "No se pudo copiar";
  }
});

API: navigator.clipboard

Identificadores únicos y cifrado

crypto.randomUUID() genera un identificador único; crypto.getRandomValues produce números aleatorios aptos para seguridad. Math.random no lo es.

const id = crypto.randomUUID();
const bytes = crypto.getRandomValues(new Uint8Array(8));

Requiere un contexto seguro (HTTPS o localhost).

Preferencias del sistema: matchMedia

matchMedia evalúa en JavaScript una media query de CSS. Sirve, por ejemplo, para detectar si el sistema está en modo oscuro.

const oscuro = matchMedia("(prefers-color-scheme: dark)");
document.documentElement.dataset.tema = oscuro.matches ? "oscuro" : "claro";

oscuro.addEventListener("change", (e) => {
  console.log("Cambió el tema:", e.matches);
});

Función: matchMedia(); propiedad: matches

12

Anticipar y encontrar problemas

Errores y depuración

Capturar errores: try, catch y finally

El código de try se ejecuta y, si falla, el control pasa a catch con el error. finally se ejecuta siempre. En catch puedes omitir la variable si no la usas.

try {
  const datos = JSON.parse("{ mal }");
} catch (error) {
  console.error("JSON no válido:", error.message);
} finally {
  console.log("Siempre se ejecuta");
}

Propiedades del error: name, message, stack

Lanzar errores: throw

throw lanza un error cuando algo no es válido. Lanza siempre un objeto Error, con un mensaje que explique el problema.

function dividir(a, b) {
  if (b === 0) {
    throw new Error("No se puede dividir entre cero");
  }
  return a / b;
}

Tipos: Error, TypeError, RangeError, SyntaxError

Errores más frecuentes

ReferenceError: usas algo que no existe. TypeError: usas un valor de forma inválida (por ejemplo, leer una propiedad de undefined). SyntaxError: el código está mal escrito. RangeError: valor fuera de rango.

console.log(noExiste);        // ReferenceError
const x = undefined;
x.nombre;                     // TypeError
null();                       // TypeError: no es una función

Lee el mensaje y la línea: suelen indicar el problema.

Crear errores propios

Puedes crear tus propias clases de error heredando de Error. Facilitan distinguir qué ha fallado en un catch.

class ValidacionError extends Error {
  constructor(mensaje, campo) {
    super(mensaje);
    this.name = "ValidacionError";
    this.campo = campo;
  }
}
try { throw new ValidacionError("Falta el correo", "correo"); }
catch (e) { if (e instanceof ValidacionError) console.log(e.campo); }

No olvides super(mensaje).

Depurar con la consola

Además de log, la consola ofrece table (datos tabulares), group (agrupar mensajes), time (medir duración) y assert. La instrucción debugger detiene la ejecución si las herramientas están abiertas.

console.table([{ a: 1, b: 2 }, { a: 3, b: 4 }]);

console.time("bucle");
for (let i = 0; i < 1e6; i++) {}
console.timeEnd("bucle");

debugger;

Atajo: F12 abre las herramientas del navegador.

Errores no capturados

Los errores que nadie captura llegan al evento global error; las promesas rechazadas sin catch, a unhandledrejection. Sirven para registrar fallos.

window.addEventListener("error", (e) => {
  console.log("Error global:", e.message);
});
window.addEventListener("unhandledrejection", (e) => {
  console.log("Promesa rechazada:", e.reason);
});

Eventos: error, unhandledrejection

13

Pequeños programas que aparecen a menudo

Ejemplos de uso frecuente

Contador de clics

El ejemplo más sencillo de interactividad: una variable que cambia y un texto que se actualiza.

let cuenta = 0;
const boton = document.querySelector("#sumar");
const salida = document.querySelector("#total");

boton.addEventListener("click", () => {
  cuenta++;
  salida.textContent = cuenta;
});

HTML necesario: un button y un elemento para mostrar el total.

Lista de tareas

Combina formulario, creación de elementos y delegación de eventos.

const form = document.querySelector("#form");
const lista = document.querySelector("#lista");

form.addEventListener("submit", (e) => {
  e.preventDefault();
  const texto = form.elements.tarea.value.trim();
  if (!texto) return;
  const li = document.createElement("li");
  li.textContent = texto;
  lista.append(li);
  form.reset();
});

lista.addEventListener("click", (e) => {
  e.target.closest("li")?.classList.toggle("hecha");
});

Añade localStorage para conservar las tareas.

Alternar modo claro y oscuro

Guarda la preferencia y aplícala con un atributo en html; el aspecto se define en CSS.

const raiz = document.documentElement;
raiz.dataset.tema = localStorage.getItem("tema") ?? "claro";

document.querySelector("#tema").addEventListener("click", () => {
  const nuevo = raiz.dataset.tema === "claro" ? "oscuro" : "claro";
  raiz.dataset.tema = nuevo;
  localStorage.setItem("tema", nuevo);
});

En CSS: [data-tema="oscuro"] { ... }

Validar un formulario

Comprueba los campos, muestra un mensaje junto al que falla y marca el campo como inválido para las tecnologías de apoyo.

form.addEventListener("submit", (e) => {
  const correo = form.elements.correo;
  const error = document.querySelector("#error-correo");
  if (!correo.validity.valid) {
    e.preventDefault();
    error.textContent = "Escribe un correo válido";
    correo.setAttribute("aria-invalid", "true");
  } else {
    error.textContent = "";
    correo.removeAttribute("aria-invalid");
  }
});

API de validación: validity, checkValidity(), setCustomValidity()

Buscador con filtro

Filtra una lista mientras se escribe. Normalizar el texto permite ignorar mayúsculas y tildes.

const normalizar = (t) =>
  t.normalize("NFD").replace(/[\u0300-\u036f]/g, "").toLowerCase();

campo.addEventListener("input", () => {
  const consulta = normalizar(campo.value);
  document.querySelectorAll("#lista li").forEach((li) => {
    li.hidden = !normalizar(li.textContent).includes(consulta);
  });
});

Es el mismo patrón que usan estas guías para buscar.

Retrasar una acción: debounce

Un debounce espera a que la persona deje de escribir antes de ejecutar una acción, evitando lanzar una petición con cada tecla.

function debounce(funcion, espera = 300) {
  let id;
  return (...args) => {
    clearTimeout(id);
    id = setTimeout(() => funcion(...args), espera);
  };
}
campo.addEventListener("input", debounce(buscar, 400));

Combina closure, setTimeout y parámetros rest.

Barajar un array

El algoritmo de Fisher-Yates mezcla un array de forma uniforme. Trabaja sobre una copia para no modificar el original.

function barajar(lista) {
  const a = [...lista];
  for (let i = a.length - 1; i > 0; i--) {
    const j = Math.floor(Math.random() * (i + 1));
    [a[i], a[j]] = [a[j], a[i]];
  }
  return a;
}

Evita sort(() => Math.random() - 0.5): no es uniforme.

Cuenta atrás

Un temporizador que cuenta segundos y se detiene al llegar a cero.

let restante = 10;
const pantalla = document.querySelector("#cuenta");

const id = setInterval(() => {
  pantalla.textContent = restante;
  if (restante === 0) clearInterval(id);
  restante--;
}, 1000);

No olvides clearInterval.

Mostrar datos de una API

Un patrón completo: estado de carga, petición, gestión de errores y pintado de los datos.

async function cargar() {
  estado.textContent = "Cargando...";
  try {
    const r = await fetch("/api/rutas");
    if (!r.ok) throw new Error(r.status);
    const rutas = await r.json();
    lista.replaceChildren(...rutas.map((ruta) => {
      const li = document.createElement("li");
      li.textContent = ruta.nombre;
      return li;
    }));
    estado.textContent = "";
  } catch {
    estado.textContent = "No se pudieron cargar las rutas.";
  }
}
cargar();

replaceChildren sustituye todo el contenido de una vez.

Contar palabras de un texto

Convierte un texto en una tabla de frecuencias usando split, reduce y un objeto.

const texto = "sol mar sol cielo mar sol";
const frecuencias = texto.split(" ").reduce((acc, p) => {
  acc[p] = (acc[p] ?? 0) + 1;
  return acc;
}, {});
// { sol: 3, mar: 2, cielo: 1 }

Resultado: { sol: 3, mar: 2, cielo: 1 }

Prueba con otra palabra, por ejemplo: variable, función, array, objeto, evento, fetch o promesa.
