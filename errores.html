HTML

Errores de HTML

Etiqueta sin cerrar o mal anidada

Si olvidas cerrar una etiqueta o las cruzas, el navegador intenta «arreglarlo» y el diseño se descuadra. Cada etiqueta que se abre debe cerrarse en el orden inverso.

<!-- Mal -->
<p>Texto <b>importante</p></b>
<div><p>Hola</div>

<!-- Bien -->
<p>Texto <b>importante</b></p>
<div><p>Hola</p></div>

Solución: validar en validator.w3.org o usar un editor que sangre automáticamente.

La imagen no se ve (icono de imagen rota)

Casi siempre es la ruta: carpeta o nombre mal escritos, mayúsculas (Foto.JPG ≠ foto.jpg en servidores Linux), extensión incorrecta o archivo que no se subió.

<!-- Mal -->
<img src="/img/Foto.JPG">      <!-- el archivo se llama foto.jpg -->

<!-- Bien -->
<img src="img/foto.jpg" alt="Descripción">

Solución: abre la pestaña Red (F12) y busca el 404.

El enlace no lleva a ningún sitio o da 404

La ruta del href es incorrecta respecto a la ubicación del archivo. Las rutas relativas dependen de dónde esté la página que enlaza.

<!-- Estás en /guias/html.html -->
<a href="css.html">          <!-- busca /guias/css.html -->
<a href="../css.html">       <!-- sube una carpeta -->
<a href="/css.html">         <!-- desde la raíz del sitio -->

Solución: ../ sube un nivel; / parte de la raíz.

Aparecen símbolos raros: Ã¡, Ã±, �

El archivo y el navegador usan codificaciones distintas. Guarda el archivo como UTF-8 y declara charset al principio del head.

<head>
  <meta charset="utf-8">     <!-- primera línea del head -->
</head>

Solución: guardar en UTF-8 y añadir <meta charset="utf-8">.

El estilo CSS o el script no se cargan

La ruta del link o del script es incorrecta, o se enlazó mal. Un link de hoja de estilos necesita rel="stylesheet".

<!-- Mal -->
<link href="estilos.css">
<script src="js/app.js"></script>      <!-- ¿existe esa carpeta? -->

<!-- Bien -->
<link rel="stylesheet" href="css/estilos.css">
<script src="js/app.js" defer></script>

Solución: pestaña Red (F12) y busca el archivo en rojo.

El formulario no envía los datos (o llegan vacíos)

Solo se envían los campos que tienen atributo name. Además, el botón debe estar dentro del form y ser de tipo submit.

<!-- Mal: sin name, no se envía -->
<input type="text" id="correo">

<!-- Bien -->
<form action="/enviar" method="post">
  <input type="text" id="correo" name="correo">
  <button type="submit">Enviar</button>
</form>

Solución: name en cada campo, action y method en el form.

Al pulsar la etiqueta no se activa el campo

El for de la etiqueta debe coincidir con el id del campo (no con el name).

<!-- Mal -->
<label for="correo">Correo</label>
<input name="correo">

<!-- Bien -->
<label for="correo">Correo</label>
<input id="correo" name="correo">

Solución: for = id.

El mismo id repetido en la página

Un id debe ser único en toda la página. Si se repite, getElementById, los enlaces con # y las etiquetas fallan de forma impredecible.

<!-- Mal -->
<div id="caja">…</div>
<div id="caja">…</div>

<!-- Bien: usa class para repetir -->
<div class="caja">…</div>
<div class="caja">…</div>

Solución: id único; class para elementos repetidos.

El párrafo se parte solo: un bloque dentro de <p>

Un p no puede contener bloques (div, ul, otro p…): el navegador lo cierra antes y el resultado no es el esperado.

<!-- Mal -->
<p>Texto <div>caja</div></p>

<!-- Bien -->
<div><p>Texto</p><div>caja</div></div>

Solución: usa span dentro de p o reorganiza.

La página se ve enorme en el móvil (falta viewport)

Sin la etiqueta viewport, los móviles muestran la página como si fuera de escritorio y las media queries no funcionan como esperas.

<meta name="viewport" content="width=device-width, initial-scale=1">

Solución: añadirla en el head.

El navegador entra en «modo quirks» (falta el doctype)

Sin <!DOCTYPE html> en la primera línea, el navegador usa reglas antiguas y el diseño puede cambiar (tamaños de caja, alineaciones).

<!DOCTYPE html>
<html lang="es">

Solución: doctype siempre en la primera línea.

El enlace con # no salta a la sección

El destino debe tener un id que coincida exactamente (mayúsculas incluidas), sin espacios.

<a href="#contacto">Contacto</a>
<section id="contacto">…</section>

Solución: href="#id" y un único id="id".

Los atributos con espacios se cortan

Si un valor tiene espacios y no va entre comillas, solo se toma la primera palabra.

<!-- Mal -->
<input value=Hola mundo>

<!-- Bien -->
<input value="Hola mundo">

Solución: comillas siempre.

Espacios o saltos de línea que no se ven

HTML junta cualquier cantidad de espacios y saltos de línea en uno solo. Para separar usa párrafos, br o CSS; para respetar el formato, pre.

<p>Hola          mundo</p>      <!-- se ve: Hola mundo -->
<pre>Hola          mundo</pre>    <!-- respeta los espacios -->

Solución: márgenes con CSS en lugar de espacios.

Enlaces externos con target="_blank" sin rel

Abrir una pestaña nueva sin rel="noopener" permite que la página abierta controle la original (navegadores modernos ya lo mitigan, pero conviene indicarlo).

<a href="https://externo.test" target="_blank" rel="noopener noreferrer">Sitio externo</a>

Solución: añadir rel="noopener noreferrer".

CSS

Errores de CSS

Mi estilo CSS no se aplica

Causas habituales: la hoja no está enlazada, el selector no coincide (clase vs id, errata), otra regla con más especificidad lo pisa, o hay un error de sintaxis antes.

/* Pasos */
1. F12 → selecciona el elemento → panel Estilos
2. ¿Aparece tu regla? Si está tachada, otra la anula
3. ¿Está enlazado el CSS? (pestaña Red)

Solución: inspeccionar el elemento y revisar la especificidad.

Selector mal escrito: falta el punto o la almohadilla

Las clases llevan punto (.caja) y los identificadores, almohadilla (#caja). Sin ellos el selector busca una etiqueta con ese nombre.

caja { color: red; }      /* busca <caja> */
.caja { color: red; }     /* class="caja" */
#caja { color: red; }     /* id="caja" */

Solución: .clase, #id.

Una propiedad se ignora: falta la unidad

Casi todas las longitudes necesitan unidad (px, rem, %…). Solo el 0 y algunas propiedades (line-height, opacity, z-index) pueden ir sin ella.

width: 100;        /* inválido: se ignora */
width: 100px;      /* correcto */
margin: 0;         /* 0 no necesita unidad */

Solución: añadir la unidad.

Falta un punto y coma y se rompen las reglas siguientes

Una declaración sin ; se une con la siguiente y ambas se invalidan.

/* Mal */
.caja {
  color: red
  margin: 10px;      /* no se aplica ninguna de las dos */
}
/* Bien */
.caja { color: red; margin: 10px; }

Solución: ; tras cada declaración.

z-index no funciona

z-index solo afecta a elementos posicionados (position distinto de static) y solo compara dentro del mismo contexto de apilamiento.

.menu { z-index: 10; }                      /* sin efecto */
.menu { position: relative; z-index: 10; }  /* funciona */

Solución: añadir position y revisar el contexto.

Un elemento absolute se sale de su contenedor

Un elemento absolute se coloca respecto a su ancestro posicionado más cercano; si no hay ninguno, respecto a la página.

.tarjeta { position: relative; }          /* ← falta esto */
.etiqueta { position: absolute; top: 8px; right: 8px; }

Solución: position: relative en el contenedor.

No consigo centrar verticalmente

El contenedor necesita altura para que haya espacio donde centrar. Con Flex o Grid basta una altura mínima.

.contenedor {
  display: flex;
  justify-content: center;
  align-items: center;
  min-height: 100vh;
}

Solución: display: flex/grid + altura definida.

height: 100% no hace nada

Un porcentaje de altura necesita que el padre tenga altura definida. Para ocupar la ventana usa vh o la cadena html, body { height: 100% }.

html, body { height: 100%; }
.pagina { min-height: 100vh; }
.pagina { min-height: 100dvh; }     /* mejor en móvil */

Solución: min-height: 100vh o dvh.

Aparece una barra de desplazamiento horizontal

Algo es más ancho que la pantalla: un width: 100vw con barra vertical, un padding sin box-sizing: border-box, una imagen o tabla grandes.

*, *::before, *::after { box-sizing: border-box; }
img { max-width: 100%; height: auto; }
/* depurar */
* { outline: 1px solid red; }

Solución: box-sizing, max-width: 100%, depurar con outline.

El padding o el borde hacen la caja más grande de lo que indico

Por defecto el ancho no incluye relleno ni borde: width: 200px + padding: 20px ocupa 240px.

*, *::before, *::after { box-sizing: border-box; }

Solución: box-sizing: border-box global.

Flex: el hijo no encoge y se sale (texto largo)

Un elemento flex tiene min-width: auto, así que no se encoge por debajo de su contenido. Pon min-width: 0 para permitirlo.

.fila { display: flex; }
.texto { min-width: 0; overflow: hidden; text-overflow: ellipsis; white-space: nowrap; }

Solución: min-width: 0.

position: sticky no se queda pegado

sticky necesita un valor top (u otro lado) y falla si algún ancestro tiene overflow distinto de visible o si el contenedor no es más alto.

header { position: sticky; top: 0; }
/* revisa: ningún padre con overflow: hidden/auto */

Solución: definir top y revisar overflow de los padres.

La transición no se anima

No se pueden animar display ni la altura auto. Anima opacity, transform o una altura/max-height concreta.

.panel { opacity: 0; transition: opacity .3s; }
.panel.abierto { opacity: 1; }
/* o con grid: 0fr → 1fr */

Solución: animar opacity y transform.

var(--x) no tiene efecto

La variable no está definida en un ancestro del elemento, tiene una errata o está en otro ámbito. Puedes dar un valor de respaldo.

:root { --marca: #245b78; }
.boton { background: var(--marca, teal); }

Solución: definir en :root y dar respaldo.

La fuente propia no se carga

Ruta o formato incorrectos en @font-face, o la fuente en otro dominio sin permisos CORS. Declara siempre una fuente de respaldo.

@font-face {
  font-family: "Mi fuente";
  src: url("fuentes/mi-fuente.woff2") format("woff2");
  font-display: swap;
}
body { font-family: "Mi fuente", system-ui, sans-serif; }

Solución: revisar la ruta en la pestaña Red.

El hover no funciona o se queda «pegado» en el móvil

En pantallas táctiles el estado :hover se queda activo tras tocar. Limita los efectos a dispositivos con puntero.

@media (hover: hover) {
  .tarjeta:hover { transform: translateY(-4px); }
}

Solución: @media (hover: hover).

100vh es demasiado alto en móvil

En móviles la barra del navegador hace que 100vh supere la zona visible. Usa dvh (o svh) con 100vh de respaldo.

.portada { min-height: 100vh; min-height: 100dvh; }

Solución: dvh.

Los márgenes verticales se «fusionan»

Los márgenes verticales de bloques adyacentes se fusionan: gana el mayor, no se suman. No ocurre en Flex ni Grid.

p { margin: 20px 0; }            /* entre dos p hay 20px, no 40 */
.padre { display: flow-root; }   /* evita la fusión con el hijo */

Solución: display: flow-root, padding o Flex/Grid.

Los elementos flotantes se salen del contenedor

Un contenedor con hijos flotantes colapsa a altura cero. Contenlos con display: flow-root.

.contenedor { display: flow-root; }
.hijo { float: left; }

Solución: flow-root o Flex/Grid.

El color o el texto parece «sin contraste»

Un texto gris claro sobre blanco puede ser ilegible. Se recomienda una relación de contraste de al menos 4,5:1.

color: #aaa; background: #fff;     /* contraste bajo */
color: #595959; background: #fff;  /* 7:1 */

Solución: comprobar con un medidor de contraste.

Grid: las columnas no se adaptan al ancho

Con anchos fijos las columnas no se reorganizan. Usa auto-fit con minmax y fr.

.rejilla {
  display: grid;
  gap: 1rem;
  grid-template-columns: repeat(auto-fit, minmax(14rem, 1fr));
}

Solución: repeat(auto-fit, minmax(…, 1fr)).

JavaScript

Errores de JavaScript

Uncaught ReferenceError: x is not defined

Usas una variable que no existe en ese ámbito: errata, está declarada dentro de otro bloque o función, o se carga después.

console.log(nombre);       // ReferenceError si no se declaró
let nombre = "Ana";

function f() { let x = 1; }
console.log(x);           // x solo existe dentro de f

Solución: declararla, revisar mayúsculas y el ámbito.

Uncaught TypeError: Cannot read properties of undefined (reading 'x')

Intentas leer una propiedad de algo que vale undefined (dato que aún no llegó, propiedad mal escrita, índice inexistente).

const usuario = {};
usuario.perfil.nombre;           // TypeError
usuario.perfil?.nombre ?? "—";   // seguro

lista[5].nombre                  // ¿existe lista[5]?

Solución: encadenamiento opcional ?. y comprobar el dato.

Uncaught TypeError: Cannot read properties of null (reading 'x')

El elemento no existe en el DOM cuando se ejecuta el script (selector mal escrito o script cargado antes que el HTML).

const boton = document.querySelector("#boton");   // null
boton.addEventListener("click", f);               // TypeError

<script src="app.js" defer></script>              // espera al HTML

Solución: defer, revisar el selector y el id.

Uncaught TypeError: Cannot set properties of null (setting 'textContent')

Asignas un valor a un elemento que no se encontró (null).

document.querySelector("#total").textContent = 5;   // #total no existe

Solución: comprueba que el selector coincide y que el DOM está listo.

Uncaught TypeError: x is not a function

Llamas con () algo que no es una función: nombre mal escrito, propiedad con otro tipo o un método que no existe en ese tipo.

const n = 5;
n();                      // TypeError

const cosa = "texto";
cosa.map(x => x);         // "map" no existe en strings
[..."texto"].map(x => x); // sí en arrays

Solución: comprobar el tipo con typeof o console.log.

TypeError: x.map is not a function

El valor no es un array (suele ser un objeto de la API, undefined o null).

const datos = await respuesta.json();
console.log(Array.isArray(datos), datos);   // ¿es array?
datos.items.map(...)                        // quizá está en .items

Solución: console.log del dato y Array.isArray.

Uncaught TypeError: Assignment to constant variable.

Intentas reasignar una variable declarada con const.

const total = 0;
total = total + 1;       // TypeError
let suma = 0;            // usa let si va a cambiar
suma += 1;

Nota: un objeto const sí se puede modificar por dentro.

Uncaught SyntaxError: Unexpected token

Hay un símbolo donde no debe: coma o paréntesis de más o de menos, llave sin cerrar, comillas desparejadas.

const o = { a: 1, b: 2, };        // correcto
const p = { a: 1 b: 2 };          // SyntaxError (falta la coma)
if (x > 1 { }                     // falta )

Solución: revisa la línea indicada y la anterior.

Uncaught SyntaxError: Unexpected end of input

Falta cerrar una llave }, un paréntesis o una cadena: el archivo termina antes de lo esperado.

function f() {
  if (x) {
    return 1;
  // falta una }

Solución: un editor con resaltado de pares ayuda.

Uncaught SyntaxError: missing ) after argument list

Suele deberse a comillas sin escapar dentro de un texto o a una coma que falta entre argumentos.

console.log("Dijo "hola"");        // comillas sin escapar
console.log("Dijo \"hola\"");      // bien
console.log('Dijo "hola"');        // bien

Solución: escapar comillas o alternar tipos.

Uncaught ReferenceError: Cannot access 'x' before initialization

Usas una variable let o const antes de la línea en la que se declara.

console.log(a);      // ReferenceError
let a = 1;

Solución: declarar antes de usar.

Uncaught SyntaxError: Identifier 'x' has already been declared

Declaras dos veces la misma variable con let o const en el mismo ámbito (o chocan scripts que comparten ámbito global).

let n = 1;
let n = 2;           // SyntaxError
n = 2;               // reasignar, sin let

Solución: reasignar o renombrar.

Failed to fetch / blocked by CORS policy

El navegador bloquea leer una respuesta de otro origen si el servidor no lo autoriza con cabeceras CORS. También aparece si el servidor no responde o la URL es incorrecta. Se arregla en el servidor.

Access to fetch at 'https://api.test' from origin 'http://localhost:5500'
has been blocked by CORS policy: No 'Access-Control-Allow-Origin' header

// Servidor: Access-Control-Allow-Origin: http://localhost:5500

Solución: configurar CORS en el servidor o usar un proxy; no en el cliente.

Unexpected token '<', "<!DOCTYPE "... is not valid JSON

Esperabas JSON, pero el servidor devolvió una página HTML (casi siempre un error 404 o 500 o una URL incorrecta).

const r = await fetch("/api/datos");
console.log(r.status, r.headers.get("content-type"));
if (!r.ok) throw new Error(r.status);
const datos = await r.json();

Solución: revisar la URL y response.ok antes de .json().

SyntaxError: JSON.parse: unexpected character / Unexpected token in JSON

El texto no es JSON válido: comillas simples, coma final, claves sin comillas o undefined.

JSON.parse("{'a': 1}");        // comillas simples: error
JSON.parse('{"a": 1}');        // correcto

Solución: JSON siempre con comillas dobles.

RangeError: Maximum call stack size exceeded

Una función se llama a sí misma sin parar (recursión sin caso base) o dos funciones se llaman mutuamente.

function f() { return f(); }       // sin caso base

function cuenta(n) {
  if (n === 0) return;             // caso base
  cuenta(n - 1);
}

Solución: añadir caso base o usar un bucle.

RangeError: Invalid array length

Intentas crear un array con una longitud negativa, decimal o enorme.

new Array(-1);       // RangeError
new Array(2.5);      // RangeError
new Array(3);        // [ <3 empty items> ]

Solución: validar la longitud.

Uncaught (in promise) …

Una promesa falló y nadie capturó el error.

fetch("/api").then(r => r.json());            // sin catch
try { await peticion(); } catch (e) { console.error(e); }
peticion().catch(console.error);

Solución: try/catch con await o .catch().

Cannot use import statement outside a module

Usas import en un script normal. Necesitas indicar que es un módulo.

<script type="module" src="app.js"></script>

// Node: en package.json
{ "type": "module" }

Solución: type="module" o "type": "module".

require is not defined / exports is not defined

require y module.exports son de CommonJS (Node clásico) y no existen en el navegador ni en módulos ES.

// Navegador y módulos ES
import { f } from "./util.js";
export function g() {}

Solución: usa import/export.

SyntaxError: await is only valid in async functions and the top level bodies of modules

await solo puede usarse dentro de una función async o en el nivel superior de un módulo.

async function cargar() {
  const r = await fetch("/api");
}

Solución: marcar la función como async.

Los botones o eventos no responden

Causas: el elemento no existe cuando se ejecuta el script, el selector es incorrecto, se ejecuta la función en vez de pasarla, o algo la tapa.

boton.addEventListener("click", saludar());   // la ejecuta ya
boton.addEventListener("click", saludar);     // la pasa

Solución: defer, selector correcto y pasar la función sin ().

La página se recarga al enviar el formulario

El envío por defecto recarga la página. Cancélalo con preventDefault() si gestionas los datos con JavaScript.

form.addEventListener("submit", (e) => {
  e.preventDefault();
  // …
});

Solución: event.preventDefault().

El resultado es NaN

Una operación numérica con algo que no es un número (texto no convertible, undefined).

Number("abc");         // NaN
undefined + 1;         // NaN
const n = Number(input.value);
if (Number.isNaN(n)) { /* avisar */ }

Solución: convertir y validar; Number.isNaN.

5 + "5" da "55" y no 10

El valor de un campo de formulario siempre es texto, y + concatena si algún operando es texto.

"5" + 5;               // "55"
Number("5") + 5;       // 10
+input.value + 5;

Solución: convertir con Number().

== da resultados inesperados

== convierte tipos antes de comparar. Usa siempre === y !==.

0 == "";              // true
"1" == 1;             // true
null == undefined;    // true
0 === "";             // false

Solución: ===.

setInterval se acumula y todo va más rápido

Cada vez que se ejecuta el código se crea un nuevo intervalo sin cancelar el anterior.

let id;
function iniciar() {
  clearInterval(id);
  id = setInterval(tic, 1000);
}

Solución: guardar el id y llamar a clearInterval.

Mixed Content: la página HTTPS carga recursos HTTP

Una página segura (HTTPS) no puede cargar recursos por HTTP: el navegador los bloquea.

<img src="http://ejemplo.test/a.png">    <!-- bloqueado -->
<img src="https://ejemplo.test/a.png">

Solución: usar siempre HTTPS.

Failed to load resource: 404 (Not Found)

El navegador no encuentra un archivo: ruta, nombre o mayúsculas incorrectos.

GET http://localhost/js/app.js 404 (Not Found)

// Revisa la ruta relativa desde la página que lo carga

Solución: pestaña Red (F12).

Refused to execute script … MIME type

El servidor devolvió HTML (normalmente una página 404) en lugar del archivo JavaScript: la ruta es incorrecta.

<script src="/js/app.js"></script>     <!-- ¿existe esa ruta en el servidor? -->

Solución: corregir la ruta del script.

localStorage: JSON.parse(null) y datos como texto

localStorage solo guarda texto: los objetos se guardan con JSON.stringify y se leen con JSON.parse. Si la clave no existe, getItem devuelve null.

localStorage.setItem("u", { a: 1 });           // guarda "[object Object]"
localStorage.setItem("u", JSON.stringify({ a: 1 }));
const u = JSON.parse(localStorage.getItem("u") ?? "{}");

Solución: stringify al guardar y valor por defecto al leer.

this es undefined o no es lo que espero

Al pasar un método como callback pierde su objeto. Usa funciones flecha o bind.

class C {
  nombre = "x";
  mostrar() { console.log(this.nombre); }
}
const c = new C();
setTimeout(c.mostrar, 0);                  // this perdido
setTimeout(() => c.mostrar(), 0);          // correcto

Solución: flecha, bind o método de clase con flecha.

Uncaught SyntaxError: Illegal return statement

Escribiste return fuera de una función.

if (!ok) return;             // fuera de función → error
function f() { if (!ok) return; }

Solución: dentro de una función.

03

Java

Errores de Java

error: cannot find symbol

El compilador no reconoce un nombre: errata, mayúsculas, variable fuera de ámbito, método que no existe o falta un import.

Scanner in = new Scanner(System.in);     // falta: import java.util.Scanner;
int total = suma;                        // ¿está declarada «suma»?
String s = "x"; s.lenght();              // errata: length()

Solución: revisa mayúsculas, ámbito e importaciones.

error: incompatible types: String cannot be converted to int

Asignas un valor de un tipo a una variable de otro tipo sin conversión.

int n = "5";                     // error
int n = Integer.parseInt("5");   // correcto
String s = 5;                    // error
String s = String.valueOf(5);

Solución: convertir con parseInt, valueOf…

error: incompatible types: possible lossy conversion from double to int

Intentas guardar un tipo mayor (como double) en uno menor (int) y Java no lo hace sin que lo indiques.

int n = 3.7;                  // error
int n = (int) 3.7;            // 3 (trunca)
int r = (int) Math.round(3.7);// 4

Solución: casting explícito o Math.round.

error: missing return statement

Un método que declara un tipo de retorno debe devolver un valor en todos los caminos posibles.

int signo(int n) {
    if (n > 0) return 1;
    else if (n < 0) return -1;
    // ¿y si n == 0?  → error
    return 0;
}

Solución: añade return al final o en cada rama.

error: ';' expected

Falta un punto y coma. El error suele señalar la línea siguiente a la que falta.

int a = 5          // falta ;
System.out.println(a);

Solución: revisa la línea anterior.

error: reached end of file while parsing

Falta cerrar una llave } de una clase, método o bloque.

public class A {
    void f() {
        if (x) {
            // …
        }
    // falta cerrar f() y la clase

Solución: un IDE que sangre automáticamente lo evita.

error: class X is public, should be declared in a file named X.java

El nombre del archivo debe coincidir exactamente con el de la clase pública (mayúsculas incluidas).

// Archivo Hola.java
public class Hola { }        // correcto
// Archivo hola.java con public class Hola → error

Solución: renombrar archivo o clase.

error: non-static method m() cannot be referenced from a static context

Llamas desde main (static) a un método de instancia sin crear un objeto.

public class App {
    void saludar() { }
    public static void main(String[] args) {
        saludar();                 // error
        new App().saludar();       // correcto
    }
}

Solución: crear el objeto o hacer el método static.

error: variable x might not have been initialized

Usas una variable local antes de asignarle un valor en todos los caminos posibles.

int x;
if (cond) x = 1;
System.out.println(x);      // error: ¿y si cond es falso?
int x = 0;                  // inicializar

Solución: inicializar al declarar.

error: unreported exception X; must be caught or declared to be thrown

Llamas a código que puede lanzar una excepción comprobada (IOException, InterruptedException…) y no la capturas ni la declaras.

String t = Files.readString(Path.of("a.txt"));      // error

try { String t = Files.readString(Path.of("a.txt")); }
catch (IOException e) { e.printStackTrace(); }
// o: void f() throws IOException { … }

Solución: try/catch o throws.

error: unreachable statement

Hay código que nunca se ejecutará (por ejemplo, tras un return o break).

return x;
System.out.println("nunca");     // error

Solución: elimina o reordena el código.

error: cannot assign a value to final variable x

Intentas cambiar una variable final.

final int MAX = 10;
MAX = 20;                       // error

Solución: quita final si debe cambiar.

error: 'else' without 'if'

Suele deberse a un ; justo después del if o a llaves mal colocadas.

if (x > 0);          // el ; termina el if
{ … }
else { … }               // error

Solución: eliminar el ; y revisar llaves.

error: package x does not exist

Falta la librería en el classpath (o la dependencia en Maven/Gradle), o el nombre del paquete tiene una errata.

import com.google.gson.Gson;      // package com.google.gson does not exist
// Añade la dependencia en pom.xml o el JAR al proyecto

Solución: añadir la dependencia.

error: method m in class X cannot be applied to given types

Llamas a un método con argumentos de número o tipo incorrectos.

static int suma(int a, int b) { … }
suma(1);                  // faltan argumentos
suma(1, "2");             // tipo incorrecto

Solución: revisa la firma del método.

error: bad operand types for binary operator

Aplicas un operador a tipos incompatibles (por ejemplo, && con números o - con cadenas).

if (edad = 18) { }          // asignación en vez de ==
if ("a" - 1 > 0) { }        // resta con String

Solución: comprobar tipos y operadores.

Exception in thread "main" java.lang.NullPointerException

Usas un objeto que vale null. La traza indica la clase y la línea exacta del problema.

String s = null;
s.length();                         // NullPointerException

if (s != null && s.length() > 3) { }
Objects.requireNonNull(valor, "valor es obligatorio");

Solución: inicializar, comprobar null o usar Optional.

ArrayIndexOutOfBoundsException: Index 5 out of bounds for length 3

Accedes a una posición que no existe. Los índices van de 0 a length - 1.

int[] a = new int[3];
a[3] = 1;                            // error
for (int i = 0; i <= a.length; i++)  // <= provoca el error
for (int i = 0; i < a.length; i++)   // correcto

Solución: usar < en el bucle.

StringIndexOutOfBoundsException

Un índice de charAt o substring está fuera de la longitud del texto.

"hola".charAt(4);            // error (válidos: 0-3)
"hola".substring(2, 10);     // error

Solución: comprobar length() antes.

ArithmeticException: / by zero

Dividiste un entero entre cero. Con double el resultado sería Infinity en lugar de error.

int r = 10 / 0;                    // ArithmeticException
if (b != 0) r = a / b;

Solución: comprobar el divisor.

NumberFormatException: For input string: "abc"

Intentas convertir en número un texto que no lo es (o que tiene espacios, comas o está vacío).

Integer.parseInt("abc");        // NumberFormatException
Integer.parseInt(" 5");         // también (espacio)
Integer.parseInt(t.trim());

Solución: validar o capturar la excepción.

ClassCastException

Conviertes un objeto a una clase que no es la suya.

Object o = "texto";
Integer n = (Integer) o;           // ClassCastException
if (o instanceof String s) { }

Solución: comprobar con instanceof.

InputMismatchException

Scanner esperaba un número y recibió otro tipo de dato (por ejemplo, letras).

Scanner in = new Scanner(System.in);
int n = in.nextInt();              // si escribes "abc": error
int n2 = Integer.parseInt(in.nextLine().trim());

Solución: hasNextInt() o leer línea y convertir.

Scanner: nextLine() devuelve vacío tras nextInt()

nextInt() no consume el salto de línea final, así que el siguiente nextLine() lee una línea vacía.

int edad = in.nextInt();
in.nextLine();                    // consumir el salto pendiente
String nombre = in.nextLine();

Solución: leer todo con nextLine() y convertir.

NoSuchElementException: No line found

Lees más datos de los que hay (entrada terminada, iterador sin elementos).

if (in.hasNextLine()) linea = in.nextLine();
if (it.hasNext()) x = it.next();

Solución: comprobar hasNext…().

ConcurrentModificationException

Modificas una colección mientras la recorres con un for-each.

for (String s : lista) if (s.isEmpty()) lista.remove(s);   // error
lista.removeIf(String::isEmpty);                           // correcto

Solución: removeIf o Iterator.remove().

UnsupportedOperationException

Intentas modificar una colección inmutable (List.of, Collections.unmodifiableList, toList()).

List<Integer> l = List.of(1, 2);
l.add(3);                              // error
List<Integer> m = new ArrayList<>(l);
m.add(3);

Solución: copiar a un ArrayList.

StackOverflowError

La recursión no termina (falta el caso base) o es demasiado profunda.

int f(int n) { return f(n - 1); }          // sin caso base
int f(int n) { return n == 0 ? 0 : f(n - 1); }

Solución: caso base o bucle.

OutOfMemoryError: Java heap space

El programa necesita más memoria de la disponible: estructuras demasiado grandes o referencias que nunca se liberan.

// Revisa colecciones que crecen sin límite

Solución: procesar por partes o ampliar -Xmx.

Error: Could not find or load main class X

Java no encuentra la clase principal: nombre mal escrito, falta el paquete o el classpath es incorrecto.

javac Hola.java
java Hola                       // sin .class
java com.ejemplo.Hola           // con paquete, desde la carpeta raíz

Solución: ejecutar desde la raíz con el nombre completo.

ClassNotFoundException / NoClassDefFoundError

Falta una clase en tiempo de ejecución: el JAR de una librería no está en el classpath.

java -cp "bin;lib/*" com.ejemplo.App          // Windows
java -cp "bin:lib/*" com.ejemplo.App          // Linux/macOS

Solución: incluir las dependencias en el classpath.

UnsupportedClassVersionError: class file version 65.0

Compilaste con una versión de Java más nueva que la que usas para ejecutar.

java -version
javac -version          // deben ser compatibles
javac --release 17 Hola.java

Solución: usar la misma versión o --release.

FileNotFoundException: archivo (El sistema no puede encontrar el archivo)

La ruta es incorrecta respecto al directorio de trabajo desde el que se ejecuta el programa.

System.out.println(new File(".").getAbsolutePath());   // dónde estás
new File("datos/a.txt");

Solución: usar rutas absolutas o ajustar el directorio de trabajo.

IllegalArgumentException / IllegalStateException

Un método recibió un argumento no válido (IllegalArgumentException) o se llamó en un estado inadecuado (IllegalStateException).

throw new IllegalArgumentException("La edad no puede ser negativa");

Solución: leer el mensaje y validar antes.

Comparar cadenas con == da resultados erróneos

== compara referencias, no el contenido. Con textos usa equals.

a == "hola";                  // false
a.equals("hola");             // true

Solución: equals.

NegativeArraySizeException

Creas un array con un tamaño negativo.

int[] a = new int[n];       // n < 0 → excepción
if (n >= 0) a = new int[n];

Solución: validar el tamaño.

Errores de Python

SyntaxError: invalid syntax

Python no entiende la línea: faltan los dos puntos, un paréntesis sin cerrar, = en lugar de ==…

IndentationError: expected an indented block after 'if' statement

    pass                   # bloque vacío

Solución: 4 espacios o pass.

IndentationError: unexpected indent / unindent does not match

Hay una sangría donde no corresponde o los niveles no coinciden.

    y = 2              # unexpected indent

Solución: usar siempre el mismo número de espacios.

Intentas unir texto y número con +.

AttributeError: 'NoneType' object has no attribute 'x'

Llamas a un método sobre None, normalmente porque una búsqueda no encontró nada.

AttributeError: 'list' object has no attribute 'push'

Usas un método de otro lenguaje o con una errata. En Python se usa append y len().

len(lista)             # no lista.length

Solución: dir(objeto) muestra los métodos.

TypeError: 'int' object is not callable

Llamas con () algo que no es una función, a menudo porque una variable tapó una función integrada.

Solución: no uses nombres como sum, list o max.

Pasas más argumentos de los que acepta la función. En métodos de clase suele faltar self.

    def f(): pass              # falta self → "takes 0 positional arguments but 1 was given"

TypeError: object of type 'int' has no len()

len(12345)               # TypeError

ValueError: invalid literal for int() with base 10: 'abc'

El texto no representa un número entero (letras, decimales, espacios o vacío).

int(float("3.5"))

ValueError: too many values to unpack (expected 2)

El número de variables no coincide con el de elementos.

a, *resto = [1, 2, 3]

KeyError: 'x'

Accedes a una clave que no existe en el diccionario.

d["b"]                       # KeyError

"b" in d

Solución: get() o comprobar con in.

IndexError: list index out of range

Pides una posición que no existe (las posiciones van de 0 a len - 1).

l[3]                         # IndexError
l[-1]                        # último elemento
for i in range(len(l)):      # no len(l) + 1

Solución: comprobar la longitud.

ZeroDivisionError: division by zero

Divides (o calculas el resto) entre cero.

try: r = a / b
except ZeroDivisionError: r = None

Solución: comprobar el divisor.

ModuleNotFoundError: No module named 'x'

El módulo existe pero no contiene ese nombre (errata, versión antigua o importación circular entre dos archivos).

FileNotFoundError: [Errno 2] No such file or directory

Path(__file__).parent / "datos.txt"

Solución: ruta absoluta o relativa al script.

PermissionError: [Errno 13] Permission denied

No tienes permiso, el archivo está abierto en otro programa o intentas abrir una carpeta como si fuera un archivo.

UnicodeDecodeError: 'utf-8' codec can't decode byte

El archivo no está en UTF-8 (a menudo Windows-1252/Latin-1).

open("a.txt", encoding="utf-8")

open("a.txt", encoding="utf-8", errors="replace")

Solución: indicar la codificación correcta.

Dentro de una función asignas una variable que también existe fuera, así que Python la trata como local y la lees antes de darle valor.

Solución: global, o mejor, pasar y devolver valores.

RecursionError: maximum recursion depth exceeded

Solución: caso base o bucle.

Cambias un diccionario (o conjunto) mientras lo recorres.

input() no encontró datos: el programa se ejecuta sin teclado (un editor en línea, un pipe o entrada vacía).

Asignar una lista no la copia: ambas variables apuntan al mismo objeto.

Cómo enfrentarse a cualquier error

Depuración en general

Cómo leer un mensaje de error

Un error tiene tres partes útiles: el tipo (TypeError, NullPointerException), el mensaje y el lugar (archivo y línea). Empieza por el final de la traza en Python y por el principio en Java y JavaScript.

Traceback (most recent call last):
  File "app.py", line 12, in <module>      ← dónde
    total = suma + "5"
TypeError: unsupported operand type(s) …   ← qué

Lee el mensaje completo, no solo el título.

Método para depurar: reproducir, aislar, probar

1) Reproduce el fallo de forma fiable. 2) Reduce el código hasta lo mínimo que lo provoca. 3) Formula una hipótesis y compruébala (print, depurador). 4) Cambia una sola cosa cada vez.

1. ¿Qué esperaba?  ¿Qué ocurre?
2. ¿Dónde empieza a ser distinto?  (print / depurador)
3. Cambio mínimo → probar → repetir

No cambies cinco cosas a la vez.

Buscar el error en internet

Copia el mensaje de error (sin rutas ni nombres propios), añade el lenguaje y la versión y busca. Prioriza la documentación oficial y respuestas con explicación.

"TypeError: Cannot read properties of undefined (reading 'map')" javascript
python "ModuleNotFoundError: No module named 'requests'"

Entiende la solución antes de copiarla.

Preguntar bien una duda de programación

Una buena pregunta incluye: qué quieres conseguir, el código mínimo que falla, el mensaje de error completo, la versión y lo que ya has probado.

Objetivo:  …
Código mínimo:  (20 líneas, no 500)
Error:  (mensaje completo)
Entorno:  Python 3.12, Windows 11
Ya probé:  …

Un ejemplo mínimo reproducible multiplica las respuestas.

Depurar con print y con el depurador

print (o console.log) es rápido para ver valores; el depurador del IDE permite detener el programa, avanzar paso a paso y ver todas las variables.

print(f"{x=}, {y=}")                 # Python
console.log({ x, y });               // JavaScript
breakpoint()                          # depurador de Python

Atajos habituales: F9 breakpoint, F10 paso, F11 entrar.

Errores de lógica: el programa corre pero el resultado es incorrecto

No hay mensaje de error, pero el resultado no es el esperado. Causas típicas: límites de bucle (< frente a <=), condiciones invertidas, variables sin reiniciar y casos extremos (vacío, cero, negativo).

for (let i = 0; i <= lista.length; i++)     // ¿hasta length - 1?
if (edad > 18)                              // ¿>= 18?

Prueba con valores límite.

Problemas de caché: «lo cambié y no se ve»

El navegador puede seguir usando archivos antiguos. Recarga forzada y desactiva la caché mientras desarrollas.

Ctrl + F5  (o Ctrl + Mayús + R)         recarga forzada
F12 → Red → «Desactivar caché»
app.js?v=3                                    cambiar la URL

Atajo: Ctrl + F5.
