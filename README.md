# 📚 Apuntes y Resúmenes de Programación

¡Bienvenido a mi proyecto personal! Este repositorio es una colección de hojas de trucos (cheat sheets) y resúmenes fundamentales sobre desarrollo web y programación, creados con el objetivo de servir como material de consulta rápida y estudio.

El proyecto está estructurado de forma limpia, donde cada tema cuenta con su propio archivo de estructura y su correspondiente hoja de estilos independiente.

## 🗂️ Contenido del Proyecto

El repositorio está compuesto por los siguientes módulos didácticos:

* **Resumen de HTML:** Un documento completo que abarca la estructura general, etiquetas esenciales, formularios y semántica web en HTML.
* **Resumen de CSS:** Una guía de referencia sobre selectores, modelo de caja, diseño responsivo (Flexbox/Grid) y estilos visuales en CSS.
* **Resumen de Java:** Un compendio sobre los fundamentos de Java, que incluye variables, estructuras de control, tipos de datos y conceptos clave del lenguaje.

---

## 🛠️ Estructura de Archivos

La organización del código se distribuye de la siguiente manera para mantener cada tema aislado y ordenado:

├── index.html      # Documento principal de HTML
├── index.css       # Estilos exclusivos para el resumen de HTML
├── css.html        # Documento principal de CSS
├── css.css         # Estilos exclusivos para el resumen de CSS
├── java.html       # Documento principal de Java
└── java.css        # Estilos exclusivos para el resumen de Java

## Para leer y navegar por los resúmenes, no necesitas instalar nada:
1. Descarga o clona este repositorio en tu ordenador.
2. Haz doble clic sobre cualquiera de los archivos `.html`.
3. El documento se abrirá automáticamente en tu navegador web listo para su lectura.
